# 802题库

唯一主库为`tiku.db`，当前966题：题集731、408真题151、重邮2024/2025/2026分别23/23/26、机构补充9、中央民族1、东华2。

- `schema.sql`：数据库结构。
- [导出](导出/)：可读题目视图；数据变动后从主库重新导出，不手改投影。
- [images](images/)：数据库题目配图，原相对路径保持有效。
- [筛选](筛选/)：题集分档、题单、外部题筛选和替代记录。
- [来源与勘误](维护/来源与勘误.md)：完整来源台账、已知参考答案错误及历史维护说明。
- [建设方案](维护/建设方案.md)：题库建立时的设计背景，按历史材料使用。

## 从项目根目录查询

```powershell
python tools/题库/tiku.py stats --by chapter
python tools/题库/tiku.py search 拓扑排序
python tools/题库/tiku.py get 真题-2026-算法24 --md
```

查询、导入、提取和导出工具已统一放在`tools/题库/`。教材摘要归[资料/教材摘要](../资料/教材摘要/)，原始卷和书籍归[资料](../资料/README.md)。六套模拟卷未写入这966题主库，仍在所属套卷目录维护。
