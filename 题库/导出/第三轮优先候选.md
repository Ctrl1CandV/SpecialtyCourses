# 题库导出（2 题）


## 【图】

### EXT-DHU-854-2025-A2-COMPONENTS
> 东华大学854-2025 | 算法设计

设计一个算法，求无向图 G（采用邻接表存储）的连通分量个数。图的邻接表结点定义如下：
```c
#define MaxVertexNum 100
typedef struct ArcNode {
    int adjvex;
    struct ArcNode *nextarc;
} ArcNode;
typedef struct VNode {
    VertexType data;
    ArcNode *firstarc;
} VNode, AdjList[MaxVertexNum];
typedef struct {
    AdjList vertices;
    int vexnum, arcnum;
} ALGraph;
```
（1）描述算法的基本设计思想；（2）采用 C 或 C++ 描述算法并对关键处注释；（3）说明时间和空间复杂度。约定空图有 0 个连通分量。

**答案**

```c
void DFSCount(ALGraph *G, int v, int visited[]) {
    visited[v] = 1;
    for (ArcNode *p = G->vertices[v].firstarc; p != NULL; p = p->nextarc) {
        int w = p->adjvex;
        if (!visited[w]) DFSCount(G, w, visited);
    }
}
int CountComponents(ALGraph *G) {
    if (G == NULL || G->vexnum <= 0) return 0;
    int visited[MaxVertexNum] = {0};
    int count = 0;
    for (int v = 0; v < G->vexnum; ++v) {
        if (!visited[v]) {
            DFSCount(G, v, visited);
            ++count;  // 每次从未访问顶点启动 DFS，恰对应一个新连通分量。
        }
    }
    return count;
}
```

**解析**：先将所有顶点标为未访问，按编号扫描顶点。遇到未访问顶点时启动一次 DFS，DFS 会访问且只访问该顶点所在的整个连通分量，因此启动次数就是连通分量数。空图返回 0。邻接表下每个顶点和边至多检查常数次，时间复杂度 O(V+E)，visited 占 O(V)，递归栈最坏 O(V)。假设 vexnum 不超过 MaxVertexNum，且输入确为无向图的邻接表。


## 【树】

### EXT-DHU-854-2025-A1-TREEDEPTH
> 东华大学854-2025 | 算法设计

以孩子兄弟链表为存储结构，设计非递归算法求树的深度。结点定义如下：
```c
typedef struct CSNode {
    Element data;
    struct CSNode *firstchild, *nextsibling;
} CSNode, *CSTree;
```
（1）描述算法的基本设计思想；（2）采用 C 或 C++ 描述算法并对关键处注释；（3）说明时间和空间复杂度。约定 root 指向树根，空树深度为 0。

**答案**

```cpp
#include <stack>
using namespace std;
typedef struct CSNode {
    int data;
    struct CSNode *firstchild, *nextsibling;
} CSNode, *CSTree;
struct Item { CSTree node; int depth; };
int TreeDepth(CSTree root) {
    if (root == nullptr) return 0;
    stack<Item> st;
    st.push({root, 1});
    int maxDepth = 0;
    while (!st.empty()) {
        Item x = st.top(); st.pop();
        if (x.depth > maxDepth) maxDepth = x.depth;
        // 兄弟与当前结点处于同一层；孩子进入下一层。
        if (x.node->nextsibling) st.push({x.node->nextsibling, x.depth});
        if (x.node->firstchild) st.push({x.node->firstchild, x.depth + 1});
    }
    return maxDepth;
}
```

**解析**：栈中保存待访问结点及其所在层数。孩子兄弟表示法中，firstchild 表示进入下一层，nextsibling 表示仍在当前层；按此更新层数并维护最大值即可。每个结点入栈、出栈一次，时间复杂度 O(n)，辅助空间最坏 O(n)。非递归遍历避免递归调用栈。答案代码按题意独立规范，未照搬解析稿中的 C++17 结构化绑定写法。
