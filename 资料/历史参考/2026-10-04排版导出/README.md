# 2026-10-04 历史排版导出

本目录保存清理旧临时区时发现的五份项目生成PDF及必要源稿、维护源码和当时的检查记录，供跨电脑回看与追溯。它们是历史排版结果，不替代当前`资料/笔记/`、题库主库、冲刺合集、C3课程或2027押题卷。

- `成品/`：精选题集、补充题集、答案册、代码总结、重邮数据结构五份PDF，均可直接打开。
- `笔记源稿/`：当时用于两份笔记PDF的修改副本与修订记录；与现行笔记不同，保留原字节。
- `维护/`：当时的题库PDF导出器、笔记生成器及检查源码。
- `审查/`：当时的v3说明、结构和公式核对结果。其结论仅针对2026-10-04的版本，不自动适用于今天的题库或课程。
- `存档核对.json`：各文件原路径、归档路径、字节数与SHA-256，记录本次归档前后的字节一致性。

历史源码仍引用`题库数据库/`、`知识笔记/`和旧临时HTML/KaTeX目录，按原样保留，不能直接当作现行构建命令。旧目录与当前目录的对应关系可查`tools/目录迁移.csv`；当前图像在`资料/笔记/image/`与`题库/images/`，主库为`题库/tiku.db`。数据库和笔记已继续修改，本目录不承诺逐字节重建旧PDF。

清理时未保留截图、浏览器profile、HTML缓存、重复KaTeX和ZIP；它们不作为现行交付依赖。外部教材原PDF仍按项目既有忽略规则只留本地，没有混入本历史成品目录。
