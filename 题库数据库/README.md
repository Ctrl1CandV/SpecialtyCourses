# 802 题库数据库

> 定位：把散在 PDF/图片/网页里的 802 题目与知识，转成集中、结构化、AI 一读就懂的题库，供 C2/C3 讲课随时取用。
> 建设方案见 `课程设计/题库数据库建设方案.md`。本文件是数据库的门面＋来源台账＋勘误审计。
> 建库日期：2026-09-06；最近更新：2026-09-07（408 网站 12 年入库、教材压缩、2015 去重）。

---

## 一、三层架构

```
① tiku.db        SQLite 主库——唯一的结构化真相源，所有题目入这里
② 工具/tiku.py    查询 CLI——AI 与人取数的唯一入口，7 个动词
③ 导出/*.md       Markdown 人读视图——从主库生成的只读投影，可随时重导
```

改数据只改主库（通过 import），再重导 Markdown；不手改导出文件。

## 二、目录结构

```
题库数据库/

├── schema.sql           # 建表 SQL（python 工具/tiku.py init 可重建）

├── 工具/
│   ├── tiku.py                    # 查询 CLI（含 delete）
│   ├── extract_zhenti_figures.py  # 真题配图抽取
│   ├── slice_tiji.py              # 题集按章切片
│   ├── extract_tiji.py            # 题集 MinerU 结果切分入库

└── 临时区/              # 注：主讲把外部 PDF 放在项目根 临时区/（非此处），版权/质量未筛，不入主库
```

## 三、questions 表字段

`id`(唯一) · `source`(来源) · `source_detail` · `chapter`(八章) · `qtype`(题型) · `number`(原题号) · `difficulty` · `tier`(题集分档) · `stem`(题干,markdown) · `options` · `answer` · `analysis` · `kaodian`(考点) · `template`(关联15模板) · `figures`(图,JSON) · `pdf_page`(原PDF页) · `real_related`(真题同源) · `raw_text` · `notes`(缺漏/勘误/存疑)。

id 命名：`真题-2026-阅读1`、`题集-07-算3`、`408-2023-5`（网站版按原题号）、`王道-06-例题2`。

## 四、tiku.py 用法（AI 取数入口）

```bash
python 工具/tiku.py init                              # 建库/升级 schema
python 工具/tiku.py list  --chapter 图 --qtype 算法设计  # 按条件列题
python 工具/tiku.py get   真题-2026-算法24 --md         # 取某题完整内容
python 工具/tiku.py search 拓扑排序                     # 全文搜题干/答案/考点
python 工具/tiku.py stats --by chapter                 # 多维统计
python 工具/tiku.py export --source 真题2026 -o 导出/真题2026.md
python 工具/tiku.py import <jsonl>                     # 批量入库(UPSERT)
python 工具/tiku.py delete --like "408-2015-选%" --yes   # 删题(默认dry-run预览,加--yes才真删)
```
通用筛选：`--source --chapter --qtype --tier --template --kaodian --difficulty --limit --md`。
备课典型用法：`list --chapter 图 --qtype 算法设计` 拉出图的所有算法题，再 `get` 逐题取全文。

## 六、真题答案勘误汇总（重要！C3-B 讲真题必用修正版）

结构化时逐题核对答案，发现答案 PDF 存在 **10 处错误/存疑**。讲真题时以本表修正版为准，不可照抄答案 PDF。每条已在对应题目的 `notes` 字段留痕。

| 卷 | 题号(id) | 考点 | 答案PDF | 修正 | 依据 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| 2026 | 填空7 | 循环队列指针 | "答案3" | front=4,rear=2 | 与其自身解析矛盾，取解析值 |
| 2026 | 填空10 | 强连通图最少边 | n+1 | **n** | n顶点强连通最少构成一个有向环=n条边 |
| 2024 | 综合1(1) | 基数排序第3趟 | 093,043… | 043,093… | LSD稳定排序，043原在093前 |
| 2024 | 综合2 | 散列ASL成功 | =2(求和18) | **19/9≈2.11** | 求和项与其表格(1,1,2,1,1,2,4,3,4)不符 |
| 2024 | 综合5 | 哈夫曼编码 | g码长2,WPL251 | **g码长1,WPL215** | 最大频率g必在最短码；原非最优、非满二叉树 |
| 2024 | 算法2 | DFS回溯visited复位 | visited[i]=0在for内 | 移到for外return前 | 循环内复位破坏"简单路径"，与其思想矛盾 |
| 2025 | 阅读2 | 双链表交换p与前驱 | ②q->next=p->next | 先存p原后继y再q->next=y | 原式在p->next=q后执行会自环 |
| 2025 | 填空2 | 出栈序列(4开头) | 9 | **1**(4,3,2,1,1) | 4最后入最先出则1,1,2,3已全压栈,LIFO锁定 |
| 2025 | 填空8 | next数组abcaaba | 011123(6位) | **0111223**(7位) | 7字符应7位next,原少一位 |
| 2025 | 综合4 | 二分ASL成功 | 33/10 | **29/10=2.9** | 各层1/2/4/3结点,(1+4+12+12)/10 |

**另记轻微笔误/存疑（未硬判错，见各题 notes）**：2024算法3 `FreeQueue(q)` 应为 `FreeQueue(Q)`；2025综合2 双散列对 70 的 H1 中间算式与公式反推不吻合，但最终落位表与 ASL成功=2 自洽，保留结论。

> 这批勘误印证了主讲"材料里可能有错误和疏漏，要避免"的提醒——答案 PDF 是回忆版配套解析，本身有错。题库的价值之一就是把这些错误在入库时拦下。
