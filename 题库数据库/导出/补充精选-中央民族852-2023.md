# 题库导出（1 题）


## 【查找】

### EXT-CUN-852-2023-A4
> 中央民族852-2023 | 算法设计

设一棵二叉排序树，结点中存放整数关键字。请设计算法，计算并输出所有关键字小于等于给定值 X 的结点关键字的平均值。若不存在满足条件的结点，说明算法如何处理。

**答案**

```c
typedef struct BSTNode {
    int key;
    struct BSTNode *left, *right;
} BSTNode;

void SumLE(BSTNode *p, int x, long double *sum, int *count) {
    if (p == NULL) return;
    if (p->key > x) {
        /* p 及其右子树都大于 x，只需检查左子树 */
        SumLE(p->left, x, sum, count);
    } else {
        /* 左子树所有关键字均 <= p->key <= x */
        SumLE(p->left, x, sum, count);
        *sum += p->key;
        ++(*count);
        /* 右子树中可能仍有 <= x 的结点 */
        SumLE(p->right, x, sum, count);
    }
}

int AverageLE(BSTNode *root, int x, double *average) {
    long double sum = 0;
    int count = 0;
    SumLE(root, x, &sum, &count);
    if (count == 0) return 0;  /* 无符合结点，平均值未定义 */
    *average = (double)(sum / count);
    return 1;
}
```


**解析**：利用二叉排序树的有序性剪枝：若当前关键字大于 X，则当前结点及其右子树都不可能入选，只递归左子树；若当前关键字不大于 X，则当前结点和左子树全部满足条件，再检查右子树中可能满足条件的部分。主调函数用计数判断空集合，避免除零。最坏时间复杂度 O(n)，递归栈空间 O(h)，h 为树高。
