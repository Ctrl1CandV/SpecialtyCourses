# EXT-INST-2026-M9-A1-LCA

> 来源:机构押题2026 | 章节:树 | 题型:算法设计 | 考点:二叉树,最近公共祖先,后序递归,指针与结点身份 | PDF页:158

## 题干
二叉树采用结点结构 (LLINK, INFO, RLINK)。ROOT 指向根，非空指针 p、q 均指向该树中的结点。编写 ANCESTOR(ROOT,p,q,r) 求最近公共祖先，通过 r 返回结点指针。结点值可以重复，以指针区分结点；结点自身可作为祖先，允许 p=q。说明思想及复杂度。

## 答案
```c
typedef struct Node {
    int INFO;
    struct Node *LLINK, *RLINK;
} Node;
Node *LCA(Node *root, Node *p, Node *q) {
    if (root == NULL || root == p || root == q) return root;
    Node *left = LCA(root->LLINK, p, q);
    Node *right = LCA(root->RLINK, p, q);
    if (left && right) return root;
    return left ? left : right;
}
void ANCESTOR(Node *ROOT, Node *p, Node *q, Node **r) {
    *r = LCA(ROOT, p, q);
}
```

## 解析
后序递归汇总左右子树：左右结果均非空时，目标分处两侧，当前根是最近公共祖先；仅一侧非空时向上传该结果。直接遇到 p 或 q 时返回该结点，覆盖一方是另一方祖先以及 p=q 的情况。前提是两个目标确实在树中；若取消此前提，须另行检查存在性，不能把找到的单个目标误当作共同祖先。最坏时间 O(n)，递归栈 O(h)。

# EXT-INST-2026-M8-A2-ALLPATHS

> 来源:机构押题2026 | 章节:图 | 题型:算法设计 | 考点:图,邻接表,DFS回溯,所有简单路径,visited复位 | PDF页:150

## 题干
给定邻接表表示的有向简单图 G，顶点编号 0…n-1，以及两个不同顶点 u、v。设计算法输出从 u 到 v 的所有简单路径（路径内顶点不得重复）。说明 visited 的复位位置、无路径时的处理与复杂度特点。

## 答案
```c
void DFSPaths(ALGraph *G, int x, int target,
              int visited[], int path[], int depth, int *found) {
    visited[x] = 1;
    path[depth] = x;
    if (x == target) {
        PrintPath(path, depth + 1);
        *found = 1;
    } else {
        for (ArcNode *p = G->vertices[x].firstarc; p; p = p->nextarc) {
            int y = p->adjvex;
            if (!visited[y])
                DFSPaths(G, y, target, visited, path, depth + 1, found);
        }
    }
    visited[x] = 0;  /* 返回父层前复位，不放在邻接点循环内部 */
}
void AllPaths(ALGraph *G, int u, int v) {
    int visited[MAXV] = {0}, path[MAXV], found = 0;
    DFSPaths(G, u, v, visited, path, 0, &found);
    if (!found) PrintNoPath();
}
```

## 解析
visited 只表示当前递归路径上的顶点；进入时置1，退出该层时置0，使同一顶点可以出现在其他路径中。抵达 v 后立即输出且不继续扩展，避免越过终点。只有未在当前路径内的邻接点才可递归，所以每条输出路径无重复顶点；枚举每个可选后继保证不遗漏。简单图约定避免平行弧导致重复输出相同顶点序列。时间随搜索的简单路径前缀数和输出长度增长，最坏可达阶乘量级，不能写成普通遍历的 O(V+E)；辅助空间 O(V)，不计输出存储。

# EXT-INST-2026-M6-C2-HUFFCOMPARE

> 来源:机构押题2026 | 章节:树 | 题型:综合应用 | 考点:Huffman编码,前缀码,等长编码,WPL,平均码长,编码效率 | PDF页:128

## 题干
通信电文有8个字符，依次记为 A、B、C、D、E、F、G、H，出现概率依次为 0.07、0.19、0.02、0.06、0.32、0.03、0.21、0.10。
（1）给出一组 Huffman 二进制前缀编码及构造过程。
（2）设计等长二进制编码。
（3）计算两者的平均码长（概率权值下的WPL），比较优缺点。编码允许左右分支交换产生不同正确答案。

## 答案
将概率乘100，权值为 (7,19,2,6,32,3,21,10)。依次合并：2+3=5，5+6=11，7+10=17，11+17=28，19+21=40，28+32=60，40+60=100。

| 字符 | 概率 | 一组Huffman码 | 码长 | 一组等长码 |
|---|---:|---|---:|---|
| A | 0.07 | 1010 | 4 | 000 |
| B | 0.19 | 00 | 2 | 001 |
| C | 0.02 | 10000 | 5 | 010 |
| D | 0.06 | 1001 | 4 | 011 |
| E | 0.32 | 11 | 2 | 100 |
| F | 0.03 | 10001 | 5 | 101 |
| G | 0.21 | 01 | 2 | 110 |
| H | 0.10 | 1011 | 4 | 111 |

Huffman平均码长 = 2×(0.19+0.32+0.21)+4×(0.07+0.06+0.10)+5×(0.02+0.03) = **2.61 bit/字符**；8个字符等长编码需要3位，平均码长为 **3 bit/字符**。节省(3−2.61)/3=13%，此比例未计码表传输等开销。

## 解析
Huffman将高频字符分配较短码，在给定概率下使二进制前缀码的平均码长最小，但需要码表/树，变长码的边界与译码较复杂；等长码便于按固定长度定位和译码，在本例中占用更多比特。把合并权重相加得到5+11+17+28+40+60+100=261，除100也得到2.61，与逐字符加权码长独立核对一致。WPL为概率加权的平均码长，不是未知电文总字符数下的总比特数。

# EXT-INST-2026-M8-C6-AOE

> 来源:机构押题2026 | 章节:图 | 题型:综合应用 | 考点:AOE网,先驱关系,拓扑顺序,关键路径,ve与vl,活动时差 | PDF页:148

## 题干
工程各工序的耗时及直接先驱如下（CE表示C、E均完成后才能开始G；“-”表示无先驱）。

| 工序 | A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|---|
| 耗时 | 3 | 2 | 2 | 3 | 4 | 3 | 2 | 1 |
| 直接先驱 | - | - | A | A | B | A | C,E | D |

（1）构造一个等价AOE网，给出事件编号和活动弧。
（2）计算各事件最早、最迟发生时间。
（3）求关键路径与最短工期，并列出各活动的最早、最迟开始时间。允许等价的事件编号/虚活动构图方式。

## 答案
一种不需虚活动的AOE网为：A:0→1(3)，B:0→2(2)，C:1→3(2)，D:1→4(3)，E:2→3(4)，F:1→5(3)，G:3→5(2)，H:4→5(1)。0为源点，5为唯一汇点。

| 事件 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|---:|
| ve | 0 | 3 | 2 | 6 | 6 | 8 |
| vl | 0 | 4 | 2 | 6 | 7 | 8 |

| 活动 | e（最早开始） | l（最迟开始） | 时差 l−e |
|---|---:|---:|---:|
| A | 0 | 1 | 1 |
| B | 0 | 0 | 0 |
| C | 3 | 4 | 1 |
| D | 3 | 4 | 1 |
| E | 2 | 2 | 0 |
| F | 3 | 5 | 2 |
| G | 6 | 6 | 0 |
| H | 6 | 7 | 1 |

关键活动为B、E、G；关键路径0→2→3→5，最短工期2+4+2=**8**。

## 解析
按拓扑序计算ve(v)=max(ve(u)+w(u,v))；令汇点vl(5)=ve(5)=8，逆拓扑计算vl(u)=min(vl(v)−w(u,v))。如ve(3)=max(3+2,2+4)=6，vl(1)=min(6−2,7−3,8−3)=4。活动(u,v)的e=ve(u)，l=vl(v)−w；e=l为关键活动。构图中3为C和E完成后的共同事件，确保G必须等待两者；5汇合F、G、H，确保整个工程全部结束。单独以工序先驱关系前推最早完成时间得到最大8，可交叉核对工期。

# 真题-2024-算法2

> 来源:真题2024 | 章节:图 | 题型:算法设计 | 模板:DFS回溯 | 考点:无向图路径存在性,DFS回溯,定长路径 | PDF页:5

## 题干
编写代码及思想，判断在无向图中是否存在从顶点 i 到顶点 j 的长度为 k 的路径(使用邻接表表示图)。

## 答案
思想：从 i 出发做深度优先搜索并用 visited 标记，每深入一层路径长度 k 减 1；当到达 j 且剩余长度恰为 0 时说明存在长度 k 的路径，返回 1；一条分支失败则回溯(取消标记)继续尝试其它分支，全部失败返回 0。

```c
int visited[MAXSIZE];
int exist_path_len(ALGraph G, int i, int j, int k) {
    if (i == j && k == 0) return 1;
    else if (k > 0) {
        visited[i] = 1;
        for (ArcNode* p = G.vertices[i].firstarc; p; p = p->nextarc) {
            int temp = p->adjvex;
            if (!visited[temp] && exist_path_len(G, temp, j, k - 1)) {
                visited[i] = 0;      // 找到即回溯复位(可选)
                return 1;
            }
        }
        visited[i] = 0;              // 所有邻接分支失败后复位
        return 0;
    }
    return 0;                        // k<0 等情形
}
```

## 解析
DFS 回溯枚举从 i 出发长度恰为 k 的简单路径。visited 保证路径为简单路径(不重复顶点)；回溯时须在当前顶点所有邻接分支都尝试完毕后再复位 visited[i]。

> 真题同源：2024算法设计题

> 备注：【答案PDF有误】PDF 代码把复位语句 `visited[i]=0;` 误放在 for 循环体内部(每尝试一个邻接点后就复位)，与其'思想'所述'递归结束时将当前顶点访问状态重置'矛盾，会导致同一顶点在一条路径中被重复经过、结果错误。正确写法是把 `visited[i]=0;` 移到 for 循环之外、`return 0` 之前(见 answer 修正代码)。
