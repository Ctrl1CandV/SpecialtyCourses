### EXT-INST-2025-M3-Q23-BFS
> 机构押题2026 | 算法设计

设 G 为一个连通无向图，采用邻接表存储，顶点编号为 0 到 n−1。给定源点 s，设计算法返回与 s 的最短路径长度最大的顶点；若有多个顶点并列最远，返回编号最小者。说明算法依据及复杂度。

**答案**

```c
int FarthestVertex(ALGraph *G, int s) {
    int dist[MAXV];
    Queue Q;
    for (int i = 0; i < G->vexnum; ++i) dist[i] = -1;
    InitQueue(&Q);
    dist[s] = 0;
    EnQueue(&Q, s);

    while (!QueueEmpty(Q)) {
        int v;
        DeQueue(&Q, &v);
        for (ArcNode *p = G->vertices[v].firstarc; p; p = p->nextarc) {
            int w = p->adjvex;
            if (dist[w] == -1) {
                dist[w] = dist[v] + 1;
                EnQueue(&Q, w);
            }
        }
    }

    int ans = 0;
    for (int i = 1; i < G->vexnum; ++i)
        if (dist[i] > dist[ans]) ans = i;
    return ans;
}
```


**解析**：无权图中从 s 开始的 BFS 首次访问顶点时得到的 dist 即为最短路径长度。连通性保证所有 dist 均已赋值。最后按顶点编号递增扫描，并且只在距离严格增大时更新答案，因此距离相同会保留编号较小者。时间复杂度 O(V+E)，辅助空间 O(V)。

### EXT-INST-2026-M8-A2-ALLPATHS
> 机构押题2026 | 算法设计

给定邻接表表示的有向简单图 G，顶点编号 0…n-1，以及两个不同顶点 u、v。设计算法输出从 u 到 v 的所有简单路径（路径内顶点不得重复）。说明 visited 的复位位置、无路径时的处理与复杂度特点。

**答案**

```c
void DFSPaths(ALGraph *G, int x, int target,
              int visited[], int path[], int depth, int *found) {
    visited[x] = 1;
    path[depth] = x;
    if (x == target) {
        PrintPath(path, depth + 1);
        *found = 1;
    } else {
        for (ArcNode *p = G->vertices[x].firstarc; p; p = p->nextarc) {
            int y = p->adjvex;
            if (!visited[y])
                DFSPaths(G, y, target, visited, path, depth + 1, found);
        }
    }
    visited[x] = 0;  /* 返回父层前复位，不放在邻接点循环内部 */
}
void AllPaths(ALGraph *G, int u, int v) {
    int visited[MAXV] = {0}, path[MAXV], found = 0;
    DFSPaths(G, u, v, visited, path, 0, &found);
    if (!found) PrintNoPath();
}
```

**解析**：visited 只表示当前递归路径上的顶点；进入时置1，退出该层时置0，使同一顶点可以出现在其他路径中。抵达 v 后立即输出且不继续扩展，避免越过终点。只有未在当前路径内的邻接点才可递归，所以每条输出路径无重复顶点；枚举每个可选后继保证不遗漏。简单图约定避免平行弧导致重复输出相同顶点序列。时间随搜索的简单路径前缀数和输出长度增长，最坏可达阶乘量级，不能写成普通遍历的 O(V+E)；辅助空间 O(V)，不计输出存储。

### EXT-INST-2026-M8-C6-AOE
> 机构押题2026 | 综合应用

工程各工序的耗时及直接先驱如下（CE表示C、E均完成后才能开始G；“-”表示无先驱）。

| 工序 | A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|---|
| 耗时 | 3 | 2 | 2 | 3 | 4 | 3 | 2 | 1 |
| 直接先驱 | - | - | A | A | B | A | C,E | D |

（1）构造一个等价AOE网，给出事件编号和活动弧。
（2）计算各事件最早、最迟发生时间。
（3）求关键路径与最短工期，并列出各活动的最早、最迟开始时间。允许等价的事件编号/虚活动构图方式。

**答案**

一种不需虚活动的AOE网为：A:0→1(3)，B:0→2(2)，C:1→3(2)，D:1→4(3)，E:2→3(4)，F:1→5(3)，G:3→5(2)，H:4→5(1)。0为源点，5为唯一汇点。

| 事件 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|---:|
| ve | 0 | 3 | 2 | 6 | 6 | 8 |
| vl | 0 | 4 | 2 | 6 | 7 | 8 |

| 活动 | e（最早开始） | l（最迟开始） | 时差 l−e |
|---|---:|---:|---:|
| A | 0 | 1 | 1 |
| B | 0 | 0 | 0 |
| C | 3 | 4 | 1 |
| D | 3 | 4 | 1 |
| E | 2 | 2 | 0 |
| F | 3 | 5 | 2 |
| G | 6 | 6 | 0 |
| H | 6 | 7 | 1 |

关键活动为B、E、G；关键路径0→2→3→5，最短工期2+4+2=**8**。

**解析**：按拓扑序计算ve(v)=max(ve(u)+w(u,v))；令汇点vl(5)=ve(5)=8，逆拓扑计算vl(u)=min(vl(v)−w(u,v))。如ve(3)=max(3+2,2+4)=6，vl(1)=min(6−2,7−3,8−3)=4。活动(u,v)的e=ve(u)，l=vl(v)−w；e=l为关键活动。构图中3为C和E完成后的共同事件，确保G必须等待两者；5汇合F、G、H，确保整个工程全部结束。单独以工序先驱关系前推最早完成时间得到最大8，可交叉核对工期。

### EXT-INST-2026-M2-Q2-BST-SUCC
> 机构押题2026 | 算法设计

二叉排序树结点关键字为整数。设计一个算法，给定关键字 x，查找树中严格大于 x 的最小关键字结点（即 x 的中序后继）；若不存在，返回空指针。

**答案**

```c
typedef struct BSTNode {
    int key;
    struct BSTNode *left, *right;
} BSTNode;

BSTNode *SuccessorGreater(BSTNode *root, int x) {
    BSTNode *p = root;
    BSTNode *candidate = NULL;
    while (p != NULL) {
        if (p->key > x) {
            candidate = p;       /* p 是当前可行候选，左侧可能更小 */
            p = p->left;
        } else {
            p = p->right;        /* p <= x，答案只能在右侧 */
        }
    }
    return candidate;
}
```


**解析**：沿查找路径维护最小的已知可行结点。遇到 key>x 时记录该结点并继续向左寻找更小的合格关键字；遇到 key<=x 时，左子树也不可能含有严格大于 x 的结点，转向右子树。循环结束时 candidate 即所求，若始终未找到则为 NULL。时间复杂度 O(h)，空间复杂度 O(1)。

### EXT-INST-2026-M6-C2-HUFFCOMPARE
> 机构押题2026 | 综合应用

通信电文有8个字符，依次记为 A、B、C、D、E、F、G、H，出现概率依次为 0.07、0.19、0.02、0.06、0.32、0.03、0.21、0.10。
（1）给出一组 Huffman 二进制前缀编码及构造过程。
（2）设计等长二进制编码。
（3）计算两者的平均码长（概率权值下的WPL），比较优缺点。编码允许左右分支交换产生不同正确答案。

**答案**

将概率乘100，权值为 (7,19,2,6,32,3,21,10)。依次合并：2+3=5，5+6=11，7+10=17，11+17=28，19+21=40，28+32=60，40+60=100。

| 字符 | 概率 | 一组Huffman码 | 码长 | 一组等长码 |
|---|---:|---|---:|---|
| A | 0.07 | 1010 | 4 | 000 |
| B | 0.19 | 00 | 2 | 001 |
| C | 0.02 | 10000 | 5 | 010 |
| D | 0.06 | 1001 | 4 | 011 |
| E | 0.32 | 11 | 2 | 100 |
| F | 0.03 | 10001 | 5 | 101 |
| G | 0.21 | 01 | 2 | 110 |
| H | 0.10 | 1011 | 4 | 111 |

Huffman平均码长 = 2×(0.19+0.32+0.21)+4×(0.07+0.06+0.10)+5×(0.02+0.03) = **2.61 bit/字符**；8个字符等长编码需要3位，平均码长为 **3 bit/字符**。节省(3−2.61)/3=13%，此比例未计码表传输等开销。

**解析**：Huffman将高频字符分配较短码，在给定概率下使二进制前缀码的平均码长最小，但需要码表/树，变长码的边界与译码较复杂；等长码便于按固定长度定位和译码，在本例中占用更多比特。把合并权重相加得到5+11+17+28+40+60+100=261，除100也得到2.61，与逐字符加权码长独立核对一致。WPL为概率加权的平均码长，不是未知电文总字符数下的总比特数。

### EXT-INST-2026-M7-Q1-EXPR-TREE
> 机构押题2026 | 算法设计

表达式树采用二叉链表存储：叶结点表示操作数，内部结点表示运算符；二元运算符结点有左右孩子，一元负号结点恰有一个孩子。设计算法输出与该树等价的中缀表达式，要求每个运算都用括号明确结合关系，且正确处理一元负号。

**答案**

```text
Emit(p):
    若 p 为空：返回（合法输入中不会出现）
    若 p 是叶结点：输出 p 的操作数
    否则若 p 表示一元负号（恰有一个孩子 c）：
        输出 "(-"
        Emit(c)
        输出 ")"
    否则（二元运算符）：
        输出 "("
        Emit(p.left)
        输出 p.data
        Emit(p.right)
        输出 ")"
```
例如，根为“*”、左子树为“a+b”、右子树为“c*(-d)”时，输出 `((a+b)*(c*(-d)))`。实现时可将“输出”改为向动态字符串缓冲区追加字符/操作数 token。


**解析**：后序式的递归结构直接对应表达式树：叶结点输出操作数；一元负号在其唯一孩子外加括号并在前面输出负号；二元运算先输出左子树、运算符、右子树，再用一对括号括起。因每个内部节点均显式加括号，不会因优先级或结合性改变原树表达式的含义。设树有 n 个结点，时间复杂度 O(n+L)，L 为输出长度；递归栈空间 O(h)。

### EXT-INST-2026-M9-A1-LCA
> 机构押题2026 | 算法设计

二叉树采用结点结构 (LLINK, INFO, RLINK)。ROOT 指向根，非空指针 p、q 均指向该树中的结点。编写 ANCESTOR(ROOT,p,q,r) 求最近公共祖先，通过 r 返回结点指针。结点值可以重复，以指针区分结点；结点自身可作为祖先，允许 p=q。说明思想及复杂度。

**答案**

```c
typedef struct Node {
    int INFO;
    struct Node *LLINK, *RLINK;
} Node;
Node *LCA(Node *root, Node *p, Node *q) {
    if (root == NULL || root == p || root == q) return root;
    Node *left = LCA(root->LLINK, p, q);
    Node *right = LCA(root->RLINK, p, q);
    if (left && right) return root;
    return left ? left : right;
}
void ANCESTOR(Node *ROOT, Node *p, Node *q, Node **r) {
    *r = LCA(ROOT, p, q);
}
```

**解析**：后序递归汇总左右子树：左右结果均非空时，目标分处两侧，当前根是最近公共祖先；仅一侧非空时向上传该结果。直接遇到 p 或 q 时返回该结点，覆盖一方是另一方祖先以及 p=q 的情况。前提是两个目标确实在树中；若取消此前提，须另行检查存在性，不能把找到的单个目标误当作共同祖先。最坏时间 O(n)，递归栈 O(h)。

### EXT-INST-2026-M5-Q2-FINDSUM
> 机构押题2026 | 算法设计

给定按非递减次序排列的整数数组 a[0…n−1] 和目标值 K，设计 O(n) 时间、O(1) 额外空间的算法，判断是否存在两个不同下标 i<j，使 a[i]+a[j]=K；若存在，输出任意一对数值，否则报告不存在。注意避免整数求和溢出。

**答案**

```c
int FindSumPair(const int a[], int n, long long K, int *x, int *y) {
    int i = 0, j = n - 1;
    while (i < j) {
        long long s = (long long)a[i] + (long long)a[j];
        if (s == K) {
            *x = a[i];
            *y = a[j];
            return 1;
        }
        if (s < K) ++i;
        else --j;
    }
    return 0;
}
```


**解析**：维护两端下标 i<j。若和小于 K，由于数组非递减，固定 i 时与当前及更小右端元素相加都不会达到 K，故 i 前移；若和大于 K，固定 j 时与当前及更大左端元素相加只会更大，故 j 后移。每轮至少移动一个下标，最多 O(n) 轮；空间复杂度 O(1)。先转为 long long 再求和，避免 int 加法溢出。

### EXT-INST-2026-M6-Q1-ARRAY-SWAP
> 机构押题2026 | 算法设计

顺序表中依次存放两个相邻序列 A=(a₁,…,aₘ) 和 B=(b₁,…,bₙ)。设计一个原地算法，将其变为 B 后接 A，即 (b₁,…,bₙ,a₁,…,aₘ)。要求使用 O(1) 额外空间，并分析时间复杂度。

**答案**

```c
void Reverse(int a[], int left, int right) {
    while (left < right) {
        int t = a[left];
        a[left++] = a[right];
        a[right--] = t;
    }
}

void ExchangeAdjacent(int a[], int m, int n) {
    /* a[0..m-1] 为 A，a[m..m+n-1] 为 B */
    Reverse(a, 0, m - 1);
    Reverse(a, m, m + n - 1);
    Reverse(a, 0, m + n - 1);
}
```


**解析**：先分别逆置 A、B，再逆置整个序列。第一次操作得到 rev(A)·rev(B)，整体逆置后为 B·A。每个元素至多参与常数次交换，时间复杂度 O(m+n)，只使用临时变量，额外空间 O(1)。当 m 或 n 为 0 时，Reverse 的空区间不执行，算法仍成立。
