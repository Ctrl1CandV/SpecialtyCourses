## 一、核心概念与定义

### 1.1 排序的基本概念

- **排序 Sorting**：将一个数据元素（或记录）的**任意序列**重排成**按关键字有序**的序列，即确定 1..n 的一种排列 p₁..pₙ，使 K_p₁≤K_p₂≤…≤K_pₙ（非递减，或非递增）。有序表可折半查找（ASL≈log₂(n+1)-1），无序表只能顺序查找（ASL≈(n+1)/2）。
- **关键字 Key**：据以排序的数据项。**主关键字**唯一标识记录，排序结果**唯一**；**次关键字**可标识多个记录，因存在关键字相等的记录，结果**不唯一**；也可是若干数据项的组合。
- **内部排序**：待排记录**全部存放在内存**中完成，排序期间无需访问外存（本章内容）。**外部排序**：记录数量很大、内存一次不能容纳，排序中**尚需访问外存**（下一章）。

### 1.2 稳定性（802 高频辨析点）

- **稳定排序**：设序列中存在 Kᵢ=Kⱼ（i≠j），且排序前 Rᵢ **领先于** Rⱼ（i<j）；若排序后 Rᵢ **仍领先于** Rⱼ（相同关键字记录**相对次序保持**），则**稳定**；否则**不稳定**。
- 判定要点：稳定性由**方法本身**决定、与初始序列无关。对不稳定方法**只需举一组关键字实例**说明即可（如 {5\*,5,2}）；对稳定方法总能找到不引起不稳定的描述形式。
- 实际意义：按**主关键字**排序时稳定与否无关紧要；按**次关键字**（多关键字）排序则必须慎重选稳定方法。

### 1.3 衡量排序方法的三大指标

1. **时间复杂度**：由**关键字间的比较次数**与**记录移动次数**共同决定。比较对多数方法必要；移动可通过改变存储方式（链表、地址排序）部分避免。
2. **空间复杂度**：排序所需**辅助存储空间**（暂存单元、递归栈、归并辅助数组、基数排序队列指针）。
3. **稳定性**：相同关键字记录的相对次序是否保持。

### 1.4 分类与两个基本操作

- **按原则分类（五类）**：插入排序、交换排序、选择排序、归并排序、基数（计数）排序。
- **按工作量分类（三类）**：① 简单排序 O(n²)（直接插入、折半插入、冒泡、简单选择）；② 先进排序 O(n log n)（快排、堆排、归并）；③ 基数排序 O(d·n)。**希尔排序介于二者之间**（约 O(n^1.3)）。
- **两个基本操作**：① 比较两个关键字的大小；② 将记录从一个位置移动到另一个位置。

### 1.5 基于比较的排序下界 Ω(n log n)

- **判定树模型**：除基数排序外各方法都基于"关键字间的比较"，可用**判定树**描述——非终端结点表一次比较、左右子树表两种结果、叶子表一种排序结果。
- **推导**：n 个记录的可能初始排列有 n! 种，故判定树必须有 **n! 个叶子**（少一叶说明还有两状态没分辨）；而 u 个叶子的二叉树高度至少 ⌈log₂u⌉+1，故必存在一条长 **⌈log₂(n!)⌉** 的根到叶路径（即最坏比较次数）。
- **结论**：任何基于比较的排序**最坏比较次数至少 ⌈log₂(n!)⌉**；由斯特林公式 = O(n log n)，故**最坏时间下界 Ω(n log n)**。快排/堆排/归并的 O(n log n) 已达此下界；**基数排序不基于比较、不受此约束**。

## 二、存储结构与分类

- **三种存储方式**：① **顺序存储**——次序由**存储位置**决定，排序**必须移动记录**（本章默认）；② **静态链表（表排序）**——次序由**指针**指示，排序**只改指针不移动记录**，适合记录大、移动代价高（表插入、链式基数）；③ **地址排序**——另设地址向量 adr，排序中只移 adr、结束后按 adr 重排（至多 ⌊3n/2⌋ 次；快排/堆排无法表排序但可地址排序）。
- **r[0] 约定**：`SqList` 含 `RedType r[MAXSIZE+1]`（**r[0] 闲置或作哨兵**）与 `int length`。直接插入中 r[0] 作**监视哨**（存待插记录、避免查找时下标越界、省去判界）；希尔、快排中 r[0] 仅作**暂存单元**（非哨兵）。
- **存储适应性**：**仅顺序存储**（需随机访问）——折半插入、希尔；**不适合链表**——快排（双指针两端扫描）、堆排（依赖顺序下标 kᵢ 与 k₂ᵢ/k₂ᵢ₊₁）；**可用链表**——直接插入、归并（链表归并空间 O(1)）、基数（链式）。

## 三、关键性质与结论

### 3.1 各种内部排序方法综合比较表

| 排序方法 | 平均时间 | 最坏情况 | 最好情况 | 辅助空间 | 稳定性 |
|----------|----------|----------|----------|----------|--------|
| 直接插入 | O(n²)（≈n²/4） | O(n²)（逆序） | **O(n)**（正序） | O(1) | ✓ 稳定 |
| 折半插入 | O(n²) | O(n²) | 比较 O(n log n) | O(1) | ✓ 稳定 |
| 希尔排序 | ≈O(n^1.3) | O(n²) | — | O(1) | ✗ 不稳定 |
| 冒泡排序 | O(n²) | O(n²)（逆序） | **O(n)**（正序+flag） | O(1) | ✓ 稳定 |
| 快速排序 | **O(n log n)** | O(n²)（有序/逆序） | O(n log n) | **O(log n)** 递归栈 | ✗ 不稳定 |
| 简单选择 | O(n²) | O(n²) | O(n²) | O(1) | ✗ 不稳定 |
| 堆排序 | O(n log n) | **O(n log n)** | O(n log n) | O(1) | ✗ 不稳定 |
| 2-路归并 | O(n log n) | O(n log n) | O(n log n) | **O(n)** | ✓ 稳定 |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(r) 队列指针 | ✓ 稳定 |

> d = 关键字位数（趟数），r = 基数/桶数（RADIX，十进制 10、字母 26）。

### 3.2 速记结论

- **稳定**：直接插入、折半插入、冒泡、归并、基数（口诀"插泡归基"）。**不稳定**：希尔、快排、简单选择、堆（口诀"**快些选一堆**"）。
- **平均 O(n log n)**：快排（常数因子最小、平均最佳）、堆排、归并。**最坏仍 O(n log n)**：堆排、归并（快排最坏退化 O(n²)）。
- **比较次数与初始无关**：简单选择（固定 n(n-1)/2）、堆排、归并、基数、折半插入。**与初始有关**：直接插入、冒泡（正序可提前结束）、快排（划分是否均匀）。
- **移动最少**：简单选择（0~3(n-1)）；直接插入正序时不移动记录。

### 3.3 方法选取策略

- **n 小或基本有序** → 直接插入（接近 O(n)，最简最优）。**n 大、追求平均最快** → 快排。**要求最坏有保证/n 很大** → 堆排或归并（n 大时归并比堆省时间但辅助空间最多）。**要求稳定** → 归并（或基数）。**Top-K** → 堆排（维护 K 大小的堆，无需全排）。**链表存储** → 归并。**关键字可分解、位数 d 少、每位范围 r 小、n 大** → 基数排序。

## 四、核心算法思想（分步骤详述）

> 本章只讲思想与分步骤过程，完整 C 代码见 知识笔记/代码总结.md。

### 4.1 插入排序类

#### 4.1.1 直接插入排序 Straight Insertion Sort

- **思想**：将一个记录插入到**已排好序的有序表**中，得到记录数增 1 的新有序表。整个过程进行 **n-1 趟**：先把第 1 个记录看成有序子序列，再从第 2 个起逐个插入。**第 i 趟**：在有序子序列 r[1..i-1] 中插入 r[i]，得 r[1..i]。
- **带哨兵的分步骤**（r[0] 作监视哨避免下标越界）：① i 从 2 到 n，若 `r[i].key < r[i-1].key`（需插入）；② `r[0]=r[i]`（复制待插记录为**哨兵**）；③ `r[i]=r[i-1]`（前一记录先后移一位）；④ 从 j=i-2 起**向前顺序查找**：只要 `r[0].key < r[j].key` 就 `r[j+1]=r[j]`（记录后移）并 j--，**边查找边后移**；⑤ 找到位置后 `r[j+1]=r[0]` 插入。
- **比较与移动次数**：**正序**——比较达最小 **n-1** 次、**不移动记录**、时间 O(n)；**逆序**——比较达最大 **(n+2)(n-1)/2**、移动达最大 **(n+4)(n-1)/2**；**随机**（各排列等概率）——取二者平均，比较与移动约 **n²/4**。
- **性质**：时间 O(n²)，空间 O(1)（一个记录辅助空间），**稳定**（相等关键字不交换、只后移）。适合 **n 很小或基本有序**。

#### 4.1.2 折半插入排序 Binary Insertion Sort

- **思想**：直接插入的"查找插入位置"可用**折半查找**替代（有序表满足折半前提），减少比较次数。
- **分步骤**：① r[i] 暂存到 r[0]；② 在 r[low..high]（low=1,high=i-1）中折半查找插入位置：`m=(low+high)/2`，若 `r[0].key<r[m].key` 则 `high=m-1`（低半区），否则 `low=m+1`（高半区），直到 low>high；③ 将 r[high+1..i-1] 统一**后移一位**；④ `r[high+1]=r[0]` 插入。
- **性质**：辅助空间同直接插入 O(1)；**仅减少比较次数**（比较与初始无关，为 O(n log n)），**移动次数不变**，故时间**仍 O(n²)**。**稳定**（定位到相等记录之后插入）。**仅顺序存储**（折半需随机访问）。

#### 4.1.3 希尔排序 Shell's Sort（缩小增量排序）

- **思想**：利用直接插入"正序可达 O(n)"与"n 小时效率高"两点。先将待排序列**分割成若干子序列**（相隔某个"增量"的记录组成一个子序列，**非逐段分割**）分别直接插入排序，待整体"**基本有序**"时，再对全体做一次增量为 1 的直接插入排序。
- **增量序列**：取 d₁（如 ⌊n/2⌋）→ 分成 d₁ 个子序列各自直接插入 → 缩小增量 d₂ → … → 最后 d=1 做一趟普通直接插入。每趟前后记录位置的增量是 dk 而非 1，r[0] 只作暂存单元（不是哨兵），j≤0 时插入位置已找到。
- **示例**：{49,38,65,97,76,13,27,49\*,55,04}，d=5 时分 {49,13}{38,27}{65,49\*}{97,55}{76,04} 五子表各自插入排序使序列“基本有序”，再按 d=3、1 递减排序，最终得 {04,13,27,38,49,49\*,55,65,76,97}。
- **为何高效**：较小关键字**不是一步步往前挪、而是跳跃式往前移**，使序列迅速趋于基本有序，最后一趟只需少量比较移动。
- **为何不稳定**：相同关键字可能分在**不同子表**被分别移动，相对次序被打乱（如两个 49 在不同增量子表排序后位置互换）。
- **复杂度**：时间是所取增量序列的函数、涉及数学未解难题、尚无最优增量序列。取 dlta[k]=2^(t-k+1)-1 时 O(n^3/2)；实验表明 n 在某范围约 **O(n^1.3)**，n→∞ 可降到 n(log₂n)²。**增量序列要求**：各值**互质（无除 1 外公因子）**且**末项必须为 1**。**仅顺序存储**。

### 4.2 交换排序类

#### 4.2.1 冒泡排序 Bubble Sort

- **思想**：借助"交换"**两两比较相邻记录**，逆序则交换，使较大记录像"石块下沉"、较小记录像"气泡上浮"，每趟把当前最大记录安置到末尾。**第 i 趟**：从 r[1] 到 r[n-i+1] 依次比较相邻两记录，逆序则交换，使这 n-i+1 个中**最大者被交换到第 n-i+1 位置**。
- **提前结束标志 flag**：设布尔变量记录本趟**是否发生过交换**；若某趟**没有任何交换**说明已有序，**提前结束**（这是冒泡的结束条件："一趟中没有进行过交换记录的操作"）。
- **复杂度与性质**：**正序**——只需一趟、比较 **n-1** 次、不移动记录、配合 flag 时间 **O(n)**；**逆序**——需 n-1 趟、比较 Σ(n-i)=**n(n-1)/2** 次、并作等数量级移动、时间 **O(n²)**。空间 O(1)，**稳定**（相等关键字不交换）。

#### 4.2.2 快速排序 Quick Sort

- **思想**：通过**一趟排序（一次划分 Partition）**将待排记录分割成独立两部分，一部分关键字均比另一部分小，再对两部分**递归**排序至整体有序。是对冒泡的改进。
- **选枢轴 pivot**：任取一个记录（通常第一个 L.r[s]）作枢轴（支点），关键字记为 pivotkey。
- **一趟划分 Partition 双指针步骤**：① 设两指针 **low、high** 初指子表两端，先把枢轴记录**暂存到 r[0]**，pivotkey=r[low].key；② 从 **high 向前搜索**找到第一个 **< pivotkey** 的记录，**移到低端** r[low]（单向移动、避免多余的枢轴赋值）；③ 从 **low 向后搜索**找到第一个 **> pivotkey** 的记录，**移到高端** r[high]；④ **重复 ②③**、两端交替向中间扫描直到 **low=high**；⑤ 此时该位置即枢轴最终位置，`r[low]=r[0]` 归位、返回 pivotloc。划分后枢轴前的记录均不大于它、后的均不小于它。
- **示例**（一趟划分）：{49,38,65,97,76,13,27,49\*}，pivotkey=49，两端交替扫描（high 找到 27 移低、low 找到 65 移高…）至 low=high，枢轴 49 归位，得 {27,38,13} **49** {76,97,65,49\*}。
- **递归**：若子序列只有一个记录则已有序；否则一趟划分后分别对 {r[s..pivotloc-1]}、{r[pivotloc+1..t]} 递归快排。
- **平均 O(n log n)（常数因子最小）**：设 T(n)=一趟划分(cn)+T(k-1)+T(n-k)，随机排列下 k 取 1..n 等概率，推得平均 O(n log n)。经验证明在所有 O(n log n) 先进排序中**快排常数因子 k 最小**，故平均性能最好、是目前公认最好的内排方法。
- **最坏 O(n²) 的原因**：初始序列**已有序（正序）或逆序**时，每趟**枢轴恰取极值**（最大或最小），划分极不均匀——一个子表为空、另一个含 n-1 个记录，退化为**冒泡**，需 n-1 趟、时间 O(n²)，递归栈最坏深度也达 **n**。
- **空间 O(log n)（递归栈）**：均匀分割时栈最大深度 ⌊log₂n⌋+1；枢轴总偏一端则最坏栈深 n。**不稳定**：划分时相等关键字可能被交换到枢轴两侧。
- **改进措施**：① **三数取中/随机枢轴**（比较 r[s]、r[t]、r[(s+t)/2] 取中值者作枢轴，大幅改善最坏性能，但不能根本避免有序退化）；② **小区间转直接插入**（子序列较短时改用直接插入、减少递归开销）；③ **先递归短子序列**（一趟后比较两部分长度、先对较短者快排，把栈深从最坏 O(n) 降到 O(log n)）；④ 划分时兼做"起泡"并用两布尔变量标记两端是否发生过交换，据此判断某端是否已有序、无需再排。

### 4.3 选择排序类

#### 4.3.1 简单选择排序 Simple Selection Sort

- **思想**：每一趟在 n-i+1（i=1..n-1）个记录中**选取关键字最小的记录**作为有序序列第 i 个。**第 i 趟**：通过 n-i 次比较从 r[i..n] 选出最小者与 r[i] **交换**；i 从 1 至 n-1、共 n-1 趟。
- **比较次数固定**：无论初始排列如何，比较次数**都相同**，均为 **n(n-1)/2**（Σ(n-i)）——这是与冒泡（可提前结束）的关键区别。
- **移动次数最少**：最小 **0**（初始已正序、每趟选中的就是自身、不交换），最大 **3(n-1)**（每趟都交换一次、一次交换 3 次移动）。
- **性质**：时间 O(n²)，空间 O(1)，**不稳定**。**不稳定反例**：序列 **{5\*,5,2}**，第一趟选最小 2 与第一个 5\* 交换 → {2,5,5\*}，原领先的 5\* 被换到 5 之后、相对次序改变。（改进方向了解：树形选择/锦标赛排序利用已比较信息，选次小值仅需 ⌈log₂n⌉ 次比较、O(n log n)，但辅助空间多——由此引出堆排序。）

#### 4.3.2 堆排序 Heap Sort

- **堆的定义**：n 个元素序列 {k₁..kₙ} 当且仅当满足下列之一时称为堆（i=1..⌊n/2⌋）：**大根堆（大顶堆）** kᵢ≥k₂ᵢ 且 kᵢ≥k₂ᵢ₊₁（非终端结点的值均**不小于**左右孩子）；**小根堆** kᵢ≤k₂ᵢ 且 kᵢ≤k₂ᵢ₊₁（均**不大于**）。将一维数组看成**完全二叉树**，则堆顶（根）必为序列**最大值**（大根堆）或**最小值**（小根堆）。
- **两个问题**：① 如何由无序序列**建堆**？② 输出堆顶后如何**调整剩余元素成新堆**（"筛选"）？
- **筛选 HeapAdjust 分步骤**（大顶堆为例，已知 r[s..m] 除 r[s] 外均满足堆定义）：① 暂存 rc=r[s]；② 从 j=2s（左孩子）起沿**关键字较大的孩子**向下：若 j<m 且 r[j].key<r[j+1].key 则 j++（指向较大孩子）；③ 若 rc.key **不小于** r[j].key，说明 rc 应插在位置 s，**break**；④ 否则 r[s]=r[j]（较大孩子上移）、s=j、继续向下（j=2s）；⑤ 循环结束 r[s]=rc 放入最终位置。
- **建堆过程**：将无序序列看成完全二叉树，**最后一个非终端结点是第 ⌊n/2⌋ 个元素**，故筛选**从 ⌊n/2⌋ 起依次向前**对 i=⌊n/2⌋,⌊n/2⌋-1,…,1 逐个调用 HeapAdjust(H,i,n)，即建成大顶堆。（示例 {49,38,65,97,76,13,27,49\*} 从第 4 个元素 97 起筛选。）
- **建堆 O(n) 推导**：对深度 k 的堆，筛选比较至多 2(k-1) 次。含 n 元素、深度 h 的堆，第 i 层结点数至多 2^(i-1)、以其为根的子树深度 h-i+1，总比较不超过 Σ2^(i-1)·2(h-i) ≤ **4n**。故**建堆是 O(n) 而非 O(n log n)**——因**大多数结点靠近叶子层、筛选代价小**（叶子层无需筛选、倒数第二层最多下沉 1 层）。
- **排序过程**（大顶堆→递增）：① 建初始大顶堆；② 将**堆顶 r[1] 与当前未排序子序列末尾 r[i] 交换**（把最大值甩到末尾）；③ 对前 i-1 个（r[1..i-1]）重新 HeapAdjust 恢复大顶堆；④ 重复 ②③、i 从 n 递减到 2、共 n-1 趟，得递增有序序列。
- **复杂度与性质**：**时间**——调整建新堆调用 HeapAdjust n-1 次、每次比较不超过 2⌈log₂(n-i+1)⌉、总比较 < 2n⌈log₂n⌉，故**最坏也是 O(n log n)**（相对快排的最大优点，快排最坏 O(n²)）；建堆 O(n) 被 n-1 趟筛选的 O(n log n) 主导。**空间 O(1)**（一个记录供交换）。**不稳定**（交换堆顶与末尾打乱相等关键字次序）。**适用**：记录少时不值得，但 **n 很大很有效**；**Top-K** 首选（维护 K 大小的堆、无需全排）；**不适合链表**（依赖顺序下标）。

### 4.4 归并排序

#### 4.4.1 2-路归并排序 Merging Sort

- **"归并"含义**：将**两个或两个以上有序表**组合成新有序表，顺序或链表存储均可在 O(m+n) 量级实现。**思想**：初始 n 个记录看成 **n 个长度 1 的有序子序列**，**两两归并**得 ⌈n/2⌉ 个长度 2 或 1 的有序段；再两两归并……直至得到长度 n 的有序序列。
- **核心操作 Merge 分步骤**（将有序 SR[i..m] 与 SR[m+1..n] 归并为有序 TR[i..n]）：① 设 j=m+1、k=i，当 i≤m 且 j≤n 时循环：比较 SR[i].key 与 SR[j].key，**取较小者**存入 TR[k] 并使对应指针与 k 同时后移；② 某段先取空则把**另一段剩余记录**直接复制到 TR 剩余位置。
- **趟数**：一趟归并调用 ⌈n/(2h)⌉ 次 Merge，把长度 h 的相邻有序段两两归并成长度 2h 的段；整个归并需 **⌈log₂n⌉ 趟**。
- **复杂度与性质**：**时间**——每趟对 n 个记录归并 O(n)、共 ⌈log₂n⌉ 趟，故**始终 O(n log n)**（最好/最坏/平均相同、**与初始无关**）。**空间 O(n)**——需与待排记录**等数量辅助空间**存结果，是 2-路归并主要**缺点**（相较快排 O(log n)、堆排 O(1)）。**稳定**——Merge 中相等关键字**先取前一段的**（`LQ` 为"≤"）、保持相对次序（相对快排、堆排的最大特点）。**改进**：用**链表**归并可把辅助空间降到 **O(1)**（只改指针），是链表排序首选；递归形式简洁但实用性差，实际常用非递归（迭代）形式。

### 4.5 基数排序

#### 4.5.1 多关键字排序：MSD 与 LSD

- **多关键字**：每记录含 d 个关键字 (K⁰..K^(d-1))，K⁰ 为**最主位关键字**、K^(d-1) 为**最次位关键字**（如扑克牌有"花色"（地位高）和"面值"两个关键字）。
- **MSD（最高位优先）**：先对最主位 K⁰ 排序，把序列**逐层分割**成若干子序列（同子序列 K⁰ 相同），再分别就每子序列对 K¹ 排序、继续分割，**必须递归分割子序列**。
- **LSD（最低位优先）**：从最次位 K^(d-1) 起排序，再对高一位 K^(d-2) 排序，依次重复至 K⁰。**不必分成子序列**、对每个关键字都是**整个序列**参加排序；但对 Kⁱ（0≤i≤d-2）排序时**只能用稳定方法**。

#### 4.5.2 链式基数排序（LSD）

- **思想**：有的逻辑关键字可看成由若干关键字**复合**而成（如 0~999 数值分解为百位 K⁰、十位 K¹、个位 K²；5 字母单词分解为 5 个关键字）。分解后每个关键字都在相同范围内（数字 0~9、字母 A~Z），按 **LSD** 更方便：从最低位起按关键字不同值将记录"**分配**"到 RADIX 个队列再"**收集**"、重复 d 次。"基"指 RADIX 取值（数字 **10**、字母 **26**）。**不基于关键字间的比较**。
- **一趟"分配+收集"分步骤**（静态链表存储 n 个记录，r[0] 为头结点）：① **分配 Distribute**——按当前位（第 i 位）扫描链表，用 `ord` 把该位映射到 [0..RADIX-1]，改指针将其**插入对应链队列**（f[j]、e[j] 为第 j 个队列的头、尾指针），使同队列中该位关键字相等；② **收集 Collect**——按队列序号 0→RADIX-1，改所有**非空队列队尾记录的指针**令其指向下一非空队列队头，把 RADIX 个队列**重新串联成一个链表**。
- **过程**：第一趟对**个位**、第二趟对**十位**、第三趟对**百位**……共 **d 趟**排序完毕。
- **复杂度与性质**：**时间 O(d(n+r))**——每趟分配 O(n)、每趟收集 O(r)（r=基数/桶数），共 d 趟；d 很小时可写 O(d·n)。**空间 O(r)**——辅助空间为 **2r 个队列指针**（f、e 各 r 个）；因用链表存储还增加 n 个指针域空间。**稳定**——收集时按桶序串联、桶内保持原次序，且 LSD 各趟必须用稳定方法；**非比较型、不受下界约束**，可优于 O(n log n)。**适用**：**n 很大而关键字位数 d 较小**、每位范围 r 小；要求关键字**可分解**为若干位数少的子关键字。

## 五、易错点与常考辨析

1. **折半插入仍 O(n²)**：**只减比较次数**（降到 O(n log n)、与初始无关）、**移动次数不变**，故总时间仍 O(n²)；**仅顺序存储**可用（折半需随机访问）。勿误答成 O(n log n)。
2. **希尔不稳定 + 增量要求**：相同关键字分在不同子表被移开；增量序列必须**互质（无除 1 外公因子）+ 末项为 1**；仅顺序存储；时间约 **O(n^1.3)**（介于 O(n²) 与 O(n log n) 之间，勿答成 O(n log n)）。
3. **快排最坏 O(n²) 的原因**：**初始已有序/逆序**时每趟枢轴恰取极值、划分极不均匀（一子表空、另一子表 n-1 个）、退化为冒泡；三数取中/随机枢轴可**改善**但不能根本避免；**先递归短子序列**把栈深从最坏 O(n) 降到 O(log n)。
4. **简单选择比较次数固定**：**n(n-1)/2** 与初始无关——区别于冒泡（正序配 flag 提前结束、只比较 n-1 次）；移动最少（0~3(n-1)）。**不稳定反例 {5\*,5,2}**（第一趟 5\* 与 2 交换 → 5\* 落到 5 之后）。
5. **建堆是 O(n) 而非 O(n log n)**：从**最后一个非终端结点 ⌊n/2⌋** 起向前逐个筛选；因多数结点近叶层、筛选代价小，总比较 ∑≤4n（堆排序总时间/最坏均 O(n log n) 由 n-1 趟筛选主导）。**大根堆→递增序列**（每趟取堆顶最大与末尾交换，勿混淆堆类型与排序方向）。
6. **归并空间 O(n) 是劣势**：时间**始终 O(n log n)**（与初始无关）、**稳定**，但需 O(n) 辅助空间——与快排 O(log n)、堆排 O(1) 对比的高频考点；**链表归并**可降到 O(1)。
7. **基数不基于比较、可突破下界**：任何**基于比较**的排序最坏至少 ⌈log₂(n!)⌉=Ω(n log n) 次比较（判定树有 n! 个叶子），快排/堆排/归并已达下界；而**基数排序非比较型**（LSD 做 d 趟"分配入桶+收集串联"、O(d(n+r))/稳定），**不受此下界约束**、可优于 O(n log n)。
