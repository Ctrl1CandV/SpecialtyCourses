## 一、核心概念与定义

- **数组**：线性表的推广，数据元素本身也是数据结构。n 维数组 ADT：数据对象 D={a_{j₁…jₙ} | 0≤jᵢ≤bᵢ−1}，n(>0) 为**维数**，bᵢ 为第 i 维**长度（维界）**，jᵢ 为下标；共含 ∏bᵢ 个元素，每个元素受 n 个关系约束，单个关系仍是线性关系（有直接后继）；n=1 时退化为定长线性表。
- **二维数组两视角**：m 行 n 列既可看成"每元素是列向量的线性表"，也可看成"每元素是行向量的线性表"；故 `ElemType A2[m][n]` 等价于"分量为一维数组的一维数组"。
- **操作特点**：数组一旦定义，**维数和维界不再改变**，元素个数与关系不再变动。故除**初始化 InitArray、销毁 DestroyArray** 外，**只有存取元素值 Value 和修改元素值 Assign，没有插入和删除**——这也决定了数组天然采用顺序存储。
- **压缩存储**：值相同的元只分配一个空间，零元不分配空间。**特殊矩阵**=相同元/零元分布**有规律**（对称矩阵 aᵢⱼ=aⱼᵢ；三角矩阵=上/下三角不含对角线的元均为同一常数 c 或零；对角/带状矩阵=非零元集中在主对角线为中心的带状区）；**稀疏矩阵**=非零元少且分布**无规律**。
- **广义表（列表 lists）**：线性表的推广，LS=(a₁,…,aₙ)，n≥0 为**长度**。aᵢ 可为单个元素（**原子**）或广义表（**子表**）；大写表名、小写表原子。定义是**递归的**（描述时又用到广义表概念），表可被共享、也可是自身的子表（递归表如 E=(a,E) 相当于无限表，长度为 2）。
- **表头 Head 与表尾 Tail**：非空时第一个元素 a₁ 为表头，其余元素组成的表 (a₂,…,aₙ) 为表尾。**表头可为原子也可为子表，表尾必定是一个列表（表）**（可为空表 ()，但不能是原子）。
- **长度与深度**：**长度**=最外层元素个数；**深度**=括号最大嵌套层数（重数）。规定：原子深度 0，空表 () 深度 1。

## 二、存储结构与分类

### 2.1 数组的顺序存储
存储单元一维而数组多维，存放就有**次序约定**问题，二维数组有两种方式：
- **行序为主序(row major)**：按行依次存放 a₀₀,a₀₁,…,a₀,ₙ₋₁,a₁₀,…。C、PASCAL、扩展 BASIC、PL/1、COBOL 采用。
- **列序为主序(column major)**：按列依次存放 a₀₀,a₁₀,…,a_{m−1,0},a₀₁,…。FORTRAN 采用。

数组属**随机存储结构**：各维长度确定后，计算任一元素地址的时间相等，故存取任一元素时间也相等。（顺序存储实现含 base/dim/bounds/constants 及变长参数求映像函数常数，见 代码总结.md。）

### 2.2 特殊矩阵的压缩存储
- **对称矩阵**：每对对称元只分配一个空间，n² 个元压缩到 **n(n+1)/2** 个；以一维数组 `sa[n(n+1)/2]` 行序为主序存**下三角（含对角线）**，sa[k] 与 aᵢⱼ 一一对应。
- **三角矩阵**：只存下（上）三角中的元，**再加一个存常数 c（或零）的空间**，共占 n(n+1)/2 + 1 个。
- **三对角（带状）矩阵**：|i−j|≤1 时元非零（主对角线及紧邻上、下各一条），共 3n−2 个非零元，按行序（或对角线顺序）压缩到一维数组。

### 2.3 稀疏矩阵的三种压缩存储
- **三元组顺序表 TSMatrix**：每个非零元用 `Triple{i(行), j(列), e(值)}`，`(i,j,aᵢⱼ)` 唯一确定一个非零元。结构 `data[MAXSIZE+1]`（data[0] 未用，非零元按**行序为主序**排列）+ `mu,nu,tu`（行数、列数、非零元个数）。又称"有序的双下标法"，便于依行处理；但按行号存取某行非零元须**从头查找**。
- **行逻辑链接顺序表 RLSMatrix**：三元组表基础上增设 `rpos[MAXRC+1]`，`rpos[row]` 指示第 row 行第一个非零元在 data 中的序号，便于**随机存取任意一行**，适合矩阵相乘。（第 row 行最后一个非零元位置为 rpos[row+1]−1，最后一行为 tu。）
- **十字链表 CrossList**：非零元个数与位置变化较大时（如相加会引起 data 移动）宜用链式。结点 `OLNode{i, j, e, right, down}`：right 链接**同一行**下一非零元，down 链接**同一列**下一非零元；每个非零元既是行链表结点又是列链表结点，整个矩阵成十字交叉链表。矩阵头 `CrossList{rhead[], chead[], mu,nu,tu}`（行、列链表头指针向量）。

### 2.4 广义表的链式存储（两种，掌握其一即可）
元素结构不一（原子或子表），难以顺序存储，通常用链式。需**表结点**（表示子表）与**原子结点**（表示原子），用标志域 tag 区分（ATOM=0，LIST=1）。
- **头尾链表**：表结点 `{tag=1; hp(指表头); tp(指表尾)}`，原子结点 `{tag=0; atom}`。特点：非空表的表头指针指向表结点，hp 指示表头、tp 指表尾（表尾为空则指针空，否则必为表结点）；易分清原子与子表层次；**最高层表结点个数即为表长**。
- **扩展线性链表（孩子兄弟式）**：表结点 `{tag=1; hp; tp}`，原子结点 `{tag=0; atom; tp}`。hp 是表结点的表头指针，tp **相当于线性链表的 next**，指向同层下一个元素结点。（两结构 tp 语义不同：头尾链表 tp 指"表尾"，扩展线性链表 tp 指"下一个兄弟元素"。）

### 2.5 应用：m 元多项式表示
m 元多项式每项变元数目不均、变元因子重复，不宜用线性表（结点大小不匀、浪费空间）。用广义表：先分解主变元再分解第二变元……每个多项式看作"一个变元 + 若干(系数,指数)偶对"。如三元多项式 P=z((A,2),(B,1),(15,0))，其中 A=y((C,3),(D,2)) 层层分解。**广义表深度即为变元个数**。结点 `{tag; exp(指数); coef或hp; tp}`，每层增设表头结点用 exp 指示该层变元。

## 三、关键性质与结论（含公式来历与推导要点）

### 3.1 二维数组地址映射（推导）
设每元素占 L 个单元，LOC(i,j) 为 aᵢⱼ 位置，LOC(0,0) 为基地址（基址），m 行 n 列、下标从 0 起。

**行优先**：
> **LOC(i,j) = LOC(0,0) + (i×n + j) × L**

推导：aᵢⱼ 之前有 i 个整行（每行 n 个，共 i×n）加本行内前面的 j 个，共 (i×n+j) 个元素，每个占 L 单元（教材记 (b₂×i+j)L，b₂=n 为列数）。

**列优先**：
> **LOC(i,j) = LOC(0,0) + (j×m + i) × L**

推导：aᵢⱼ 之前有 j 个整列（每列 m 个，共 j×m）加本列内前面的 i 个。**记忆：行优先乘子用列数 n，列优先乘子用行数 m；都是"整块数×每块大小 + 块内偏移"。**

### 3.2 n 维数组映像函数（推导）
> **LOC(j₁,…,jₙ) = LOC(0,…,0) + Σ(i=1..n) cᵢ·jᵢ**，其中 **cₙ=L，c_{i−1}=bᵢ×cᵢ (1<i≤n)**。

来历：cᵢ 是"第 i 维下标变动 1 引起的地址增量"，等于后面各维长度乘积再乘 L；展开即 (b₂×…×bₙ×j₁ + b₃×…×bₙ×j₂ + … + bₙ×j_{n−1} + jₙ)×L。**存储位置是下标的线性函数**，各维长度定后 cᵢ 为常数，故数组是随机存储结构。

### 3.3 对称矩阵下三角映射（完整推导）
`sa[]` 行序为主序存下三角（含对角线），下标 i,j,k 均从 0 起。

**下三角 i≥j**：
> **k = i(i+1)/2 + j**

推导：aᵢⱼ 前，第 0 行 1 个、第 1 行 2 个、…、第 i−1 行 i 个下三角元，累计 1+2+…+i = **i(i+1)/2**；再加本行内 aᵢⱼ 前的 j 个（第 i 行下三角从列 0 到列 j），得 k=i(i+1)/2+j。

**上三角 i<j**：由 aᵢⱼ=aⱼᵢ 交换下标：**k = j(j+1)/2 + i**。

**若下标从 1 起（i,j,k 均从 1）**：aᵢⱼ 前累计 1+…+(i−1)=i(i−1)/2，再加本行前的元并因数组从 1 计数，化简得 **k = i(i−1)/2 + j**（i≥j）。**关键：i、j、k 下标基准必须统一（同从 0 或同从 1）。**

### 3.4 三对角（带状）矩阵映射（推导）
|i−j|≤1 的 3n−2 个非零元按行序压缩（下标从 0 起）：**k = 2i + j**（等价写法 k=2i+j−1 视基准而定）。

推导：首、末行各只 2 个非零元、中间行 3 个，前 i 行共约 3i−1 个，再加本行内偏移；行优先下常用结论 k=2i+j（i,j 从 0 起且 |i−j|≤1）。**做题务必按给定下标基准重新核对首尾行元素个数。**

### 3.5 稀疏矩阵相关结论
- **稀疏因子** δ=t/(m×n)，t 为非零元个数；无严格定义，凭直觉，**通常 δ≤0.05 称为稀疏矩阵**。
- **转置矩阵**：m×n 矩阵 M 的转置 T 是 n×m 矩阵，T(i,j)=M(j,i)；稀疏矩阵转置仍是稀疏矩阵。

### 3.6 广义表 () 与 (()) 辨析
- **()**：空表，长度 0，深度 1。
- **(())**：长度 1（最外层只有一个元素即子表 ()），表头表尾**均为空表 ()**，深度 2（括号嵌套两层）。二者不同，切勿混淆。

### 3.7 广义表深度递归定义
> DEPTH(空表)=1；DEPTH(原子)=0；DEPTH(LS)=1+Max{DEPTH(aᵢ)}，n≥1。

即非空表深度为各元素深度最大值加 1；执行过程实质是遍历广义表，先求各子表深度再综合。

## 四、核心算法思想

### 4.1 稀疏矩阵转置（三步 + 两种方法）
**转置三件事**：(1) 行列值互换（T.mu=M.nu, T.nu=M.mu, T.tu=M.tu）；(2) 每个三元组 i、j 调换；(3) 重排三元组次序，使 b.data 以 T 的行（即 M 的列）为主序排列。前两条易做，**关键是第三条**。

**方法一：普通转置（按 M 列序，算法 5.1）**
- 思想：按 b.data 应有次序（即按 M 列序）依次在 a.data 中找相应三元组转置。为找 M 每列所有非零元，需对 a.data 整个扫描一遍；a.data 以行序为主序存放，由此得到的恰是 b.data 应有顺序。
- 步骤：外层 col 从 1 到 M.nu 遍历每列；内层 p 从 1 到 M.tu 遍历整个三元组表；当 M.data[p].j==col 时转置（i、j 互换）放入 T.data[q]，q++。
- **时间 O(nu×tu)**（与列数×非零元个数成正比），仅适合 tu≪mu×nu；tu 与 mu×nu 同量级时退化为 O(mu×nu²)，虽省空间但变慢。对比：稠密矩阵经典转置 O(mu×nu)。

**方法二：快速转置（附设 num[] 与 cpot[]，算法 5.2）**
- 思想：按 a.data 次序转置，并将三元组**直接置入 b.data 恰当位置**。转置前先求 M 每列（即 T 每行）非零元个数，进而求每列首非零元在 b.data 中位置。
- 辅助向量：**num[col]**=M 中第 col 列非零元个数；**cpot[col]**=M 中第 col 列首非零元在 b.data 中位置。关系：cpot[1]=1；cpot[col]=cpot[col−1]+num[col−1] (2≤col≤nu)。
- **分步骤**：① 交换行列值 T.mu=M.nu、T.nu=M.mu、T.tu=M.tu；② num[col] 全清 0（col=1..nu）；③ 遍历 a.data（t=1..tu），`++num[M.data[t].j]` 求每列非零元个数；④ 求 cpot：cpot[1]=1，for col=2..nu：cpot[col]=cpot[col−1]+num[col−1]；⑤ 遍历 a.data（p=1..tu）：col=M.data[p].j，q=cpot[col]，将 M.data[p] 转置后放入 T.data[q]（i、j 互换、e 复制），再 `++cpot[col]`（该列下个位置后移）；⑥ 返回 OK。
- **时间 O(nu+tu)**（4 个并列单循环，循环次数分别为 nu、tu）；tu 与 mu×nu 等量级时为 O(mu×nu)，与经典算法相同，仅多用两个辅助向量（稍改可只用一个）。

### 4.2 稀疏矩阵相乘 Q=M×N（行逻辑链接，算法 5.3）
- 前提：M 是 m₁×n₁、N 是 m₂×n₂，n₁=m₂ 时可乘，Q(i,j)=Σ(k) M(i,k)×N(k,j)。经典稠密 O(m₁×n₁×n₂)，不论是否为零都乘一次。
- 稀疏化：两者有一为零则积为零，应免无效操作——只找 **M.data 的 j 值 == N.data 的 i 值** 的各对元素相乘；借 N.rpos 定位 N 中第 k 行非零元（rpos[row] 到 rpos[row+1]−1，最后一行到 N.tu）。
- 逐行处理：Q 行号与 M 一致且 M 以行序为主序，故逐行处理；设累计和 ctemp[]（初值 0），扫 M 当前行每个非零元求积累加到 ctemp[] 对应列，一行完后将 ctemp[] 非零元压缩存入 Q.data。
- 注意：**乘积矩阵不一定稀疏**；分量不为零时累加值 Q[i][j] 也可能为零，须求得累加和后才知是否非零元。时间 O(M.mu×N.nu + M.tu×N.tu/N.mu)，两稀疏因子均<0.05 且 n<1000 时约 O(m×p)。

### 4.3 十字链表建立与矩阵相加（算法 5.4 及 B→A）
- **建立十字链表**：按任意次序输入非零元，每建一个结点都要寻查它在行表和列表中的插入位置，时间 **O(t×s)**，s=max{m,n}；若按行序为主序依次输入三元组可改写为 **O(t)**。
- **矩阵相加（B 加到 A 上）**：与一元多项式相加相似，但非零元有行、列两个变元，每个结点既在行表又在列表，指针修改更复杂。从第一行起逐行进行，设 pa、pb 分别指向 A、B 中行值相同的结点，**四种情况**：① pa==NULL 或 pa->j>pb->j：在 A 中**插入**值为 bᵢⱼ 的新结点（改同行前驱 right、同列前驱 down）；② pa->j<pb->j：只需 **pa 右移**一步；③ pa->j==pb->j 且 pa->e+pb->e≠0：将 aᵢⱼ+bᵢⱼ 送到 pa 所指结点 **e 域**（其余不变）；④ pa->j==pb->j 且 pa->e+pb->e==0：在 A 中**删除** pa 所指结点（改同行前驱 right、同列前驱 down）。
- 辅助指针：A 行链表设 **pre** 指示 pa 前驱；A 每列链表设 **hl[j]**（初值 hl[j]=chead[j]）指示同列前驱。时间 **O(tₐ+t_b)**（逐行扫描 A、B 十字链表，取决于两矩阵非零元个数）。

### 4.4 广义表递归算法（分治法）
- 递归定义 = **基本项**（**终结状态**，如 n=0 或 n=1，可直接求解）+ **归纳项**（原问题与子问题的转化关系）。设计要点：先定义功能与接口，对每个递归调用只看成简单操作，接口一致即可递归，切忌想太深（如同第二数学归纳法不怀疑归纳假设）。
- **求深度（5.5）**：终结状态空表(返回1)、原子(返回0)；非空表遍历第一层由 tp 相连的结点，对各 hp 所指子表递归求深度取最大值加 1。例 D=((),(e),(a,(b,c,d)))：DEPTH(A)=1、DEPTH(B)=1、DEPTH(C)=2，故 DEPTH(D)=1+Max{1,1,2}=**3**。
- **复制广义表（5.6）**：非空表可分解成表头、表尾，反之确定的表头表尾唯一确定表；复制即分别复制表头表尾再合成。基本项：空表置空表；归纳项：COPY(GetHead(LS)→GetHead(NEWLS))、COPY(GetTail(LS)→GetTail(NEWLS))。
- **建立存储结构（5.7 + sever 5.8）**：把书写形式看成字符串 S。基本项：S='()' 建空表、单字符串建原子结点；归纳项：脱最外层括号，用 **sever** 分离最外层第一个逗号前的表头串递归建子表，逐个建表结点用 tp 串联，末结点 tp=NULL。sever 用 k 记未配对左括号数（遇 '(' 加、遇 ')' 减），只在 k=0 的逗号处分割。

### 4.5 广义表 GetHead/GetTail 运算示例
以 B=(e)、C=(a,(b,c,d))、D=(A,B,C)=((),(e),(a,(b,c,d))) 为例：
- GetHead(B)=e（原子），GetTail(B)=()（空表）；
- GetHead(D)=A=()，GetTail(D)=(B,C)=((e),(a,(b,c,d)))；对 (B,C) 再分解：GetHead=B=(e)，GetTail=(C)=((a,(b,c,d)))；
- 对 L=(a,(b,c))：GetHead=a，GetTail=((b,c))；再对 (b,c)：GetHead=b，GetTail=(c)；再对 (c)：GetHead=c，GetTail=()。
- 规律：**表头取出可为原子或表；表尾取出一定是表（外层再套一对括号）**。

## 五、易错点与常考辨析

- **行/列优先勿混**：行优先乘子用**列数 n**（i×n+j），列优先乘子用**行数 m**（j×m+i）；都是"整块数×每块元素数 + 块内偏移"，下标一般从 0 起。
- **对称矩阵映射的下标基准**：从 0 起 k=i(i+1)/2+j（i≥j），从 1 起 k=i(i−1)/2+j，i、j、k 必须同基准；分清下三角(i≥j)与上三角(i<j、交换下标)两式。三角矩阵要多一个存常数 c 的空间（n(n+1)/2+1）。
- **三对角矩阵首尾行元素个数不同**：首、末行各只 2 个非零元，中间行 3 个，共 3n−2 个；k=2i+j 须按给定下标基准核对。
- **表尾必为表**：(a,(b,c)) 的 Head=a、Tail=((b,c))；表头可为原子，表尾一定是列表（外层再套括号），空表 () 也是合法表尾。
- **长度≠深度**：长度=最外层元素个数，深度=括号最大嵌套层数。**空表 () 长度 0、深度 1（非 0）**，原子深度 0；(()) 长度 1、深度 2。
- **转置复杂度**：普通转置 **O(nu×tu)**（非 O(mu×nu)，仅 tu 与 mu×nu 同量级时才写 O(mu×nu²)）；快速转置 **O(nu+tu)**，多用 num[]、cpot[] 两辅助向量。
- **稀疏矩阵非严格定义**：凭 δ≤0.05 直觉判断；三元组顺序表按行存便于逐行运算，但随机取某行须从头查找（引出 rpos[]）；乘积矩阵不一定稀疏。
- **两种广义表结构 tp 语义不同**：头尾链表 tp 指**表尾**（必为表结点，最高层表结点数=表长），扩展线性链表 tp 指**下一元素**（类 next、孩子兄弟式）。
- **递归设计别想太深**：接口一致就把递归调用看成简单操作；广义表操作前提是"非递归表且无共享子表"。
