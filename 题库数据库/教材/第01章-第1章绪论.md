## 一、核心概念与定义

- **数据(data)**：对客观事物的符号表示，在计算机科学中指所有能输入到计算机中并被程序处理的符号的总称，是程序加工的"原料"。整数、实数、字符串、图像、声音等经编码后均属数据范畴。

- **数据元素(data element)**：数据的基本单位，在程序中通常作为一个整体考虑和处理。一个数据元素可由若干**数据项(data item)**组成，数据项是数据的不可分割的最小单位。

- **数据对象(data object)**：性质相同的数据元素的集合，是数据的一个子集。如整数对象 N={0,±1,±2,…}。

- **数据结构(data structure)**：相互之间存在一种或多种特定关系的数据元素的集合。形式定义为二元组 `Data_Structure=(D,S)`，D 是数据元素的有限集，S 是 D 上关系的有限集。

- **数据结构三义**（高频考点）：
  1. **逻辑结构**——数据元素之间的逻辑关系，独立于计算机；
  2. **存储结构（物理结构）**——逻辑结构在计算机中的表示，含元素的表示和关系的表示；
  3. **数据运算**——施加于数据的操作集（插入、删除、查找、排序等）。
  - 关系：算法设计取决于逻辑结构，算法实现依赖于存储结构，运算定义在逻辑结构上、实现在存储结构上。

- **数据类型(data type)**：一个值的集合和定义在该值集上的一组操作的总称。按"值"的特性分两类：
  - **原子类型**：值不可分解（整型、实型、字符型、枚举、指针、空类型）；
  - **结构类型**：值由若干成分按某种结构组成、可分解（如数组）。数据结构可看成"一组具有相同结构的值"，结构类型 = 数据结构 + 其上的一组操作。

- **抽象数据类型(ADT)**：一个数学模型以及定义在该模型上的一组操作。定义仅取决于逻辑特性，与内部表示和实现无关。三元组 `(D,S,P)`：D 数据对象，S 关系集，P 基本操作集。
  - ADT 与数据类型实质是一个概念，"抽象"意义在于数学抽象特性；但 ADT 范畴更广，还含用户自定义类型。
  - **封装与信息隐蔽**：将用户不必了解的细节封装在类型中，模块外部只用抽象数据和抽象操作，抽象层次越高复用程度越高。
  - **ADT 值的细分**：原子类型(不可分解)、固定聚合类型(成分数确定，如复数)、可变聚合类型(成分数不定，如可变长序列)；后两者统称结构类型。
  - **多形数据类型**：值的成分不确定但元素间关系和基本操作相同（需 C++ 等实现）。

- **算法(algorithm)**：对特定问题求解步骤的描述，是指令的有限序列，每条指令表示一个或多个操作。

- **算法五特性**：
  1. **有穷性**——对任何合法输入，在执行有穷步后结束，每步在有穷时间内完成（"有穷"指实际合理可接受，非纯数学）；
  2. **确定性**——每条指令含义确切无二义性，相同输入只有唯一执行路径、得出相同输出；
  3. **可行性**——算法中描述的操作都可通过已实现的基本运算执行有限次来实现；
  4. **输入**——有零个或多个输入，取自某个特定对象的集合；
  5. **输出**——有一个或多个输出，是同输入有特定关系的量。

## 二、存储结构与分类

### 四类逻辑结构

| 逻辑结构 | 元素间关系 | 典型例子 |
|---------|-----------|---------|
| 集合 | 仅"同属一个集合"，最松散 | 某班全体学生 |
| 线性 | 一对一 | 书目文件、线性表、栈、队列 |
| 树形 | 一对多 | 对弈树、族谱、文件目录 |
| 图状/网状 | 多对多 | 交通路网、课程先修关系 |

集合是关系极松散的结构，也可用其他结构来表示它。

### 逻辑结构 vs 存储结构

- 逻辑结构是元素关系的数学描述，独立于计算机；存储结构是其计算机映像。
- 同一逻辑结构可有多种存储方式（线性表可顺序可链式）。

### 四种存储方式

1. **顺序存储**：借助元素在存储器中的**相对位置**表示逻辑关系。逻辑相邻则物理相邻；随机访问 O(1)；插入删除需移动元素 O(n)；需预分配连续空间。典型实现：一维数组。
2. **链式存储**：借助**指针**表示逻辑关系。不要求物理相邻；插入删除只需修改指针；访问需顺序遍历 O(n)；有指针域空间开销但无需预分配。典型实现：C 指针+结构体。
3. **索引存储**：建立附加索引表（关键字→地址），查找快但索引表需额外空间。例：图书按书名/作者/分类号建的索引表。
4. **散列(哈希)存储**：通过散列函数由关键字直接计算存储地址，理想 O(1) 查找，需处理冲突。

### 存储单元术语

- **位(bit)**：计算机表示信息的最小单位。
- **元素/结点(node)**：若干位组合成的位串，表示一个数据元素。
- **数据域(data field)**：位串中对应各数据项的子位串。

## 三、关键性质与结论

### 算法设计四要求

1. **正确性(correctness)**：算法应满足具体问题需求。正确性分四层次：
   - a. 不含语法错误；b. 几组输入满足规格；c. 精心选择的典型、苛刻、刁难性输入满足规格；d. 一切合法输入满足规格。
   - d 层极难达到，实践以**第 c 层**为程序合格标准。

2. **可读性(readability)**：算法首为人阅读交流、次为机器执行。晦涩程序易藏错、难调试修改。

3. **健壮性(robustness)**：输入非法时能适当反应或处理，不产生莫名结果。出错时返回表示错误性质的值（非崩溃/中止），以便在更高抽象层次处理。

4. **效率与低存储量需求**：效率指执行时间，存储量指最大存储空间，两者均与问题规模有关。

### 原地工作

额外空间相对输入数据量为常数 → 原地工作（in-place），部分排序算法属此类。

## 四、核心算法思想（复杂度分析方法）

### 度量方法

- **事后统计**：运行程序计时。缺陷：①须先运行；②依赖软硬件环境，掩盖算法本身优劣。
- **事前分析估算**（主流）：撇开硬软件因素，认为算法"运行工作量"只依赖问题规模 n。程序运行时间取决于：①算法策略；②问题规模；③实现语言（级别越高效率越低）；④编译代码质量；⑤机器速度。其中只有①②属算法本身。

### 时间复杂度

- **基本操作**：从算法中选取重复执行次数与执行时间成正比的原操作，以其次数量度时间。多数情况是最深层循环内的原操作。
- **语句频度**：语句重复执行的次数，基本操作频度 = 含它语句的频度。
- **渐近时间复杂度**：基本操作次数是 n 的函数 f(n)，记作 `T(n)=O(f(n))`，表示随 n 增大，算法执行时间增长率与 f(n) 增长率相同。
- **O 记号形式定义**：x=O(f(n)) 表示存在正常数 M 和 n₀，当 n≥n₀ 时 |x|≤M·|f(n)|（渐进上界）。
- **求阶技巧**：取频度表达式中关于 n 增长最快的项，忽略低阶项和常数系数。如 (n-1)(n-2)/2 → O(n²)。

- **三种情况**：
  - 最好情况：最有利输入下的复杂度；
  - 最坏情况：最不利输入下的复杂度（执行时间上界）；
  - 平均情况：所有输入的期望值（概率难定故难求）。
  - **约定**：除特别指明外均指最坏情况。
  - 起泡排序例：最好(正序)交换0次 O(n)；最坏(逆序)交换 n(n-1)/2 次 O(n²)；平均(等概率) O(n²)。

### 常见数量级（由低到高）

`O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)`

- O(1) 常量阶：直接访问 | O(log n) 对数阶：二分查找 | O(n) 线性阶：遍历
- O(n log n)：归并/快排(平均)/堆排 | O(n²)：冒泡/选择/插入 | O(n³)：朴素矩阵乘
- O(2ⁿ) 指数阶：子集枚举 | O(n!) 阶乘阶：全排列枚举
- 应选多项式阶 O(nᵏ)，忌指数阶。

### 递归式求解示例

- T(n)=T(n-1)+O(1) → O(n)（线性递归）
- T(n)=2T(n/2)+O(n) → O(n log n)（归并排序）：递归树共 log n 层，每层合计工作量 n
- T(n)=T(n/2)+O(1) → O(log n)（二分查找）
- T(n)=2T(n/2)+O(1) → O(n)（二叉树遍历）

### 空间复杂度

`S(n)=O(f(n))`，n 为问题规模。程序存储需求含：指令/常数/变量/输入数据 + 操作工作单元 + 辅助空间。若输入空间只取决于问题本身，则只分析额外辅助空间。依赖特定输入时按最坏分析。

### 估算结合实例

10×10 矩阵相乘 12ms，由 T(n)=O(n³) 估算 31×31 约 (31/10)³×12 ≈ 358ms。

## 五、易错点与常考辨析

- **三义完整性**：回答"数据结构"须含逻辑结构+存储结构+运算三方面，只答前两者不完整。
- **逻辑 vs 存储**：同一逻辑结构可多种存储；逻辑独立于计算机，存储依赖计算机。
- **数据类型 vs ADT**：ADT 范畴更广（含用户自定义）；强调数学抽象与实现无关（封装/信息隐蔽）。
- **确定性 vs 有穷性**：确定性 = 指令无二义+同输入同输出+路径唯一；有穷性"有穷"是实际可接受而非纯数学。算法必须有穷，程序不一定（如操作系统）。
- **时间复杂度含义**：只反映增长率，与语言/编译器/机器无关；O 记号是渐进上界非精确时间。
- **最好/最坏/平均区分**：冒泡最好(正序)交换0次但仍比较 n-1 次 → O(n)；最坏(逆序) O(n²)；区分"次数"与"阶"；考试默认最坏。
- **顺序 vs 链式常见误区**：顺序随机访问 O(1) 但插删 O(n)；链式插删 O(1)（已知位置后）但访问 O(n)；顺序需连续空间可能浪费/溢出，链式有指针开销。
- **N×N 矩阵相乘**：三重循环基本操作（乘法）n³ 次 → O(n³)，是"基本操作在最深层循环内"的经典示例。
