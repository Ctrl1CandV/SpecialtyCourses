## 一、核心概念与定义

### 线性结构的特点
在数据元素的**非空有限集**中：①存在唯一的"第一个"元素；②存在唯一的"最后一个"元素；③除第一个外每个元素均只有一个直接前驱；④除最后一个外每个元素均只有一个直接后继。第2~4章的线性表、栈、队列、串均属线性结构。

### 线性表定义
- **线性表(linear list)**：n(n≥0)个数据元素的**有限序列**，记作 (a₁, …, aᵢ₋₁, aᵢ, aᵢ₊₁, …, aₙ)，是最常用、最简单的一种数据结构。
- **逻辑特征**：有限、有序、一对一。aᵢ₋₁ 领先于 aᵢ，aᵢ 领先于 aᵢ₊₁；称 aᵢ₋₁ 是 aᵢ 的**直接前驱**，aᵢ₊₁ 是 aᵢ 的**直接后继**。i=1,…,n−1 时 aᵢ 有且仅有一个直接后继；i=2,…,n 时 aᵢ 有且仅有一个直接前驱。同一表中元素必属同一数据对象（相同特性），相邻元素间存在序偶关系。
- **长度**：元素个数 n(n≥0)；n=0 时为**空表**。
- **位序**：aᵢ 是第 i 个数据元素，称 i 为 aᵢ 的位序（**从1开始**），区别于数组下标（从0开始）。
- 数据元素可由若干**数据项(item)**组成，此时称元素为**记录(record)**；含大量记录的线性表又称**文件(file)**。线性表长度可增可减，元素可访问、插入、删除。

### ADT List（抽象数据类型）
- **数据对象**：D = {aᵢ | aᵢ∈ElemSet, i=1,2,…,n, n≥0}
- **数据关系**：R1 = {<aᵢ₋₁, aᵢ> | aᵢ₋₁, aᵢ∈D, i=2,…,n}（元素间存在唯一的序偶先后关系）
- **12个基本操作**：`InitList(&L)` 构造空表；`DestroyList(&L)` 销毁 L；`ClearList(&L)` 重置为空表；`ListEmpty(L)` 空表返 TRUE；`ListLength(L)` 返回元素个数；`GetElem(L,i,&e)` 返回第 i 个元素值(1≤i≤表长)；`LocateElem(L,e,compare())` 返回第1个满足 compare() 的元素位序，不存在返0；`PriorElem(L,cur_e,&pre_e)` 返回前驱；`NextElem(L,cur_e,&next_e)` 返回后继；`ListInsert(&L,i,e)` 在第 i 位**之前**插入 e(1≤i≤表长+1)；`ListDelete(&L,i,&e)` 删第 i 个元素并 e 返回(1≤i≤表长)；`ListTraverse(L,visit())` 依次对每元素调用 visit()。

> 更复杂操作（合并、拆分、复制）可由基本操作组合实现。

## 二、存储结构与分类

线性表有两种物理存储：**顺序存储**（顺序表）与**链式存储**（链表）。链式又细分单链表、循环链表、双向链表、静态链表。

### 1. 顺序表（顺序存储结构）
- 用一组**地址连续**的存储单元依次存储数据元素。设每元素占 l 个存储单元，以第一个单元地址作元素存储位置，则 **LOC(aᵢ) = LOC(a₁) + (i−1)×l**（来历：相邻元素 aᵢ 与 aᵢ₊₁ 存储位置相差 l，逐次累加即得）。LOC(a₁) 称为**起始位置/基地址**。
- 特点：逻辑相邻 → 物理相邻，元素位置与基地址之差与位序成正比。**只要确定基地址，任一元素都可随机存取**，故顺序存储是**随机存取**结构，取第 i 个元素 O(1)。
- C语言用**动态分配一维数组**描述（长度可变、最大空间随问题而异）：`typedef struct { ElemType *elem; int length; int listsize; } SqList;`——elem 为基址，length 为当前长度，listsize 为当前分配容量（以 sizeof(ElemType) 为单位）。初始 LIST_INIT_SIZE=100，增量 LISTINCREMENT=10。
- **初始化**：malloc 分配 LIST_INIT_SIZE 空间，length=0，listsize=LIST_INIT_SIZE；失败 exit(OVERFLOW)。
- **扩容**：插入时若 length≥listsize（空间不足），realloc 增加 LISTINCREMENT 个元素空间，更新 elem 新基址与 listsize。
- 注意：第 i 个元素是 `L.elem[i-1]`。

### 2. 单链表（线性链表）
- 特点：用一组**任意**（可连续可不连续）的存储单元存储元素；为表示 aᵢ 与其直接后继的逻辑关系，除存 aᵢ 本身信息外还需存其直接后继的位置。**结点(node)** = 数据域(data) + 指针域(next，存直接后继位置，即"指针/链")。n 个结点链结成**链表**；每结点仅一个指针域，故称**线性链表/单链表**。结构：`typedef struct LNode { ElemType data; struct LNode *next; } LNode, *LinkList;`
- **头指针**：指示第一个结点位置，单链表由头指针唯一确定；最后一个结点指针为 NULL。
- **头结点**：在第一个结点前附设的结点，数据域可不存信息或存表长等附加信息，指针域指向首元结点（此时头指针指向头结点）。
  - **头结点作用（常考）**：①统一空表与非空表的处理（带头结点空表判定 `L->next==NULL`，头指针仍非空）；②使首元结点的插入/删除与其他位置一致，无需特殊化（否则表头操作要单独改头指针）。
- 因任何两元素存储位置无固定联系，取第 i 个元素必须从头指针顺链寻找，故单链表是**非随机存取**结构，按序号查找 O(n)。
- 单链表是**动态结构**：可用空间可为多链表共享、按需即时生成，不需预先划定。

### 3. 循环链表
- 表中**最后一个结点的指针域指向头结点**，整个链表形成一个环；从任一结点出发均可找到其他结点。
- 操作与线性链表基本一致，差别仅在**循环终止条件**：不是判断 `p==NULL` 或 `p->next==NULL`，而是判断**是否等于头指针** `p==L`。
- **仅设尾指针不设头指针**可简化某些操作：如合并两个循环链表（一个表尾接另一个表头），仅需改变两个指针值，运算时间 **O(1)**。

### 4. 双向链表
- 结点含两个指针域：prior 指向直接前趋、next 指向直接后继（克服单链表**单向性**：单链表 NextElem O(1) 但 PriorElem 需从头遍历 O(n)）。结构：`typedef struct DuLNode { ElemType data; struct DuLNode *prior, *next; } DuLNode, *DuLinkList;`；**核心等式** `d->next->prior = d->prior->next = d`。
- ListLength/GetElem/LocateElem 只涉及一个方向指针，算法同单链表；但**插入/删除需同时修改两个方向的指针**，定位仍 O(n)。双向循环链表可含两个环，空表（只有头结点）时头结点 prior 与 next 均指向自身。
- **插入指针修改顺序**（在 p 所指结点前插 s）：`s->prior=p->prior; p->prior->next=s; s->next=p; p->prior=s;`——必须先完成 s 与前后结点的链接，**最后才能改 p->prior**（否则丢失 p 的前驱）。
- **删除指针修改**（删 p）：`p->prior->next=p->next; p->next->prior=p->prior; free(p);`。

### 5. 静态链表
- **借用一维数组描述链表**，便于在不设"指针"类型的语言中使用链表结构：`typedef struct { ElemType data; int cur; } component, SLinkList[MAXSIZE];`（MAXSIZE=1000，cur 为游标）。
- 数组一个分量表示一个结点，用**游标 cur 代替指针**；数组第0分量可看作头结点，`S[0].cur` 指示第一个结点位置。`i=S[i].cur` 相当于 `p=p->next`（指针后移）。
- 仍需预分配较大空间，但**插入删除不需移动元素，仅修改游标**，保留链式存储的主要优点。
- 需用户自行实现 malloc/free：将未使用及被删除的分量用游标链成**备用链表**；插入时从备用链表取结点，删除时将结点回收链回备用链表。

## 三、关键性质与结论

### 顺序表平均移动次数的推导（等概率）
顺序表插删的时间主要耗费在**移动元素**上（移动个数是预估复杂度的基本操作），取决于插删位置。

**① 插入——平均移动 n/2**：在第 i 个元素前插入，需将第 n 至第 i 个（共 **n−i+1** 个）元素后移一位。设 pᵢ 为在第 i 位前插入的概率，i 取值 1~n+1（共 **n+1 个可插入位置**），则 E_ins = Σpᵢ(n−i+1)。等概率 pᵢ=1/(n+1) 时：**E_ins = (1/(n+1))·Σ(n−i+1) = (1/(n+1))·[n(n+1)/2] = n/2**（因 n−i+1 随 i 从1到n+1 取 n,n−1,…,0，求和 = n(n+1)/2）。

**② 删除——平均移动 (n−1)/2**：删除第 i 个元素，需将第 i+1 至第 n 个（共 **n−i** 个）元素前移一位。设 qᵢ 为删除第 i 个的概率，i 取值 1~n（共 **n 个可删除位置**），则 E_del = Σqᵢ(n−i)。等概率 qᵢ=1/n 时：**E_del = (1/n)·Σ(n−i) = (1/n)·[n(n−1)/2] = (n−1)/2**（因 n−i 随 i 从1到n 取 n−1,…,0，求和 = n(n−1)/2）。

**③ 按值查找（成功）——平均比较 (n+1)/2**：顺序查找第 i 个元素需比较 i 次，等概率 1/n，Σ(i/n)=(n+1)/2；LocateElem_Sq 复杂度 O(length)（找到比较 i 次，未找到比较 length 次）。

**结论汇总**（等概率）：插入（n+1 个位置）**n/2**、删除（n 个位置）**(n−1)/2**、按值查找成功 **(n+1)/2**，均为 O(n)；即插删一个元素平均约移动表中**一半**元素。

### 顺序表 vs 链表（全面对比）

| 维度 | 顺序表 | 链表 |
|------|--------|------|
| 存取方式 | **随机存取** O(1) | **顺序存取**，按序号查找 O(n)、求表长 O(n) |
| 逻辑↔物理 | 逻辑相邻 → 物理相邻 | 指针表示逻辑关系，物理位置任意 |
| 插入/删除 | 需移动约一半元素 O(n) | 已知位置改指针 O(1)，但**定位第 i−1 结点须遍历 O(n)** |
| 空间开销 | 无额外指针域；预分配可能浪费 | 每结点多存指针域；动态分配不浪费 |
| 适用场景 | 频繁按位访问、少插删 | 频繁插删、长度变化大、不宜预分配 |

> 链式存储因空间合理利用与插删不移动元素，在很多场合是首选存储结构；缺点是求表长不如顺序表，"位序"被"位置"淡化。

### 集合运算复杂度
- `union(La,Lb)`（把 Lb 中不在 La 的元素插入 La）：对 Lb 每个元素在 La 中查访，**O(La_len × Lb_len)**；而两有序表归并 `MergeList` 仅 **O(La_len + Lb_len)**（含3个 while 但后两个只执行其一）。

## 四、核心算法思想

> 完整代码见 知识笔记/代码总结.md，此处给分步骤思想。

### 1. 顺序表插入 ListInsert_Sq（第 i 位前插 e）
思想：逻辑相邻即物理相邻，插入须后移元素腾位。步骤：①验证 1≤i≤length+1 否则 ERROR；②若 length≥listsize（空间满）realloc 扩容；③将第 n 至第 i 个元素（从表尾到插入位）依次后移一位；④elem[i-1]=e；⑤length++。复杂度 O(n)。

### 2. 顺序表删除 ListDelete_Sq（删第 i 个，e 返回）
①验证 1≤i≤length；②e=elem[i-1]；③将第 i+1 至第 n 个元素依次前移一位；④length--。复杂度 O(n)。

### 3. 单链表按序号查找 GetElem_L
思想：从头指针顺链后移，计数器 j 比对位序。①p=L->next（指首元），j=1；②while(p && j<i){p=p->next;++j;}；③若 !p 或 j>i 返 ERROR（第 i 个不存在）；④e=p->data。复杂度 O(n)。

### 4. 单链表第 i 位前插 ListInsert_L
思想：在第 i 位前插须先找到**第 i−1 个结点** p（需改指针的结点）。①p=L,j=0，while(p && j<i−1) 后移找第 i−1 结点；②若 !p 或 j>i−1 返 ERROR；③s=malloc，s->data=e；④`s->next=p->next; p->next=s;`（**顺序不可颠倒**）。复杂度 O(n)（瓶颈在定位）。
- **前插 vs 后插**：已知 p 指向 a，在 a **后**插 x 只需 `s->next=p->next; p->next=s`（O(1)）；在 a **前**插则须先定位 a 的前驱（O(n)）。

### 5. 单链表删除第 i 个 ListDelete_L
①找第 i−1 结点 p（while p->next && j<i−1）；②若 !(p->next) 或 j>i−1 返 ERROR；③q=p->next（待删）；④`p->next=q->next`；⑤e=q->data；⑥free(q)。复杂度 O(n)。

### 6. 单链表按值查找与求表长
- **按值查找**：p=L->next，顺链比较 p->data==e，命中返回位序/位置，至尾(NULL)未命中返回失败。O(n)。
- **求表长**：p=L->next, count=0；while(p){count++; p=p->next;}；返回 count（**头结点不计**）。从头到尾遍历计数 O(n)（链表长度隐含，不能像顺序表 O(1) 取得）。

### 7. 头插法建表 CreateList_L（逆位序输入）
思想：新结点始终插在头结点之后，故输入序列与链表序列**逆序**。①L=malloc 建头结点，L->next=NULL；②循环 n 次：p=malloc；scanf(p->data)；`p->next=L->next; L->next=p;`。复杂度 O(n)。
- **尾插法**（正序建表）：需设**尾指针 r** 始终指向当前表尾，新结点接在 r 后并更新 r，最后 r->next=NULL。避免每次尾插都从头遍历（否则 O(n²)）。

### 8. 有序链表归并 MergeList_L（La+Lb→Lc，非递减）
思想：摘取两表结点重链，不另建空间。①pa=La->next, pb=Lb->next；Lc=pc=La（**用 La 的头结点作 Lc 头结点**）；②while(pa && pb)：比较 data，小者链到 pc 后（pc 与对应指针后移）；③一表空后 `pc->next=pa?pa:pb` 直连剩余段；④free(Lb) 释放 Lb 头结点。复杂度 O(m+n)。

### 9. 一元多项式表示与相加 AddPolyn
**表示**：一元 n 次多项式 Pₙ(x)=p₁x^e₁+…+pₘx^eₘ（0≤e₁<…<eₘ=n），只存**非零项**，用有序链表，每结点含 coef(系数)+expn(指数)：((p₁,e₁),…,(pₘ,eₘ))。选择：**仅求值**→顺序存储；**加减乘**等改变结构→链式存储（避免如 S(x)=1+3x^10000+2x^20000 用长度20001顺序表浪费空间）。

**相加**（和多项式结点从两链表摘取，无需另生成）：qa/qb 指向 A/B 当前结点，比较指数分三种：①qa 指数<qb：摘 qa 插入和多项式，qa 后移；②qa>qb：摘 qb 插入，qb 后移；③相等：系数相加，和≠0 则改 qa 系数、释放 qb，和=0 则从 A 删除 qa 并释放 qa、qb。一表完后链另一表剩余段，释放 B 头结点（与归并两有序表极相似）。O(项数之和)；相乘可分解为一系列加法。

## 五、易错点与常考辨析

### 基础辨析
1. **位序 vs 下标**：第 i 个元素 = elem[i-1]；插入合法 i∈[1,n+1]，删除合法 i∈[1,n]。
2. **插入 n/2 ≠ 删除 (n−1)/2**：插入 n+1 个位置、删除 n 个位置，勿混；按值查找成功为 (n+1)/2。
3. **头结点 ≠ 头指针**：头指针指向头结点（或首元结点）；带头结点空表判定 `L->next==NULL`，头指针本身非空。
4. **单链表插删 O(n) 的瓶颈**：是"定位第 i−1 结点须从头遍历"，而非指针修改本身（改指针仅 O(1)）；插入两句 `s->next=p->next; p->next=s` 不可颠倒，否则丢链。
5. **循环链表遍历终止**：判断 `p==L`（回到头指针）而非 `p==NULL`。
6. **静态链表**：虽用数组描述，逻辑上仍是链表，插删**不移动元素**只改游标；游标 0 表空指针；须自管备用链表。
7. **链式归并不另建空间**（原地摘取结点重链）；顺序表归并需 malloc 新数组存 Lc。
8. **多项式存储选择**：仅求值→顺序存储；加减乘改变结构→链式存储（省空间）。

### 常考应用题（给思想）
9. **单链表就地逆置**：依次摘下原表结点用**头插法**重插入头结点后实现逆序。时间 O(n)，**空间 O(1)**（原地不新建结点）。
10. **找倒数第 k 个结点**：**快慢指针**。fast 先走 k 步，然后 fast、slow 同步后移；fast 到表尾(NULL)时 slow 即倒数第 k 个。一趟遍历 O(n)，无需先求表长。
11. **约瑟夫环**：n 人围圈报数，报到 m 者出列，从下一人重报。用**循环链表**模拟（常不带头结点或用尾指针），删除出列结点并继续，直到全部出列。
12. **两链表公共后缀结点**：先分别求两表长，长表指针先走长度差步，再同步后移，第一个相同结点即公共后缀起点（Y 形相交）。O(m+n)。
13. **有序链表合并**：见四.8 MergeList_L，摘取重链、不另建空间、余段直连、释放多余头结点。
