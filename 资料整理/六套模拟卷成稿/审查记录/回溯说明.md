## 重建与核验

在仓库根目录、安装所需Python依赖后运行：

```powershell
python tools/exam_blueprint.py --write
python tools/build_exam_papers.py --build --render
python tools/build_answer_figures.py
python tools/build_exam_answers.py --render
```

以上会重建PDF；修改后需要重新审查变动页与答案，并更新独立报告的版本哈希，之后才运行：

```powershell
python tools/package_exam_delivery.py
python tools/verify_exam_delivery.py
```

构建依赖包括reportlab、pypdf、pypdfium2、Pillow；字体使用Windows宋体/黑体和等宽字体，详见工具脚本。跨机器运行需调整字体和C编译器路径。重建PDF的二进制哈希可能因生成时间改变，不应仅刷新哈希就视作内容复核完成。

验算源文件ZIP使用仓库相对路径，解压到仓库根目录恢复`_tmp/exam_final/`后运行。脚本中可能记录本工作机的Python/GCC路径，异机需相应修改。旧v5验算档案只证明对应历史版本，不能替代当前检查。

原题库未修改；历史快照、命题依据、源稿、独立审查记录和验算源文件保留。临时exe/dll、重复渲染PNG和编译缓存清理。独立审查记录保留每题结论与已解决问题，困难度与作答时间仍待限时试做校准。
