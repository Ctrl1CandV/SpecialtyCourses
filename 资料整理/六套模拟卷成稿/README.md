## 结构与定位

每套24题、150分、180分钟：程序阅读4×5分，填空10×3分，综合应用7×10分，算法设计8、10、12分。第一至三套保守，第四至六套适度创新。算法题统一要求基本思想、C实现、时间与辅助空间复杂度。
