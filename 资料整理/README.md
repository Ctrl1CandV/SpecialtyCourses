## 资料登记原则

登记粒度按资料价值和后续用途确定：

1. 历年真题、正式考纲、官方参考书目、主库、核心答案等资料，记录来源、年份、专业课代码、版本和文件位置。
2. 辅导书题库、章节题等大量同类材料，优先按“来源＋版本＋章节或页码范围”登记批次，不要求给每道题补齐完整来源描述。
3. 只有准备选入或改编成模拟卷、答案不一致、识别有疑问、可能重复、考纲边界不明的题目，才单独追踪题号和原页。
4. 可信度只用于会影响考纲判断或成卷正确性的关键资料。普通练习题不做形式化评分；存疑时标成“待核”并说明原因。
5. 原始 PDF 和现有数据库不在整理阶段移动、覆盖或删除。数据库导出文件是只读视图，数据库本身为结构化主库。
