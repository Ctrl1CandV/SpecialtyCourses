## 换电脑审阅与继续修改

更新到本次提交后，直接从[C3九节课程](课程/课件/C3/README.md)和[三套押题卷](试卷/2027押题卷/README.md)打开PPT、PDF及对应讲稿。打开和录制不依赖本机的Codex运行库、编译器或临时目录；课件字体为Microsoft YaHei和Consolas，建议使用已安装这两种字体的电脑。

设计取舍、题源、排除范围和审查结果保存在现有设计文档、各课讲稿“课前准备”、套卷README及JSON的basis/guide中。旧方案保留在课程历史参考和Git历史，不需要恢复临时截图、编译文件或旧ZIP。

后续反馈请标明课程节次与PPT页码（如`C3-B-04 P7`），或套卷题号（如`P2-III07`），并附问题描述。新C3同步修改deck与逐页讲稿后按专用工具重建；押题卷先改JSON，再统一生成试卷、答案与讲解，复核后更新指纹。若直接手改PPT，请明确说明，重建前先保留并同步手改内容。

可从项目根目录运行`python -B tools/verify_current_delivery.py`，只用Python标准库检查本次九课三件套、三份题源、六份PDF及历史排版存档与记录是否一致；发现差异只报告，不覆盖文件。制作依赖和替换本机工具路径的方法见[工具入口](tools/README.md)。

## 保存约定

- 主体内容只归入上述五类；相关设计、源稿、成品和审查记录跟随所属课程或套卷。
- PDF/PPTX是交付物；必要的JSON/YAML、配图和脚本是维护源。源稿与成品分开存放，不在交付区堆放过程文件。
- 不长期保留重复ZIP和调试截图。临时输出统一写入被Git忽略的`_tmp/`，不得把唯一源文件放进去。
- 历史审查JSON保留原字节和旧路径，通过[目录迁移表](tools/目录迁移.csv)解析，避免改坏既有内容哈希。
- 清理旧临时区时保全的[2026-10-04历史排版结果](资料/历史参考/2026-10-04排版导出/)随Git同步；本机同步恢复补丁与旧工具只留在被忽略的`资料/历史参考/本地恢复/`，不是当前交付依赖。
- 目录重构已保存于提交`03f5b81`；搬迁时的检查结果见[目录整理记录](tools/目录整理记录.md)，后续提交状态以Git为准。
