## 保存约定

- 主体内容只归入上述五类；相关设计、源稿、成品和审查记录跟随所属课程或套卷。
- PDF/PPTX是交付物；必要的JSON/YAML、配图和脚本是维护源。源稿与成品分开存放，不在交付区堆放过程文件。
- 不长期保留重复ZIP和调试截图。临时输出统一写入被Git忽略的`_tmp/`，不得把唯一源文件放进去。
- 历史审查JSON保留原字节和旧路径，通过[目录迁移表](tools/目录迁移.csv)解析，避免改坏既有内容哈希。
