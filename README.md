## C2/C3 单节制作的最短阅读路径

依次读 `课程设计/课件制作SKILL.md` → 当前节所在的 `课程设计/C2-A课程内容设计.md`、`C2-B课程内容设计.md` 或 `C3课程内容设计.md`（只读当前节）→ `知识笔记/代码总结.md`、`知识笔记/重邮数据结构.md` 的相关章节及命中的 `课程设计/C2C3缺口代码与勘误修正.md` → `tools/CONTENT-SPEC.md`。选题时先读 `题库数据库/README.md`，只查与当前考点相关的候选题并核对原页、答案及存疑记录；不遍历题库。写作时从 `课程设计/AI味语料库/02-积极案例/主讲笔记样本.md` 与 `01-消极案例/消极案例总台账.md` 各看一个相关例子；需要判断讲稿与实讲关系时再看 `04-讲稿对照/` 的两份报告，不读完整转写。

`课程设计/课程设计总体框架.md` 供查课段边界；`课程设计/授课反思与改进清单.md` 只查命中的历史勘误；`课程设计/授课技法指南.md` 是解释资料。一次性实施方案、题库建设方案与已完成的题集工作流是历史/专用资料，**不是每节必读，更不应重复执行其中的实施提示**。勘误口径以 `C2C3缺口代码与勘误修正.md` 中较新的逐项结论为准；保留主讲笔记原貌。

## 课件生产架构（内容与渲染分离）

```
内容AI ──产出──> deck.yaml（讲什么） + 讲稿.md
                       │
                       ▼
渲染引擎 render-pptx.js（怎么摆，样式唯一权威）
                       │
                       ▼
                  课程名.pptx（交付物，带机构底图）
```

- 内容侧只写结构化内容（页型/标题/表格/代码），**不碰样式**；
- 渲染侧统一版式（16:9、三色制、顶部安全区、页脚页码），**不改内容**；
- 规范详见 `tools/CONTENT-SPEC.md`。

## 快速命令

```powershell
cd tools
npm install                                        # 首次：安装依赖
node render-pptx.js "..\课件\C1\C1-A-01\deck.yaml" # 渲染单节课
# 只对未封存课节运行单节检查；check 会重渲染目标 pptx
node check.js "..\课件\C2\<未封存节次>"
```
