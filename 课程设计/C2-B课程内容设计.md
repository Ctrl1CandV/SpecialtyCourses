### 知识点与关键代码

**改指针的三条规矩**（本页是整节的方法论，后面每个算法都回来对照）：

1. **先接后断**：新结点的指针先接好，再改前驱的指针。反过来写，后面的链就找不到了。
2. **画图再写**：任何改指针的操作先在纸上画出改之前与改之后的两张图，再照着图写代码。C1-B 六节课练的就是这个。
3. **改完检查孤立结点**：问一句"有没有哪个结点没有人指向它了"。有就是漏了一句赋值。

**原地逆置（普通单链表）**（材料原文）：

```c
void InvertedList(LinkList &L){
    if(L == NULL || L->next == NULL) return;
    LNode *p = L->next, *temp;
    L->next = NULL;                       // 先断成空表
    while(p != NULL){
        temp = p;                         // 摘下当前结点
        p = p->next;                      // 先存后继（否则下一步找不到）
        temp->next = L->next;             // 头插
        L->next = temp;
    }
}
```

思想一句话：把链断开成"空表 + 一串待处理的结点"，然后逐个用头插法插回空表，头插天然反序。四行的次序是重点：`temp = p` 摘下、`p = p->next` 先存后继、两句头插。空间 O(1)（没有新结点），时间 O(n)。

**循环单链表逆置**（材料原文）：与普通版差两处——终止条件是 `p != L`（不是 `p != NULL`），循环结束后要 `rear->next = L` 把环接回去。rear 在循环开始前记下（就是原来的第一个结点，逆置后它变成尾结点）。

**倒数第 k 的方法一：快慢指针**（材料原文）：

```c
int findK(LinkList &L, int k){
    LNode *p = L, *q = L;
    while(k != 0 && q != NULL){ q = q->next; k--; }   // q 先走 k 步
    if(q == NULL) return 0;                            // k 超过表长
    while(q != NULL){ q = q->next; p = p->next; }      // 两个一起走
    printf("%d", p->data);
    return 1;
}
```

思想：q 先走 k 步，然后 p 与 q 同步走，q 到表尾时 p 恰好落后 k 个结点。**p 与 q 都从头结点 L 出发**，这是这个写法能对上"倒数第 k 个数据结点"的关键：头结点算作一个位置，正好抵消掉。时间 O(n) 一趟，空间 O(1)。这是 2025 年真题第 1 题。

**倒数第 k 的方法二：辅助栈**（材料原文）：全部结点压栈，弹出 k 次，第 k 次弹出的就是。时间 O(n)，空间 O(k)。两法对比要讲：快慢指针空间更省，辅助栈的思路更直白且能处理"倒数第 k 到倒数第 1 全部输出"这类变体。

**条件删除（前驱跟随）**：删除满足某条件的结点，必须记住前驱，因为单链表没有 prior。

```c
void DeleteIf(LinkList &L, int x){          // 删除所有大于 x 的结点（示例条件）
    LNode *pre = L, *p = L->next, *temp;
    while(p != NULL){
        if(p->data > x){
            temp = p;
            pre->next = p->next;            // 摘掉 p
            free(temp);
            p = pre->next;                  // p 从 pre 后面重新取，pre 不动
        }else{
            pre = p; p = p->next;           // 不删时两个一起走
        }
    }
}
```

**p 什么时候不能动**是本页的重点：删除时 pre 停在原地，p 从 `pre->next` 重新取，因为下一个待检查的结点现在紧跟在 pre 后面。如果删除后还写 `pre = p`，就会跳过下一个结点。2021 年真题第 2 问的第三小问（删除比 x 大的正偶数）就是这个模板，材料的解答里专门注释了"只有不删除下一个元素的时候才移动 p"。

**交换相邻两个结点**（材料原文，双链表版）：

```c
void exchange(DNode *p, DNode *q){          // 前提：q 紧跟 p，且 p 有前驱、q 有后继
    p->prior->next = q;      // ① 先把外部两端接好
    q->next->prior = p;      // ②
    p->next = q->next;       // ③ 再改 p、q 自身
    q->prior = p->prior;     // ④
    p->prior = q;            // ⑤ 最后互指
    q->next = p;             // ⑥
}
```

六条赋值的次序原则：**先用旧指针把外部接好，最后再改 p、q 自身的互指**。因为 ⑤⑥ 一执行，p->prior 与 q->next 的旧值就没了，①② 再也写不出来。这个原则和 A4 双链表插入的"③ 必须在 ④ 前"是同一条道理，讲的时候点一句"还是先接后断"。

### 推演与动画

三个动画页。P7 普通逆置：三个结点 A、B、C，逐步画 `L->next = NULL` 之后的四次头插，每步一张图。P12 条件删除：一个含 5 个结点的表，删除两个满足条件的，逐步画 pre 与 p 的位置，特别画出"删除后 pre 不动、p 重新取"那一帧。P13 之后可加一帧交换相邻结点的六步（若页数紧张，改为口播逐步、页面上只放六条赋值）。

### 设问清单

1. 原地逆置为什么第一句是 `L->next = NULL`？（把链断成空表，才能逐个头插）
2. 逆置循环里为什么先写 `p = p->next` 再头插？（头插会改掉 temp->next，先存后继才找得到下一个）
3. 快慢指针法里 p 与 q 为什么都从 L 出发而不是从 L->next？（头结点算一个位置，正好抵消）
4. k 大于表长时怎么发现？（q 先走 k 步的过程中变成 NULL）
5. 条件删除时删掉一个结点后 pre 要不要动？（不动，p 从 pre->next 重新取）
6. 交换相邻结点的六条赋值里，哪两条必须最后做？（⑤⑥ 互指，做了之后旧值就丢了）

### 易错与误解破除

- 逆置时忘了先存后继，头插之后找不到下一个结点。
- 循环链表逆置还用 `p != NULL` 做终止条件（A4 讲过，这里再撞一次）。
- 快慢指针法里两个指针起点不一致，导致结果差一个位置。
- 条件删除后 `pre = p`，跳过了下一个待检查的结点。
- 删除时先 free 再改 pre->next：读的是已回收内存。

### 知识点与关键代码

**归并两个递增表为递减表**（材料原文）：

```c
bool Union(LinkList &la, LinkList lb){
    if(la == NULL || lb == NULL) return false;      // 任一为空就不能解引用，必须用 ||
    LNode *pa = la->next, *pb = lb->next;
    la->next = NULL;                                // 以 la 的头结点作为新表
    while(pa != NULL && pb != NULL){
        LNode *temp;
        if(pa->data <= pb->data){ temp = pa; pa = pa->next; }
        else{ temp = pb; pb = pb->next; }
        temp->next = la->next;                      // 头插：自然反序
        la->next = temp;
    }
    while(pa != NULL){ LNode *temp = pa; pa = pa->next; temp->next = la->next; la->next = temp; }
    while(pb != NULL){ LNode *temp = pb; pb = pb->next; temp->next = la->next; la->next = temp; }
    free(lb);                                       // lb 的头结点已无用
    return true;
}
```

材料的思路要点原话值得直接念给学生：**归并成递减表，用头插即可自然反序，不需要先归并再逆置**。这是"递增表归并成递减表"这一类题的通用套路。递增版与递减版的差别只有一处：递增版用尾插（要 rear 指针），递减版用头插（不需要 rear）。这个对比是本页的核心。

三个细节：判空必须用 `||`（任一为空就不能解引用）；两个收尾循环处理剩下的那一段；`free(lb)` 释放的是 lb 的头结点（它的数据结点已经被摘走了）。

**408-2019 重排**（材料原文，三步）：题目是把 L=(a1,a2,...,an) 重排成 L'=(a1,an,a2,an-1,...)，要求空间 O(1)。

```c
void Reorder(NODE *head){
    if(head == NULL || head->next == NULL || head->next->next == NULL) return;
    // 第一步：快慢指针找中点
    NODE *slow = head->next, *fast = head->next;
    while(fast != NULL && fast->next != NULL){ slow = slow->next; fast = fast->next->next; }
    // 第二步：断开并逆置后半段
    NODE *second = slow->next, *p = second->next;
    slow->next = NULL;
    while(p != NULL){ NODE *temp = p->next; p->next = second->next; second->next = p; p = temp; }
    // 第三步：交替插入
    NODE *first = head->next;
    while(second != NULL){
        NODE *temp1 = first->next, *temp2 = second->next;
        second->next = temp1; first->next = second;
        first = temp1; second = temp2;
    }
}
```

讲法：先说清三步各用什么模板（第一步模板 2 快慢指针，第二步模板 1 头插逆置，第三步是新动作"交替插入"），再逐步走。快慢指针的终止条件 `fast != NULL && fast->next != NULL` 决定了偶数个结点时 slow 停在前半段的最后一个，这是第三步能交替的前提。

**约瑟夫环**（经典问题；材料在真题汇总里给了完整解答，本题不展开题面与分值，那是 C3-B-01 的事）：

```c
int Josephus(int n, int s, int m){
    // 建立循环单链表，结点编号 1~n（注意：这里不用头结点，材料原文如此）
    LNode *head = (LNode*)malloc(sizeof(LNode));
    head->data = 1;
    LNode *r = head;
    for(int i = 2; i <= n; i++){
        LNode *p = (LNode*)malloc(sizeof(LNode));
        p->data = i; r->next = p; r = p;
    }
    r->next = head;                                  // 成环
    // 从第 s 个结点开始报数
    LNode *p = head, *pre = r;
    while(p->data != s){ pre = p; p = p->next; }
    // 报数到 m 出列，直到只剩一个
    while(p->next != p){
        for(int i = 1; i < m; i++){ pre = p; p = p->next; }
        pre->next = p->next;                         // 摘除 p
        free(p);
        p = pre->next;
    }
    return p->data;
}
```

四个要点：① 这道题**不带头结点**（材料原文用 head 存 1 号），要在页面上说明"题目没要求头结点，这里直接拿第一个数据结点当起点"，与 A3 的默认约定形成对照；② 成环那句 `r->next = head`；③ 定位到第 s 个时要同时维护 pre（因为摘结点需要前驱）；④ 只剩一个结点的判定是 `p->next != p`（自己指向自己）。时间 O(nm)，空间 O(n)。

**稀疏多项式奇偶分解**（2022 真题，缺口 14，补写版）：题目要求把循环链表表示的稀疏多项式分解成两个链，各自只含奇次项或偶次项，并且**利用原链表中的结点空间**（不许新 malloc）。

```c
// PolyNode 定义见题目：float coef; int exp; struct PolyNode *next;
void SplitPoly(PolyNode *L, PolyNode *&odd, PolyNode *&even){
    odd  = (PolyNode*)malloc(sizeof(PolyNode));  odd->next  = odd;   // 两个新头结点，各自成环
    even = (PolyNode*)malloc(sizeof(PolyNode));  even->next = even;
    PolyNode *p = L->next, *temp;
    while(p != L){
        temp = p->next;
        if((int)p->exp % 2 == 0){                     // 偶次项接到 even 链
            p->next = even->next; even->next = p;
        }else{                                        // 奇次项接到 odd 链
            p->next = odd->next;  odd->next  = p;
        }
        p = temp;
    }
    free(L);                                          // 原头结点已无用
}
```

要点：① "利用原结点空间"意味着只新建两个头结点，数据结点全部是从原链上摘下来的；② 摘结点前必须先存后继（`temp = p->next`），否则改指针之后找不到下一个；③ 用头插接到两个新链上，顺序会反，如果题目要求保持原顺序就改用尾插（要维护两个 rear）；④ 原头结点 free 掉。这道题的完整解答在材料里没有，是缺口 14，补写版同时收在 `C2C3缺口代码与勘误修正.md` 第 14 项，C3-B-02 讲这道真题时直接用。

**括号匹配**（缺口 4 补写）：

```c
bool BracketMatch(char str[], int n){
    SqStack S; InitStack(S);
    for(int i = 0; i < n; i++){
        if(str[i]=='(' || str[i]=='[' || str[i]=='{') Push(S, str[i]);
        else if(str[i]==')' || str[i]==']' || str[i]=='}'){   // 只拦右括号，其他字符跳过
            if(IsEmpty(S)) return false;            // 右括号多了
            char top; Pop(S, top);
            if((top=='(' && str[i]!=')') || (top=='[' && str[i]!=']') || (top=='{' && str[i]!='}'))
                return false;                        // 类型不匹配
        }
    }
    return IsEmpty(S);                               // 栈非空说明左括号多了
}
```

三种失配情况要分开讲：扫描中栈空却遇到右括号（右多了）、弹出的左括号与当前右括号类型不符（交叉了，例如 `[(])`）、扫描结束栈非空（左多了）。最后 `return IsEmpty(S)` 一句同时处理了第三种。**分支必须写成 `else if` 只拦右括号，不能写 `else`**：写 `else` 会把字母、数字、运算符也当成右括号，输入 `a+(b*c)` 这种带操作数的表达式就会误判失配。这一处当反例讲：处理字符序列时，“不是我要的左括号”与“是我要的右括号”是两件事。

**中缀转后缀**（缺口 4 补写，规则先讲清再给代码）：

规则四条：① 遇操作数直接输出；② 遇左括号压栈；③ 遇右括号，弹栈并输出直到遇到左括号，左括号弹出但不输出；④ 遇运算符，把栈里优先级**大于等于**它的都弹出并输出，然后自己压栈。扫描结束后把栈里剩下的全部弹出输出。

```c
void ToPostfix(char infix[], char postfix[]){
    SqStack S; InitStack(S);
    int k = 0;
    for(int i = 0; infix[i] != '\0'; i++){
        char c = infix[i];
        if(c >= '0' && c <= '9') postfix[k++] = c;                 // ①
        else if(c == '(') Push(S, c);                              // ②
        else if(c == ')'){                                         // ③
            char top;
            while(GetTop(S, top) && top != '('){ Pop(S, top); postfix[k++] = top; }
            Pop(S, top);                                           // 弹出左括号，不输出
        }else{                                                     // ④
            char top;
            while(GetTop(S, top) && top != '(' && Prior(top) >= Prior(c)){ Pop(S, top); postfix[k++] = top; }
            Push(S, c);
        }
    }
    char top;
    while(!IsEmpty(S)){ Pop(S, top); postfix[k++] = top; }
    postfix[k] = '\0';
}
```

规则 ④ 里"大于等于"这四个字是考点：同级运算符（例如连续的加减）要先算左边的，所以栈里的同级运算符要先弹出。这就是左结合。

**后缀求值**（缺口 4 补写）：

```c
int EvalPostfix(char postfix[]){
    SqStack S; InitStack(S);
    for(int i = 0; postfix[i] != '\0'; i++){
        char c = postfix[i];
        if(c >= '0' && c <= '9'){ int x = c - '0'; Push(S, x); }
        else{
            int b, a; Pop(S, b); Pop(S, a);      // 注意次序：先弹的是右操作数
            switch(c){
                case '+': Push(S, a + b); break;
                case '-': Push(S, a - b); break;
                case '*': Push(S, a * b); break;
                case '/': Push(S, a / b); break;
            }
        }
    }
    int result; Pop(S, result);
    return result;
}
```

**先弹的是右操作数**是本页最重要的一个细节：栈是后进先出，后压进去的是右边的操作数。减法和除法搞反就全错。

**判回文**（材料原文，元素类型按约定 4 换成结点指针）：

```c
bool IsPalindrome(LinkList L, int n){
    SqStack s; InitStack(s);
    LNode *q, *p = L->next;
    for(int i = 1; i <= n / 2; i++){ Push(s, p); p = p->next; }   // 前半压栈
    if(n % 2 == 1) p = p->next;                                   // 奇数长度跳过中点
    while(p != NULL){
        Pop(s, q);
        if(p->data != q->data) break;
        else p = p->next;
    }
    return IsEmpty(s);                                            // 栈空则是回文
}
```

为什么用 `return IsEmpty(s)` 而不是一个 bool 标志：失配时 break 出循环，栈里还有没弹完的元素，栈非空；全部匹配时弹了 n/2 次刚好栈空。一个返回值同时表达了两种情况。奇数长度跳过中点那句 `if(n % 2 == 1) p = p->next;` 是边界。

**双栈模拟队列**（材料只有知识描述，代码补写）：

```c
// 用两个栈 s1、s2 实现队列：入队一律压 s1；出队时若 s2 非空则弹 s2，
// s2 空则把 s1 全部倒进 s2 再弹
bool EnQueue2(int x){ return Push(s1, x); }
bool DeQueue2(int &x){
    if(!IsEmpty(s2)) return Pop(s2, x);
    while(!IsEmpty(s1)){ int t; Pop(s1, t); Push(s2, t); }   // 倒过去，顺序就反了
    if(IsEmpty(s2)) return false;
    return Pop(s2, x);
}
```

思想一句话：s1 倒进 s2 时顺序反了一次，两次反正好是队列的先进先出。**只有 s2 空了才倒**，否则会把新旧元素的顺序打乱。均摊复杂度 O(1)。

**从 BF 到 KMP**（A6 已讲 next 手算，本页只讲"为什么"，不重复手算）：BF 失配时主串指针 i 要回到本轮起点加一，已经比对过的字符又比了一遍，最坏 O(nm)。KMP 让 i 永不回溯，失配时把模式串的 j 退到 next[j]，因为 next[j] 记录了"模式串前 j-1 个字符里最长相等前后缀的长度加一"，那段前缀已经和主串对上了，可以直接从它后面继续。时间 O(n+m)。

## B4 树算法一：递归三件套（45min，17页）

### 目标

### 逻辑链

本节七个算法分成两类。第一类是**递归三件套**（求高度、结点数、叶子数），它们共享同一个骨架，差别只在终止条件返回什么、两个子结果怎么合并，所以当一个模式讲，三个实例并列。第二类是**需要辅助信息的**（判完全要层序加 tag、判平衡要把高度往上带、镜像要交换、求度要全局变量），每个有自己的关键技巧。顺序是：递归三件套的通用骨架 → 三个实例对比 → 判完全二叉树（层序加 tag）→ 判平衡二叉树（返回高度并用 -1 短路）→ 镜像 → 求树的度（孩子兄弟加全局变量）。

递归三件套的通用骨架是本节的核心认识，也是模板 5。它长这样：终止条件返回一个基准值；否则递归拿到左右子树的结果；把两个结果合并加上本结点的贡献返回。三个实例的差别只在第一行与第三行。

### 知识点与关键代码

**递归三件套的通用骨架**：

```
int 某统计(BiTree T){
    if(T == NULL) return 基准值;                    // 终止
    左 = 某统计(T->lchild);                          // 缩小
    右 = 某统计(T->rchild);
    return 合并(左, 右, 本结点);                     // 返回
}
```

**三个实例对比**（材料原文，并排放在一页）：

```c
int TreeDepth(BiTree T){                            // 求高度
    if(T == NULL) return 0;
    return max(TreeDepth(T->lchild), TreeDepth(T->rchild)) + 1;
}
int CountNodes(BiTree T){                           // 求结点数
    if(T == NULL) return 0;
    return CountNodes(T->lchild) + CountNodes(T->rchild) + 1;
}
int CountLeaves(BiTree T){                          // 求叶子数
    if(T == NULL) return 0;
    if(T->lchild == NULL && T->rchild == NULL) return 1;   // 多了一个叶子判定
    return CountLeaves(T->lchild) + CountLeaves(T->rchild);
}
```

对比表是本页的核心：

| 实例 | 终止返回 | 合并方式 | 多出来的判断 |
| :-- | :-- | :-- | :-- |
| 求高度 | 0 | max 加 1 | 无 |
| 结点数 | 0 | 相加加 1 | 无 |
| 叶子数 | 0 | 相加 | 当前结点是叶子则直接返回 1 |

三个函数只有两行不同。把这张表讲透，学生就掌握了“写一个新的树统计函数”的方法：先定终止值，再定合并方式，最后看需不需要额外判断。这个认识在 B5 的判 BST、最长路径上直接复用。

**孩子兄弟版的叶子数**（材料原文，对比用）：

```c
int CountLeaves2(CSTree T){
    if(T == NULL) return 0;
    if(T->firstchild == NULL) return 1 + CountLeaves2(T->nextbro);
    return CountLeaves2(T->firstchild) + CountLeaves2(T->nextbro);
}
```

关键差别：在孩子兄弟表示法里，“叶子”的判据是 `firstchild == NULL`（没有第一个孩子），而不是两个孩子都空；而且无论哪个分支都要加上 `CountLeaves2(T->nextbro)`，因为兄弟链上的结点也要统计。这两处差别是 A8 与 B4 的衔接点。

**判完全二叉树**（材料原文，命中勘误 C2 缩进破损，课件重排）：

```c
int JudgeComplete(BiTree T){
    if(T == NULL) return 1;
    SqQueue Q; InitQueue(Q);
    EnQueue(Q, T);
    int tag = 0; BiTree p;
    while(!IsEmpty(Q)){
        DeQueue(Q, p);
        if(p->lchild != NULL){
            if(tag) return 0;                       // 已经出现过缺孩子，后面却有左孩子
            EnQueue(Q, p->lchild);
        }else{ tag = 1; }
        if(p->rchild != NULL){
            if(tag) return 0;
            EnQueue(Q, p->rchild);
        }else{ tag = 1; }
    }
    return 1;
}
```

思想一句话（材料原注）：**在完全二叉树中，若某个结点缺少子结点，则其后所有结点都必须是叶子结点**。所以用 tag 记“是否已经出现过缺孩子”，一旦出现，后面再遇到任何非空孩子就不是完全二叉树。两个分支里 `else{ tag = 1; }` 的位置很关键：左孩子为空时立即置 tag，所以“有右孩子但没左孩子”这种情况会在第二个 if 里被 tag 拦下，返回 0，这是正确的。

**判平衡二叉树**（材料原文）：

```c
int JudgeAVL(BiTree T){
    if(T == NULL) return 0;                         // 空树高度 0，也平衡
    int HL = JudgeAVL(T->lchild);
    if(HL == -1) return -1;                         // 左子树已不平衡，短路
    int RL = JudgeAVL(T->rchild);
    if(RL == -1) return -1;
    if(HL - RL < -1 || HL - RL > 1) return -1;       // 本结点不平衡
    return max(HL, RL) + 1;                          // 平衡，返回高度
}
```

**为什么返回 int 而不是 bool** 是本页的核心设问：因为这个函数同时干两件事——往上报高度、往上报是否平衡。如果返回 bool，求高度就要再递归一遍，时间从 O(n) 变 O(n²)。用 -1 作为“不平衡”的标志之所以安全，是因为合法高度总是 ≥ 0。两个 `if(HL == -1) return -1;` 是短路：子树已经不平衡了，不必再算另一边。这是“返回值携带双重信息”的典型写法，B8 的 BST 删除与 B9 的快排也会遇到类似技巧。

**求镜像树**（材料原文）：

```c
void mirrorTree(BiTree &T){
    if(T == NULL) return;
    BiTNode *temp = T->rchild;
    T->rchild = T->lchild;
    T->lchild = temp;
    mirrorTree(T->lchild);
    mirrorTree(T->rchild);
}
```

三行交换加两行递归。注意交换必须在递归之前做也可以、之后做也可以（因为交换的是子树整体），但要提醒学生：如果先递归再交换，递归进去的是原来的左右子树，结果一样；两种次序都对，选一种写到底。

**求树的度**：A8 已逐行讲过（孩子兄弟递归加全局变量），本页只做两件事：把它归入模板 5（递归三件套的变体：返回值是兄弟链长度，全局变量存最大值），并提醒一句“这是 802 常考的‘递归中维护全局量’写法，B5 的最长路径也是这个套路”。不重复讲代码。

### 易错与误解破除

- 求叶子数写成 `return CountLeaves(左) + CountLeaves(右) + 1`：那算的是结点数。

- 镜像树用值传递的参数（`BiTree T` 而不是 `BiTree &T`）：本题只改结点内部指针，值传递也能完成，但要讲清区别（改 T 本身的指向才需要引用）。

### 知识点与关键代码

**last 分层的思路**：层序遍历本身不知道“一层到哪里结束”。加一个变量 last，它记录当前层最右结点在队列里的下标；当 `front > last` 时说明本层已经全部出队，此时 rear 指向的就是下一层的最右结点，把 last 更新为 rear。这个技巧一旦掌握，所有“按层统计”的题都能写。

**求树的宽度**（材料原文）：

```c
int Width(BiTree T){
    if(T == NULL) return 0;
    int front = 0, rear = -1, last = 0;
    BiTree Q[MaxSize]; BiTree p;
    Q[++rear] = T;
    int temp = 0, maxwidth = 0;
    while(front <= last){                       // 注意终止条件用 last
        p = Q[front++]; temp++;
        if(p->lchild != NULL) Q[++rear] = p->lchild;
        if(p->rchild != NULL) Q[++rear] = p->rchild;
        if(front > last){                       // 本层结束
            last = rear;
            if(temp > maxwidth) maxwidth = temp;
            temp = 0;
        }
    }
    return maxwidth;
}
```

四个变量的分工要一个个说：front 是队头，rear 是队尾，last 是本层最右结点的下标，temp 是本层计数器。注意这里没用 SqQueue 而是直接用数组加两个下标，因为需要 last 这个额外信息，封装好的队列拿不到下标。这一点要向学生说明：工具可以降级，为了拿到下标。

**繁荣度**（材料真题 2024 第 3 题原文）：定义为每一层的结点数乘以该层的层数，求和。

```c
int prosperity(BiTree T){
    if(T == NULL) return 0;
    int front = 0, rear = -1, last = 0;
    BiTree Q[MaxSize]; BiTree p;
    Q[++rear] = T;
    int totalProsper = 0, width = 0, height = 1;
    while(front <= rear){
        p = Q[front++]; width++;
        if(p->lchild != NULL) Q[++rear] = p->lchild;
        if(p->rchild != NULL) Q[++rear] = p->rchild;
        if(front > last){
            totalProsper += height * width;      // 本层贡献：层号乘本层结点数
            last = rear; height++; width = 0;
        }
    }
    return totalProsper;
}
```

讲法：先说“这就是求宽度的代码改三处”——把 maxwidth 换成累加器 totalProsper、多一个 height 计数器、每层结束时累加 `height * width`。这种“从已知算法改三处得到新算法”的讲法为 C3 的改条件训练打底。注意材料这里外层循环用的是 `front <= rear` 而不是 `front <= last`，两个写法在本题里等价（因为内层已经用 `front > last` 判层结束），但要向学生指出一处不一致，建议统一用 `front <= last`。

**最长路径**（材料真题 2025 第 2 题原文）：输出从根到叶子的最长路径与该路径长度。

```c
void longestPath(BiTree node, int path[], int pathLen, int maxPath[], int &maxLen){
    if(node == NULL) return;
    path[pathLen++] = node->data;                    // 当前结点入路径
    if(node->lchild == NULL && node->rchild == NULL){ // 到叶子了
        if(pathLen > maxLen){
            maxLen = pathLen;
            for(int i = 0; i < maxLen; i++) maxPath[i] = path[i];   // 拷贝当前路径
        }
    }else{
        longestPath(node->lchild, path, pathLen, maxPath, maxLen);
        longestPath(node->rchild, path, pathLen, maxPath, maxLen);
    }
}
```

三个要点：① `path` 存当前正在走的路径，`maxPath` 存目前最长的那条，两个数组分工不同；② `pathLen` 用值传递，因为递归回来后它应该自动“恢复”（每层自己的 pathLen 不受子层影响），而 `maxLen` 用引用，因为它是全局最优记录，必须能被子层改写；③ 只在叶子处比较与拷贝，不在内部结点比。

“为什么 pathLen 不用引用而 maxLen 用引用”是本页最有价值的设问，它把 C1-B-05 的值传递与引用传参在真实算法里用上了：需要“每层自己的副本”的用值传递，需要“跨层共享并改写”的用引用。

**判 BST**（材料真题 2024 第 1 题原文，命中勘误 A5）：

```c
int checkBST(BiTNode *node, int &prev){          // 先声明（勘误 A5：材料里调用在声明前）
    if(node == NULL) return 1;
    if(!checkBST(node->lchild, prev)) return 0;  // 左子树不是 BST
    if(node->data <= prev) return 0;             // 中序序列不严格递增
    prev = node->data;
    return checkBST(node->rchild, prev);
}
int JudgeBST(BiTree T){
    int prev = INT_MIN;                          // 勘误 A5：材料用 -1，隐含“所有值大于 -1”
    return checkBST(T, prev);
}
```

思想：BST 的中序序列严格递增，所以中序遍历时用一个 prev 记住上一个访问的值，每次比较当前值与 prev。两个勘误处置要在页面上说清：材料的 `int prev = -1` 隐含了“所有结点值都大于 -1”的假设，如果树里有负数就错，改用 INT_MIN 或题目给定的下界；材料里 `JudgeBST` 调用 `checkBST` 时后者还没声明，伪代码里不挑，但课件把声明放前面。`prev` 必须用引用，因为它是跨递归层共享的状态，这与最长路径的 maxLen 是同一个道理。

## B6 图算法一：遍历应用（45min，17页）

### 目标

学完能默写判两点连通、DFS 回溯找路径（visited 复位）、拓扑排序与判给定序列是否拓扑序列，并能说清“连通性判断”与“路径搜索”在 visited 处理上的根本区别。

### 逻辑链

本节六个算法全部建在 A9 的 DFS 与 BFS 上，差别只在“visited 怎么处理”与“额外带什么信息”。顺序是：判两点连通（一次性 visited，不复位）→ 经过 k 的路径（2025 真题，回溯时复位）→ 长度 k 的路径（2024 真题，带 depth 参数）→ **两种 visited 处理的对比页**（本节核心认识）→ 拓扑排序（入度表加栈）→ 判给定序列是否拓扑序列（2026 真题）→ 判拓扑序列是否唯一。

### 知识点与关键代码

**判两点连通**（材料原文，命中勘误 C1，当对比教学点用）：

```c
int visited[MaxVertexNum] = {0};
int Pathitoj(ALGraph G, int i, int j){
    if(i == j) return 1;
    visited[i] = 1;
    for(ArcNode *p = G.vertices[i].firstarc; p != NULL; p = p->nextarc){
        int k = p->adjvex;
        if(!visited[k] && Pathitoj(G, k, j)) return 1;
    }
    return 0;                          // 注意：这里不复位 visited
}
```

为什么可以不复位：本题只问“能不能到”，不问“走哪条路”。一个顶点探索过发现到不了 j，那么从其他路径再走到它也一样到不了，所以标记留着反而是剪枝。但它有一个隐患：visited 是全局的且从不复位，同一个程序里调第二次就会错，所以要么每次调用前手动清零，要么把它当一次性函数用。这个隐患要向学生说清。

**经过 k 的路径**（材料真题 2025 第 3 题原文）：

```c
bool checkPath(ALGraph G, int u, int v, bool visited[]){
    if(u == v) return true;
    visited[u] = true;
    for(ArcNode *p = G.vertices[u].firstarc; p != NULL; p = p->next){
        int k = p->adjvex;
        if(visited[k]) continue;
        if(checkPath(G, k, v, visited)) return true;
    }
    visited[u] = false;                // 回溯：这条路不行，把标记清掉让其他路能再试
    return false;
}
bool IsExistPathGoBy(ALGraph G, int u, int k, int v){
    if(G.vexnum == 0 || G.arcnum == 0) return false;
    bool visited[MaxVertexNum] = {false};      // 勘误 A6：材料写的是变长数组带初始化
    for(int i = 0; i < G.vexnum; i++) visited[i] = false;
    if(!checkPath(G, u, k, visited)) return false;   // 先判 u 能不能到 k
    for(int i = 0; i < G.vexnum; i++) visited[i] = false;   // 复位再判第二段
    return checkPath(G, k, v, visited);
}
```

三个要点：① `visited[u] = false` 写在 `return false` 之前，这就是回溯；② 成功返回时**不清标记**（直接 `return true`），因为已经找到一条路径，不需要再试其他；③ 把“u 到 v 经过 k”拆成两段独立的可连性问题，中间必须复位 visited，否则第一段用过的标记会让第二段误判。这个“拆成两段”的思路是本题的解题关键，要在讲代码之前先说。

**长度 k 的路径**（材料真题 2024 第 2 题原文）：

```c
bool DFS(ALGraph& G, int i, int depth, int k, int visited[]){
    if(depth == k) return true;                 // 走了 k 条边就成功
    visited[i] = 1;
    for(ArcNode* e = G.vertices[i].firstarc; e != NULL; e = e->next){
        int v = e->adjvex;
        if(!visited[v]){
            if(DFS(G, v, depth + 1, k, visited)){ visited[i] = 0; return true; }
        }
    }
    visited[i] = 0;                             // 回溯
    return false;
}
bool existsKSimplePath(ALGraph& G, int k){
    if(k < 1 || k > G.vexnum - 1) return false;  // k 条边需要 k+1 个不同顶点
    int visited[MaxVertexNum];
    for(int i = 0; i < G.vexnum; i++){
        for(int j = 0; j < G.vexnum; j++) visited[j] = 0;   // 每个起点前复位
        if(DFS(G, i, 0, k, visited)) return true;
    }
    return false;
}
```

两个要点：① 多带一个 `depth` 参数，每往下一层加 1，到 k 就成功——这是“递归中携带额外信息”（B4、B5 的同一个套路）；② `k > G.vexnum - 1` 这个边界要讲清理由：简单路径要求顶点不重复，k 条边需要 k+1 个不同顶点，而图里只有 vexnum 个。注意材料成功分支里也写了 `visited[i] = 0`，与 2025 题的写法不同（那个成功时不清），两种都对（成功了就不再继续搜索），但课件要统一并说明一句。

**拓扑排序**（材料原文）：

```c
bool TopoLogicalSort(ALGraph G, int print[]){
    if(G.kind != 1) return false;                       // 只有有向图才有拓扑序
    int indegree[MaxVertexNum] = {0};
    for(int i = 0; i < G.vexnum; i++)
        for(ArcNode *p = G.vertices[i].firstarc; p != NULL; p = p->nextarc)
            indegree[p->adjvex]++;                       // 第一步：求全部入度（A9 已讲）
    SqStack S; InitStack(S);
    for(int i = 0; i < G.vexnum; i++)
        if(indegree[i] == 0) Push(S, i);                 // 入度为 0 的全部入栈
    int count = 0;
    while(!IsEmpty(S)){
        int u; Pop(S, u);
        print[count++] = u;                              // 输出
        for(ArcNode *p = G.vertices[u].firstarc; p != NULL; p = p->nextarc)
            if(--indegree[p->adjvex] == 0) Push(S, p->adjvex);   // 后继入度减 1，减到 0 就入栈
    }
    return count == G.vexnum;                            // 输出个数不足说明有环
}
```

`return count == G.vexnum` 为什么能判环：有环时环上的顶点入度永远减不到 0，不会入栈，最终 count 小于顶点数。用栈换成队列也对，得到的拓扑序不同但都合法，这一点要提（为下一题“是否唯一”做铺垫）。

**判给定序列是否拓扑序列**（经典问题；材料在真题汇总里给了完整解答，题面与分值在 C3-B-04 讲）：

```c
bool IsTopoSeq(ALGraph G, int seq[], int n){
    if(G.vexnum == 0) return false;
    int indegree[MaxVertexNum] = {0};
    for(int i = 0; i < G.vexnum; i++)
        for(ArcNode *p = G.vertices[i].firstarc; p != NULL; p = p->nextarc)
            indegree[p->adjvex]++;
    for(int i = 0; i < n; i++){
        int u = seq[i];
        if(indegree[u] != 0) return false;      // 还有前驱没输出，不合法
        for(ArcNode *p = G.vertices[u].firstarc; p != NULL; p = p->nextarc)
            indegree[p->adjvex]--;              // 把它的后继入度减 1
    }
    return true;
}
```

本题的关键认识：**不需要真的做一遍拓扑排序再比较**，只要按给定序列的顺序模拟一遍，每次检查当前顶点的入度是不是已经变成 0。这比先排序再比较快，也简单。时间 O(|V|+|E|)，空间 O(|V|)。这个“按题目给的顺序模拟而不自己生成”的思路要在讲代码前说清，否则学生会先去写一个完整拓扑排序。

**判拓扑序列是否唯一**（材料原文，命中勘误 B2）：思路是每一轮入度为 0 的顶点只能有一个，如果某一轮同时存在两个入度为 0 的顶点，它们就可以互换位置，拓扑序不唯一。材料用的是邻接矩阵与另一套 MGraph 字段名（`numVertices`、`Edge`），课件按 A9 的统一口径改写成邻接表版本，并给一张两套字段名的对应表（勘误 B2 的处置）。

### 知识点与关键代码

**Prim**（材料原文，命中勘误 A3：用了 `p->weight` 但邻接表的 weight 字段被注释掉了）：

```c
const int INF = 0x3f3f3f3f;
void Prim(ALGraph &G){                          // 前提：ArcNode 里必须有 weight 字段
    bool include[MaxVertexNum];
    int dist[MaxVertexNum], parent[MaxVertexNum];
    // 勘误：不能写 int dist[] = {INF}，那样只有第一个元素是 INF，其余为 0（约定 5）
    for(int i = 0; i < G.vexnum; i++){ include[i] = false; dist[i] = INF; parent[i] = -1; }
    dist[0] = 0;                                // 从顶点 0 开始长
    for(int k = 0; k < G.vexnum; k++){
        int u = -1, minDist = INF;
        for(int i = 0; i < G.vexnum; i++)
            if(!include[i] && dist[i] < minDist){ minDist = dist[i]; u = i; }
        if(u == -1) break;                       // 图不连通
        include[u] = true;                       // u 进入生成树
        for(ArcNode *p = G.vertices[u].firstarc; p != NULL; p = p->nextarc){
            int v = p->adjvex, w = p->weight;
            if(!include[v] && w < dist[v]){ dist[v] = w; parent[v] = u; }
        }
    }
}
```

三个数组的分工要一个个说：`include[i]` 表示顶点 i 是否已在生成树里；`dist[i]` 是 i 到生成树的最小边权（不是到起点的距离，这是与 Dijkstra 的关键区别）；`parent[i]` 记录选中 i 时走的是哪条边。主循环两轮：选最小的 u 并入树，再用 u 的边更新邻居的 dist。时间 O(n²)（邻接表下也是，因为选最小要扫全部顶点）。

**勘误 A3 的处置**要在页面上明说：材料里邻接表的 `weight` 字段是注释掉的，但 Prim 用了 `p->weight`，两者不自洽。A9 的定义里已经把 weight 放出来并注明“带权时用”，所以本节代码能对上。这个交代本身就是教学：让学生知道“拿到一段代码要先检查它用的字段定义里有没有”。

**约定 5 的再现**：材料原注“不能写 `int dist[] = {INF}`，那样只有第一个元素是 INF，其余为 0”。这是 A1 讲过的约定在真实代码里的第二次出现，要点一句“这就是当时说的那个坑”。

**Kruskal**（缺口 9 补写，含并查集，兑现 A9 埋的钩子）：

```c
int Find(int parent[], int x){ while(parent[x] != x) x = parent[x]; return x; }
void Union(int parent[], int a, int b){ int ra = Find(parent,a), rb = Find(parent,b); if(ra != rb) parent[ra] = rb; }

void Kruskal(ALGraph G, int vexnum){
    // 第一步：把全部边收进一个数组，按权值从小到大排序（伪代码里一句带过）
    Edge E[MaxEdgeNum]; int m = CollectEdges(G, E); SortByWeight(E, m);
    // 第二步：初始化并查集，每个顶点自成一棵树
    int parent[MaxVertexNum];
    for(int i = 0; i < vexnum; i++) parent[i] = i;
    // 第三步：按序扫边，两端不在同一棵树就加入
    int cnt = 0;
    for(int i = 0; i < m && cnt < vexnum - 1; i++){
        int a = Find(parent, E[i].u), b = Find(parent, E[i].v);
        if(a != b){ parent[a] = b; cnt++; }      // 不成环，加入生成树
    }
}
```

并查集在这里的作用一句话：判断一条边的两个端点是不是已经在同一棵树里，是就会成环，不能加。Find 沿 parent 往上找到根，Union 把一棵树的根接到另一棵的根下。A9 埋的钩子在本页兑现。时间 O(e log e)（排序主导），所以稀疏图用 Kruskal、稠密图用 Prim，这个选择依据给一句即可（不做优劣论述，那是专业课的事）。

**Dijkstra 骨架**（缺口 9，只给骨架与三个数组的含义）：

```c
void Dijkstra(MGraph G, int v0){
    // dist[i]：v0 到 i 的当前最短距离；S[i]：i 是否已确定；path[i]：最短路上 i 的前驱
    for(int i = 0; i < G.vexnum; i++){ dist[i] = G.edge[v0][i]; S[i] = false; }
    dist[v0] = 0; S[v0] = true;
    for(int k = 1; k < G.vexnum; k++){
        int u = 选 dist 最小且 S[u]==false 的 u;      // 本轮确定的顶点
        S[u] = true;
        for(int i = 0; i < G.vexnum; i++)
            if(!S[i] && dist[u] + G.edge[u][i] < dist[i]){
                dist[i] = dist[u] + G.edge[u][i]; path[i] = u;   // 松弛
            }
    }
}
```

**与 Prim 的对比是本页的重点**：两个算法骨架几乎一样（都是每轮选一个最小的并入集合，再更新其余），差别只在更新式：Prim 用 `w < dist[v]`（只看边权，因为要的是到树的最短边），Dijkstra 用 `dist[u] + w < dist[i]`（要累加路径长度）。把这两行并排放，学生就能记住两个算法的区别。时间 O(n²)。

**Floyd 骨架**（缺口 9）：

```c
void Floyd(MGraph G){
    // A[i][j]：i 到 j 的当前最短距离；初始化 A = G.edge
    for(int k = 0; k < G.vexnum; k++)          // 中转点
        for(int i = 0; i < G.vexnum; i++)
            for(int j = 0; j < G.vexnum; j++)
                if(A[i][k] + A[k][j] < A[i][j]) A[i][j] = A[i][k] + A[k][j];
}
```

三重循环的含义只用一句话讲透：依次把每个顶点 vk 当作可能的中转点，对所有 (i,j) 试一次“经过 vk 会不会更近”。**k 必须在最外层**，这是学生最容易写错的地方，理由：A[i][k] 与 A[k][j] 必须是“只允许用前 k-1 个顶点做中转”的结果，k 放内层会用到本轮还没算完的值。时间 O(n³)。材料里 Floyd 的手算表格与递推公式很详细，本节课件只给骨架与这一句理由，手算训练指向专业课。

**多源 BFS**（2023 真题像素距离图，缺口 13 补写）：题目是 n×m 的 01 位图，求每个像素到最近白像素的曼哈顿距离。

```c
void PixelDist(int g[][MaxM], int dist[][MaxM], int n, int m){
    SqQueue Q; InitQueue(Q);
    // 关键一步：所有白像素先全部入队，dist 置 0；其余置 -1 表示未访问
    for(int i = 0; i < n; i++)
        for(int j = 0; j < m; j++){
            if(g[i][j] == 1){ dist[i][j] = 0; EnQueue(Q, i * m + j); }
            else dist[i][j] = -1;
        }
    int dir[4][2] = {{-1,0},{1,0},{0,-1},{0,1}};      // 上下左右
    while(!IsEmpty(Q)){
        int cur; DeQueue(Q, cur);
        int x = cur / m, y = cur % m;                  // 一维编号还原为二维坐标
        for(int d = 0; d < 4; d++){
            int nx = x + dir[d][0], ny = y + dir[d][1];
            if(nx < 0 || nx >= n || ny < 0 || ny >= m) continue;   // 越界
            if(dist[nx][ny] == -1){                                 // 未访问过
                dist[nx][ny] = dist[x][y] + 1;
                EnQueue(Q, nx * m + ny);
            }
        }
    }
}
```

**与普通 BFS 只差一处**，这句话是本页的教学重点：普通 BFS 从一个起点入队，多源 BFS 把所有源点（全部白像素）先入队、dist 全置 0，后面完全一样。因为 BFS 逐层扩散的性质，每个黑像素第一次被访问时的 dist 就是它到最近白像素的距离。三个细节：队列里存的是一维编号 `i*m+j`（约定 4 的变通：存的是坐标而不是结点指针，取出时用除与模还原）；`dist[nx][ny] == -1` 同时充当 visited 的作用；四个方向数组避免写四段重复代码。时间 O(nm)，每个像素入队出队各一次，这就是题目要求的“时间复杂度尽可能低”。

**关键路径一页**：四个量一句话说清——ve(j) 是事件 j 的最早发生时间（从源点正向推，取最大），vl(j) 是最迟发生时间（从汇点逆向推，取最小），e(i) 是活动 i 的最早开始时间（等于起点的 ve），l(i) 是最迟开始时间（等于终点的 vl 减活动时长）。e == l 的活动就是关键活动。只给这一页说明，不写代码，因为 802 考的是手算 AOE 网（题集 7答10），代码课写它没有收益。

### 知识点与关键代码

**哨兵版顺序查找**（缺口：材料无，从教材补）：

```c
int SeqSearch(int A[], int n, int key){
    A[0] = key;                       // 哨兵：把待查值放在 0 位
    int i = n;
    while(A[i] != key) i--;            // 不需要判 i >= 0，因为 A[0] 一定会命中
    return i;                          // 返回 0 表示查找失败
}
```

哨兵的价值一句话：它把循环里的两个判断（越界与相等）合并成一个。普通版每次循环要判 `i >= 0 && A[i] != key`，哨兵版只判 `A[i] != key`，因为 0 位放了 key 保底。前提是数据存在 A[1..n]，这正是约定 1 里“查找章节的哨兵变体”。n 很大时这个优化能省一半的比较次数。

**折半查找**（材料原文）：

```c
int BinSearch(int A[], int low, int high, int key){
    int mid;
    while(low <= high){
        mid = (low + high) / 2;
        if(key == A[mid]) return mid + 1;      // 返回位序
        else if(key < A[mid]) high = mid - 1;
        else low = mid + 1;
    }
    return 0;                                  // 查找失败
}
```

三个边界要讲：`low <= high` 为什么带等号（low==high 时区间里还有一个元素要查）；`mid-1` 与 `mid+1` 为什么不能写成 `mid`（会死循环）；返回 `mid+1` 是位序（与 A2 的 LocateElem 同一口径）。时间 O(logn)。

**判定树**：把折半查找的每一次比较画成一个结点，左子树是“往左半区找”、右子树是“往右半区找”，得到一棵平衡的二叉树。成功查找的比较次数等于结点所在的层数，失败查找等于走到对应外部结点的层数。ASL 的算法：成功 ASL = 各层结点数乘层数的总和除以 n；失败 ASL = 各外部结点数乘层数的总和除以外部结点数。**本课只要求会画判定树与读出比较次数，ASL 的完整计算训练在专业课**（题集 9答3 给作课后选做）。

**BST 的查找与插入**（材料 `重邮数据结构.md` 原文有代码）：

```c
BSTNode *BSTSearch(BSTNode *T, int key){
    while(T != NULL && key != T->key){
        if(key < T->key) T = T->lchild; else T = T->rchild;
    }
    return T;                                  // NULL 表示没找到
}
int BSTInsert(BSTNode *&T, int key){
    if(T == NULL){                             // 找到空位，新建结点
        T = (BSTNode *)malloc(sizeof(BSTNode));
        T->key = key; T->lchild = T->rchild = NULL;
        return 1;
    }
    if(key == T->key) return 0;                // 已存在，不插
    return key < T->key ? BSTInsert(T->lchild, key) : BSTInsert(T->rchild, key);
}
```

插入的参数为什么是 `BSTNode *&T`（指针的引用）：因为要改的是父结点的 lchild 或 rchild 字段，不是 T 自己的副本。这里要呼应 C1-B-05：不带 & 的话新建的结点接不到树上。这是一个很好的“引用传参在真实算法里的必要性”例子。

**BST 的删除**（缺口 5，两份材料都没有，从教材补）：

```c
int BSTDelete(BSTNode *&T, int key){
    if(T == NULL) return 0;                              // 没找到
    if(key < T->key) return BSTDelete(T->lchild, key);
    if(key > T->key) return BSTDelete(T->rchild, key);
    // 找到了，分三种情况
    if(T->lchild == NULL && T->rchild == NULL){          // ① 叶子
        free(T); T = NULL; return 1;
    }
    if(T->lchild == NULL){                               // ② 只有右孩子
        BSTNode *s = T; T = T->rchild; free(s); return 1;
    }
    if(T->rchild == NULL){                               // ② 只有左孩子
        BSTNode *s = T; T = T->lchild; free(s); return 1;
    }
    // ③ 两个孩子：用中序前驱（左子树的最大值）替换，再递归删那个前驱
    BSTNode *pre = T->lchild;
    while(pre->rchild != NULL) pre = pre->rchild;
    T->key = pre->key;
    return BSTDelete(T->lchild, pre->key);
}
```

三种情况的讲法：叶子直接删，不影响其他结点；只有一个孩子时把孩子接到父结点上（因为参数是引用，`T = T->rchild` 就直接改了父结点的字段）；两个孩子时不能直接删，因为删完两棵子树就断了，所以**用一个值替换它再删那个值的结点**，替换值取中序前驱（左子树里最大的）或中序后继（右子树里最小的），两者都只会有一个或零个孩子，于是回到情况 ① 或 ②。

为什么用中序前驱能保持 BST 性质：前驱是中序序列里刚好小于它的那个值，拿它替换后，左子树全部小于它、右子树全部大于它，性质不变。这个理由要讲，不能只给代码。

**AVL 插入与四种旋转**（缺口 6，材料只有文字与图）：插入后从新结点往上找**最小失衡子树**（第一个平衡因子绝对值大于 1 的结点），根据新结点在它四代里的位置定旋转类型：

| 新结点位置 | 类型 | 旋转 |
| :-- | :-- | :-- |
| 失衡结点的左孩子的左子树 | LL | 右单旋 |
| 右孩子的右子树 | RR | 左单旋 |
| 左孩子的右子树 | LR | 先左后右双旋 |
| 右孩子的左子树 | RL | 先右后左双旋 |

```c
void RotateR(BSTNode *&T){            // 右单旋（LL）
    BSTNode *B = T->lchild;
    T->lchild = B->rchild;             // B 的右子树回挂给 T 当左子树
    B->rchild = T;
    T = B;                             // B 上位当根
}
```

**散列表构造与两种冲突处理**（缺口 7，材料有 22 处知识描述但无完整代码）：

```c
// 开放定址：线性探测
int Hash(int key){ return key % p; }                       // p 取不大于表长的最大质数
void InsertHash(int H[], int key){
    int addr = Hash(key);
    while(H[addr] != EMPTY){
        if(H[addr] == key) return;                         // 已存在
        addr = (addr + 1) % TableLen;                      // 线性探测下一位
    }
    H[addr] = key;
}

// 链地址：同义词拉成一条单链表
void InsertHash2(LNode *H[], int key){
    int addr = Hash(key);
    LNode *s = (LNode*)malloc(sizeof(LNode));
    s->data = key;
    s->next = H[addr]; H[addr] = s;                        // 头插到同义词链
}
```

两种方法的对比一句话：开放定址把冲突元素存在表内的其他位置（不需要额外空间，但会聚集，删除麻烦），链地址把同义词拉成链表（不聚集，删除方便，但要额外的指针空间）。ASL 的计算训练留给专业课（题集 9答26、9答27、9答28），本课只要求能写出构造代码与说出两者的区别。

### 知识点与关键代码

**哨兵位的三个作用**（本页是整节的地基）：① 存待插入的元素，腾出一个变量位；② 在直接插入里免掉循环的越界判断（j 减到 0 时 `L.data[j] > L.data[0]` 必然为假，因为 data[0] 就是它自己）；③ 在快排里存枢轴，避免反复读写 low 位置。注意：哨兵只在需要它的算法里用，冒泡不需要哨兵（所以材料里它从 0 开始是另一种口径，本节统一改成 1 起，见勘误 A1）。

**直接插入**（材料原文）：

```c
void InsertSort(SqList &L){                   // 数据存 L.data[1..length]
    for(int i = 2; i <= L.length; i++){
        L.data[0] = L.data[i];                // 哨兵存待插入元素
        int j = i - 1;
        while(L.data[j] > L.data[0]){         // j=0 时必然跳出
            L.data[j + 1] = L.data[j];
            j--;
        }
        L.data[j + 1] = L.data[0];
    }
}
```

“为什么 j=0 时一定会跳出”是本节第一个关键设问：data[0] 存的就是待插入元素自己，`data[0] > data[0]` 为假。这就是哨兵免掉越界判断的原理。时间 O(n²)，最好情况（已有序）O(n)，稳定。

**折半插入**（材料原文）：

```c
void BinarySort(SqList &L){
    for(int i = 2; i <= L.length; i++){
        if(L.data[i] >= L.data[i - 1]) continue;    // 已就位，跳过
        L.data[0] = L.data[i];
        int low = 1, high = i - 1;
        while(low <= high){
            int mid = (low + high) / 2;
            if(L.data[0] < L.data[mid]) high = mid - 1; else low = mid + 1;
        }
        for(int j = i; j > low; j--) L.data[j] = L.data[j - 1];   // 统一后移
        L.data[low] = L.data[0];
    }
}
```

关键认识：**比较次数降到 O(nlogn)，但移动次数仍是 O(n²)**，所以总体时间复杂度不变。这个“比较与移动分开算”的考点在选择题里常考（题集 10选相关），要单独强调。开头的 `continue` 是一个优化：已经比前一个大就不用找了。

**二路插入**（材料原文，较难，讲清三种情形即可）：用一个容量为 n 的循环数组 temp，`first` 指向当前最小值的位置，`final` 指向最大值的位置。插入时分三种情形：比最小值还小就往前（逆时针）扩展 first；比最大值还大就往后（顺时针）扩展 final；落在中间就从 final 一侧往后腾位置再插。最后从 first 开始按环序回填到 L.data[1..n]。目标是减少移动次数（最坏也只移 n²/8 次），代价是多一个辅助数组。

**希尔排序一页**：取一个增量 d，把下标相隔 d 的元素分成一组做直接插入，然后减小 d 重做，直到 d=1。它不稳定（相隔的元素交换可能改变相同值的相对次序）。只给思想与一趟手算（题集 10选15、10选18、10选25 全是手算），代码不写。

**冒泡（修正版，勘误 A1）**：

```c
void BubbleSort(SqList &L){                   // 数据存 L.data[1..length]
    for(int i = 1; i < L.length; i++){        // 修正：从 1 开始，不是 0
        bool swapped = false;
        for(int j = 1; j <= L.length - i; j++) // 修正：到 length-i，不是 length-1-i
            if(L.data[j] > L.data[j + 1]){
                int tmp = L.data[j];
                L.data[j] = L.data[j + 1];
                L.data[j + 1] = tmp;
                swapped = true;
            }
        if(!swapped) break;                    // 提前退出：本趟没交换说明已有序
    }
}
```

勘误 A1 的交代要放在页面上：材料的冒泡从 j=0 开始，排的是 data[0..length-1]，既动了哨兵位又漏了 data[length]，与它自己的全局约定 1 冲突。两种修法：要么改成上面这个 1 起的版本，要么明确声明“冒泡不用哨兵，本函数按 0 起口径”并把循环边界改成 `j < L.length - 1 - i`。课件选前者，与全章口径统一。`swapped` 优化让最好情况（已有序）降到 O(n)，这也是“用某一趟的结果判断能不能提前结束”的典型例题。

**快排**（材料原文）：

```c
int Partition(SqList &L, int low, int high){
    L.data[0] = L.data[low];                  // 哨兵存枢轴（取第一个元素）
    while(low < high){
        while(L.data[high] >= L.data[0] && low < high) high--;   // 从右找比枢轴小的
        L.data[low] = L.data[high];                              // 填到左边坑里
        while(L.data[low] <= L.data[0] && low < high) low++;     // 从左找比枢轴大的
        L.data[high] = L.data[low];                              // 填到右边坑里
    }
    L.data[low] = L.data[0];                  // 枢轴归位
    return low;
}
void QuickSort(SqList &L, int low, int high){
    if(low < high){
        int p = Partition(L, low, high);
        QuickSort(L, low, p - 1);
        QuickSort(L, p + 1, high);
    }
}
```

Partition 的讲法是“挖坑填数”：先把枢轴挖出来存到哨兵，low 位置就成了一个坑；从右往左找到第一个比枢轴小的，填进坑里，high 位置变成新坑；再从左往右找第一个比枢轴大的填过去；两个指针相遇时把枢轴放进最后的坑。内外两层循环的条件都要包含 `low < high`，否则越界。平均 O(nlogn)，最坏（已有序）O(n²)，空间 O(logn)（递归栈），不稳定。

**以平均值为界值的划分**（2021 类真题，命中勘误 A2 死递归，给修正版）：

```c
void QuickSortAvg(int R[], int low, int high){
    if(low >= high) return;
    int sum = 0;
    for(int i = low; i <= high; i++) sum += R[i];      // 只对当前区间求和
    int avg = sum / (high - low + 1);
    int i = low, j = high;
    while(i <= j){
        while(i <= j && R[i] <= avg) i++;
        while(i <= j && R[j] >  avg) j--;
        if(i < j){ int t = R[i]; R[i] = R[j]; R[j] = t; i++; j--; }
    }
    // 修正（勘误 A2）：加进度保护，避免区间不变时死递归
    if(low <= j && j < high) QuickSortAvg(R, low, j);
    if(low < i && i <= high) QuickSortAvg(R, i, high);
}
```

**死递归要当反例讲透**：区间内元素全部 ≤ avg 时（例如全相等），第一个内层 while 把 i 推到 high+1，第二个内层 while 因为 `i <= j` 已不成立而不执行，j 停在 high；退出外层循环后 `low < j` 仍成立，于是递归区间 [low, high] 与原来完全一样，永远停不下来。修正的两个条件 `j < high` 与 `low < i` 就是“区间必须真的变小”的保证。课堂上拿 R = {5,5,5} 走一遍，学生自己就能看到死递归。这是本节最有价值的一段，因为它同时教了三件事：平均值划分的写法、递归必须有进度的普适道理、以及怎么用一个小反例验证自己的代码。

### 知识点与关键代码

**简单选择**（材料原文，写法巧妙要逐行讲）：

```c
void SelectSort(SqList &L){                   // 数据存 L.data[1..length]
    for(int i = 1; i < L.length; i++){        // 最后一个元素无需遍历
        L.data[0] = i;                        // 用哨兵位存当前最小值的下标
        for(int j = i + 1; j <= L.length; j++) // 找最小时最后一个元素仍要遍历
            if(L.data[j] < L.data[L.data[0]]) L.data[0] = j;
        if(L.data[0] != i){
            int tmp = L.data[i];
            L.data[i] = L.data[L.data[0]];
            L.data[L.data[0]] = tmp;
        }
    }
}
```

两个细节：哨兵位这里不是存值而是存**下标**（`L.data[0] = i`），比较时要写 `L.data[L.data[0]]`（双重下标），这是学生最容易看错的一行；外层到 `L.length - 1` 而内层到 `L.length`，两个边界不同，因为最后一轮只剩一个元素不用比，但找最小值时必须把它算进去。时间 O(n²) 且与初始序列无关，稳定（用 `<` 而不是 `<=`）。

**大根堆的定义与下标关系**：完全二叉树顺序存储，下标从 1 开始，则结点 i 的左孩子是 2i、右孩子是 2i+1、父结点是 i/2。大根堆要求每个结点不小于它的两个孩子。这就是约定 1 里“排序章节从 1 开始”的真正原因（A1 理已经埋下，本页兑现）。

**HeapAdjust**（材料原文，逐行走）：

```c
void HeapAdjust(int arr[], int k, int len){   // 把 arr[k] 往下沉到合适位置
    arr[0] = arr[k];                          // 哨兵存待下沉的结点
    for(int i = 2 * k; i <= len; i *= 2){     // i 从 k 的左孩子开始，每轮翻倍到下一层
        if(i < len && arr[i + 1] > arr[i]) i++;   // 选较大的孩子（i<len 防止越界）
        if(arr[0] >= arr[i]) break;            // 已经不小于两个孩子，到位
        arr[k] = arr[i];                       // 大孩子上移
        k = i;                                 // 继续往下比
    }
    arr[k] = arr[0];                           // 哨兵里的值落到最终位置
}
```

四个关键点：① `i *= 2` 是“往下一层”，不是逐个遍历；② `if(i < len && arr[i+1] > arr[i]) i++` 选较大的孩子，`i < len` 是防止只有左孩子时读 arr[i+1] 越界；③ `arr[0] >= arr[i]` 时 break，因为大根堆只要求父不小于子；④ 循环结束后 `arr[k] = arr[0]` 把待下沉的值放到最终位置。时间 O(logn)（树高）。

**建堆与排序主循环**（材料原文，两份材料写法不同，命中勘误 B5）：

```c
void HeapSort(int arr[], int len){
    if(arr == NULL || len <= 1) return;
    for(int i = len / 2; i > 0; i--) HeapAdjust(arr, i, len);   // 建堆：从最后一个分支结点开始
    while(len > 1){
        int tmp = arr[1]; arr[1] = arr[len]; arr[len] = tmp;    // 堆顶与末尾交换
        HeapAdjust(arr, 1, --len);                              // 剩下 len-1 个重新调整
    }
}
```

**建堆为什么从 len/2 开始**：下标大于 len/2 的结点都是叶子，没有孩子，不需要调整。从最后一个分支结点往前逐个下沉，每个都只需 O(logn)，总建堆代价是 O(n)（不是 O(nlogn)，这个结论要给出并说一句理由：大部分结点靠近底层，下沉距离短）。交换用局部变量 tmp 还是用 arr[0] 当暂存两种写法都对（勘误 B5），课件统一用 tmp，页脚注明另一种写法也对。

**二路归并**（材料原文）：

```c
void Merge(SqList &L, SqList &T, int low, int mid, int high){
    int p = low, q = mid + 1, k = low;
    while(p <= mid && q <= high){
        if(L.data[p] <= L.data[q]) T.data[k++] = L.data[p++];   // 取等号保证稳定性
        else T.data[k++] = L.data[q++];
    }
    while(p <= mid) T.data[k++] = L.data[p++];                  // 收尾两个循环
    while(q <= high) T.data[k++] = L.data[q++];
    for(int i = low; i <= high; i++) L.data[i] = T.data[i];      // 拷回原表
}
void MergeSort(SqList &L, SqList &T, int low, int high){
    if(low < high){
        int mid = (low + high) / 2;
        MergeSort(L, T, low, mid);
        MergeSort(L, T, mid + 1, high);
        Merge(L, T, low, mid, high);
    }
}
```

`<=` 保证稳定性这一点要单独强调：相等时先取左半段的，相同值的相对次序不变。三个指针 p、q、k 的分工与两个收尾循环是本页重点。复杂度用 A1 教的逐层累加推：每层合并总代价 O(n)，共 logn 层，所以时间 O(nlogn) 且与初始序列无关；空间 O(n)（辅助表 T）；稳定。

**逆序对个数**（材料真题 2020 第 2 题原文）：

```c
int merge(int A[], int temp[], int left, int mid, int right){
    for(int k = left; k <= right; k++) temp[k] = A[k];         // 先复制到辅助表
    int i = left, j = mid + 1, k = left, count = 0;
    while(i <= mid && j <= right){
        if(temp[i] <= temp[j]) A[k++] = temp[i++];
        else{
            count += mid - i + 1;                              // 关键一行：左半剩下的都比 temp[j] 大
            A[k++] = temp[j++];
        }
    }
    while(i <= mid) A[k++] = temp[i++];
    while(j <= right) A[k++] = temp[j++];
    return count;
}
```

**关键就一行** `count += mid - i + 1`，要讲透为什么：当 temp[j]（右半段当前元素）被选中时，左半段从 i 到 mid 的所有元素都大于 temp[j]（因为左半段有序且 temp[i] > temp[j]），而它们的下标都在 j 对应元素之前，所以每一个都与 temp[j] 构成一个逆序对，一次加 mid-i+1 个。这是“归并加计数”模板（模板 10）的核心，也是本题唯一的难点。题目限定 n ≤ 30000 且值不大于 200，暗示不能用 O(n²) 的双重循环，必须用归并的 O(nlogn)。

**基数排序一页**：按位数分配与收集，从低位到高位做 d 趟（d 是最大位数）。每趟用 10 个队列（十进制）按当前位分配再按序收集。时间 O(d(n+r))，r 是基数；不需要比较，所以能到线性。稳定。只给思想与一趟手算（题集 10选33、10选39），代码不写。

**外部排序一页**：四个名词各一句话——多路平衡归并（一次合并 k 个有序段，减少归并趟数）、败者树（在 k 路归并里选最小元素只需 logk 次比较而不是 k-1 次）、置换选择排序（生成比内存容量更长的初始有序段）、最佳归并树（按哈夫曼思路安排归并顺序使总读写最少）。802 考手算与概念（题集第10章相关题），代码不写，本课只要学生听到这四个名字知道各自解决什么问题。

**排序算法比较表**（本阶段收官页，必背）：

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
| :-- | :-- | :-- | :-- | :-- |
| 直接插入 | O(n²) | O(n²) | O(1) | 稳定 |
| 折半插入 | O(n²) | O(n²) | O(1) | 稳定 |
| 希尔 | 约 O(n^1.3) | O(n²) | O(1) | 不稳定 |
| 冒泡 | O(n²) | O(n²) | O(1) | 稳定 |
| 快速 | O(nlogn) | O(n²) | O(logn) | 不稳定 |
| 简单选择 | O(n²) | O(n²) | O(1) | 稳定 |
| 堆排序 | O(nlogn) | O(nlogn) | O(1) | 不稳定 |
| 二路归并 | O(nlogn) | O(nlogn) | O(n) | 稳定 |
| 基数 | O(d(n+r)) | O(d(n+r)) | O(r) | 稳定 |

配套两句选择依据（材料标注为高频）：要稳定且 n 小用插入；n 大且要平均最快用快排；要最坏情况也有保证用堆排；要稳定且 n 大用归并；元素位数少且范围小用基数。另补一句材料里有的专题：链表存储下快排与堆排不适用（需要随机访问），归并与插入仍可用。

### 易错与误解破除

- 简单选择的双重下标看成一层。
- HeapAdjust 里忘了选较大的孩子，直接拿左孩子比。
- 建堆从 len 开始而不是 len/2，白做一半。
- 堆排序每轮交换后忘了 `--len`，把已排好的末尾又卷进调整。
- Merge 的两个收尾循环只写一个。
- 逆序对里把 `count += mid - i + 1` 写成 `count++`，只算了一对。
- 以为堆排序不稳定是因为交换：不稳定的真正原因是相同值的结点可能分属不同子树、下沉时相对次序改变。
