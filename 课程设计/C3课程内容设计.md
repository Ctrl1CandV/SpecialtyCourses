# C3 题型课：课程内容设计（8节，约5.6小时）

> 配套文件：`课程设计总体框架.md` 五（大纲）、2.5（15 个模板与答题心法）、2.7（缺口登记）、`C2-B课程内容设计.md`（模板卡在 B 段已逐个建立）、`C2C3缺口代码与勘误修正.md`（3 道无解答真题的补写版）、`知识笔记/代码总结.md` 真题汇总（17 题原文与 14 题解答）。
> 本文件是每节课的备料清单（授课技法指南 §4.8 备料先行）。

## 全课段通用约定

**C3 与 C2 的分工**：C2 按章节教"这个算法怎么写"，C3 按题型教"拿到一道没见过的题，怎么认出它考哪个模板、改哪几处、评分点在哪"。同一批真题只在 C3 讲，C2-B 的模板卡页只标"考过哪年哪题"，不展开题面（框架 2.2）。

**每道真题的固定讲法（四步，与 2.5 的答题心法一致）**：

1. **给题面，按暂停让学生自己写**。这一步不能省，学生不先自己写，看讲解时会产生"我懂了"的错觉。
2. **认结构加选模板**：报出题目给的结构（带头结点吗、邻接表还是矩阵、下标从几起）与模板编号（2.5 的 1—15）。
3. **改条件**：逐段写代码，边写边说改动了模板的哪一处。这是四步里最值钱的一步，因为 802 的命题本质就是模板加改条件。
4. **补边界与复杂度**：空表、越界、visited 复位、k 与 n 的合法性，然后按三件套给出完整答案与评分点。

**评分点怎么讲**：802 的算法分析题一般 8—12 分，评分点是思想（约 2—3 分）、代码（约 5—7 分）、复杂度（约 1—2 分）。每道题讲完要给一句"这道题最容易丢的是哪一分"。

**每节的课后任务**：1 道真题（课上讲过的，要求课后自己重写并计时）加 1 道变式题（改一个条件的新题，从题集筛选工作稿的一档题里选）。

**C3-B 给完整代码，但不重讲算法原理**：按框架 1.4 的冲刺入口，学生可能没学 C2-B，所以 C3-B 必须自洽：题面、代码、复杂度全部给全。但讲解重心是“从模板到这道题改了哪几处”与评分点，算法为什么这么写的推导一句“见 C2-B 第几节”带过。两遍分工是硬的：**C2-B 讲为什么这样写，C3-B 讲怎么认出它、改了哪几处、分怎么给**。把同一段代码在两处各逐行讲一遍，就是第十一轮在 C1-B-05 上治过的重复论证，只不过换到了课段之间。

**页型与时长表的分钟数是内容预算**，允许与节标题的 duration 有 5 分钟以内的出入。**预算少于 duration 说明内容不够，要补知识点而不是把每页讲慢**；预算多于 duration 是正常余量。制作讲稿时按实测权重（字数/160＋停顿数×0.4＋跟画页加成 3 分钟）用最大余数法把页级标注调到合计精确等于 duration（SKILL 第五节第6条）。

## C3-A-01 导学＋答题四步法＋链表骨架（35min，15页）

### 目标

学完能按四步法处理一道链表题，能默写链表五个骨架，并能在 30 秒内报出一道链表题该套哪个模板。

### 逻辑链

顺序是：课段导学 → 802 代码题全景（算法分析 3 题 30 分、程序阅读约 20 分）→ 答题三件套的书写格式 → 答题四步法逐步示范一遍（用一道简单题走完四步）→ 链表五个骨架逐个过（头插逆置、快慢指针、断链拼接三步走、条件删除前驱跟随、循环链表模拟）。

四步法必须先示范再给骨架，否则学生不知道骨架是为哪一步服务的。示范题选 2算17（单链表逆置），因为它同时用到模板 1 且步骤最少。

### 页型与时长

| 页 | 内容 | 分钟 |
| :-- | :-- | :-- |
| P1 | 封面 | 1 |
| P2—P4 | 课段导学三块：C3 在备考中的位置（30 分怎么拿）、目录（A1—C1 八节）、学习要求（先自己写再看讲评） | 5 |
| P5 | 答题三件套的书写格式与分值分布 | 3 |
| P6 | 答题四步法：认结构、选模板、改条件、补边界 | 4 |

| P8 | 骨架一：头插逆置（模板 1） | 3 |
| P9 | 骨架二：快慢指针（模板 2，含找中点与倒数第 k 两个变体） | 4 |
| P10 | 骨架三：断链拼接三步走（模板 3，摘、逆、插） | 4 |
| P11 | 骨架四：条件删除前驱跟随（模板 4） | 3 |
| P12 | 骨架五：循环链表模拟（模板 11） | 3 |
| P13 | 小结：五个骨架一张表，各自适用什么题面特征 | 1 |
| P14 | 课后任务 | 1 |

预算合计 37，比 duration 35 多 2 分钟，属正常余量（P7 的四步法示范需要让学生真的按一次暂停）。制作讲稿时按实测权重压到 35。

### 关键内容

**四步法示范**（用单链表逆置走一遍，每步一句话）：

- 认结构：带头结点的单链表，L 指头结点，数据从 L->next 开始。
- 选模板：要把顺序反过来，用模板 1 头插法。
- 改条件：题目要求原地（空间 O(1)），所以不新建结点，把原链断开后逐个头插回去。
- 补边界：空表与只有一个结点时直接返回；循环里先存后继再改指针。

**五个骨架的呈现方式**：每个骨架一页，页面上只放三五行核心代码加一句"什么时候用它"。骨架不是完整函数，是学生要背下来默写的那几行。

| 骨架 | 核心几行 | 题面特征 |
| :-- | :-- | :-- |
| 头插逆置 | `L->next = NULL; while(p){ temp=p; p=p->next; temp->next=L->next; L->next=temp; }` | 逆置、重组、归并成递减、局部倒置 |
| 快慢指针 | `while(fast && fast->next){ slow=slow->next; fast=fast->next->next; }` | 找中点、倒数第 k、判环 |
| 断链拼接三步走 | 摘下一段、逆置它、插回指定位置 | 重排、改造链的结构 |
| 条件删除前驱跟随 | `if(条件){ pre->next=p->next; free(p); p=pre->next; } else { pre=p; p=p->next; }` | 按条件删结点、保留满足条件的 |
| 循环链表模拟 | 建环 `r->next=head`、终止 `p->next != p`、摘结点 `pre->next=p->next` | 报数出列、轮转、约瑟夫环 |

**倒数第 k 的两个变体**要放一页对比：快慢指针版（q 先走 k 步再同步走）与辅助栈版（全压栈再弹 k 次）。前者空间 O(1)，后者思路直白且能处理"输出倒数 k 个"这类变体。

### 设问清单

1. 拿到一道题，第一步做什么？（认结构：带头结点吗、下标从几起、什么存储）
2. 答题三件套各占多少分？（思想约 2—3、代码约 5—7、复杂度约 1—2）
3. 快慢指针找中点，偶数个结点时 slow 停在哪？（前半段的最后一个，由终止条件决定）
4. 条件删除时删掉一个结点后 pre 要不要动？（不动，p 从 pre->next 重新取）
5. 循环链表怎么判断只剩一个结点？（`p->next == p`）

### 课后题

- **默写题**：五个骨架合上资料各写一遍。
- **识别题**：给四道题面（2算21 归并成递减、2算12 删区间内结点、2算6 倒数第 k、2算30 循环链表删前驱），只要求报出模板编号与需要改动的地方，不写代码。

### 材料与勘误处置

骨架全部来自 `代码总结.md` 链表经典算法与 `C2-B课程内容设计.md` B1、B2 的模板卡。无缺口，无勘误命中。题源：2算6、2算12、2算17、2算21、2算30。

## C3-A-02 树图查找排序骨架（35min，15页）

### 目标

学完能默写树、图、查找、排序四类的九个骨架，能把 15 张模板卡汇总成的决策表看懂并用于认题。

### 逻辑链

顺序是：树的四个骨架（递归三件套、层序加 last 分层、中序加 prev、递归建树区间划分）→ 图的两个骨架（DFS 回溯含 visited 复位、BFS 分层含多源）→ 查找的两个骨架（折半框架改判定、辅助栈逆序）→ 排序的一个骨架（Partition 与归并加计数）→ 收尾把 15 张模板卡汇总成一页决策表。

决策表是本节的落点：三问定模板——什么结构、做什么操作、有什么约束。

### 关键内容

**九个骨架的核心几行**（页面只放这几行，完整代码在 C2-B 已讲）：

| 骨架 | 核心几行 | 题面特征 |
| :-- | :-- | :-- |
| 递归三件套 | `if(T==NULL) return 基准值; 左=递归(左); 右=递归(右); return 合并(左,右,本结点);` | 求高度、结点数、叶子数、判平衡 |
| 层序加 last 分层 | `if(front > last){ last = rear; 本层结算; }` | 宽度、繁荣度、按层统计 |
| 中序加 prev | 中序遍历里 `if(当前 <= prev) 返回假; prev = 当前;` | 判 BST、有序性校验 |
| 递归建树 | `根=A[preL]; 在中序定位 k; leftLen=k-inL; 递归左右两段` | 由遍历序列构造二叉树 |
| DFS 回溯 | `visited[u]=true; 递归邻居; visited[u]=false;` | 找路径、经过某点、所有简单路径 |
| BFS 分层 | 队列加 `front > last` 结算；多源版把所有源点先入队且 dist 置 0 | 最短步数、距离图、像素距离 |
| 折半改判定 | `while(low<high){ mid=...; if(判定) high=mid; else low=mid+1; }` | 双调序列峰值、旋转数组、第一个满足条件的位置 |
| 归并加计数 | 合并时 `count += mid - i + 1` | 逆序对、跨越两半的统计 |
| 入度表法 | 求全部入度 → 按给定顺序检查入度是否为 0 → 减后继入度 | 拓扑排序、验证拓扑序列、判环 |

**决策表（三问定模板）**是本节的收官页：

- 问一：**什么结构**？单链表 / 双链表 / 循环链表 / 二叉树 / 图（矩阵还是邻接表）/ 数组。结构定了候选模板的范围。
- 问二：**做什么操作**？走一遍（遍历类）/ 改结构（插入删除重排）/ 找一个东西（查找类）/ 统计一个量（计数类）/ 排顺序。操作定了模板类型。
- 问三：**有什么约束**？原地（空间 O(1)）/ 时间尽可能低 / 利用原结点空间 / 不能修改原表 / k 与 n 的关系。约束定了要改模板的哪一处。

三问之后报出模板编号，然后按四步法往下走。这一页在 C3-C-01 会变成一棵决策树。

### 设问清单

1. 层序加 last 分层里，last 什么时候更新？（front > last，即本层全部出队时）
2. DFS 回溯里 visited 什么时候复位？（这条路走不通返回 false 之前；找到答案直接返回时可以不复位）
3. 多源 BFS 与普通 BFS 差在哪一处？（所有源点先全部入队且 dist 置 0）
4. 折半框架改判定时，`high = mid` 与 `high = mid - 1` 的区别是什么？（前者保留 mid 作为候选，后者排除它；用错会漏解或死循环）
5. 归并加计数里 `count += mid - i + 1` 数的是什么？（左半段从 i 到 mid 全部与当前右半元素构成逆序对）
6. 入度表法验证拓扑序列时，需要真的排一遍序吗？（不需要，按给定顺序模拟即可）

### 课后题

- **默写题**：九个骨架各写一遍，并写出每个骨架对应 2.5 里的模板编号。
- **识别题**：给五道题面（6算20 繁茂度、7算18 长度 k 的简单路径、9算7 判 BST、10算26 有序数组合并、2算32 拆表），只报模板编号与需要改动的地方。

骨架全部来自 `代码总结.md` 与 `C2-B课程内容设计.md` 的模板卡。无缺口，无勘误命中。题源：6算20、7算18、9算7、10算26、2算32。

## C3-B-01 链表真题一：顺着链走（45min，16页）

### 目标

学完能独立完成 2026 约瑟夫环、2025 倒数第 k、2021 有序单链表三问，并能按三件套格式书写，知道每道题最容易丢的是哪一分。

### 逻辑链

三道题都是"顺着链走"型：不改链的结构，只是走一遍并做统计或摘结点。难度递增：倒数第 k（一个动作）→ 有序链表三问（三个动作，共享一次遍历）→ 约瑟夫环（建环、定位、报数、摘结点四个动作，8 分）。

讲法固定四步，每道题的"改条件"部分是本节重点。

### 页型与时长

| :-- | :-- | :-- |
| P1 | 封面 | 1 |
| P2 | 本节三题的共同点：顺着链走，不改结构 | 2 |

### 三道题的四步法要点

**2025 倒数第 k**：

- 认结构：题目给了结点定义 `typedef struct node{ int data; struct node *next; }LNode, *LinkList;`，字段名与材料一致，直接用。**题目没说有头结点**，代码总结的解答按带头结点写（p 与 q 都从 L 出发），这一点要在页面上说明：如果题目明确无头结点，两个指针都从 L 出发仍然正确，因为差值关系不变。
- 选模板：模板 2 快慢指针。
- 改条件：题目要求"找到就打印该元素的值并返回 1，否则返回 0"，所以骨架的返回值改成 1/0，并在返回前加 printf。
- 补边界：k 大于表长时 q 先变成 NULL，返回 0；k 等于 0 或负数要说明按题意 k 是正整数。
- 评分点：最容易丢的是"k 超过表长返回 0"这一分支，很多人只写主流程。
- 一题多解：辅助栈法（模板 14），空间 O(k)，讲一句它的适用场景（要输出倒数 k 个全部元素时更自然）。

**2021 有序单链表三问**（这是一道三小问的题，共享"表有序"这个条件）：

- 认结构：带头结点的**有序**单链表，正整数序列。"有序"是关键条件，三问都要用它。
- 第一问（比 x 大的数有几个，相同值只算一次）：顺着走，用 `before` 记住上一个计入的值，`if(value > x && value != before){ count++; before = value; }`。改条件就是加了"值不等于上一个计入值"这一句，这是"相同值只算一次"的翻译。
- 第二问（比 x 小的按递减排列）：这是三问里最难的。思路是找到最后一个比 x 小的结点 p，把 [L->next, p] 这一段摘下来用头插法逆置，再接回去。材料解答里的关键几句：`rear = L->next` 记住原第一个结点（逆置后它变成这一段的尾），`p->next = NULL` 断链，头插循环，最后 `rear->next = q` 接回。要逐句走一遍，尤其"为什么用 rear 而不是重新找尾"。
- 第三问（删除比 x 大的正偶数）：条件删除前驱跟随，条件是 `value > x && value % 2 == 0`。材料解答里那句注释值得直接念：**只有不删除下一个元素的时候才移动 p**。
- 评分点：三问共 12 分左右，第二问占一半以上，因为它同时要断链、逆置、接回三个动作。

**2026 约瑟夫环**（8 分）：

- 认结构：题目说 n 个人围成圈编号 1—n，从第 s 个开始报数，数到 m 出列。**这道题不带头结点**（材料解答用 head 存 1 号），与 A3 的默认约定不同，要在页面上对照说明。
- 选模板：模板 11 循环链表模拟。
- 改条件：三处——① 建环时结点的 data 存编号 1—n；② 报数起点是第 s 个而不是第 1 个，所以建完环先走一段定位到 s，同时维护 pre；③ 出列条件是数到 m，所以内层循环走 m-1 步。
- 补边界：只剩一个结点的判定是 `p->next != p`；m=1 时每轮直接摘当前结点；s 大于 n 时按题意 s 在 1—n 范围内，若超范围可以走 `(s-1)%n` 步（说明这是加分处理，不写也不扣分）。
- 复杂度：时间 O(nm)（n 个人各出列一次，每次走 m 步），空间 O(n)（建了 n 个结点）。
- 评分点：最容易丢的是"从第 s 个开始"这一条件，很多人默认从 1 号开始。其次是复杂度写不出来。

### 设问清单

1. 倒数第 k 里 p 与 q 都从 L 出发，如果题目明确无头结点还成立吗？（成立，差值关系不变）
2. 2021 第一问怎么翻译"相同值只算一次"？（用 before 记住上一个计入的值）

4. 第三问删除后 p 为什么不能动？（下一个待检查结点现在紧跟 pre）
5. 约瑟夫环怎么判断只剩一个人？（`p->next == p`）
6. 约瑟夫环的复杂度为什么是 O(nm) 不是 O(n)？（每次出列要走 m 步）

### 三道题的四步法要点

**2022 稀疏多项式奇偶分解**：

- 认结构：循环链表，结点定义题目给了（`float coef; int exp; struct PolyNode *next;`）。约束是"利用原链表中的结点空间构成这两个链表"，意思是数据结点不许新 malloc，只能新建两个头结点。
- 选模板：拆表加头插（模板 1 的变体）。
- 改条件：判断依据从"值"换成"指数的奇偶"（`(int)p->exp % 2`）；摘结点前必须先存后继。
- 补边界：原头结点最后 free；如果要求保持原顺序，头插会反序，要改用尾插并维护两个 rear（这一点要在页面上说明，因为题目没明确要求顺序，两种都给分）。
- 复杂度：时间 O(n)，空间 O(1)（只新建两个头结点）。
- 评分点：最容易丢的是"利用原结点空间"这个约束——新 malloc 了数据结点就违反题意。

**2023 循环段倒置**（12 分，本节最重的一道）：

- 认结构：L 是链表头结点地址，表中共 m 个结点（m>3），**从第 i 个结点到第 m 个结点构成一个循环部分链表**（1<i<m）。要求时间 O(n)。函数签名题目给了：`PattemInvertL(LinkList L, int i, int m)`。
- 选模板：模板 1 头插法，但只在局部区间上用；加上模板 3 的断链拼接。
- 改条件：三处——① 先走 i-1 步定位到区间前驱 head；② 头插的目标位置是 `head->next` 而不是 `L->next`；③ 循环次数是 m-i+1 次（区间长度），循环结束后要把原区间第一个结点（现在成了尾）的 next 接回 `head->next`。
- 材料解答的关键几句：`while(j < i-1){ head = head->next; j++; }` 定位；`LNode *p = head->next, *rear = head->next` 记住区间起点（它逆置后变成尾）；`while(j < m)` 做头插；最后 `rear->next = head->next` 接环。
- 补边界：`i <= 1 || i >= m` 直接返回；L 为 NULL 返回。
- 复杂度：O(m)，满足题目 O(n) 的要求；空间 O(1)。
- 评分点：12 分的题，思想约 3 分、代码约 7 分、复杂度约 2 分。最容易丢的是"接环"那一句，漏了整个链就断了；其次是循环次数的边界（j 从 i-1 开始数到 m）。

**2020 双向循环链表改造**：

- 认结构：带头结点的双向循环链表 L=(a1,a2,...,an)，目标是 L=(a1,a3,...,an,...,a4,a2)，即奇数位置按原序在前、偶数位置按原序在后。
- 选模板：模板 3 断链拼接（摘、移、插），因为是双链表加循环，每步要改四条指针。
- 改条件：p 从 a1 开始，每轮把 p 的下一个结点 q（偶数位置）摘下来插到 rear 之后（rear 是头结点的 prior，即当前尾结点）；然后 p 跳到 q 原来的下一个（temp）。终止条件是 p 走到 rear 或 p->next 是 rear。
- 材料解答的四条指针要逐条讲：`p->next = temp; temp->prior = p;`（把 q 从原位置摘掉并接好 p 与 temp）、`q->next = rear->next; q->prior = rear;`（把 q 接到尾部，rear->next 是头结点）、`rear->next->prior = q; rear->next = q;`（头结点的 prior 与 q 的 next 互指，完成插入并更新尾）。
- 补边界：n 小于 3 时不需要改造，直接返回（材料解答的第一个 if 处理了三种情况）。
- 复杂度：O(n)，空间 O(1)。
- 评分点：双链表加循环的指针最容易漏一条，漏了链就断。建议的书写策略是先在草稿上画改前改后两张图，再照着图写四条指针（这正是 C1-B 练的"画图再写"）。

2. 循环段倒置里 head 是什么？（区间前一个结点，即第 i-1 个）

### 四道题的四步法要点

**2024 判 BST**：

- 认结构：题目给了 `typedef struct BiTNode{ int data; struct BiTNode *lchild, *rchild; }BiTNode, *BiTree;`，字段名与材料一致。
- 选模板：模板 15 中序加 prev。
- 改条件：骨架的中序遍历里加两行——比较当前值与 prev、更新 prev。返回值用 int（1 是、0 不是）。
- 补边界：**prev 的初值**是本题最大的坑。材料用 `int prev = -1`，隐含“所有结点值大于 -1”；如果树里有负数就错。修正版用 INT_MIN，或在答题时写一句“设结点值均为正整数，prev 初值取 0”。这个假设必须写在答案里。
- 另一个细节：prev 必须用引用 `int &prev`，因为它是跨递归层共享的状态（与最长路径的 maxLen 同一道理）。
- 短路：`if(!checkBST(node->lchild, prev)) return 0;` 左子树不是 BST 就不必再看右边。
- 复杂度：时间 O(n)，空间 O(树高)。

**2024 繁荣度**：

- 认结构：普通二叉链表。题目定义繁荣度为“每一层的结点数乘以该层的层数”求和。
- 选模板：模板 6 层序加 last 分层。
- 改条件：从求宽度改三处——把 maxwidth 换成累加器 totalProsper、多一个 height 计数器从 1 起、每层结束时 `totalProsper += height * width`。这个“从已知算法改三处”的讲法就是四步法里“改条件”的标准示范，要明说。
- 补边界：空树返回 0；height 从 1 还是从 0 起要与题目定义的层号一致。
- 复杂度：时间 O(n)，空间 O(n)（队列）。
- 一题多解：也可以用递归按层统计（额外传一个层号参数与一个每层计数的数组），讲一句不展开。

**2025 最长路径**：

- 认结构：题目给了 BiTNode 定义（用 ElemType），并给了两个函数签名 `longestPath` 与 `findLongestPath`。这是少见的“题目把骨架给了一半”的题，要提醒学生先看题目给了什么。
- 选模板：模板 5 递归三件套的变体（遍历中维护全局信息）。
- 改条件：两处——用 path 数组存当前路径、maxPath 存最长路径；只在叶子结点处比较与拷贝。
- 补边界：**pathLen 用值传递而 maxLen 用引用**，这是本题的核心设计。值传递让每层有自己的 pathLen 副本，递归回来自动恢复；引用让 maxLen 能被子层改写。这个对比是 C1-B-05 值传递与引用传参在真题里的直接应用，要讲透。
- 复杂度：时间 O(n)，空间 O(树高) 加两个 O(n) 的数组。
- 评分点：最容易丢的是“输出路径长度”与“打印路径结点值”两个要求只做了一个。

**2026 先序中序建树**（10 分）：

- 认结构：题目说结点值互不相同，先序与中序分别存在 A[1..n] 与 B[1..n]（**下标从 1 起**，这是题目给的口径，与材料的 0 起不同，答题时按题目的来）。
- 选模板：模板 12 递归建树（区间划分）。
- 改条件：四步——先序第一个是根；在中序里找到根的位置 k；算出左子树结点个数 leftLen = k - inL；用 leftLen 把先序也切成两段，递归建左右子树。
- 补边界：`if(preL > preR) return NULL;` 区间为空就是空子树；结点值互不相同是“能在中序里唯一定位根”的前提，如果题目没说互不相同这个算法就不成立，这一点要提一句。
- 复杂度：时间 O(n²)（每次定位根要在中序里扫一遍），空间 O(n)（递归栈）。加分思路：用哈希表存中序的值到下标的映射，把定位降到 O(1)、总体 O(n)，提一句即可。
- 评分点：四个下标边界（preL+1、preL+leftLen、preL+leftLen+1、preR、inL、k-1、k+1、inR）最容易写错一个，建议在草稿上先画两个数组与四个边界的位置再写代码。

### 设问清单

1. 判 BST 为什么用中序而不是先序？（BST 的中序序列才有序）
2. prev 为什么必须用引用？（它是跨递归层共享的状态）
3. prev 初值取 -1 有什么隐患？（隐含所有值大于 -1，有负数就错）
4. 繁荣度相比求宽度改了哪三处？（累加器、height 计数器、每层累加）
5. 最长路径里 pathLen 为什么用值传递？（每层要自己的副本，递归回来自动恢复）
6. 为什么只在叶子处比较路径长度？（内部结点的路径不是完整的根到叶路径）
7. 建树时 leftLen 有什么用？（用它把先序序列也切成左右两段）
8. 建树的时间复杂度为什么是 O(n²)，怎么降到 O(n)？（每次定位根要扫中序；用哈希表存值到下标的映射）

### 四道题的四步法要点

**2026 判拓扑序列**（12 分）：

- 认结构：邻接表存储的图，题目给了一个序列 V1V2...Vn。材料解答用的边表字段名是 `nextarc`，而 2025 真题用的是 `next`，两题并讲时按 A9 的统一规则交代一句：以题目给出的定义为准。
- 选模板：模板 13 入度表法。
- 改条件：**关键认识是不需要真的做一遍拓扑排序再比较**。只求入度表，然后按给定序列的顺序模拟：每检查一个顶点 u，如果当前入度不为 0 就返回 false（说明还有前驱没在它前面输出），否则把 u 的所有后继入度减 1。
- 补边界：`G.vexnum == 0` 返回 false；序列长度 n 默认等于 vexnum。
- 复杂度：时间 O(|V|+|E|)，空间 O(|V|)。
- 评分点：12 分里“不真排序而按给定顺序模拟”这个思路占思想分的大头。写成先排序再比较也能得大部分分，但代码量与时间都大。

**2025 经过 k 的路径**：

- 认结构：邻接表表示的**连通图**，题目给了完整的 ArcNode、VNode、ALGraph 定义（字段名是 `next` 而不是 `nextarc`，按题目写）。要求输出从 u 到 v 并经过 k 的一条路径，不存在输出 -1。
- 选模板：模板 7 DFS 回溯。
- 改条件：两处——把“u 到 v 经过 k”拆成两段独立的可连性问题（u 到 k、k 到 v）；checkPath 带回溯复位 `visited[u] = false`。
- 补边界：**两段之间必须把 visited 全部复位**，否则第一段用过的标记会让第二段误判。这是本题最容易丢分的地方。另外 `G.vexnum == 0 || G.arcnum == 0` 直接返回 false。
- 复杂度：单次 DFS 是 O(|V|+|E|)，最坏情况（要回溯全部路径）更高，答题时写 O(|V|+|E|) 并说明是单次 DFS 的代价。
- 勘误处置：材料用 `bool visited[G.vexnum] = {false}`（变长数组带初始化）与约定 5 矛盾，课件改用固定长度数组加循环赋值（勘误 A6）。

**2024 长度 k 的路径**：

- 认结构：**无向图**，邻接表存储。问是否存在长度为 k 的路径（k 条边）。
- 选模板：模板 7 DFS 回溯。
- 改条件：多带一个 `depth` 参数，每往下一层加 1，`depth == k` 就成功。这是“递归中携带额外信息”（与最长路径的 pathLen 同源）。
- 补边界：`k < 1 || k > G.vexnum - 1` 返回 false，理由是简单路径要求顶点不重复，k 条边需要 k+1 个不同顶点。每个起点前要把 visited 全部清零。
- 与 2025 题的对比（P7 专页）：两题都用 DFS 回溯，差别在三处——2025 题有明确的起点终点与必经点，2024 题要枚举所有起点；2025 题拆两段，2024 题带 depth；停止条件一个是“到 v”，一个是“depth 等于 k”。

**2023 像素距离图**（多源 BFS，缺口 13 补写）：

- 认结构：n×m 的 01 位图，1 表示白。距离定义是曼哈顿距离。要求时间复杂度尽可能低，输入输出格式题目给了。
- 选模板：模板 8 BFS 分层，但是**多源**版。
- 关键认识（本题的解题突破口，单独一页讲）：直接对每个黑像素做一次 BFS 是 O(n²m²)，会超时。反过来想：**从所有白像素同时往外扩散**，每个黑像素第一次被扩散到时，那一层的层号就是它到最近白像素的距离。所以把所有白像素先全部入队、dist 置 0，其余置 -1 表示未访问，然后普通 BFS 逐层扩散，每扩一层 dist 加 1。时间 O(nm)。
- 改条件：三处——初始化时双层循环把白像素全部入队；队列里存的是一维编号 `i*m+j`（约定 4 的变通），取出时用除与模还原坐标；用 `dist[nx][ny] == -1` 同时充当 visited，避免额外数组。
- 补边界：四个方向的越界判断；n 或 m 为 0；题目保证至少一个白像素，所以队列不会一开始就空。
- 复杂度：时间 O(nm)（每个像素入队出队各一次），空间 O(nm)。
- 评分点：本题最难的是想到“反过来从白像素扩散”。写成对每个黑像素做 BFS，思想分能拿一部分但复杂度分全丢。讲评时要明确说这一点。

**2022 最小半径生成树（选讲）**：题目定义树的半径为根到叶子的最大距离，要求找出半径最小的生成树。思路是枚举每个顶点作根求生成树再算半径，或用“图的中心”概念（Floyd 求全源最短路径后找 min max）。难度高、材料无解答（缺口 15），处理方式：只给思想两句话与一个解法方向，不写完整代码，并说明这道题在考场上属于难题，时间不够可以先跳过。

### 设问清单

1. 判拓扑序列需要真的排一遍序吗？（不需要，按给定顺序模拟即可）
2. 检查到某个顶点入度不为 0 说明什么？（它的前驱没在它前面输出，序列不合法）
3. 2025 题为什么要把 visited 复位两次？（两段独立搜索，第一段的标记会影响第二段）
4. 2024 题的 k 上界为什么是 vexnum-1？（简单路径顶点不重复，k 条边需 k+1 个顶点）
5. 像素距离图为什么不能对每个黑像素各做一次 BFS？（O(n²m²) 超时）
6. 多源 BFS 的 dist 数组除了存距离还充当什么？（充当 visited，-1 表示未访问）
7. 队列里为什么存一维编号而不是两个坐标？（材料的 SqQueue 只存一个 int，用 i*m+j 编码）

### 两道真题的四步法要点

**2021 双调序列最大值**：

- 认结构：n 个数组成的双调序列（先递增后递减），要求尽可能高效地找最大的关键值。“尽可能高效”这个提示就是在说：不能扫一遍 O(n)，要用 O(logn)。
- 选模板：模板 9 折半框架改判定。
- 改条件：把折半查找的“与 key 比较”换成“看 mid 处于上升段还是下降段”：如果 `A[mid-1] > A[mid]` 说明 mid 在下降段，峰值在左边，`right = mid`（**不是 mid-1，因为 mid 自己可能就是峰值**）；如果 `A[mid+1] > A[mid]` 说明在上升段，峰值在右边，`left = mid + 1`；两边都不满足说明 mid 就是峰值，直接返回。
- 补边界：`n <= 0` 返回 -1；`mid >= 1` 与 `mid < n-1` 两个判断防止读 A[-1] 与 A[n]；循环终止条件 `left < right`，最后返回 A[left]。
- 复杂度：时间 O(logn)，空间 O(1)。
- 评分点：最容易丢的是 `right = mid` 与 `left = mid + 1` 的不对称。理由要讲清：下降段时 mid 可能就是答案所以不能排除，上升段时 mid 一定不是答案（右边还有更大的）所以可以排除。这是“折半框架改判定”这一类题的通用难点。

**2020 逆序对个数**：

- 认结构：n（n ≤ 30000）个不大于 200 的正整数，要求时间复杂度尽可能小。**n ≤ 30000 这个提示就是在排除 O(n²)**：30000 的平方是九亿，会超时；O(nlogn) 是四十多万，可以。
- 选模板：模板 10 归并加计数。
- 改条件：在二路归并的 Merge 里加一行——当右半段的元素被选中时，左半段从 i 到 mid 的所有元素都大于它且下标在前，所以 `count += mid - i + 1`。
- 补边界：先把待合并区间复制到辅助表 temp（避免边合并边覆盖）；两个收尾循环；递归终止 `left >= right` 返回 0。
- 复杂度：时间 O(nlogn)，空间 O(n)。
- 一题多解：题目说值不大于 200，所以也可以用计数数组或树状数组做，但归并解法更通用且是模板，课件主推归并，另一种提一句不展开。
- 评分点：`count += mid - i + 1` 写成 `count++` 是最常见的错，只算了一对而不是全部。

**Top-K 变式**（题集 6算46 数据流第 k 大、10答14 前 k 大最小比较）：两种解法对比一页。① 小根堆法：维护一个大小为 k 的小根堆，扫一遍数组，比堆顶大就替换堆顶并调整，最后堆顶就是第 k 大，时间 O(nlogk)，适合数据流。② 快排划分法：Partition 之后看枢轴位置，只递归包含第 k 大的那一侧，平均 O(n)、最坏 O(n²)。选择依据：数据流或 n 极大用堆，一次性数组且要平均最快用划分。

### 程序阅读题的答题方法（缺口 16）

程序阅读题约 20 分，4—5 小题，形式固定为三类。这是两份材料都没覆盖的部分，以下方法从真题形态归纳，**制作课件前需用 `真题资料/` 里的 2024—2026 真题 PDF 逐题核对**，核对后把真实例子补进 P13。

**考法一：挖空补全**。四步做法：① 先读函数名、参数与返回值，猜整体功能；② 标出所有变量并说出各自含义（尤其指针指向什么、下标从几起）；③ 看空格所在的位置是在循环条件、赋值语句还是返回语句，按位置定候选；④ 回代验证：把答案代进去走一个小例子。常考的空格类型：循环边界（`i < n` 还是 `i <= n`）、指针移动（`p = p->next`）、递归调用的参数怎么变、返回条件。

**考法二：片段排序**。三步做法：① 找入口片段（含变量声明与初始化的那段）；② 找依赖关系（哪一段用到了另一段定义的变量，被依赖的在前）；③ 验证：按排好的顺序走一遍小例子。技巧：初始化一定在最前，输出或返回一定在最后，中间按数据流排。

**考法三：功能与复杂度分析**。写法是一句功能加一句依据：功能要用“这个函数做什么”的句式（例如“把链表逆置并返回新表头”），不能只写“处理链表”；复杂度要给一句理由（例如“双层循环，外层 n 次内层平均 n/2 次，所以 O(n²)”）。只写 O(n²) 不给理由会扣分，这与 A1 讲的答题三件套一致。

### 设问清单

1. 双调序列题里“尽可能高效”暗示了什么？（不能 O(n) 扫，要 O(logn) 折半）
2. 为什么 `right = mid` 而 `left = mid + 1`？（下降段时 mid 可能就是答案，上升段时 mid 一定不是）

### 关键内容

**题型识别决策树**（三问，每问一页）：

- 第一问：**什么结构**？单链表 → 模板 1、2、3、4、14；双链表或循环链表 → 模板 3、11；二叉树 → 模板 5、6、12、15；图 → 模板 7、8、13；数组 → 模板 9、10。
- 第二问：**做什么操作**？走一遍并统计 → 模板 5、6、8；改结构（插入删除重排）→ 模板 1、3、4；找一个位置或值 → 模板 2、9；验证或排序序列 → 模板 13；倒着处理 → 模板 14。
- 第三问：**有什么约束**？原地且空间 O(1) → 排除需要辅助数组的解法；时间尽可能低 → 排除 O(n²)，想折半或归并；利用原结点空间 → 不许新 malloc 数据结点；经过某点或某长度 → 模板 7 加参数。

**高频易错清单七条**（每条配一个具体例子，不空讲）：

1. **下标基准写错**：排序章节用 0 起、查找章节返回下标而不是位序。例子：折半查找返回 mid 而不是 mid+1。
2. **忘判空**：malloc 后不判、递归前不判、访问 p->next 前不判 p。例子：非递归后序遍历缺 T==NULL 判断（勘误 A4）。
3. **visited 忘复位**：路径搜索不回溯、多次调用不清全局数组、两段搜索之间不复位。例子：2025 题两段之间必须复位。
4. **malloc 忘 free 或 free 后不置 NULL**：销毁链表只 free 头结点、删除结点先 free 再取值。例子：DestroyList 必须先存后继。
5. **k 与 n 的合法性**：倒数第 k 里 k 超过表长、长度 k 的路径里 k 超过 vexnum-1、约瑟夫环里 m 或 s 超范围。
6. **递归漏终止条件或漏进度保证**：无限递归、区间不缩小。例子：平均值划分的死递归（勘误 A2）。
7. **复杂度只给结论不给理由**：三件套的第三件写“O(nlogn)”就完了。正确写法是一句结论加一句依据。
