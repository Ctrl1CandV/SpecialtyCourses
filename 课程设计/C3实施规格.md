# C3 题型实战阶段实施规格（生产依据）

> 与 `C3课程内容设计.md`（逐节备料，695行）配套。设计文档回答"每节讲什么"，本规格回答"怎么生产、C3 与 C2 的边界差异、资源在哪"。
> 通用生产流程/质量标准/图形用法与 `C2-B实施规格.md` 完全一致（六步流程、check.js 0 ERROR、页序对应、时长合计=duration、三页型、禁语、加粗≤10、口播无表格、指针 `\*`），此处只写 C3 特有规则。

## 一、C3 与 C2 的边界差异（最重要，写反就废）

| 项 | C2-B | C3 |
| :-- | :-- | :-- |
| 真题题面 | 不出完整题面，匿名化/缩短/改写 | **给完整题面原文**（PPT 展示，讲稿带读） |
| 年份分值 | 不提分值评分点 | **明说年份与分值**（学生页可以出现"2026年·12分"badge） |
| 四步法 | 不做完整示范 | **每道题完整走四步法**（认结构→选模板→改条件→补边界） |
| 评分点 | 不讲 | **每题讲评分点**：思想约2-3分、代码约5-7分、复杂度约1-2分，并给一句"这道题最容易丢的是哪一分" |
| 算法原理 | 逐行讲透"为什么这样写" | **一句"见数据结构强化阶段第N节"带过**，重心是"从模板改了哪几处" |
| 课后任务 | 1跟练+1变式 | **1道真题重写（计时）+1道变式** |

**两遍分工是硬的**：C2-B 讲为什么这样写，C3-B 讲怎么认出它、改了哪几处、分怎么给。同一段代码不许在两处各逐行讲一遍。C3-B 给完整代码保证课段自洽（冲刺入口的学生可能没学 C2-B）。

## 二、每道真题的固定页面结构（四步法）

1. **题面页**：完整题面 + badge（"真题·2026""12分"）+ 一句"先按暂停自己写"；
2. **认结构+选模板页**：题目给了什么结构定义（字段名以题目为准）、下标从几起、有无头结点；报模板编号；
3. **改条件页**（可多页）：逐段写代码，每段明说"这里把模板的哪一处改成了什么"——这是四步里最值钱的一步；
4. **补边界+评分点页**：空表/越界/复位/k 合法性；三件套完整答案；复杂度；"最容易丢哪一分"。

过程页（动画/跟画）按需插入：改指针的题画链表状态（linkedlist diagram），数组的题画格子（array diagram），树的题用 PNG（`assets/diagrams/` 已有 b4/b5 树形图可参考画风）。
