# C2-B 强化阶段实施规格（builder 生产依据）

> 本文档是 C2-B 十节课件生产的**实施规格**，与 `C2-B课程内容设计.md`（逐节备料）配套使用。
> 设计文档回答"每节讲什么"，本规格回答"怎么生产、质量标准是什么、资源在哪"。
> 生产顺序：B1 先行（首节含课段导学，是后 9 节的模板）→ 验收后批量推进 B2-B10。

---

## 一、任务概述

- **产出物**：每节三件套 = `课件/C2/C2-B-0N/deck.yaml` + `C2-B-0N-讲稿.md` + `C2-B-0N.pptx`（渲染产物）
- **节数与时长**：B1-B10 共 10 节，约 7.2 小时（430 分钟），各节 duration 以设计文档节标题为准
- **学生-facing 名称**：封面 title 用"数据结构强化阶段"，subtitle 用"第N节 主题"；内部代号 C2-B 只出现在目录/文件名/meta.id，**严禁出现在学生页**（check.js 第6项拦 C2-B，但裸写"B1""B段"抓不到，需人工注意——C2-A-03 曾泄漏"A2"）

## 二、生产流程（每节固定六步）

1. **读设计文档对应节**：`课程设计/C2-B课程内容设计.md` 找到 `## BN` 小节，通读目标/逻辑链/页型与时长/知识点与关键代码/推演与动画/设问清单/易错/802挂钩/课后题/材料与勘误处置。
2. **核对缺口代码**：设计文档"材料与勘误处置"里标注的缺口编号（B2 缺口14、B3 缺口4、B5 缺口8、B6 无、B7 缺口9/10、B8 缺口5/6/7、B9/B10 缺口11/12），到 `课程设计/C2C3缺口代码与勘误修正.md` 取补写版代码，**不在写稿时现编**。
3. **参考 C2-A 成品**：`课件/C2/C2-A-03/deck.yaml` 与 `C2-A-03-讲稿.md` 是最近产出的质量模板（新生产法产物）；A5/A7/A9 的图形补充（diagram 块、image 块）是 B 段图形的参考。
4. **生产 deck.yaml + 讲稿**：按 CONTENT-SPEC 写 deck（代码≤10行、bullets≤6条、表格≤6行、YAML 特殊字符加引号）；按 SKILL 第五节写讲稿（`## P{n} 页名（约Xmin）` 逐页对应、页级时长合计=duration、封面页固定开场白、课前准备登记动画页）。
5. **图形补充**：简单规则图形（链表、数组格子、栈队列）用 `diagram` 块（渲染器已支持 array/linkedlist，参数见 C2-A 成品）；复杂示意图（树形、图形、算法过程）用 Python matplotlib 生成 PNG 放 `assets/diagrams/`，image 块引入（生成脚本参考 `_tmp/gen_diagrams.py`）。
6. **渲染 + 自检**：`node tools/check.js "课件/C2/C2-B-0N"`，要求 0 ERROR；WARN 只允许中性"估时提醒"。

## 三、质量标准（交付硬要求）

| 检查项 | 标准 |
| :-- | :-- |
| check.js | 0 ERROR；WARN 仅中性估时提醒 |
| 页序对应 | deck 第 n 页 = 讲稿 P{n}，标题逐页核对（check.js 只比页数比不出错位） |
| 时长 | 讲稿页级"（约X分钟）"合计 = deck.meta.duration |
| 三页型 | 每节至少各一个：问题页（具体引题）、过程页（真实状态变化，拿纸跟画）、检查页（预测一步/补代码/判断边界，设问后真停顿） |
| 五步讲法 | 每个算法按"思想→小实例推演→骨架填空→完整代码→复杂度"组织（框架 4.4） |
| 模板卡页 | 每节末尾一页模板卡：算法名+适用场景+骨架三五行+复杂度+框架2.5模板编号 |
| 真题边界 | 可用匿名化/缩短/改写任务当教学载体；**不出现完整真题原文、不讲年份分值评分点、不做四步法示范**；模板卡可标"考过哪年哪题" |
| 答案页 | 末尾两页一题一页（不口播），讲稿建"（不口播）"占位小节 |
| 讲稿定位 | 骨架+内容清单，不是逐字稿；文风对齐 `AI味语料库/02-积极案例/主讲笔记样本.md`（术语直给、零铺垫）；主讲自发内容五类型备进骨架但不虚构立场经历 |
| 禁语 | 学生页严禁内部代号（C2-B、B1-B10、"B段"）与自造词（口径/落点/底座/抓手/闭环/心智模型等，check.js 第14项） |
| 加粗 | 讲稿每节≤10处；口播正文禁用 Markdown 表格 |
| 代码一致 | 与 `知识笔记/代码总结.md` 全局约定一致（排序 data[0] 哨兵、线性表 0 起位序 1 起、带头结点、top=-1、牺牲一单元、nextarc）；勘误按 `授课反思与改进清单.md` 附录二处置 |

## 四、每节特殊要点速查（风险点前置）

| 节 | 主题 | 关键风险点 |
| :-- | :-- | :-- |
| B1 | 导学＋线性表算法一 | 课段导学三块（P2-P4）；改指针三条规矩是方法论页；快慢指针 p、q 都从 L 出发（头结点抵消）；交换相邻结点六条赋值次序（⑤⑥必须最后） |
| B2 | 线性表算法二 | 归并递减用头插自然反序；408-2019 重排三步各点明用哪个模板；约瑟夫环**不带头结点**（材料原文，页面要说明与 A3 默认约定的对照）；多项式分解是缺口14补写版 |
| B3 | 栈队应用与串匹配 | 括号匹配必须 `else if` 只拦右括号（写 `else` 会误判 `a+(b*c)`，当反例讲）；ToPostfix 的 `top != '('` 守卫不能缺；后缀求值先弹的是右操作数；KMP 只讲思想不重复 A6 的 next 手算 |
| B4 | 树算法一：递归三件套 | 三件套当一个模式讲（终止/缩小/返回），三个实例只差两行；判完全二叉树层序加 tag；判平衡返回高度用 -1 短路；求树的度 A8 已讲，本页只复习归入模板5 |
| B5 | 树算法二：层序与路径 | 繁荣度是 2024 真题匿名化载体；最长路径 path/maxPath 双数组；判 BST 中序加 prev（勘误 A5：prev 初值假设要点明）；哈夫曼只给思想与骨架（缺口8，802 以手算为主） |
| B6 | 图算法一：遍历应用 | 判连通 visited 不复位 vs 找路径 visited 回溯复位（勘误 C1 对比教学点）；拓扑排序入度表加栈；判拓扑序列唯一；2025 经过 k 的路径匿名化 |
| B7 | 图算法二：生成树与最短路径 | Prim 先补 weight 字段（勘误 A3 已在 A9 处理，本节直接用）；Kruskal 含并查集（缺口9，A9 已埋钩子本节兑现）；Dijkstra/Floyd 给骨架讲三重循环；关键路径 ve/vl/e/l 一页手算指向专业课（缺口10） |
| B8 | 查找算法 | 顺序查找哨兵法（为什么省越界判断）；折半返回 mid+1 口径与判定树 ASL；BST 删除三情况（缺口5）；AVL 四种旋转（缺口6，代码面）；散列两种冲突处理（缺口7）；分块一页 |
| B9 | 排序算法一：插入与交换 | **两套下标基准与哨兵位在本节正式落地**（约定1 排序下标 1 起、约定5 {INF} 写循环）；冒泡注意勘误 A1（材料 0 起写法保留，课件口头讲清边界）；快排 Partition；平均值界值划分含死递归修正（勘误 A2，反例 R={5,5,5} 走一遍）；希尔一页（缺口11） |
| B10 | 排序算法二：选择归并与比较 | 简单选择用 data[0] 存最小值下标；堆排序 HeapAdjust 逐行、建堆从 len/2 起、勘误 B5 交换写法择一（建议 arr[0] 暂存）；逆序对是 2020 真题匿名化（归并加计数）；基数一页、外部排序一页（缺口11/12）；排序比较表（时间/空间/稳定性/链表可用性） |

## 六、验收流程

1. builder 每节完成后跑 check.js，报告结果（0 ERROR + WARN 内容）。
2. 统筹方抽查：页序对应（deck 第n页 vs 讲稿P{n}标题）、时长合计、模板卡页、真题边界、图形效果。
3. 关键节（B1 首节、B9/B10 排序）过记忆干净 subagent 独立审查（只审不改，独立推演代码、手算数字）。
4. 全部 10 节完成后做课段级核对：15 个模板卡与框架 2.5 编号一一对应、钩子台账（A 段埋的钩子在 B 段兑现：A3 逆置→B1、A7 非递归借栈→B4/B5、A9 visited 复位→B6、A9 并查集→B7）。
