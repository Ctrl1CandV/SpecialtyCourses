# 消极案例总台账

> 用途：收集"超出常规人类表达"的讲稿/文本实例，供后续分析 AI 味的判定规律。
> 收录标准：例句保留原文、标注出处与问题类型；不给改写答案（改写属后续分析轮）。
> 已定罪 = 十三轮修订中主讲反馈确认过的表述型；新疑点 = 本轮扫描新发现、尚未经主讲确认。

## 一、主讲口举例句（最高优先级）

| # | 例句 | 出处 | 主讲说明 |
| :--- | :--- | :--- | :--- |
| Z1 | "立六个全局约定" | 讲课开场语境（旧版 C2-A-01 曾有"六条全局约定"表述） | 讲课不会这么说。"立"是书面仪式动词，正常说"先说清楚几条约定" |
| Z2 | "那句话的真实含义，用今天学的东西翻译" | **现行 `课件/C1/C1-B-02/C1-B-02-讲稿.md` P9**（约第101行） | 讲课不会说"翻译那句话的真实含义"，正常会说"这句话意思就是……" |

> 两条共同点：把一个平常的教学动作（提约定、解释句子）包装成一个不平常的说法（"立""翻译"）。

## 二、历史取证固定负例（已定罪，来自技法指南 §4.7 对照表与反思清单取证）

以下每条都曾在封存课件中实际出现并被主讲点名，是"已确认的 AI 味判定样本"：

### 型一：比喻替代术语（该给术语时只给比喻）

| 例句 | 应表达的内容 |
| :--- | :--- |
| "a像钉在地上的路标，p是拿着路标地址到处走的快递员" | a是固定地址不能改，p是变量可以换指向 |
| "骨子里都是指针在走路""把这层窗户纸捅破" | 本质上都是指针在移动 |
| "都是在这张图上添加新家具" | 往这张图上加内容 |
| "回车的编号" | 回车的ASCII码 |
| "内存图上添加新家具""下一节学一个新零件" | 加内容 / 新知识点 |

### 型二：AI 专用词与生造说法

| 例句 | 正常说法 |
| :--- | :--- |
| "路线报一下""先盘点今天要解的问题" | 这节课的顺序是 / 先把问题说清楚 |
| "立一个规矩""规矩就一条" | 只有一条要记住 |
| "这个换算关系是后面所有内容的数学基础" | 后面讲数组全靠这一条 |
| "试图在脑子里构建这个画面" | 脑子里要有这么一幅图 |
| "i++是先按现在的值办事，办完再加" | 先用当前的值，用完再加1 |
| "两套写法完全互通，你能自由翻译才算真懂" | 两种写法你要能互相改写 |
| "%c的脾气是不管三七二十一" | %c不做任何跳过 |
| "C语言的设计哲学是把这份自由交给程序员" | C语言把这个责任交给程序员 |
| "严丝合缝一个字节都不浪费""家常便饭""你品一下" | （书面腔/口头禅式表达） |

### 型三：把简单内容讲复杂

- C1-B-02 P8 用 9 段 1310 字讲"两种遍历"（按 160 字/分约 8 分钟，页标注 5 分钟），内含与相邻页重复的论证段；
- C1-B-05 值传递/副本这一个结论在引题、机制、失败版、引用传参、伪代码 **5 页各论证一遍**，"复印件"全稿出现 16 次；
- 课后任务叠四层附加要求；非收官课做"六节课串网"。

### 读者负担型（第十三轮取证）

- 自造词当术语："心智模型"（C1-B-04）、"口径"（题集九章）；
- 斜杠列举念不出来："冒泡/插入/选择""读/填""跟练/模仿"（题集九章 26 处）；
- 名词标签当标题：kicker/title 短到不像话（"选型""单链表推演"）。

### 结构性负例（非单句）

- 铺垫钩子复读：同一钩子"后面强化阶段会说"跨节铺垫 13+ 次（C1-A）；
- 板书样板重复：非首节课板书结论中样板行占 33%—67%；
- 课程定位越界：工具课用 3 页教专业课内容（C1-B-06）。
