## 本轮核心发现（数据层结论，分析方法见 04 目录）

1. **全部负例都长在写稿层**：两节对照中，讲稿病句与"绕"句（N1/N2/Z2）主讲实讲时要么顺成人话要么直接跳过——实讲不产生这类表述；
2. **讲稿实为骨架，主讲才是血肉**：主讲自发补充的内容稳定落在五类：具体考情判断、考场实操建议、完整推导展开、个人立场表达、自问自答式澄清——全是内容增量，没有一句是"表达修饰"；
3. **主讲口头语指纹**：那么/然后/就是说/对不对/嘛/我们视角——讲稿不需要模仿，但说明讲稿写得比口语"整齐"这件事本身与照念需求冲突；
4. 以上为两节课的取证，其余课节与分析方法、解决假设见 04 目录与后续分析轮。

## 转写方法（复现）

```bash
# 依赖：uv 临时环境（faster-whisper + CUDA 12 运行库），模型 large-v3-turbo（GPU）
cd "D:\Program Project\SpecialtyCourses\_tmp"
HF_ENDPOINT=https://hf-mirror.com uv run --python 3.12 \
  --with faster-whisper --with nvidia-cublas-cu12 --with nvidia-cudnn-cu12 \
  python transcribe.py "<视频路径>" "课程设计/AI味语料库/03-主讲视频转写" large-v3-turbo
```

- faster-whisper 参数：`language=zh, beam_size=5, vad_filter=True, condition_on_previous_text=False`（防幻觉循环）；
- 每个视频产出三件：`.txt`（带时间戳）、`.plain.txt`（纯文本，语料用）、`.meta.json`（时长/耗时/段数）；
- 已知限制：语音识别无法区分"照读讲稿"与"自发表达"，两者的区分靠第 04 步与讲稿逐页对照完成。
