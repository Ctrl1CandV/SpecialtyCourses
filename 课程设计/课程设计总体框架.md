## 一、考情分析与教学定位

### 1.1 802试卷结构（2024—2026年，与代码教学直接相关部分）

> 2024年起题型已调整（取消选择题），以下四部分为近三年稳定结构，本框架所有分值表述以此为准。

| 题型 | 数量与分值 | 与代码教学的关系 |
| :--- | :--- | :--- |
| 程序阅读题 | 约4—5题 ≈ 20分 | 给出代码片段挖空补全/片段排序/功能与复杂度分析，考"看得懂代码" |
| 填空题 | 约10空 ≈ 30分 | 手算小题（KMP next、数组地址、哈夫曼、广义表、堆调整、出栈序列等），部分涉代码过程 |
| 综合应用题 | 约6—7题 ≈ 70分 | 手算大题（散列ASL、BST/AVL、哈夫曼编码、Floyd/Dijkstra、AOE、判定树等），理解算法过程依赖代码思维 |
| **算法分析题** | **3题 = 30分** | **核心目标：写算法思想 + 伪代码 + 复杂度** |

### 1.2 代码题命题规律（2024—2026真题归纳，2020—2023真题作为变式练习）

- **题型结构（2024年起稳定）**：一、程序阅读题（约20分，挖空补全/功能分析）；二、填空题（约30分，手算小题）；三、综合应用题（约70分，手算大题）；四、算法分析题（30分，3道写代码大题）。
- **算法大题覆盖三大类**：链表操作（倒数第k、约瑟夫环）、二叉树递归（最长路径、繁荣度、判BST、先序中序建树）、图（经过k的路径、长度k路径、拓扑序列验证）。
- **趋势**：难度逐年上升；2026年出现约瑟夫环（循环链表模拟）、先序+中序建树（递归划分）、拓扑序列验证（入度表法），全部仍由经典模板加条件改写而来。
- **命题本质：模板＋改条件**。通读2020—2026真题，15道算法大题全部由经典模板加条件改写而来（模板清单见2.5）。因此教学主线是"C2-B种模板 → C3练改条件"。
- **考察形式**：伪代码即可，格式不严苛，**重思路、轻语法**；但结构体定义、指针操作、递归框架必须规范。
- **标准答题三件套**：①算法思想（文字描述）②代码/伪代码 ③时间、空间复杂度分析——三者缺一扣分。

### 1.3 与408的差异

802为自命题：不要求可编译的严格C代码；综合应用题题型相对固定；代码题分值集中且是主要拉分点。因此教学策略是**"语法够用即可，思路训练为重"**。

### 1.4 学情与总体策略：阶段即分层，课段即完整课程

学生水平参差不齐，因此**阶段不是课程内部的固定流程，而是按难度分层的独立课段**：

- 每个阶段都是**一段自包含的完整课程**（有自己的目录、自己的首课导学、自己的课后任务体系），学生按自身基础选择入口，不必逐级爬完；
- 每门课的**阶段数量按需设置，不是硬性三段**：C语言内容简单，只设基础、强化两段；数据结构代码与题型课难度高、跨度大，设完整三段；
- 三门课之间仍是递进关系：

```
C1 C语言（工具课，兜底）
        ↓ 提供语法与指针基础
C2 数据结构代码（核心课，按章节：定义→基本操作→经典算法→真题变式）
        ↓ 提供结构模板与算法弹药
C3 题型课（实战课，按真题题型：套路骨架→真题精讲→变式训练）
```

**学生选课建议（分层入口）**：

| 学生水平 | 推荐路线 |
| :--- | :--- |
| 零基础/跨考，不会写代码 | C1-A → C1-B → C2-A → C2-B → C3 |
| 学过C语言但生疏 | C1-B（旁听A中指针节）→ C2-A → C2-B → C3 |
| 有代码基础，专业课一轮已复习 | C2-B → C2-C → C3 |
| 基础扎实，冲刺阶段 | C2-C + C3-B/C（按需查漏） |

## 二、通用规范（所有课段共同遵守）

### 2.1 两级先导体系

代码班设**两层先导**，各司其职、互不重复：

**① 代码班总先导课**（全课程唯一，约10分钟，独立成片 `C0-代码班总先导`，置于C1-A-01之前）
面向全体学员（尤其零基础/跨考新生），讲"整个代码班怎么学"：
1. **802代码题考什么**：算法分析题3题30分的分值地位＋程序阅读题约20分、考察形式（伪代码、重思路轻语法）、答题三件套（思想+代码+复杂度）；
2. **学习代码的流程**：五层能力阶梯——语法→结构→操作→算法→变式，学员自测当前所在层；
3. **怎么学**：跟练、手撕代码、默写模板、课后必做题量等学习方法要求；
4. **代码班全景介绍**：C1/C2/C3三门课的地图、分层选课建议（对照1.4学情表）。

**② 课段导学**（每个课段第一节开头，约5分钟，作为该课段首节PPT的前几页）
固定内容四块：
1. **本课段在备考中的位置**（对应试卷哪些题、占多少分）与**适合人群**；
2. **本课段目录与学习路线**（学完能得到什么、与相邻课段的衔接关系）；
3. **本课段专属的伪代码约定与答题规范**（如C2-A强调下标两套约定、C3-A强调答题心法四步）；
4. **本课段学习方法要求**（跟练、手撕代码、课后必做题量）。

两级先导的课件页型规范见 `课程设计/课件制作SKILL.md` 第3.2节。

### 2.2 阶段定义（难度分层，按需启用）

| 阶段 | 定位 | 内容形态 | 适合人群 |
| :--- | :--- | :--- | :--- |
| A 基础 | 看得懂、写得出模板 | 结构定义+基本操作逐行讲，语法/概念从零讲起 | 零基础可跟 |
| B 强化 | 掌握经典算法/真题套路 | 算法拆解：思想→手写过程→代码→复杂度 | 已完成对应A阶段或有等价基础 |
| C 举一反三 | 能独立解真题与变式 | 真题精讲+变式题+一题多解+限时训练 | 冲刺拿分 |

各课段启用的阶段：**C1 = A + B；C2 = A + B + C；C3 = A + B + C**。

### 2.3 单节课标准结构（模板，约30—40分钟/节，微课模式）

1. **引题**（1—2min）：从一个具体问题/真题片段出发，说明"为什么要学这个"；
2. **思想先行**（3—5min）：图解+自然语言描述算法思想，不上代码；
3. **板书推演**（5—8min）：用小规模实例手工模拟过程（录制时在PPT上书写演示）；
4. **代码精讲**（10—15min）：先给框架骨架，再逐块填空，重点行单独放大；
5. **复杂度收尾**（1—2min）：时间/空间分析，一句话总结（无算法课可省略）；
6. **课后任务**（1—2min）：1道跟练题+1道变式题（A阶段可将变式题降为模仿题）。

### 2.4 代码与命名统一规范

- 全部采用与考生笔记一致的命名体系，避免学生换体系：`SqList`/`SeqList`、`LNode, *LinkList`、`DNode`、`SqStack`、`SqQueue`、`BiTNode, *BiTree`、`CSNode, *CSTree`、`ArcNode/VNode/ALGraph`、`MGraph`、`BiThrNode`。
- 元素类型统一用 `int`（说明ElemType含义即可，不纠缠）。
- 参数传递用C++引用 `&`（说明其在伪代码中的含义），默认**带头结点**链表、`top=-1`栈、牺牲一单元循环队列，遇到变体时单独对比。
- 伪代码允许省略头文件与main函数，但**结构体定义、函数签名、边界判断必须完整**。

### 2.5 核心模板库与答题心法（C2-B / C3 共享弹药）

802代码题全部由经典模板加条件改写而来。下表13个模板覆盖2020—2026全部算法大题，是C2-B（种模板）与C3（练改条件）共用的弹药清单：

| # | 模板 | 适用场景 | 代表真题 |
| :--- | :--- | :--- | :--- |
| 1 | 头插法 | 逆置、重组、分解、归并成递减表 | 2023循环段倒置、2022多项式分解、2021比x小者递减排列 |
| 2 | 快慢指针 | 找中点、倒数第k | 2025倒数第k、408-2019重排 |
| 3 | 断链拼接三步走 | 链表重排/改造（摘→逆→插） | 408-2019重排、2020双向循环改造 |
| 4 | 条件删除（前驱跟随） | 按条件删除链表结点 | 2021删除大于x的正偶数 |
| 5 | 递归三件套（终止/缩小/返回＋遍历中维护全局） | 树的高/宽/结点数、路径类、判BST | 2025最长路径、2024判BST |
| 6 | 层序＋last分层 | 层相关统计（宽度、繁荣度） | 2024繁荣度 |
| 7 | DFS回溯（visited标记＋清除） | 图中带约束的路径（经过/长度） | 2025经过k的路径、2024长度k路径 |
| 8 | BFS分层／多源BFS | 无权最短距离、多起点距离图 | 2023像素距离图 |
| 9 | 二分框架改判定 | 有序/特殊序列的查找变式 | 2021双调序列最大值 |
| 10 | 归并＋计数 | 逆序对等统计类 | 2020逆序对个数 |
| 11 | 循环链表模拟 | 环形结构报数/轮转类 | 2026约瑟夫环 |
| 12 | 递归建树（区间划分） | 由遍历序列构造二叉树 | 2026先序+中序建树 |
| 13 | 入度表法 | 拓扑序验证、判环 | 2026验证拓扑序列、2024拓扑排序填空 |

> 使用方式：C2-B每讲完一个经典算法，结尾出"模板卡页"（算法名＋适用场景＋骨架＋复杂度，用content页＋表格呈现，页型规范见课件制作SKILL第三节）；C3-A汇总复习骨架；C3-B讲真题先报模板名再写代码。

**答题心法（思维四步）**：拿到真题按四步走——①**认结构**（带头结点？邻接表还是矩阵？下标从几起？）→ ②**选模板**（套上表哪个）→ ③**改条件**（把题目条件翻译成模板的改动点）→ ④**补边界**（空表、越界、visited复位、k的合法性）。书写时按"思想+代码+复杂度"三件套组织答案。该心法在C2-B每节课收尾反复示范，C3-A-01正式讲授。

### 2.6 内容设计三道审查（基础阶段录制复盘后新增）

所有课段制作大纲与课件时必须过这三道审查。背景与证据见 `课程设计/授课反思与改进清单.md`。

**审查一：知识链完整性**
- 每个知识点在大纲中标注它的**兄弟知识点**：讲while必须提do-while，讲`&&`短路必须提`||`同样短路，讲malloc必须提free；
- 兄弟知识点可以不展开，但**不能不提及**（一句"它存在、什么场景用、为什么本课不重点练"即可）；学员需要完整的知识地图，缺角的地图会在后续阶段变成认知断层；
- 交付前自查：本节每个新语法/概念，相邻概念是否至少被点名一次。

**审查二：阶段适配与符号审查**
- **代码示例符号审查**：选用任何代码示例前，逐符号检查有没有学员此刻无法解释的东西；有则换例子或删符号。C1-A的教训：`SqList &L`在讲变量的课里出现4次且从未解释（学员连函数都还没学）；
- 超纲符号确需出现（如真题原文展示），必须口头降级处理且全课不超过1处；
- 阶段边界双向不越界：A阶段不提前展开B的机制，B阶段也不把C的内容拖进来。知识要适合当前阶段，这是硬约束。

**审查三：板书与习题的增量原则**
- 板书只写**本节课新增的内容**：程序骨架（头文件、main、return 0）在课段首节书写一次建立习惯，之后口头带过不再书写；
- 每处板书、每道习题过价值三问：练的是不是本节核心？能不能用更少笔画达成？删掉有没有损失？一问答否就删；
- 板书有时长与触屏书写的真实成本，每节板书总时长不超过8分钟，超了砍内容不赶书写。

## 三、C1：C语言代码讲解（工具课）

**课程目标**：不求学完C语言，只求"能读懂并重写数据结构伪代码"。所有语法教学均以数据结构小例子为载体。

**课程目标**：以"题型套路"而非"知识章节"组织教学，直接对标802算法大题与代码填空。三个阶段为难度分层的完整课段：A给模板、B拆真题、C练迁移。

目标：拿到一道802算法题，30秒内识别题型，并能默写出对应骨架代码。

| 节次 | 主题 | 骨架内容 | 预计时长 |
| :--- | :--- | :--- | :--- |

| A2 | 树图查找排序骨架 | 递归三件套、层序+last分层、DFS回溯、BFS分层、折半框架、Partition骨架 | 30min |

### 5.2 C3-B 强化阶段（4节，约2.0小时）：真题精讲

目标：按答题四步法完整示范真题作答，示范评分点在哪。

## 七、质量保障机制

1. **真题反向校验**：C2-C与C3-B每节课的题目必须能映射到真题年份；变式题优先由真题改编。
2. **模板一致性**：所有代码命名、约定（头结点、top初值等）与考生复习资料（`知识笔记/代码总结.md`/`知识笔记/重邮数据结构.md`）保持一致，学生无需切换体系。
3. **板书留白**：PPT刻意留出书写区（详见SKILL），录制时进行手写推演，PPT只承载结论性内容。
4. **课后闭环**：每节课固定"1跟练+1变式"（A课段可用模仿题替代变式题），题目答案放入讲稿附录，供机构分发。
5. **课段自洽**：每个阶段课段可独立观看、独立考核，不依赖未观看的前置课段内容；跨课段引用必须给出"回看指引"（课段编号+节次）。
6. **前向引用台账**（复盘新增）：每节课维护悬念钩子台账（埋了什么、在哪兑现、已铺垫几次）；同一钩子全课程只铺垫一次；跨课段钩子的埋设与兑现位置登记在本框架3.1清单与3.2登记表，新课段开工前先核对。
7. **内容三道审查**（复盘新增）：每节课大纲与课件必须通过2.6的知识链完整性、阶段适配与符号审查、板书与习题增量原则三道审查。
8. **讲稿格式与语感检查**（复盘新增）：check.js自动检测前向引用重复与讲稿加粗密度；交付前主讲人（或制作人）朗读全稿一遍，念着不像说话的段落重写。
9. **机构物料边界**（合作课件专用）：机构提供的PPT底图、logo、机构页文案一律不改，只允许修改我方内容页的正文文字；讲稿涉及机构页按原文意思写，不删减不过度扩充。详见课件制作SKILL第七节。
