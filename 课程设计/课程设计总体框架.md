## 一、考情分析与教学定位

### 1.1 802试卷结构（2024—2026年，与代码教学直接相关部分）

> 2024年起题型已调整（取消选择题），以下四部分为近三年稳定结构，本框架所有分值表述以此为准。

| 题型 | 数量与分值 | 与代码教学的关系 |
| :--- | :--- | :--- |
| 程序阅读题 | 约4—5题 ≈ 20分 | 给出代码片段挖空补全/片段排序/功能与复杂度分析，考"看得懂代码" |
| 填空题 | 约10空 ≈ 30分 | 手算小题（KMP next、数组地址、哈夫曼、广义表、堆调整、出栈序列等），部分涉代码过程 |
| 综合应用题 | 约6—7题 ≈ 70分 | 手算大题（散列ASL、BST/AVL、哈夫曼编码、Floyd/Dijkstra、AOE、判定树等），理解算法过程依赖代码思维 |
| **算法分析题** | **3题 = 30分** | **核心目标：写算法思想 + 伪代码 + 复杂度** |

### 1.2 代码题命题规律（2024—2026真题归纳，2020—2023真题作为变式练习）

- **题型结构（2024年起稳定）**：一、程序阅读题（约20分，挖空补全/功能分析）；二、填空题（约30分，手算小题）；三、综合应用题（约70分，手算大题）；四、算法分析题（30分，3道写代码大题）。
- **算法大题覆盖三大类**：链表操作（倒数第k、约瑟夫环）、二叉树递归（最长路径、繁荣度、判BST、先序中序建树）、图（经过k的路径、长度k路径、拓扑序列验证）。
- **趋势**：难度逐年上升；2026年出现约瑟夫环（循环链表模拟）、先序+中序建树（递归划分）、拓扑序列验证（入度表法），全部仍由经典模板加条件改写而来。
- **命题本质：模板＋改条件**。通读2020—2026真题，15道算法大题全部由经典模板加条件改写而来（模板清单见2.5）。因此教学主线是"C2-B种模板 → C3练改条件"。
- **考察形式**：伪代码即可，格式不严苛，**重思路、轻语法**；但结构体定义、指针操作、递归框架必须规范。
- **标准答题三件套**：①算法思想（文字描述）②代码/伪代码 ③时间、空间复杂度分析——三者缺一扣分。

### 1.3 与408的差异

802为自命题：不要求可编译的严格C代码；综合应用题题型相对固定；代码题分值集中且是主要拉分点。因此教学策略是**"语法够用即可，思路训练为重"**。

### 1.4 学情与总体策略：阶段即分层，课段即完整课程

学生水平参差不齐，因此**阶段不是课程内部的固定流程，而是按难度分层的独立课段**：

- 每个阶段都是**一段自包含的完整课程**（有自己的目录、自己的首课导学、自己的课后任务体系），学生按自身基础选择入口，不必逐级爬完；
- 每门课的**阶段数量按需设置，不是硬性三段**：C语言内容简单，只设基础、强化两段；数据结构代码与题型课难度高、跨度大，设完整三段；
- 三门课之间仍是递进关系：

```
C1 C语言（工具课，兜底）
        ↓ 提供语法与指针基础
C2 数据结构代码（核心课，按章节：定义→基本操作→经典算法→真题变式）
        ↓ 提供结构模板与算法弹药
C3 题型课（实战课，按真题题型：套路骨架→真题精讲→变式训练）
```

**学生选课建议（分层入口）**：

| 学生水平 | 推荐路线 |
| :--- | :--- |
| 零基础/跨考，不会写代码 | C1-A → C1-B → C2-A → C2-B → C3 |
| 学过C语言但生疏 | C1-B（旁听A中指针节）→ C2-A → C2-B → C3 |
| 有代码基础，专业课一轮已复习 | C2-B → C2-C → C3 |
| 基础扎实，冲刺阶段 | C2-C + C3-B/C（按需查漏） |

## 二、通用规范（所有课段共同遵守）

### 2.1 两级先导体系

代码班设**两层先导**，各司其职、互不重复：

**① 代码班总先导课**（全课程唯一，约10分钟，独立成片 `C0-代码班总先导`，置于C1-A-01之前）
面向全体学员（尤其零基础/跨考新生），讲"整个代码班怎么学"：
1. **802代码题考什么**：算法分析题3题30分的分值地位＋程序阅读题约20分、考察形式（伪代码、重思路轻语法）、答题三件套（思想+代码+复杂度）；
2. **学习代码的流程**：五层能力阶梯——语法→结构→操作→算法→变式，学员自测当前所在层；
3. **怎么学**：跟练、手撕代码、默写模板、课后必做题量等学习方法要求；
4. **代码班全景介绍**：C1/C2/C3三门课的地图、分层选课建议（对照1.4学情表）。

**② 课段导学**（每个课段第一节开头，约5分钟，作为该课段首节PPT的前几页）
固定内容四块：
1. **本课段在备考中的位置**（对应试卷哪些题、占多少分）与**适合人群**；
2. **本课段目录与学习路线**（学完能得到什么、与相邻课段的衔接关系）；
3. **本课段专属的伪代码约定与答题规范**（如C2-A强调下标两套约定、C3-A强调答题心法四步）；
4. **本课段学习方法要求**（跟练、手撕代码、课后必做题量）。

两级先导的课件页型规范见 `课程设计/课件制作SKILL.md` 第3.2节。

### 2.2 阶段定义（难度分层，按需启用）

| 阶段 | 定位 | 内容形态 | 适合人群 |
| :--- | :--- | :--- | :--- |
| A 基础 | 看得懂、写得出模板 | 结构定义+基本操作逐行讲，语法/概念从零讲起 | 零基础可跟 |
| B 强化 | 掌握经典算法/真题套路 | 算法拆解：思想→手写过程→代码→复杂度 | 已完成对应A阶段或有等价基础 |
| C 举一反三 | 能独立解真题与变式 | 真题精讲+变式题+一题多解+限时训练 | 冲刺拿分 |

各课段启用的阶段：**C1 = A + B；C2 = A + B + C；C3 = A + B + C**。

### 2.3 单节课标准结构（模板，约30—40分钟/节，微课模式）

1. **引题**（1—2min）：从一个具体问题/真题片段出发，说明"为什么要学这个"；
2. **思想先行**（3—5min）：图解+自然语言描述算法思想，不上代码；
3. **板书推演**（5—8min）：用小规模实例手工模拟过程（录制时在PPT上书写演示）；
4. **代码精讲**（10—15min）：先给框架骨架，再逐块填空，重点行单独放大；
5. **复杂度收尾**（1—2min）：时间/空间分析，一句话总结（无算法课可省略）；
6. **课后任务**（1—2min）：1道跟练题+1道变式题（A阶段可将变式题降为模仿题）。

### 2.4 代码与命名统一规范

- 全部采用与考生笔记一致的命名体系，避免学生换体系：`SqList`/`SeqList`、`LNode, *LinkList`、`DNode`、`SqStack`、`SqQueue`、`BiTNode, *BiTree`、`CSNode, *CSTree`、`ArcNode/VNode/ALGraph`、`MGraph`、`BiThrNode`。
- 元素类型统一用 `int`（说明ElemType含义即可，不纠缠）。
- 参数传递用C++引用 `&`（说明其在伪代码中的含义），默认**带头结点**链表、`top=-1`栈、牺牲一单元循环队列，遇到变体时单独对比。
- 伪代码允许省略头文件与main函数，但**结构体定义、函数签名、边界判断必须完整**。

### 2.5 核心模板库与答题心法（C2-B / C3 共享弹药）

802代码题全部由经典模板加条件改写而来。下表13个模板覆盖2020—2026全部算法大题，是C2-B（种模板）与C3（练改条件）共用的弹药清单：

| # | 模板 | 适用场景 | 代表真题 |
| :--- | :--- | :--- | :--- |
| 1 | 头插法 | 逆置、重组、分解、归并成递减表 | 2023循环段倒置、2022多项式分解、2021比x小者递减排列 |
| 2 | 快慢指针 | 找中点、倒数第k | 2025倒数第k、408-2019重排 |
| 3 | 断链拼接三步走 | 链表重排/改造（摘→逆→插） | 408-2019重排、2020双向循环改造 |
| 4 | 条件删除（前驱跟随） | 按条件删除链表结点 | 2021删除大于x的正偶数 |
| 5 | 递归三件套（终止/缩小/返回＋遍历中维护全局） | 树的高/宽/结点数、路径类、判BST | 2025最长路径、2024判BST |
| 6 | 层序＋last分层 | 层相关统计（宽度、繁荣度） | 2024繁荣度 |
| 7 | DFS回溯（visited标记＋清除） | 图中带约束的路径（经过/长度） | 2025经过k的路径、2024长度k路径 |
| 8 | BFS分层／多源BFS | 无权最短距离、多起点距离图 | 2023像素距离图 |
| 9 | 二分框架改判定 | 有序/特殊序列的查找变式 | 2021双调序列最大值 |
| 10 | 归并＋计数 | 逆序对等统计类 | 2020逆序对个数 |
| 11 | 循环链表模拟 | 环形结构报数/轮转类 | 2026约瑟夫环 |
| 12 | 递归建树（区间划分） | 由遍历序列构造二叉树 | 2026先序+中序建树 |
| 13 | 入度表法 | 拓扑序验证、判环 | 2026验证拓扑序列、2024拓扑排序填空 |

> 使用方式：C2-B每讲完一个经典算法，结尾出"模板卡页"（算法名＋适用场景＋骨架＋复杂度，页型见SKILL 4.5）；C3-A汇总复习骨架；C3-B讲真题先报模板名再写代码。

**答题心法（思维四步）**：拿到真题按四步走——①**认结构**（带头结点？邻接表还是矩阵？下标从几起？）→ ②**选模板**（套上表哪个）→ ③**改条件**（把题目条件翻译成模板的改动点）→ ④**补边界**（空表、越界、visited复位、k的合法性）。书写时按"思想+代码+复杂度"三件套组织答案。该心法在C2-B每节课收尾反复示范，C3-A-01正式讲授。

## 三、C1：C语言代码讲解（工具课）

**课程目标**：不求学完C语言，只求"能读懂并重写数据结构伪代码"。所有语法教学均以数据结构小例子为载体。

**教学参照**：以经典教材《C Primer Plus》的章节体系为骨架取材，按"数据结构够用"原则裁剪。取舍采用**双标准**：是否直接服务802考试 / 是否帮助理解后续内容——考试不考但有助于理解的（如二进制概念、作用域），**保留浅讲**；既非考点也无理解价值的，砍掉。字符串函数虽非考点，但C2串章节会用到，届时在C2-A-07按需补讲，不在C1占课。

| 保留（进课程） | 酌情保留（帮助理解，浅讲） | 砍掉（不讲） |
| :--- | :--- | :--- |
| 数据类型、运算符、表达式 | 二进制与"数据在内存中是一串0/1"的概念（理解"类型决定盒子大小"） | 进制转换技巧、补码运算 |
| 分支与循环控制结构 | 字符串字面量与printf输出（A3，仅"字符vs字符串"层面） | 字符串函数 strlen/strcmp/strcpy |
| 函数（定义/调用/返回值） | 作用域概念（全局/局部，浅讲） | 形参实参深入辨析、函数指针 |
| 数组（一维/二维） | printf/scanf 常用转换说明（%d/%c/%f） | 宽度精度修饰符等格式化细节 |
| 指针、结构体、动态内存（C1-B） | 递归（C1-B，作为树遍历的预演） | 位运算细节、条件编译、共用体、位域、复杂声明 |
| 预处理仅讲 #define | 位运算只提"存在"，避免与 scanf 的 `&` 混淆 | 命令行参数、可变参数、文件I/O、多文件工程 |

### 3.1 C1-A 基础阶段（5节，约3.0小时）：零基础语法地基，完整课段

**设计原则**：面向完全没有计算机基础的跨考者，总时长控制在3小时以内（主编要求约2小时，与用户确认为3小时上限）。以《C Primer Plus》第1—10章为蓝本按"数据结构够用"原则裁剪，**每节只立一个核心概念**（分支与循环合并为一节"控制结构"、函数与数组合并为一节）；凡需要"地址/指针"才能解释的内容（scanf的`&`、参数传递、指针移动），一律**只讲用法、埋悬念**，留到C1-B讲指针时统一揭晓，不提前展开。

| 节次 | 主题 | 《C Primer Plus》对应 | 关键内容 | 预计时长 |
| :--- | :--- | :--- | :--- | :--- |
| A1 | 导学+初识C程序 | 第1—2章 | C1-A课段导学（5min）、程序骨架、main、printf、#define、注释 | 35min |
| A2 | 数据类型、变量与输入输出 | 第3—4章 | int/char/double/bool、变量声明与赋值、常量、printf转换说明、scanf（&留悬念） | 35min |
| A3 | 运算符与表达式 | 第5章 | 算术（含%）、赋值、关系、逻辑、++/--入门 | 30min |
| A4 | 分支与循环 | 第6—7章 | if/else/switch、while/for、break/continue、循环三要素 | 40min |
| A5 | 函数与数组 | 第9—10章 | 函数定义与调用、返回值、一维数组、for遍历、字符数组与'\0'（串章节前置） | 40min |

> 压缩说明：原8节合并为5节——输入输出并入数据类型（A2）、分支与循环合并（A4）、函数与数组合并（A5），字符串基础（字符数组与'\0'）并入A5数组部分（BF匹配/KMP手算需要，strlen/strcpy等字符串函数仍不讲），总时长180分钟。

**C1-A教学要点**（每节30—40分钟；统一采用2.3标准六步，A阶段轻量化：复杂度只给结论不推导、板书只做最简内存图）：

- A1：课段导学后，第一个程序只做"输出"，建立"程序=输入→处理→输出"的直觉；
- A2：画内存图（变量=带名字的盒子），"类型决定盒子大小"；转换说明只记%d/%c/%f；bool单独落脚（伪代码到处是bool返回值）；scanf的`&`只讲用法不讲原理，明确说"为什么需要&，C1-B讲指针时揭晓"；
- A3：%用"奇偶判断""取个位"落地；++/--只讲"自身加1/减1"的直觉（数据结构代码高频），不展开前置后置差异；优先级只记"括号＞乘除＞加减"口诀，不背全表；
- A4：if用生活化例子（成绩及格、范围判断）；循环三要素（初始化、条件、更新）讲透；嵌套循环只提一句"用到时再展开"，不展开；
- A5：函数用"做菜步骤"类比，**不展开形参实参/值传递**（C1-B-03讲引用时系统讲）；数组=一排带编号的盒子，编号从0开始；哨兵位概念不讲（留给C2-A）；结尾用5分钟讲字符数组与'\0'（"字符串=字符数组+结尾标记"），为C2-B-02的串与BF铺路，不展开任何字符串函数。

**课后任务**：每节固定"1道跟练题＋1道模仿题"（A阶段不设变式题；模仿题=把课上代码改一个数/换一个场景），题面与答案进讲稿附录。

**与C1-B的衔接**：C1-A只讲"用法"，所有"为什么"（scanf的`&`、函数参数为何改不动实参、指针为何能移动）统一由C1-B的指针课揭晓。C1-A每节课要主动埋这些悬念，不许提前展开。

### 3.2 C1-B 强化阶段（4节，约2.5小时）：指针与结构体（本课程重心），完整课段

| 节次 | 主题 | 关键内容 | 预计时长 |
| :--- | :--- | :--- | :--- |
| B1 | 导学+指针入门与数组 | 课段导学、地址、*与&、指针移动、数组名退化 | 40min |
| B2 | 结构体与typedef | struct定义、`.`与`->`、typedef别名 | 30min |
| B3 | 动态内存与引用 | malloc/free、NULL判断、C++引用`&`传参 | 35min |
| B4 | 递归与综合实战 | 递归三要素（终止条件、缩小规模、返回值）、递归栈图示、从零手写"顺序表+单链表" | 45min |

> 压缩说明：原6节合并为4节——指针与数组合并（B1）、递归与综合实战合并（B4）；"为C2铺路"的实战内容并入B4结尾。

## 四、C2：802数据结构课程相关代码讲解（核心课）

**课程目标**：建立"结构定义→基本操作→经典算法→真题变式"四层代码能力，覆盖802全部代码考点。三个阶段为难度分层，各自是贯穿全部7章的完整课段。

### 4.1 C2-A 基础阶段（6节，约3.0小时）：定义与基本操作

目标：核心结构"怎么定义、基本操作怎么写"，学完能在白纸上默写全部模板。

| 节次 | 主题 | 关键内容 | 预计时长 |
| :--- | :--- | :--- | :--- |
| A1 | 导学+绪论 | 课段导学、时间/空间复杂度分析题的写法（代码题的前置技能） | 30min |
| A2 | 顺序表 | 静态/动态定义、初始化、按位插入/删除、按值查找 | 30min |
| A3 | 单链表 | 定义、头插/尾插、按位插入/删除、按序/按值查找 | 30min |
| A4 | 栈与队列 | 顺序栈全套（top=-1约定）、循环队列（牺牲一单元）、判满三策略、链式概念 | 30min |
| A5 | 树与二叉树 | 二叉链表、先/中/后序递归遍历、层序、顺序存储 | 30min |
| A6 | 图存储与遍历 | 邻接矩阵/邻接表定义、DFS、BFS（visited数组约定） | 30min |

> 压缩说明：原11节合并为6节——双链表/循环链表（指针次序并入C2-B-01带过）、共享栈/链栈（并入A4一句话）、串（定义并入C2-B-02开头）、查找基础（并入C2-B-05）、排序基础（并入C2-B-06）。

### 4.2 C2-B 强化阶段（6节，约4.0小时）：经典算法

目标：802会考的全部经典算法，每个按"思想→板书推演→骨架填空→完整代码→复杂度"五步讲透。

| 节次 | 主题 | 关键内容 | 预计时长 |
| :--- | :--- | :--- | :--- |
| B1 | 导学+线性表算法 | 课段导学、原地逆置（头插法）、快慢指针求倒数第k、条件删除、双链表插删指针次序 | 40min |
| B2 | 栈队应用与串 | 括号匹配、双栈模拟队列、串概念与BF思想、KMP手算（next/nextval数组，**不考匹配代码**） | 40min |
| B3 | 树算法 | 深度/宽度/结点数/叶子数（递归）、层序+last分层、判完全/平衡、镜像、先序中序建树 | 40min |
| B4 | 图算法 | DFS/BFS应用与连通性、拓扑排序（含验证序列）、Prim/Kruskal思路、Floyd（概念+手算，无代码） | 40min |
| B5 | 查找算法 | 顺序（哨兵法）、折半、BST的查/插/删/判、AVL旋转（概念+手算衔接） | 40min |
| B6 | 排序算法 | 直接插入/冒泡/简单选择速览、快排Partition、堆排HeapAdjust与建堆、二路归并Merge | 40min |

> 说明：希尔、基数、外部排序（败者树、置换选择）802以手算为主，不安排代码课，仅在对应章节用1页PPT带过。

### 4.3 C2-C 举一反三阶段（3节，约1.5小时）：真题变式

目标：每类结构1—2道真题+变式，训练"识别本题套哪个模板"。

| 节次 | 主题 | 代表题目 | 预计时长 |
| :--- | :--- | :--- | :--- |
| C1 | 链表与树真题 | 课段导学、2023循环段倒置、2026约瑟夫环、2026先序中序建树 | 30min |
| C2 | 图真题 | 2025经过k的路径、2024长度k路径、2026拓扑序列验证 | 30min |
| C3 | 查找排序真题+课段总结 | 2021双调序列、平均值枢轴快排、2020逆序对、Top-K | 30min |

### 4.4 三阶段课段的落地方式

- **A 基础**：结构体定义逐字段讲（画内存图）→ 基本操作逐行讲 → 学生课后默写模板；
- **B 强化**：每个经典算法固定五步——思想 → 小实例板书推演 → 骨架填空 → 完整代码 → 复杂度；
- **C 举一反三**：1道真题 + 1道变式，先让学生暂停视频自己写，再讲评，并总结"本题套用了哪个模板"。

## 七、质量保障机制

1. **真题反向校验**：C2-C与C3-B每节课的题目必须能映射到真题年份；变式题优先由真题改编。
2. **模板一致性**：所有代码命名、约定（头结点、top初值等）与考生复习资料（`知识笔记/代码总结.md`/`知识笔记/重邮数据结构.md`）保持一致，学生无需切换体系。
3. **板书留白**：PPT刻意留出书写区（详见SKILL），录制时进行手写推演，PPT只承载结论性内容。
4. **课后闭环**：每节课固定"1跟练+1变式"（A课段可用模仿题替代变式题），题目答案放入讲稿附录，供机构分发。
5. **课段自洽**：每个阶段课段可独立观看、独立考核，不依赖未观看的前置课段内容；跨课段引用必须给出"回看指引"（课段编号+节次）。
