## P3 顺序查找与哨兵法（约4分钟）

顺序查找最简单，从头到尾逐个比。但考试爱考的是它的优化版——哨兵法。

先看普通版的问题：循环里每次要判两个条件，一个是 i 有没有越界，一个是 A[i] 等不等于 key。两个判断，n 个元素最多判 2n 次。

哨兵法把这两个判断合并成一个。做法是：查找前先把 key 放进 A[0]，然后从后往前扫，循环条件只写 A[i] != key。

【停顿】为什么不用判越界了？因为 A[0] 放的就是 key，扫到 0 位一定会命中、循环一定会停。A[0] 就是"哨兵"，它保证了循环的终止。

两个前提要记：第一，数据必须存 A[1..n]，A[0] 留作哨兵位——这和上一节排序的 data[0] 哨兵是同一个思路，查找章节的哨兵变体；第二，返回值是下标，返回 0 表示查找失败（找到了 A[0] 的哨兵，说明真数据里没有）。

n 很大的时候，这个优化能省接近一半的比较次数。时间复杂度还是 O(n)，但常数小了一半。

## P4 折半查找与三个边界（约4分钟）

那么讲完了顺序查找，接下来看折半查找。前提是线性表有序、而且必须顺序存储——链表不能折半，因为取中间元素要 O(n) 走到那里，折半就失去意义了。

代码很短，但三个边界全是考点。

第一个边界，循环条件 low <= high 为什么带等号？【停顿】因为 low == high 的时候，区间里还剩一个元素没查，去掉等号这个元素就漏了。

第二个边界，high = mid - 1 和 low = mid + 1，为什么不能写成 mid？写成 mid 的话，区间没有真正缩小，low 和 high 卡在原地，死循环。mid 已经比较过了，下一轮区间必须把它排除掉。

第三个边界，返回 mid + 1 而不是 mid。题目问的是"第几个"，位序从 1 起，下标从 0 起——这和数据结构基础阶段第2节 LocateElem 返回 i+1 是同一个约定。返回 0 表示查找失败。

时间复杂度 O(logn)，每比较一次区间砍一半。

## P5 判定树：折半查找的图形化（约4分钟）

折半查找的过程可以画成一棵树，叫判定树。画法是：每次比较的 mid 画成一个结点，往左半区找就是左子树，往右半区找就是右子树。

屏幕上这棵是 n=11 的判定树。你验证一下：根是 6，也就是 (1+11)/2；6 的左子树管 [1,5]，根是 3；右子树管 [7,11]，根是 9；一层层往下，每个结点都是它管辖区间的中点。

这棵树有两个直接的读法。成功查找：查某个值，从根走到它，比较次数就是它所在的层数。比如查 6 比较 1 次，查 3 比较 2 次，查 2 比较 4 次。失败查找：走到外部结点（图里没画出来的空位置），比较次数等于走到那个外部结点的层数。

ASL 就是从树上算平均：成功 ASL 等于每层结点数乘层数，全加起来除以 n。这棵 n=11 的树，(1×1 + 2×2 + 4×3 + 4×4)/11 = 33/11 = 3。失败 ASL 同理，用外部结点算。

本课只要求你会画判定树、会从树上读比较次数；ASL 的完整计算训练在专业课，题集勾画的 9答3 留作选做。

## P6 BST 的查找与插入（约4分钟）

那么讲完了线性表查找，接下来看树形查找，先是二叉排序树 BST。

BST 的性质一句话：左子树全部小于根，右子树全部大于根，中序遍历出来是有序序列。查找就是拿这个性质走：比根小往左、比根大往右，走到 NULL 就是没找到。

插入的代码有一个必须讲清的点：参数写的是 BSTNode \*&T，指针的引用，不是指针本身。

【停顿】为什么必须带 &？因为插入要做的事是"把新结点接到父结点的 lchild 或 rchild 字段上"。不带 & 的话，函数里改的只是 T 这个副本，新建的结点根本接不到树上，函数一返回就丢了。这是引用传参在真实算法里的必要性——C语言强化阶段讲引用时说过"要改外面的变量就带 &"，这里就是活例子。

插入的位置一定是叶子：找空位的过程就是查找的过程，走到 NULL 就在那里新建。时间 O(树高)，最坏 O(n)——退化成单支树的时候，比如按有序序列依次插入。这个最坏情况就是 AVL 要解决的问题。

## P7 BST 的删除：三种情况（约5分钟）

BST 三个操作里，删除是唯一的难点，也是程序阅读题和综合应用题都可能考的点。

删除分三种情况。情况①，待删结点是叶子：直接 free，父结点的对应字段置 NULL，不影响其他任何结点。情况②，只有一个孩子：把孩子接到父结点上顶替自己的位置。代码里 T = T->rchild 这一句，因为参数是引用，改的就是父结点的字段，接完之后 free 掉自己。

情况③是关键：有两个孩子。【停顿】能不能直接删？不能。删了之后左子树和右子树就都断了，没法同时挂回父结点。

做法是"值替换"：找一个值顶替它，然后去删那个值的结点。替换值取中序前驱——左子树里最大的那个，也就是左子树的最右结点。为什么用中序前驱能保持 BST 性质？前驱是中序序列里刚好小于它的值，替换之后，左子树全部还是小于它、右子树全部还是大于它，性质不变。

而且前驱一定没有右孩子（有的话它就不是最右了），所以删前驱就回到了情况①或②，递归下去就能删掉。也可以用中序后继（右子树最小值），对称的道理，本课统一用前驱。

## P8 过程页：删除双孩子结点四步（约4分钟）

这一页拿纸跟着画。屏幕上这棵树，删除根结点 45，它有两个孩子，走情况③。

第一步，找中序前驱：45 的左子树以 24 为根，往右走到头，是 37。37 就是 45 的中序前驱。

第二步，把 37 的值拷到根结点。注意这一步只改值、不动结构，树还是原来那棵树，只是根上写的数从 45 变成了 37。

第三步，递归到左子树删 37。现在左子树里的 37 是个叶子（它没有孩子），按情况①直接删掉。

第四步，验证。中序走一遍：12、24、37、53、93，还是有序的，BST 性质保持。

你看清这个套路了吗——双孩子删除从来不是"删它"，是"拿前驱的值顶替它，再去删前驱"。前驱最多只有一个孩子，问题就降级了。

## P9 AVL 插入与四种旋转（约4分钟）

BST 最坏会退化成单支树，O(n)。AVL 就是给 BST 加了一个平衡约束：任何结点的左右子树高度差不超过 1，树高稳定在 O(logn)。

插入后的修复分两步。第一步，从新结点往上找，找到第一个平衡因子绝对值大于 1 的结点——这叫最小失衡子树的根。第二步，看新结点在它下面四代里的位置，定旋转类型，屏幕上这张表：新结点在左孩子的左子树，LL 型，右单旋；右孩子的右子树，RR 型，左单旋；左孩子的右子树，LR 型，先左后右双旋；右孩子的左子树，RL 型，先右后左双旋。

代码只给右单旋一个作代表，三行指针操作：B 上位当根，B 的右子树回挂给 T 当左子树，T 挂到 B 的右边。其余三个旋转都是对称写法，课后自己补。

为什么不把四个旋转代码全讲？因为 802 对 AVL 考的是手算：插入一个序列，画出每一步的树，指出发生了什么旋转（题集勾画的 9选14、9选20 就是这个考法），不是让你写旋转代码。所以记住决策表、会画旋转后的树，就够考试用了。

## P10 散列表构造与两种冲突处理（约4分钟）

那么讲完了树形查找，接下来看散列查找。散列的理想状态是 O(1)：Hash(key) = key % p，直接算出存储位置。p 取不大于表长的最大质数，质数能让余数分布更均匀、冲突更少。

冲突不可避免，两种处理办法。

第一种，开放定址：冲突了就线性探测下一位，addr = (addr+1) % TableLen，直到找到空位。它有一个最容易考的坑——删除不能直接把格子置 EMPTY。【停顿】为什么？因为查找是靠探测链走的，你把中间一个格子清空，后面靠探测放进去的元素就再也找不到了，查找会在空位提前停。所以开放定址的删除只能打一个删除标记 DELETED，查找遇到 DELETED 要继续探。

第二种，链地址法：同义词拉成一条单链表，头插。不聚集、删除直接摘结点，代价是额外的指针空间。

还有一个边界要注明：开放定址的查找循环，终止依赖表里至少有一个空槽。表满（装载因子等于 1）再查一个不存在的关键字，会无限探测。所以这个函数在装载因子小于 1 时才成立，答题时注一句，或者加一个探测次数上限兜底。

ASL 的计算训练同样留给专业课（题集勾画的 9答26、9答28），本课要求能写构造与查找代码、能说出两种方法的代价差别。

## P11 分块查找（约1分钟）

分块查找是顺序与折半的折中，一页带过。结构是索引表加块：索引表存每块的最大值与起始位置，块间有序、块内无序。查找先在索引表里找块（索引表有序，可以折半），再到块内顺序查找。ASL 是两次查找之和。代码不写，思想记住就行，它是填空题的考点。

```c
int SeqSearch(int A[], int n, int key){
    A[0] = key;                       // 哨兵

    while(A[i] != key) i--;           // 不需要判越界
    return i;                         // 返回 0 表示失败
}
```

跟练题二：折半查找。

```c
int BinSearch(int A[], int low, int high, int key){
    while(low <= high){
        int mid = (low + high) / 2;
        if(key == A[mid]) return mid + 1;      // 返回位序
        else if(key < A[mid]) high = mid - 1;
        else low = mid + 1;
    }
    return 0;
}
```

```c
// BST 的查找（材料原文）
BSTNode *BSTSearch(BSTNode *T, int key){
    while(T != NULL && key != T->key){
        if(key < T->key) T = T->lchild; else T = T->rchild;
    }
    return T;
}

// BST 的插入（材料原文，参数是指针的引用）
int BSTInsert(BSTNode *&T, int key){
    if(T == NULL){
        T = (BSTNode *)malloc(sizeof(BSTNode));
        T->key = key; T->lchild = T->rchild = NULL;
        return 1;
    }
    if(key == T->key) return 0;
    return key < T->key ? BSTInsert(T->lchild, key) : BSTInsert(T->rchild, key);
}

// BST 的删除（缺口5 补写版，三种情况）
int BSTDelete(BSTree &T, int key){
    if(T == NULL) return 0;
    if(key < T->key) return BSTDelete(T->lchild, key);
    if(key > T->key) return BSTDelete(T->rchild, key);
    if(T->lchild == NULL){ BSTNode *s = T; T = T->rchild; free(s); return 1; }
    if(T->rchild == NULL){ BSTNode *s = T; T = T->lchild; free(s); return 1; }
    BSTNode *pre = T->lchild;                    // 双孩子：中序前驱替换
    while(pre->rchild != NULL) pre = pre->rchild;
    T->key = pre->key;
    return BSTDelete(T->lchild, pre->key);
}

// AVL 右单旋（缺口6 补写版，LL 型代表；其余三种对称）
void RotateR(AVLTree &T){
    AVLTree B = T->lchild;
    T->lchild = B->rchild;
    B->rchild = T;
    T = B;
}

// 散列：开放定址线性探测（缺口7 补写版）
int Hash(int key){ return key % 11; }            // p 取不大于表长的最大质数
void InsertOpen(int H[], int key){
    int addr = Hash(key);
    while(H[addr] != EMPTY && H[addr] != DELETED){
        if(H[addr] == key) return;
        addr = (addr + 1) % TableLen;
    }
    H[addr] = key;
}
```
