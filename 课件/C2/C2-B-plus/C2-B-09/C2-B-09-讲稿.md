## P2 两套下标基准与哨兵位的三个作用（约4分钟）

排序章节的第一个难点不是算法，是下标。

基础阶段第1节立过六条约定，其中约定1说：排序章节 data[0] 留作哨兵、数据存 data[1..length]。这个约定到本节才正式落地，因为前面没有哪个算法真的需要哨兵。

【停顿】哨兵到底干什么用？三个作用。第一，直接插入里存待插入的元素，腾出一个变量位，不用单独声明一个 temp。第二，免掉循环的越界判断——这是最值钱的一个，等下看直接插入的代码你就明白。第三，快排里存枢轴，避免反复读写 low 位置。

还要说清一件事：哨兵只在需要它的算法里用。冒泡就不需要哨兵，所以材料里的冒泡从 0 开始排，这是另一种写法，等讲到冒泡那一页专门说明，你先记住"不是所有排序都 1 起"。

两套下标基准对比着记：线性表与查找章节，data[0] 起存、位序从 1 数；排序章节，data[0] 是哨兵、数据从 1 起存。做题第一件事是看清题目用哪套。

## P3 直接插入：j 减到 0 为什么一定跳出（约4分钟）

那么有了哨兵，看第一个算法，直接插入。思想一句话：第 i 个元素插进前面已经有序的区域里，插的过程就是边找位置边后移。

代码的骨架：外层 i 从 2 到 length，每趟先把 data[i] 存进哨兵 data[0]，然后 j 从 i-1 往前扫，只要 data[j] 大于哨兵里的值就后移，扫到头把哨兵的值放进 data[j+1]。

本节第一个关键设问：【停顿】内层 while 只判了 data[j] > data[0]，没有判 j >= 1，j 一路减下去减到 0、减到负数怎么办？

答案是它一定在 j=0 的时候跳出来。因为 data[0] 存的就是待插入元素自己，j 减到 0 时比较的是 data[0] > data[0]，自己大于自己，恒为假，循环停。这就是哨兵免掉越界判断的原理——不用写 j>=1 这个条件，哨兵在 0 位保底。

复杂度：时间 O(n²)，最好情况是已有序，每趟只比较一次、不移动，O(n)。稳定，相等不移动、相对次序不变。

## P4 过程页：五个数的直接插入逐趟（约4分钟）

这一页拿纸跟着画。屏幕上数组下标 0 到 5，0 位是哨兵（高亮），数据 49、38、65、97、76 存在 1 到 5。

第2趟插 38：38 存进哨兵，j 从 1 开始，data[1]=49 大于 38，49 后移到 data[2]；j 减到 0，data[0]=38 不大于 38，停，38 放进 data[1]。结果 38 49 65 97 76。

第3趟插 65：65 比 data[2]=49 大，已就位，continue 都不用进内层。第4趟插 97 同理就位。

第5趟插 76：76 存哨兵，data[4]=97 大于 76，97 后移；data[3]=65 不大于 76，停，76 放进 data[4]。结果 38 49 65 76 97。

你注意每趟的比较次数与移动次数：已就位时只比较 1 次、移动 0 次；完全逆序时比较与移动都最多。最好 O(n) 与最坏 O(n²) 的差距就在这。

## P5 折半插入：比较与移动要分开算（约4分钟）

那么直接插入每趟找位置是从后往前逐个比的，前面那段已经有序，找位置能不能快点？能，用折半。这就是折半插入。

代码改的只有一处：找插入位置不再用 while 逐个比，改成在有序区 [1, i-1] 里折半，找到 low 就是插入位置，然后统一后移、放进 data[low]。开头还有一句 continue 优化：data[i] 已经比 data[i-1] 大，就位，这趟跳过。

本节第二个关键认识：【停顿】折半插入把比较次数降到了 O(nlogn)，那它的时间复杂度是不是就是 O(nlogn) 了？

不是。比较与移动要分开算。比较确实降到了每趟 O(logn)、总共 O(nlogn)；但找到位置之后，后面的元素照样要一个一个后移，移动次数还是 O(n²)。总时间取大头，还是 O(n²)。

这个"比较降了、移动没降、总体不变"是选择题的常考点，记住了就不会掉坑。

## P6 二路插入：循环数组的 first 与 final（约4分钟）

二路插入是插入类里最巧的一个，目标是减少移动次数。

它用一个容量 n 的循环数组 temp，两个指针：first 指当前最小值的位置，final 指最大值的位置。插入一个新元素分三种情形。

第一种，比当前最小值还小：放到 first 前面一格（逆时针方向），first 前移。第二种，比当前最大值还大：放到 final 后面一格（顺时针方向），final 后移。第三种，落在中间：从 final 那一侧往后腾位置，再插进去。

为什么能减少移动？因为最小值往头插、最大值往尾插都不动已有元素，只有落在中间的才需要腾挪，最坏也只移 n²/8 次，比直接插入的 n²/2 少一半还多。

排完之后从 first 开始按环序回填到 data[1..n]。代价是多一个辅助数组，空间 O(n)。802 对二路插入考手算过程，代码不要求默写，你把三种情形和 first、final 的含义记清就行。

## P7 希尔排序：增量序列与为什么不稳定（约2分钟）

希尔排序一页带过。思想：取一个增量 d，把下标相隔 d 的元素分成一组，每组做直接插入；然后减小 d 重做，直到 d=1 做最后一趟普通的直接插入。常用增量序列是 n/2、n/4、一直到 1。

为什么它比直接插入快？d 大的时候组少、组内元素相距远，一趟能消除很多逆序；越往后逆序越少，最后一趟 d=1 时序列已经基本有序，直接插入的最好情况。时间约 O(n^1.3)，依赖增量序列的取法。

【停顿】希尔稳定吗？不稳定。相同值的两个元素可能分在不同的组里，各自被移动，相对次序就变了。

## P8 冒泡：提前退出优化与下标说明（约4分钟）

那么讲完了插入类，接下来看交换类，先是冒泡。

思想最简单：每趟从头到尾相邻比较，逆序就交换，一趟下来最大的元素"冒"到末尾。第 i 趟结束后，末尾 i 个元素已就位，所以内层 j 只走到 length-1-i。

swapped 标志是优化：一趟下来一次交换都没发生，说明序列已经有序，提前退出。最好情况（已有序）从 O(n²) 降到 O(n)——只走一趟、比较 n-1 次、零交换。这是"用某一趟的结果判断能不能提前结束"的典型例题。

下标要专门说明一句：屏幕上这段冒泡是材料原文，按 0 起写，数据存 data[0..length-1]，内层 j 从 0 到 length-2-i。它与本章其他用哨兵的排序（数据 1 起）起点不同。这不是错误，是伪代码的写法差异——冒泡不需要哨兵，从 0 排起完全正确，不影响算法。做题的时候看清题目给的数组是从 0 还是从 1 存数据，跟着题目的来。

复杂度：时间最坏与平均 O(n²)、最好 O(n)；空间 O(1)；稳定，相等不交换。

## P9 快排 Partition：哨兵存枢轴，挖坑填数（约4分钟）

交换类的第二个，快速排序，本节最重要的算法。

快排的核心是 Partition，一次划分：选一个枢轴（取 low 位置的元素），把序列重排成"左边全小于枢轴、右边全大于枢轴"，枢轴落到最终位置。然后对左右两段递归。

Partition 的过程叫"挖坑填数"。第一步，把枢轴 data[low] 挖出来存进哨兵 data[0]——这是哨兵的第三个作用——low 位置就成了一个坑。第二步，从 high 往左找第一个比枢轴小的，填进 low 的坑里，high 位置变成新坑。第三步，从 low 往右找第一个比枢轴大的，填进 high 的坑，low 又变坑。两步交替，直到 low 与 high 相遇，把哨兵里的枢轴放进最后那个坑，返回相遇位置。

两个边界：内外两层循环的条件都要带 low<high，不带会越界。递归是 QuickSort(low, p-1) 与 QuickSort(p+1, high)，枢轴已经归位，两个区间都不能再包含它，写成 (low,p) 与 (p,high) 就死递归了。

复杂度：平均 O(nlogn)，最坏（已有序，每次枢轴都是最值）O(n²)，空间 O(logn) 是递归栈；不稳定。

## P10 过程页：七元素数组的 Partition 逐步（约4分钟）

这一页拿纸跟着画。序列 49、38、65、97、76、13、27 存 data[1] 到 data[7]，枢轴取 data[1]=49 存进哨兵（屏幕上高亮哨兵位与第一个坑），low=1、high=7。

第一步从右：data[7]=27 小于 49，填到 data[1]，坑移到 7。第二步从左：data[2]=38 小于 49 跳过，data[3]=65 大于 49，填到 data[7]，坑移到 3。第三步从右：data[6]=13 小于 49，填到 data[3]，坑移到 6。第四步从左：data[4]=97 大于 49，填到 data[6]，坑移到 4。第五步从右：data[5]=76 大于 49 跳过，high 移到 4，与 low 相遇。枢轴 49 填进 data[4]。

结果：27 38 13 49 76 97 65。左边 {27,38,13} 全小于 49，右边 {76,97,65} 全大于 49，49 归位在第 4 个。

你把坑的位置一步步标出来：1→7→3→6→4，最后枢轴落进 4。这个"坑在两边交替移动"的画面记住了，Partition 的代码自然就会写。

## P11 平均值划分：死递归与进度保护（约4分钟）

快排的界值是取端点元素，还有一类题把界值换成区间平均值，2021 年那道双调序列就是这一族。

代码骨架：先对当前区间 [low,high] 求和算出 avg，然后 i 从 low 往右找大于 avg 的、j 从 high 往左找小于等于 avg 的，i<j 就交换，直到 i 与 j 交错。划分完递归处理两段。

但材料原文有一个死递归的坑，勘误 A2。【停顿】什么输入会触发？区间内元素全部小于等于 avg 的时候，最典型的就是全相等。

拿 R={5,5,5} 说：avg=5，第一个内层 while 找"大于 avg 的"，三个元素都不大于，i 一路推到 high+1；第二个内层 while 因为 i<=j 已经不成立，根本不执行，j 停在 high。这时候如果递归条件只写 if(low<j)，low<j 成立，递归区间 [low, high] 与原来一模一样——永远停不下来。

修正版加了进度保护：if(low<=j && j<high) 与 if(low<i && i<=high)。j<high 与 i>low 保证递归区间真的变小了。下一页拿 {5,5,5} 完整走一遍验证。

## P12 检查页：拿 R={5,5,5} 走一遍（约3分钟）

这一页你先自己推，别急着看结论。R={5,5,5}，low=0、high=2，用不加保护的版本走一遍，看递归调用是什么区间；再用修正版走一遍，看停在哪。

【停顿】对一下。avg=5。第一个内层 while：R[0]=5 小于等于 5，i=1；R[1]=5，i=2；R[2]=5，i=3——i 推到 3，也就是 high+1。第二个内层 while 判 i<=j，3<=2 不成立，不执行，j 停在 2。外层 while 判 i<=j 也不成立，退出。

不加保护：if(low<j) 即 0<2 成立，递归 QuickSortAvg(R, 0, 2)——区间没变，下一轮还是同样的过程，死递归。

修正版：if(low<=j && j<high) 即 0<=2 且 2<2，后半不成立，不递归。停下来了，排序完成（本来就全相等）。

这个反例值三件事：平均值划分的写法、递归必须有进度保证这个普适道理、以及怎么用一个小反例验证自己的代码。以后你写任何递归，都问一句"区间真的变小了吗"。

// 直接插入（数据存 L.data[1..length]，data[0] 哨兵）
void InsertSort(SqList &L){
    for(int i = 2; i <= L.length; i++){
        L.data[0] = L.data[i];                // 哨兵存待插入元素

        }
        L.data[j + 1] = L.data[0];
    }
}

        L.data[0] = L.data[i];  int low = 1, high = i-1;
        while(low <= high){ int mid = (low+high)/2;
            if(L.data[0] < L.data[mid]) high = mid-1; else low = mid+1; }
        for(int j = i; j > low; j--) L.data[j] = L.data[j-1];
        L.data[low] = L.data[0];
    }
}

// 冒泡（材料原文 0 起写法，数据存 data[0..length-1]，见勘误 A1 说明）
void BubbleSort(SqList &L){
    for(int i = 0; i < L.length - 1; i++){
        bool swapped = false;
        for(int j = 0; j < L.length - 1 - i; j++)
            if(L.data[j] > L.data[j+1]){
                int tmp = L.data[j]; L.data[j] = L.data[j+1]; L.data[j+1] = tmp;
                swapped = true;
            }
        if(!swapped) break;
    }
}

// 快排 Partition（哨兵存枢轴，挖坑填数）
int Partition(SqList &L, int low, int high){
    L.data[0] = L.data[low];
    while(low < high){
        while(L.data[high] >= L.data[0] && low < high) high--;
        L.data[low] = L.data[high];
        while(L.data[low] <= L.data[0] && low < high) low++;
        L.data[high] = L.data[low];
    }
    L.data[low] = L.data[0];  return low;
}
void QuickSort(SqList &L, int low, int high){
    if(low < high){
        int p = Partition(L, low, high);
        QuickSort(L, low, p - 1);
        QuickSort(L, p + 1, high);
    }
}

// 以平均值为界值的划分（勘误 A2 修正版：进度保护）
void QuickSortAvg(int R[], int low, int high){
    if(low >= high) return;
    int sum=0;  for(int i=low;i<=high;i++) sum+=R[i];
    int avg=sum/(high-low+1), i=low, j=high;
    while(i <= j){
        while(i<=j && R[i]<=avg) i++;
        while(i<=j && R[j]>avg) j--;
        if(i<j){ int t=R[i]; R[i]=R[j]; R[j]=t; i++; j--; }
    }
    if(low<=j && j<high) QuickSortAvg(R,low,j);   // 进度保护：区间必须真变小
    if(low<i && i<=high) QuickSortAvg(R,i,high);
}
