## P2 引题：层序遍历能干什么，last 为什么需要（约3分钟）

先看层序遍历这一边。数据结构基础阶段第7节写过层序遍历：队列一圈一圈往外扩，天然按层访问。按层访问直接能答两类问题：树有几层、结点总数是多少。出队时计数，遍历完就是总数。

但它答不了另一类问题：每一层有多少个结点，哪一层最宽。为什么答不了？因为队列本身不知道一层到哪里结束。层序的队列里，第1层的结点后面紧跟第2层的结点，中间没有分隔符。

所以给它加一个变量 last：记下当前层最右结点在队列里的下标。出队出着出着，front 超过了 last，说明本层全部出完了；这时候 rear 指向的就是下一层的最右结点，把 last 换成 rear，重新数下一层。这一个机制就是本节第一组算法的全部内容。

【停顿】先回答屏幕上的问题：层序队列里，凭什么判断一层已经出完了？想两三秒，带着答案进下一页。

## P3 求树的宽度：last 分层逐行走（约5分钟）

第一个算法：求树的宽度，模板6。宽度的定义：各层结点个数的最大值。

看代码 Width。开头判空。然后变量一起声明：front 是队头下标，rear 是队尾下标，last 是本层最右结点的下标，temp 是本层计数器，maxwidth 记历史最大。根入队，last 初始指向下标 0，也就是根自己。

循环体五行。前三行是标准层序：出队一个，temp 加一，左右孩子非空就入队。后两行是本题的灵魂：出队之后检查 front 是否大于 last，是，说明本层出完了，做三件事——last 换成 rear、用 temp 更新 maxwidth、temp 清零。三件事缺一不可，temp 不清零，下一层的个数就叠在上一层头上。

【停顿】注意一个选择：这里不用封装好的循环队列，直接用数组加 front、rear 两个下标。为什么？因为我们要拿队列里的下标去更新 last，封装好的队列只给出队入队两个动作，下标拿不到。记住这个取舍：工具可以降级，为了拿到需要的信息。

复杂度：每个结点入队出队各一次，时间 O(n)；队列空间 O(n)。

## P5 繁荣度：求宽度的代码改三处（约4分钟）

第二个算法：繁荣度，2024 年考过。题目定义：每一层的结点数乘以该层的层数，全部加起来。

讲法就一句话：求宽度的代码改三处。第一处，maxwidth 换成累加器 totalProsper；第二处，多一个 height 计数器，从 1 起；第三处，层结束时不再比大小，改成加 height 乘 width。屏幕上 prosperity 的代码对着 Width 看，骨架一行不差。

两个坑点明。第一，height 从 1 起：题目定义的层号从 1 起，从 0 起算，每层的贡献全错。第二，材料原代码的外层循环条件是 front 小于等于 rear，而求宽度用的是 front 小于等于 last：这两个写法在本题里等价，因为内层已经用 front 大于 last 判了层结束，但一份笔记里两种写法并存容易记混，本页统一成 last。

从已知算法改三处得到新算法，这是本节要带走的能力：考场上见到按层加权的新定义，先认出它是宽度骨架，再换累加式。复杂度与宽度相同，O(n)。

## P7 最长路径：path 与 maxPath 双数组（约5分钟）

第三个算法：输出从根到叶子的最长路径，2025 年考过。代码 longestPath，五个参数，先看分工：path 记当前正在走的路径，pathLen 是 path 里元素的个数；maxPath 记目前最长的那条，maxLen 是它的长度。

递归体四步。第一步，当前结点值写入 path，pathLen 加一。第二步，到叶子了——左右孩子都空——就比较：pathLen 大于 maxLen，更新 maxLen，把 path 前 maxLen 个元素拷进 maxPath。第三步，没到叶子，递归左子树，再递归右子树。

回到上一页的问题：pathLen 值传递，maxLen 引用。为什么？pathLen 要的是每层自己的副本：从 4 递归进 6，6 那一层把 pathLen 加到了 4；退回 4 这一层，4 自己的 pathLen 还是 3，path 里的 6 自动作废——值传递替我们完成了退格。maxLen 相反，它是全局最优记录，子树里发现了更长的路，必须改写外层那个 maxLen，所以用引用。数据结构基础阶段第8节讲过值传递与引用传参，这里是它在真题里的标准用法。

一个边界：只在叶子处比较。内部结点也拿来比，拿到的就不是完整路径。

调用入口：pathLen 与 maxLen 初值都置 0，遍历完打印 maxPath 前 maxLen 个元素。时间 O(n)，两个数组 O(n)。

## P9 判 BST：中序加 prev，prev 为什么用引用（约3分钟）

第四个算法：判断一棵二叉树是不是二叉排序树，2024 年考过。思想从中序遍历来：BST 的中序遍历序列严格递增。所以判 BST 等价于查它的中序序列是不是严格递增。

做法：中序遍历，每访问一个结点，用 prev 记住上一个访问的值。当前值不大于 prev——出现相等或更小——就不是 BST。注意比较符号是小于等于：BST 不允许重复值，相等也判不是，这个判定约定答题时写明。

为什么用中序不用先序？只有中序序列对 BST 是有序的，先序序列无此性质。遍历顺序选错，这个算法就不成立。

prev 必须引用：它跨递归层共享——左子树里更新过的 prev，根结点比较时要读；根结点更新过的 prev，右子树要读。写成值传递，每层拷贝一份，比较就全乱。

## P12 哈夫曼构造：思想与骨架（约3分钟）

最后一个：哈夫曼树的构造。先说明定位：802 以手算为主，考的是手算构造与编码，左右分支标 0 和 1，代码不要求写。本页只给思想与存储结构，课后也不留代码题。

思想一句话：森林里每次取两棵权值最小的树合并，新树的权值是两棵之和，重复 n 减 1 次，剩一棵就是哈夫曼树。

存储结构用双亲表示法：一个 2n-1 个结点的数组，每个结点四个字段——weight、parent、lchild、rchild，指针字段存的是数组下标，0 表示没有。为什么恰好 2n-1 个结点：n 个叶子，每次合并减少一棵树，合并 n-1 次，多出 n-1 个内部结点。怎么知道谁还没被合并？parent 等于 0。每轮扫一遍选两个最小，所以构造是 O(n²)，用优先队列可以降到 O(n log n)，知道即可。

## 附录一：课后题参考答案

跟练题一：求树的宽度（默写）。

```c
int Width(BiTree T){
    if(T == NULL) return 0;
    int front = 0, rear = -1, last = 0, temp = 0, maxwidth = 0;
    BiTree Q[MaxSize]; BiTree p;
    Q[++rear] = T;
    while(front <= last){                    // 终止条件用 last
        p = Q[front++]; temp++;
        if(p->lchild != NULL) Q[++rear] = p->lchild;
        if(p->rchild != NULL) Q[++rear] = p->rchild;
        if(front > last){ last = rear;       // 本层结束：last 换成队尾
            if(temp > maxwidth) maxwidth = temp;
            temp = 0; }
    }
    return maxwidth;
}
```

要点：last 只在层结束那一刻更新；不用封装队列是为了拿得下标；时间 O(n)、队列 O(n)。

跟练题二：判 BST（默写，勘误 A5 修正版）。

```c
int checkBST(BiTNode *node, int &prev);      // 先声明再被调用

int JudgeBST(BiTree T){
    int prev = INT_MIN;                      // 初值不隐含"值都大于 -1"
    return checkBST(T, prev);
}
int checkBST(BiTNode *node, int &prev){
    if(node == NULL) return 1;
    if(!checkBST(node->lchild, prev)) return 0;   // 左子树不是 BST，短路
    if(node->data <= prev) return 0;              // 中序必须严格递增
    prev = node->data;
    return checkBST(node->rchild, prev);
}
```

要点：prev 初值用 INT_MIN 或题目给定下界，并在答案里写明假设；比较用小于等于，相等也判不是。

// 求树的宽度：层序加 last 分层
int Width(BiTree T){
    if(T == NULL) return 0;
    int front = 0, rear = -1, last = 0, temp = 0, maxwidth = 0;
    BiTree Q[MaxSize]; BiTree p;
    Q[++rear] = T;
    while(front <= last){                    // 终止条件用 last
        p = Q[front++]; temp++;
        if(p->lchild != NULL) Q[++rear] = p->lchild;
        if(p->rchild != NULL) Q[++rear] = p->rchild;
        if(front > last){ last = rear;       // 本层结束：last 换成队尾
            if(temp > maxwidth) maxwidth = temp;
            temp = 0; }
    }
    return maxwidth;
}

int checkBST(BiTNode *node, int &prev){
    if(node == NULL) return 1;
    if(!checkBST(node->lchild, prev)) return 0;      // 左子树不是 BST，短路
    if(node->data <= prev) return 0;                 // 中序序列必须严格递增
    prev = node->data;

// 由先序与中序建树：模板 12（数据结构基础阶段第7节已逐行讲过）
BiTree Build(BiTree &T, int A[], int B[], int preL, int preR, int inL, int inR){
    if(preL > preR) return NULL;
    T = (BiTNode*)malloc(sizeof(BiTNode));
    T->data = A[preL];                   // 先序第一个元素为根
    int k = inL;
    while(B[k] != A[preL]) k++;          // 在中序中定位根
    int leftLen = k - inL;               // 左子树结点个数
    Build(T->lchild, A, B, preL + 1, preL + leftLen, inL, k - 1);
    Build(T->rchild, A, B, preL + leftLen + 1, preR, k + 1, inR);
    return T;
}

void CreateHuffman(HTNode HT[], int w[], int n){

        HT[i].parent = HT[i].lchild = HT[i].rchild = 0;
