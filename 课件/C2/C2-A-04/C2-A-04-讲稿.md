## P2 引题：单链表的两个不方便（约3分钟）

那么我们先回头看单链表，它有两个不方便的地方，这一节的三种变体就是来补这两个不方便的。

第一个不方便，单链表每个结点只有一根 next 指针，只能往前走、不能回头。你站在某个结点上，想找它前一个结点，没办法直接找到，只能从头结点开始顺着 next 一个一个走，走到它前面那个，这需要 O(i) 的时间。如果链表有一万个结点，就得从头走过几千个结点才能找到它的前驱，这个代价是非常巨大的。

第二个不方便，正因为不能回头，要在某个结点 p 的前面插入一个新结点，你就必须先从头发找到 p 的前驱，才能改它的 next，找前驱就要走一趟。

这两个不方便的根子，都在于单链表只有向后的指针。弥补的办法有两种。第一种，给每个结点再加一根指向前驱的指针 prior，这就是双链表，有了 prior，找前驱、往前插都能在O(1)的时间内解决。第二种，把尾巴的 next 接回头结点，让链表绕成一个圈，这就是循环链表，它解决的是循环报数这类问题。
此外的静态链表，就是用数组加游标来模拟链表。我们一个一个看。

## P3 双链表定义（约3分钟）

先看双链表的定义。跟单链表比，只是简单的多了一个成员。typedef struct DNode，里面三个成员：int data 存数据，一个 struct DNode 指针 prior 指向前一个结点，一个 struct DNode 指针 next 指向后一个结点。同样起两个名字，DNode 是一个结点，DLinkList 是指向结点的指针、也就是整条链。

关键就在这个 prior。单链表只有 next，只能往后；双链表多了 prior，从任意一个结点出发，既能顺着 next 往后走，也能顺着 prior 往前走。这就把刚才那两个不方便都解决了：要找 p 的前驱，直接 p->prior，不用从头走；要在 p 前面插入，也能直接通过 prior 操作。

当然，多一根指针是有代价的，每个结点多存一个地址，空间开销比单链表大。所以双链表不是什么时候都用，只有当你确实需要频繁往前找、或者频繁在前驱位置操作时，多这个prior指针才划算。这一点最后选链表的时候再展开。顺带说一句，双链表也常常和循环结合，做成带头结点的双向循环链表，头结点的 prior 指向最后一个结点、next 指向第一个，首尾相接。2020年真题考的就是这种结构，我们这一节先把普通双链表的插删练熟，循环的部分前面已经讲了思路，合起来就是它。

## P4 双链表插入：四条赋值（约4分钟）

那么定义清楚了，看双链表的插入。它比单链表复杂，因为插入要同时管 prior 和 next 两根指针，一共四条赋值，次序有讲究。

看代码 ListInsert。跟单链表一样，第一步找前驱，p 等于 GetElem(L, i-1)，判空；然后新建结点 s、把 elem 装进 s->data。接下来是四条赋值：第一条 s->next = p->next，让 s 的 next 接住 p 原来的后继；第二条 s->prior = p，让 s 的 prior 指回 p；第三条，如果 p->next 不为空，就 p->next->prior = s，把 p 原来那个后继的 prior 改成指向 s；第四条 p->next = s，让 p 的 next 指向 s。

这四条里，前两条①②是安置新结点 s 自己，把它两根指针接好，这两条谁先谁后都无所谓。真正有次序要求的是③和④，**1必须要在4之前**。为什么，下一页画图你就看明白了，这里先记住这个结论：先改原后继的 prior，再改 p 的 next。

还有③为什么要判 p->next != NULL？因为如果 p 是最后一个结点，它后面是可以没有后继的，那么就没有谁的 prior 需要改，这时候跳过③。这个判空漏了，插在表尾时就会对一个空指针取 prior，出错。你可能要问，双链表都有 prior 了，插入为什么还要先 GetElem 找前驱、不直接用 prior？因为我们这个 ListInsert 是按位序 i 插入，接口给的是位置，你还是得先走到第 i-1 个结点。prior 的价值在于，走到那个结点之后往前往后都能直接操作，以及像课后那道“在 p 之前插入”的题，有了 p 就能直接用 p->prior，不用回头找。

## P5 过程页：四条赋值一步步画（约5分钟）

这一页你拿纸跟着画，PPT一步步放，我们把双链表插入的四条赋值画清楚，重点看③④换次序会出什么事。

先画好现场：有两个结点连着，p 和 p 的后继，我们叫它 x。p->next 指向 x，x->prior 指向 p。现在要在 p 和 x 之间插入新结点 s。

第一步①，s->next = p->next，也就是 s->next 指向 x，画出来是 s 的 next 箭头指向 x。第二步②，s->prior = p，s 的 prior 箭头指向 p。这两步 s 自己的两根指针接好了，但 p 和 x 还没接上 s。

第三步③，p->next->prior = s，p->next 现在是 x，所以这句就是 x->prior = s，把 x 的 prior 从原来指 p 改成指 s。画出来是 x 的 prior 箭头从 p 转到 s。

第四步④，p->next = s，把 p 的 next 从原来指 x 改成指 s。画出来是 p 的 next 箭头从 x 转到 s。四步画完，p、s、x 就正确串起来了，prior 和 next 两个方向都对。

走完双链表插入的整个流程，我们来仔细讲解一下为什么四个语句中，实际上只有1不能在4之后的这一个约束。对于链表而言，插入次序不对导致的问题是链表断裂，这会导致我们无法通过现有的元素去找到后面需要变更的元素，这也是为什么我在上一节课的时候说，先做新结点的指针赋值，再做原有节点的指针变更是一定不会出错的。我们用p代表前驱，s代表插入结点，唯一没有被赋予变量名的是p->next，关于这个结点我们所需要做的操作有两个，分别是`s->next = p->next`和`p->next->prior = s`，一旦在s与后驱建立链接之前p与后驱的指针变更，我们就无法完成这两个操作了。那么对于`p->next->prior = s`这个语句而言，其在任何位置都是可以的，如果在14后面的话，那就需要改为`s->next->prior = s`。

## P6 双链表删除（约4分钟）

那么插入会了，删除是它的反操作。ListDelete 删第 i 个结点，也要先找前驱 p，判两次空：p 不能空，p->next 也不能空，跟单链表一样。然后用 s 记住要删的结点，也就是 s 等于 p->next，先 elem = s->data 把值取出来带出。

接下来改指针，这里比单链表多一步。单链表删除只要 p->next = s->next，让前驱跨过 s 就行。双链表是双向的，还要把 s 的后继的 prior 改回指向 p。所以两句：p->next = s->next，让 p 跨过 s 接住后继；然后如果 s->next 不为空，s->next->prior = p，让后继的 prior 指回 p。最后 free(s)。

这里同样有个判空，if s->next != NULL。为什么？如果删的是尾结点，s 后面没有后继，就没有谁的 prior 要改，跳过这句。漏了这个判空，删尾结点时就会对一个空指针取 prior，出错。

你把双链表的插入和删除放一起对比：插入是四条赋值；删除是改 p->next 和后继的 prior、两处都要判空。核心就一句，双链表动一个结点，前后两根指针、两边的结点都要照顾到，别只顾一头。我们走一遍。假设双链表是 头结点、10、20、30 这么串着，每个结点 prior 指前一个、next 指后一个，我要删第2个也就是20。先找前驱，GetElem(L,1) 走到10那个结点，p 指它；判两次空，p 不空、p->next（20）也不空，通过；s 指向20，elem 取出20。然后改指针：p->next = s->next，让10的 next 跨过20直接指向30；再 s->next->prior = p，也就是30的 prior 从原来指20改成指10。最后 free 掉20。删完这条链是 头结点、10、30，10和30之间 prior、next 两个方向都接对了。你注意，双链表删除比单链表多的那一句，就是改后继的 prior，漏了它，从后往前走就会断。

## P7 循环单链表（约5分钟）

接下来看循环单链表。它跟单链表的区别就一个：单链表尾结点的 next 是 NULL，循环单链表尾结点的 next 指回头结点，整条链绕成一个圈。就这么一个改动，带来三处不同，我们一处一处对比。

第一处，建表结束。单链表尾插完，最后 r->next = NULL；循环单链表是 r->next = L，让尾巴接回头结点。

第二处，判空。单链表空表是 L->next == NULL；循环单链表没有 NULL 了，空表是 L->next == L，也就是头结点的 next 指向它自己。

第三处，遍历终止。单链表遍历是 while p != NULL，走到 NULL 停；循环单链表没有 NULL，你要是还写 p != NULL，就永远停不下来，绕着圈死循环。正确的终止条件是 p != L，走到绕回头结点就停。

【停顿】这三处里最容易错的是遍历终止。很多人写循环链表的遍历，习惯性还写 p != NULL，结果程序卡死在那。你要记住，循环链表是绕圈的，判断"走了一圈回到起点"用的是 **p != L，不是 p != NULL**。这个终止条件很重要，2026年的约瑟夫环就是用循环单链表模拟报数，靠的正是这种绕圈遍历。我给你走一遍循环单链表的遍历，你就明白 p != L 是怎么回事。假设头结点是 L，后面串着10、20、30，30的 next 又指回 L。遍历从 p = L->next 也就是10开始，处理10；p 走到20，处理20；p 走到30，处理30；p 再走就到 L 了，这时候 p != L 不成立，循环停。你看，它靠走回头结点就停来结束，而不是靠遇到 NULL。要是你写成 p != NULL，因为这条链根本没有 NULL，p 永远不为 NULL，就绕着圈出不来了。

## P8 循环双链表（约2分钟）

循环双链表，就是把循环和双链表合起来：既有 prior 又有 next，而且首尾相接成一个环。头结点的 next 指向第一个结点，prior 指向最后一个结点。

它有一个要注意的点，判空要两个条件：L->next == L 并且 L->prior == L，两个都成立才是空表。为什么不能只判一个？因为在插入删除的过程中，可能出现一个中间状态，next 已经接成环了、但 prior 还没接好，这时候只判 next==L 会误判成空表。两个都判才稳妥。循环双链表考得不多，你记住判空要两个条件就行。

## P9 静态链表（约4分钟）

最后一种，静态链表。前面几种链表，结点都是 malloc 出来、用指针串的。静态链表换个做法：用一个数组存所有结点，结点之间不用指针连，而是用一个下标指向下一个，这个下标就叫游标。

看定义：一个数组，每个元素是一个结构体，两个成员，data 存数据，next 存的是下一个元素的下标，是个 int，不是指针。next 等于 -1 表示到头了，相当于单链表里的 NULL。

它的操作跟链表一样，只是把指针换成下标。比如在游标 p 的结点后面插入一个游标 s 的结点，两句：L[s].next = L[p].next，让新结点的游标接住 p 原来的后继；L[p].next = s，让 p 的游标指向 s。你看，这跟单链表插入的两句 s->next = p->next、p->next = s 是一模一样的，只不过把箭头换成了下标赋值。插入删除都只改游标、不搬数据，这一点和链表一样，和顺序表不一样。举个具体的。假设数组下标1、2、3存着10、20、30，它们的 next 游标分别是2、3、-1，也就是1号指向2号、2号指向3号、3号到头。现在要在1号后面插入一个存在4号位置的数15。两句：L[4].next = L[1].next，也就是4号的游标设成2，接住1号原来的后继2号；L[1].next = 4，1号的游标改成4。这样链就是 1号(10)、4号(15)、2号(20)、3号(30)，15插进了10和20之间。你发现没有，整个过程只改了游标这几个 int，一个数据都没搬，这跟顺序表插入要挪一大片元素完全不同。

那静态链表存在的意义是什么？两个：一是在那些没有指针的语言里，用它来模拟链表；二是有些题目明确要求用数组实现链表操作。802 里静态链表考得不多，你理解它"数组加游标、改游标不搬数据"这个思路就够了，复杂的备用链管理我们不展开，也基本不会考察。

## P10 检查页：四种链表怎么选（约4分钟）

这一节讲了好几种链表，这一页你来判断，给一个场景该选哪种。先自己想，别急着看答案。

第一个场景，常在表的尾部操作、而且要保持输入顺序，选择加入尾指针的用单链表，其实也可以选择选循环双链表。第二个，需要频繁找某个结点的前驱，或者要前后双向走，选用双链表，prior 直接给你前驱。第三个，要做循环报数、轮转，比如约瑟夫环那种，选用循环单链表，走到尾自动回头。头尾两端都频繁操作，用循环双链表，头和尾都是 O(1)。第四个，要频繁在表头和表尾两端都操作，选哪种？第五个，只有当题目要求必须用数组的时候，才用静态链表，游标代替指针，不过基本不会出现。

这种"给场景选存储"的判断题，是考试里常见的考法。你选的时候抓住每种结构最本质的那个特点：双链表的本质是 prior 能直接找前驱，循环链表的本质是循环，静态链表的本质是数组加游标。抓住本质，场景一对就上号了。再多想一层：为什么频繁在头尾两端操作要选循环双链表？因为循环让尾结点能直接回到头，双链让两头都能 O(1) 插删，两个特点合起来，头尾操作都不用来回走。你把每种结构的特点拆开看，选型就是把这些特点跟题目需求对上。

## P11 小结（约2分钟）

这一节收一下，三种单链表的变体。

双链表，多一根 prior，能往前找。插入四条赋值，建立连接之前不要更改指针，换了就断链；删除要改后继的 prior，还要判空。这是本节重点，2020真题考过。

循环单链表，尾巴接回头结点，三处跟单链表不同：建表 r->next=L、判空 L->next==L、遍历终止 p!=L，其中遍历终止最容易错写成 p!=NULL 导致死循环。循环双链表判空要 next 和 prior 两个条件。2026约瑟夫环用的就是循环单链表。

静态链表，数组加游标，next 存下标不存地址，插删只改游标不搬数据。

选哪种看需求：找前驱用双链表，循环报数用循环链表，题目要数组用静态链表。这一节你重点把双链表的插入四条赋值次序吃透，那是2020真题的原型；循环链表记住三处差别尤其遍历终止 p!=L，那是2026约瑟夫环的原型；静态链表理解思路即可。

## 附录一：课后题参考答案

跟练题：默写 DNode 定义、双链表插入与删除，并标出插入四条赋值的次序约束。

```c
typedef struct DNode{ int data; struct DNode *prior, *next; }DNode, *DLinkList;

bool ListInsert(DLinkList &L, int i, int elem){
    DNode *p = GetElem(L, i - 1);
    if(p == NULL) return false;
    DNode *s = (DNode *)malloc(sizeof(DNode));
    if(s == NULL) return false;
    s->data = elem;
    s->next = p->next;                        // ① s 接住原后继
    s->prior = p;                             // ② s 认 p 做前驱
    if(p->next != NULL) p->next->prior = s;   // ③ 必须在④前，改原后继的 prior
    p->next = s;                              // ④ p 指向 s
    return true;
}
bool ListDelete(DLinkList &L, int i, int &elem){
    DNode *p = GetElem(L, i - 1);
    if(p == NULL) return false;
    if(p->next == NULL) return false;
    DNode *s = p->next;  elem = s->data;
    p->next = s->next;
    if(s->next != NULL) s->next->prior = p;   // 后继的 prior 改指 p
    free(s);  return true;
}
```

次序约束：③（原后继的 prior 改指 s）必须在④（p->next = s）之前；④一旦执行，p->next 就变成 s，③再写就改到 s 自己，原后继的 prior 丢失、且原后继再也找不到。

模仿题（2答8 同类）：在双链表结点 p 之前插入 s。

```c
s->next = p;                          // s 的后继是 p
s->prior = p->prior;                  // s 的前驱是 p 的原前驱
if(p->prior != NULL) p->prior->next = s;  // 原前驱的 next 改指 s（必须先做）
p->prior = s;                         // p 的前驱改成 s
```

要点：不能换的是"p->prior->next = s"与"p->prior = s"，必须先让原前驱接住 s，再改 p->prior，否则原前驱找不到；在 p 之前插入正好用上 prior，不用像单链表那样从头找前驱。
