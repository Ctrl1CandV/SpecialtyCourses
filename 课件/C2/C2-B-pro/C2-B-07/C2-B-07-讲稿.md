## P3 最小生成树与 Prim 的思想（约2分钟）

先说什么是最小生成树。从一个连通图里选出 n-1 条边，把所有顶点连起来、并且不成环，这是一棵生成树；同一幅图的生成树有很多棵。在所有生成树里权值和最小的那一棵，叫最小生成树。Prim 和 Kruskal 干的都是这件事，只是一个从顶点长、一个从边收。

看屏幕这张图和 Prim 的思想。初始时将一个顶点放入生成树。每轮从连接树内顶点与树外顶点的边中选权值最小的一条，再把对应的新顶点加入生成树；直到全部顶点并入，选中的 n-1 条边就是最小生成树。

Prim 每轮选择的是**连接当前生成树的最小边**，不是起点到该顶点的最短路径。这个区别正是它与 Dijkstra 更新方式不同的原因。图上的选择过程会在后面的动画中逐轮展示。

## P4 Prim 的三个数组与 weight 字段（约2分钟）

写 Prim 之前先补一个字段检查。Prim 的代码里用 `p->weight` 取边权，那就要求邻接表的边表结点 ArcNode 里必须有 weight 字段。数据结构基础阶段第9节给邻接表定义时就把 weight 放出来了，注明带权的图用它，所以这里直接对上。读图算法代码前，先对照结构定义确认所用字段存在且含义一致。

Prim 用三个数组，分工一个个说。`include[i]` 记顶点 i 是否已经在生成树里，在树里就不再碰它。`dist[i]` 记顶点 i 到生成树的最小边权——注意，是**到树的最小边权**，不是 i 到起点 0 的距离，这是 Prim 和 Dijkstra 最要紧的区别。`parent[i]` 记选中 i 时走的那条边从哪个顶点来，树建好之后沿 parent 一路回溯，能把全部树边还原出来。

【停顿】先自己说一遍：dist[i] 是 i 到起点的距离吗？不是。它是 i 连进生成树的那条最小边的权值。起点 0 的 dist 是 0，因为它已经在树里，代价为零，仅此而已。初始化能不能偷懒，下一页专门讲。

## P5 Prim 主循环逐行走（约3分钟）

主循环两行骨架先看清，再逐行走。屏幕上这段是骨架：第一行初始化循环，单独讲；然后 `dist[0] = 0`，从顶点 0 开始长；外层循环 n 轮，每轮两拍。

第一拍，选最小的 u：在树外顶点里找 dist 最小的那个。内层循环扫全部顶点，`!include[i] && dist[i] < minDist` 同时成立才更新候选，扫完 u 就是本轮要并入的顶点。如果 u 等于 -1，说明树外顶点的 dist 全是 INF，图不连通，直接 break。

第二拍，并入加刷新。`include[u] = true` 之后，沿 u 的边表扫一圈：对每条边，只要另一端 v 不在树里、且边权 w 比 v 现有的 dist[v] 小，就刷新 `dist[v] = w`、`parent[v] = u`。w 不比它小就不动——注意这里只比边权本身，不做任何加法。

【停顿】回到第一行初始化：为什么不能写 `int dist[] = {INF}`？那样写只有第一个元素是 INF，其余全是 0。数组初始化列表这种简写只有"等于 0"一种用法，非 0 的初值一律写循环，这个坑在真实代码里这是第二次出现。初始化写错后，后续每轮选出的顶点和边权都可能不正确。

复杂度收尾：外层 n 轮，每轮选最小要扫全部顶点，是 O(n²)，邻接表也一样，因为瓶颈在选最小不在扫边。图不连通时 u 等于 -1 直接停，不会死循环。dist 数组到底怎么一轮轮变，下一页动画对着图走。

## P7 Kruskal 的思想与并查集判环（约3分钟）

Kruskal 先把边按权值从小到大排序，再依次检查。若一条边连接的两个端点还属于不同连通分量，就把它加入生成树；选满 n-1 条边后结束。

和 Prim 对着记：Prim 盯着顶点往外长，Kruskal 盯着边往里收。还是那张图，边按权排好是 0-1 权 2、1-2 权 3、1-4 权 5、0-3 权 6、2-4 权 7、1-3 权 8、3-4 权 9。依次看：前四条两端都不在一棵树里，全部加入，正好是 2、3、5、6，权值和还是 16，和 Prim 的结果一致——两个算法找的是同一棵最小生成树。

关键问题只有一个：怎么知道两个端点"在不在同一棵树里"。答案是并查集，数据结构基础阶段第9节讲并查集时留的问题在这里兑现。并查集就一个 parent 数组，初始化 parent[i] 等于 i，每个顶点自成一棵树，屏幕上 Find 这三行就是全部判环逻辑：从 x 出发沿 parent 一路往上走到根，根就是 x 所属树的编号。两个端点各做一次 Find，根相同说明已经连通，这条边再加就成环，跳过；根不同就合并，把一棵树的根挂到另一棵的根下面。

【停顿】对着扫边序想一步：如果前四条加完继续看 2-4 权 7，这时 2 的根和 4 的根是同一个，说明 2 和 4 已经连通了，加这条边会成环——这就是并查集判环的样子。

复杂度：排序主导，O(e log e)，e 是边数。边少的稀疏图用 Kruskal 顺手，顶点多边稠密的图用 Prim，这个选择依据记一句就够，优劣论述是专业课的事。

## P8 Kruskal 骨架填空（约2分钟）

屏幕上这段是骨架，三处空先自己试着填。

第一处，初始化并查集：每个顶点的 parent 指自己，`parent[i] = i`，一个循环。第二处，扫边循环的条件：`i < m && cnt < vexnum - 1`，m 条边扫完或者 n-1 条边加够，双保险，哪个先到都停。第三处，判环加边：`a != b` 说明 Find 出来的两个根不同、不成环，`parent[a] = b` 合并，cnt 加一。

两个辅助点。Edge 结构一行就够：u、v 两个端点加 w 权值，排序按 w 排。完整写法还要先遍历邻接表，把边收进 E 数组并按 w 升序排序，再执行这段循环。排序是准备工作，判断两端点是否会构成环并合并连通分量，是这里的关键。复杂度还是 O(e log e)，排序最贵，并查集带路径思想后接近 O(e)，考场上写这个数。

## P9 Dijkstra 骨架（约3分钟）

进入最短路径。Dijkstra 求单源最短路径：给定起点 v0，求 v0 到每个顶点的最短距离。还是那张图，从 0 出发。

三个数组。`dist[i]` 是 v0 到 i 的当前最短距离，注意和 Prim 的 dist 不是一个东西。`S[i]` 记 i 的最短路是否已经确定。`path[i]` 记最短路上 i 的前驱，用来还原路径本身。初始化：dist 直接取邻接矩阵第 v0 行，S 全 false；path[i] 初值看这一行是不是 INF，不是就记 v0，是就记 -1。然后 `dist[v0] = 0`、`S[v0] = true`，起点先确定。

主循环 n-1 轮，每轮两拍，骨架和 Prim 几乎一样。第一拍，选树外 dist 最小且 S 为 false 的 u，它的最短路此刻确定，置 S[u] 为 true。第二拍，松弛：对每个还没确定的 i，试"经过 u 会不会更近"——`dist[u] + G.edge[u][i]` 小于 `dist[i]` 就刷新 dist 和 path。

在那张图上走一遍收尾：初始 dist 是 0、2、INF、6、INF。并入 1 之后，2 刷成 2 加 3 等于 5，4 刷成 2 加 5 等于 7，3 那条 2 加 8 等于 10 比 6 大不动。最后 dist 是 0、2、5、6、7。复杂度 O(n²)，每轮选最小扫全部顶点。

## P10 Prim 与 Dijkstra 对照表（约1分钟）

屏幕上这张对照表是本节重点之一。Prim 和 Dijkstra 的骨架几乎一样，都是每轮选最小的并入、再更新其余；差别全在更新式那一行：Prim 是边权 w 直接和 dist[v] 比，因为只要管"到树的最短边"；Dijkstra 是 dist[u] 加 w 再和 dist[i] 比，因为要累加整条路径的长度。

再看结果那一行：Prim 那边 dist 存的是边权，2 的位置是 3、4 的位置是 5；Dijkstra 这边是路径长 5 和 7。把这两行并排记住，对照这两个结果，可以看出它们保存的 dist 含义不同。

## P11 Floyd 骨架：三重循环的含义（约3分钟）

Floyd 求所有顶点对之间的最短路径，用邻接矩阵，输出一个距离矩阵 A。屏幕上这个三顶点小例先看清：0-1 权 5，1-2 权 3，0-2 权 10。

代码就三重循环加一个初始化：A 先初始化为邻接矩阵，然后 k 从 0 到 n-1，每个 k 里对全部 i、j 试 `A[i][k] + A[k][j] < A[i][j]`，成立就刷新。

每轮固定一个顶点 vk 作为中转点，再检查所有顶点对 i、j，比较直接到达和经过 vk 哪个更短。k 等于 0 时还没有允许中转，0 到 2 只能直连，A[0][2] 是 10；k 等于 1 时可以经过顶点 1，A[0][2] 更新为 5 加 3 等于 8，右侧矩阵的红框标出了这个位置。

【停顿】k 为什么**必须**在最外层？因为更新式里读的 A[i][k] 和 A[k][j]，必须是"只允许前 k-1 个顶点做中转"已经算完的结果。k 放内层，会读到本轮还没算完的值，等于允许 vk 中转它自己，结果直接错。这是学生最容易写错的一处，写 Floyd 先写 k 循环再写里面两层。

两个收尾。实际写要判 A[i][k] 和 A[k][j] 都小于 INF 再相加，0x3f3f3f3f 这个数的设计就是让 INF 加 INF 不溢出成负数，但判一下更稳。手算怎么画 n 张矩阵、每轮 k 怎么填表，是专业课的必练项，考场上按那个要求做，这里只记骨架和 k 在最外层这条纪律。时间 O(n³)。

## P12 多源 BFS：题目翻译与核心思想（约2分钟）

这一块是本节大头，2023 年第 2 题的解法。题目形态：n×m 的 01 位图，1 是白像素，求每个像素到最近白像素的曼哈顿距离。注意题目里没有出现"图"字，但你把每个像素当一个顶点、上下左右相邻当一条边，它就是一张网格图，这是把真题翻译成图论问题的第一步。

朴素想法：对每个黑像素各做一次 BFS，求它到最近白像素的距离。n×m 个像素各做一遍，复杂度 n²m²，考场上必然超时。反过来想：不要从每个黑像素出发找白像素，让所有白像素同时出发往外扩散，每个像素第一次被访问到的层号，就是它到最近白像素的距离。只扫一遍，O(nm)。

【停顿】为什么第一次访问到的距离就是最短？BFS 逐层扩散，源点这一层是 0，它的邻居是 1，再往外一层加 1。队列保证了层数小的先出队，一个黑像素第一次被访问时，得到的就是它到最近源点的距离。这来自 BFS 按层扩展的性质。

## P13 多源 BFS 骨架代码（约2分钟）

看代码骨架。与普通 BFS **只差一处**：初始化的时候，把所有白像素的 dist 置 0、全部先入队，其余像素 dist 置 -1 表示没访问过。后面的 while 循环和普通 BFS 一模一样：出队一个坐标，看上下左右四个邻居，没访问过的 dist 置当前值加 1、入队。

三个细节都是得分点。第一，队列里存的是一维编号 `i * m + j`，因为顺序队列只存一个 int，取出来用除和模还原成二维坐标。第二，dist 等于 -1 同时充当 visited，省一个数组，忘了置 -1 会重复入队。第三，四个方向写成一个方向数组 dir，四段 if 合成一段循环，代码短一半。

时间 O(nm)，每个像素入队出队各一次——这正是题目"时间复杂度尽可能低"要的答案。下一页看扩散过程。

## P14 逐层扩散动画（约4分钟）

【PPT动画·4击】①第0层源点入队 ②第1层6个邻居dist=1 ③第2层3个像素dist=2 ④队列空扩散停。每击停两三秒，学员拿纸跟着填格子。

这一页拿纸跟着画。3×4 的位图，白像素在 (0,1) 和 (2,2)。先在纸上把每个像素到最近白像素的曼哈顿距离手算一遍，写在格子里，等下和动画对答案。

第 0 层（第①击）：两个源点 dist 置 0 同时入队，队列里是 (0,1) 和 (2,2) 两个坐标。注意"同时"两个字就是多源的全部秘密——两个源点在同一起跑线。

第 1 层（第②击）：出队 (0,1)，它的上下左右里，上越界，下是 (1,1)，左右是 (0,0) 和 (0,2)，三个像素 dist 置 1 入队。出队 (2,2)，下越界，上是 (1,2)，左右是 (2,1) 和 (2,3)，也置 1 入队。这一层一共 6 个新像素。记住每个像素只入队一次：后面再遇到已访问的像素，dist 为 -1 才入队这个判断会把它拦住，这就是 visited 的用法。

第 2 层（第③击）：继续出队。(0,0) 的下 (1,0) 置 2；(0,2) 的右 (0,3) 置 2，它的下 (1,2) 已经访问过；(2,3) 的上 (1,3) 置 2。剩下出队的像素四邻居全访问过了，没有新像素入队，队列出空，扩散停（第④击）。

对照手算结果，动画得到的距离矩阵分别是 1、0、1、2；2、1、1、2；2、1、0、1，与各像素的曼哈顿距离一致。BFS 按距离逐层扩展，因此像素第一次被访问时得到的距离就是最近距离。

## P15 关键路径：认识四个量（约2分钟）

关键路径用于分析 AOE 网上的活动时间。802 主要考手算，这一页只认识 ve、vl、e、l 的含义和推导方向，不练代码。

ve(j) 是事件 j 的最早发生时间，沿拓扑序正推，取前驱加活动时长的最大值。vl(j) 是最迟发生时间，逆拓扑序反推，取后继减活动时长的最小值。e(i) 等于活动起点的 ve；l(i) 等于活动终点的 vl 减活动时长。e(i)=l(i) 的活动是关键活动，关键活动组成关键路径。

手算填表留到专业课，题集 7答10 是对应练习。

## P16 模板卡（约1分钟）

这一节一张模板卡：模板 8，BFS 分层与多源 BFS。适用场景：单源分层统计、求到最近源点的距离、01 位图扩散这一类"逐层往外数"的题。骨架就两句：源点入队 dist 置 0；出队一层，邻居 dist 加 1 再入队。多源写法只改第一步，所有源点 dist 置 0 全部入队，之后和普通 BFS 完全一样。复杂度 O(nm) 或 O(n+e)。

求到最近源点的距离时，可以考虑多源 BFS，初始化时把所有源点同时入队。相关题型包括 2023 年第 2 题的多源 BFS、题集 7选25 的生成树权值计算，以及 Dijkstra 和 Floyd 的最短路手算。本节重点是算法的状态变化和代码结构。

跟练题一：Prim 主循环默写。初始化必须写循环，不能写 `dist[] = {INF}`（只有第一个元素是 INF）；每轮三拍：选树外 dist 最小的 u、`include[u] = true`、沿 u 的边表用边权刷新 dist 与 parent。

```c
void Prim(ALGraph &G){
    bool include[MaxVertexNum];
    int dist[MaxVertexNum], parent[MaxVertexNum];
    for(int i = 0; i < G.vexnum; i++){ include[i] = false; dist[i] = INF; parent[i] = -1; }
    dist[0] = 0;
    for(int k = 0; k < G.vexnum; k++){
        int u = -1, minDist = INF;
        for(int i = 0; i < G.vexnum; i++)
            if(!include[i] && dist[i] < minDist){ minDist = dist[i]; u = i; }
        if(u == -1) break;
        include[u] = true;
        for(ArcNode *p = G.vertices[u].firstarc; p != NULL; p = p->nextarc){
            int v = p->adjvex, w = p->weight;
            if(!include[v] && w < dist[v]){ dist[v] = w; parent[v] = u; }
        }
    }
}
```

## 附录二：本节代码合集

Prim 与 `知识笔记/代码总结.md` 图·经典算法段一致（weight 字段已按勘误 A3 在基础阶段放出）；Kruskal、Dijkstra、Floyd 用缺口9补写版；多源 BFS 用缺口13补写版。

```c
const int INF = 0x3f3f3f3f;

// ---------- Prim：前提 ArcNode 带 weight 字段（数据结构基础阶段第9节已放出）----------
void Prim(ALGraph &G){
    bool include[MaxVertexNum];
    int dist[MaxVertexNum], parent[MaxVertexNum];
    // 不能写 int dist[] = {INF}：只有第一个元素是 INF，其余为 0；数组初始化列表只有等于0一种简写，非0初值写循环
    for(int i = 0; i < G.vexnum; i++){ include[i] = false; dist[i] = INF; parent[i] = -1; }
    dist[0] = 0;                                // 从顶点 0 开始长
    for(int k = 0; k < G.vexnum; k++){
        int u = -1, minDist = INF;
        for(int i = 0; i < G.vexnum; i++)
            if(!include[i] && dist[i] < minDist){ minDist = dist[i]; u = i; }
        if(u == -1) break;                       // 图不连通
        include[u] = true;                       // u 进入生成树
        for(ArcNode *p = G.vertices[u].firstarc; p != NULL; p = p->nextarc){
            int v = p->adjvex, w = p->weight;
            if(!include[v] && w < dist[v]){ dist[v] = w; parent[v] = u; }
        }
    }
}

// ---------- 并查集（数据结构基础阶段第9节的问题在此兑现）----------
int Find(int parent[], int x){
    while(parent[x] != x) x = parent[x];        // 沿父结点往上找到根
    return x;
}
void Union(int parent[], int a, int b){
    int ra = Find(parent, a), rb = Find(parent, b);
    if(ra != rb) parent[ra] = rb;               // 一棵树的根接到另一棵的根下
}

// ---------- Kruskal：E 已按 w 升序 ----------
typedef struct{ int u, v, w; }Edge;             // 一条边：两端点与权值

void Kruskal(ALGraph G, Edge E[], int m, int vexnum){
    int parent[MaxVertexNum];
    for(int i = 0; i < vexnum; i++) parent[i] = i;   // 每个顶点自成一棵树
    int cnt = 0;
    for(int i = 0; i < m && cnt < vexnum - 1; i++){
        int a = Find(parent, E[i].u), b = Find(parent, E[i].v);
        if(a != b){                                  // 不在同一棵树，加入不成环
            parent[a] = b;
            cnt++;
        }
    }
}

// ---------- Dijkstra：单源最短路径，邻接矩阵 ----------
void Dijkstra(MGraph G, int v0, int dist[], int path[], bool S[]){
    for(int i = 0; i < G.vexnum; i++){
        dist[i] = G.edge[v0][i];                     // 初始：v0 直接可达的距离
        S[i] = false;
        path[i] = (G.edge[v0][i] < INF) ? v0 : -1;
    }
    dist[v0] = 0; S[v0] = true;
    for(int k = 1; k < G.vexnum; k++){
        int u = -1, minDist = INF;
        for(int i = 0; i < G.vexnum; i++)
            if(!S[i] && dist[i] < minDist){ minDist = dist[i]; u = i; }
        if(u == -1) break;                           // 剩下的都不可达
        S[u] = true;                                 // u 的最短距离已确定
        for(int i = 0; i < G.vexnum; i++)            // 用 u 松弛其余顶点
            if(!S[i] && G.edge[u][i] < INF && dist[u] + G.edge[u][i] < dist[i]){
                dist[i] = dist[u] + G.edge[u][i];
                path[i] = u;
            }
    }
}

// ---------- Floyd：各顶点对最短路径，邻接矩阵 ----------
void Floyd(MGraph G, int A[][MaxVertexNum]){
    for(int i = 0; i < G.vexnum; i++)
        for(int j = 0; j < G.vexnum; j++) A[i][j] = G.edge[i][j];   // 初始化

    for(int k = 0; k < G.vexnum; k++)              // k 必须在最外层
        for(int i = 0; i < G.vexnum; i++)
            for(int j = 0; j < G.vexnum; j++)
                if(A[i][k] + A[k][j] < A[i][j]) A[i][j] = A[i][k] + A[k][j];
}

// ---------- 多源 BFS：像素距离图 ----------
int dir[4][2] = {{-1,0},{1,0},{0,-1},{0,1}};      // 上下左右

void PixelDist(int g[][MaxM], int dist[][MaxM], int n, int m){
    SqQueue Q; InitQueue(Q);
    // 第一步：所有白像素先全部入队、dist 置 0；其余置 -1 表示未访问
    for(int i = 0; i < n; i++)
        for(int j = 0; j < m; j++){
            if(g[i][j] == 1){ dist[i][j] = 0; EnQueue(Q, i * m + j); }
            else dist[i][j] = -1;
        }
    // 第二步：普通 BFS 逐层扩散，每扩一层距离加 1
    while(!IsEmpty(Q)){
        int cur; DeQueue(Q, cur);
        int x = cur / m, y = cur % m;              // 一维编号还原为二维坐标
        for(int d = 0; d < 4; d++){
            int nx = x + dir[d][0], ny = y + dir[d][1];
            if(nx < 0 || nx >= n || ny < 0 || ny >= m) continue;    // 越界
            if(dist[nx][ny] == -1){                                  // 未访问，dist 兼作 visited
                dist[nx][ny] = dist[x][y] + 1;
                EnQueue(Q, nx * m + ny);
            }
        }
    }
}
// 时间 O(nm)：每个像素入队出队各一次；空间 O(nm)：队列最坏存一层
```
