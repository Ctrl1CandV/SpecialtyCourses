## P2 引题：重新安排链表结点的连接（约2分钟）

先看这节课要处理的几类链表问题。

归并算法的实操是把两条递增链表合成一条递减链表；重排是把 a1 到 an 调整为 a1、an、a2、an-1 的次序；约瑟夫环用循环链表模拟报数和删除；多项式分解则按指数奇偶把结点分到两条链里，复用原有的数据结点。

这些题都要修改结点之间的连接。看推演时可以在纸上标出修改前后的结点顺序，再逐步核对 next 指向哪里；这样更容易发现断链、漏结点或接错位置。

重排题会用到找中点和逆置，再加上交替插入。讲解时我们会把这三步分开看，再检查它们怎样接成完整算法。

## P3 归并两个递增表为递减表（约5分钟）

先看两条递增链表怎样合并成一条递减链表。这里会用到头插法。

pa、pb 分别指向两条链表的当前结点。每次摘下数据较小的结点，插到结果链表的表头。结点取出的顺序是递增的，头插会把这个顺序反过来，因此结果是递减的；不必先得到递增表再整体逆置。

看 Union 代码。开头检查 la 和 lb 是否为空；任意一个为空都不能继续访问它的 next，所以条件要用 ||。接着 pa、pb 分别指向两条链表的首个数据结点，并把 la 的 next 置空，让 la 的头结点作为结果表的头。主循环比较 pa、pb，摘下较小结点并头插，随后移动对应指针。一条链表走完后，另一条可能还有剩余结点，下面两个循环会把它们也逐个头插。最后释放 lb 的头结点；lb 中的数据结点已经转接到 la。

容易错的地方有三处。判空若写成 &&，只有两条链都为空才会返回；其中一条为空时，后面仍可能访问空指针。主循环结束后还要处理另一条链表的剩余部分，否则会漏结点。最后，释放的是 lb 的头结点，不能释放已经转接到 la 的数据结点。

每个数据结点只摘取和插入一次，时间复杂度是 O(n)；没有新建数据结点，额外空间是 O(1)。

【停顿】可以问学生：为什么不先合并成递增链表，再整体逆置？因为每次头插已经改变了结点顺序，合并结束时结果就是递减的，少做一遍整体逆置。

## P4 递增版与递减版对比（约3分钟）

屏幕上这张表就两行：递增版尾插、要维护 rear、结果从小到大；递减版头插、不要 rear、结果从大到小。

两版的差别**只改一处**：主循环里插入那两句。尾插要一个 rear 指针永远指着结果表的尾，每摘一个结点接到 rear 后面、rear 后移；头插永远插在头结点之后，不需要 rear，指针更少。其余全部一样：双指针比较、判空用 ||、两个收尾循环、free(lb)。

两个提醒。第一，易错点：题目要递减，你顺手写成尾插，结果会与题目要求相反。读到“递减”时，要检查代码采用的是头插还是尾插。第二，相等怎么办：pa 的数据小于等于 pb 时摘 pa，稳定的写法，谁前谁后不影响正确性。

【停顿】再追一句上一页的判空：为什么用 ||？因为任一为空就不能解引用，&& 拦不住"一个空一个不空"的情况。让学生先说明：任一链表为空时，程序就不能继续访问其 next。

## P6 重排第一步：快慢指针找中点（约5分钟）

进入第二道题：把 L 等于 a1 到 an 重排成 a1、an、a2、an-1 这样交替的次序，要求空间 O(1)。这是一道统考真题的题型，整个解法三步，每一步都点明用哪个模板，这是本题最重要的学法。

第一步，快慢指针找中点，用上一节的模板2。看代码：slow 和 fast 都从第一个数据结点出发，循环里 fast 走两步、slow 走一步。终止条件是 fast 的 next 为空，或者 fast 的 next 的 next 为空：fast 每走两步就越接近尾，一旦再往前走会越界，就停；这时 slow 正好走到一半。

【停顿】关键结论记牢：**偶数个结点时 slow 停在前半段的最后一个**，奇数个结点时停在中点。为什么终止条件不写 fast 不等于 NULL 就停？先写下你的理由。提示：看六个结点的情况，若只判断 fast 是否为空，slow 可能停到后半段，分段后两边长度不合适，交替连接时会留下结点。

slow 的 next 就是后半段的头，第二步从它开始。

## P7 重排第二三步：逆置与交替插入（约4分钟）

先断开前后两段，再把后半段原地逆置。令 second 指向后半段首结点，rev 置空；每轮先保存 temp=second->next，再把 second 头插到 rev 前面，最后令 second=temp。六个结点时，a4→a5→a6 变为 a6→a5→a4。
接着交替插入。first 指向 a1；每轮先保存 first、second 各自的后继 temp1、temp2，再把 second 接到 first 后，最后让 first=temp1、second=temp2。
【停顿】为什么要先保存两个后继？任一 next 被覆盖后，后面的结点就无法沿旧指针找到。按顺序修改，结果才会接成 a1→a6→a2→a5→a3→a4。三步各扫描常数次，时间 O(n)，额外空间 O(1)。

## P8 过程页：六个结点重排（约3分钟）

【PPT动画·4击】
初始链 a1 到 a6。第1击看快慢指针：fast 越界时 slow 停在 a3，在 a3 后断开。
第2击将 a4→a5→a6 逆置为 a6→a5→a4。此时前后半段都完整，方向也已调整。
第3击把 a6 插到 a1 后面，first 前进到 a2，second 前进到 a5。
第4击依次接入 a5、a4，得到 a1→a6→a2→a5→a3→a4。每次改 next 前先保存下一步还要访问的结点。

## P9 约瑟夫环（约5分钟）

第三个算法，约瑟夫环，模板11循环链表模拟。题型：n 个人围成一圈编号 1 到 n，从第 s 个人开始报数，报到 m 的人出列，下一个人重新从 1 报，直到只剩一个人。这两年刚考过，是循环链表的标准考法。

看代码 Josephus，分三段。第一段建环：head 直接存 1 号，r 指着它；循环里依次 malloc 2 到 n 号，用尾插接到 r 后面；最后 r 的 next 指向 head，成环。第二段定位：p 从 head 出发，没到第 s 个就 p 和 pre 一起后移，pre 的初值是 r，也就是尾结点。第三段报数：只要 p 的 next 不等于 p，就报数循环走 m 减 1 次，pre 跟着 p 走；数到 m 的 p 出列，pre 的 next 跨过 p 接好，free 掉 p，p 从 pre 的 next 重新取。

【停顿】这里有一个刻意的对照，屏幕上代码注释也标了：**不带头结点**。数据结构基础阶段第3节默认带头结点，这一题题目没要求头结点，就直接拿第一个数据结点当起点，head 存的就是 1 号。考场上按题面来：题面说带头结点你才建头结点，没说就不建。四个要点各记一句：成环靠 r 的 next 指向 head；定位第 s 个必须维护 pre，摘结点要知道前驱；报数循环是 m 减 1 次，因为自己算第 1 个；只剩一个的判定是 p 的 next 等于 p，自己指向自己，环里没有 NULL 可用。

复杂度：出列 n 减 1 轮，每轮报数走 m 步，时间 O(nm)；n 个结点同时在环里，空间 O(n)。

## P10 过程页：约瑟夫环报数（约4分钟）

【PPT动画·4击】
示例 n=5、s=1、m=3，循环链表不带头结点。先接成环，p 指向1，pre 指向前驱5。
第1击从1开始数到3，删除3，pre仍为2，p改指4。第2击数4、5、1，删除1，下一轮从2开始。
第3击数2、4、5，删除5；pre停在4，p回到2。第4击删除2，环里只剩4，返回4。
每次删除都由 pre->next 越过 p；pre 要保持在 p 前面。合法输入需满足 n≥1、1≤s≤n、m≥1。

## P11 稀疏多项式奇偶分解（约4分钟）

第四个算法：循环链表表示的稀疏多项式，按指数的奇偶拆成两个链，各自只含奇次项或偶次项，并且利用原链表中的结点空间，数据结点不许新malloc。这也是这两年考过的题型。

看代码 SplitPoly。开头 malloc 两个新头结点 odd 和 even，各自指向自己，自成环。然后 p 从 L 的 next 开始扫，终止条件是 p 不等于 L：循环链表回到头结点就停，这里没有 NULL。循环体四行：先存后继 temp，再按指数奇偶把 p 头插进 even 或 odd，最后 p 走到 temp。

【停顿】为什么必须先存后继？头插那两句会改掉 p 的 next，**先存后继** temp，改完之后才找得到下一个待处理的结点。归并和逆置也用到这一步；改写 next 前先保存后继，就能继续访问剩余结点。

四个要点。第一，利用原结点空间：数据结点全部从原链上摘下重接，只新建两个头结点；若新建数据结点，就不符合题目复用原结点的要求。第二，两个新链都用头插，挂进去的顺序和原链相反；题目要求保持原顺序就换尾插，各维护一个 rear，两种都给分，答题时说明一句。第三，指数可用对 2 取余判断奇偶；按题目给定的指数范围处理即可。第四，扫完 free 掉原头结点 L，它已经没用了。

复杂度：每个结点只处理一次，时间 O(n)；只新建两个头结点，空间 O(1)。

## P12 指针次序专题：先接外部，再改自身（约3分钟）

这一页对照三种改链操作：双链表插入、双链表删除、交换相邻结点。先看插入：新结点的 prior/next 接好后，再改前后结点的指针。删除时，让前驱跨过被删结点，再释放结点。

跟练题一：归并两个递增表为递减表。

```c
bool Union(LinkList &la, LinkList lb){
    if(la == NULL || lb == NULL) return false;    // 判空用 ||：任一为空就不能解引用
    LNode *pa = la->next, *pb = lb->next;
    la->next = NULL;                              // 以 la 的头结点作新表
    while(pa != NULL && pb != NULL){
        LNode *temp;
        if(pa->data <= pb->data){ temp = pa; pa = pa->next; }
        else{ temp = pb; pb = pb->next; }
        temp->next = la->next; la->next = temp;   // 头插：自然反序
    }
    while(pa != NULL){ LNode *t = pa; pa = pa->next; t->next = la->next; la->next = t; }
    while(pb != NULL){ LNode *t = pb; pb = pb->next; t->next = la->next; la->next = t; }
    free(lb);                                     // lb 的头结点已无用
    return true;
}
// 时间 O(n)：每个结点摘一次插一次；空间 O(1)：没有新开数据结点
```

跟练题二：约瑟夫环。

```c
int Josephus(int n, int s, int m){
    // 不带头结点：head 直接存 1 号，与基础阶段默认带头结点形成对照
    LNode *head = (LNode*)malloc(sizeof(LNode));
    head->data = 1;  LNode *r = head;
    for(int i = 2; i <= n; i++){
        LNode *p = (LNode*)malloc(sizeof(LNode));
        p->data = i;  r->next = p;  r = p;
    }
    r->next = head;                               // 成环
    LNode *p = head, *pre = r;                    // 定位第 s 个，pre 同步维护
    while(p->data != s){ pre = p; p = p->next; }
    while(p->next != p){                          // 自己指自己＝只剩一个
        for(int i = 1; i < m; i++){ pre = p; p = p->next; }
        pre->next = p->next;  free(p);            // 摘结点
        p = pre->next;
    }
    return p->data;
}
// 时间 O(nm)：出列 n-1 轮、每轮报数 m 步；空间 O(n)
```

题集练习 2算27：求两个单链表的交集，并且利用 A 的空间。骨架照归并改：pa、pb 双指针比较，相等的结点摘下接到 A 的头结点之后（头插或尾插皆可，说明一句），不相等时数据小的指针后移。全程不新malloc数据结点。

```c
void Intersect(LinkList &la, LinkList lb){        // 利用 A 的空间存交集
    if(la == NULL || lb == NULL) return;
    LNode *pa = la->next, *pb = lb->next;
    la->next = NULL;                              // 以 la 的头结点作结果表
    while(pa != NULL && pb != NULL){
        if(pa->data < pb->data){ pa = pa->next; }
        else if(pb->data < pa->data){ pb = pb->next; }
        else{ LNode *t = pa; pa = pa->next;       // 相等：摘下 pa 头插进结果表
              t->next = la->next; la->next = t; pb = pb->next; }
    }
}
// 时间 O(n)；空间 O(1)：结果结点全部来自 A
```

// 归并两个递增表为递减表（模板1：头插自然反序）
bool Union(LinkList &la, LinkList lb){
    if(la == NULL || lb == NULL) return false;
    LNode *pa = la->next, *pb = lb->next;
    la->next = NULL;
    while(pa != NULL && pb != NULL){
        LNode *temp;
        if(pa->data <= pb->data){ temp = pa; pa = pa->next; }
        else{ temp = pb; pb = pb->next; }
        temp->next = la->next; la->next = temp;
    }
    while(pa != NULL){ LNode *t = pa; pa = pa->next; t->next = la->next; la->next = t; }
    while(pb != NULL){ LNode *t = pb; pb = pb->next; t->next = la->next; la->next = t; }
    free(lb);
    return true;
}

// 重排 a1..an 为 a1,an,a2,an-1,...（修正版：找中点 + 头插逆置后半 + 交替插入）
void Reorder(NODE *head){
    if(head == NULL || head->next == NULL || head->next->next == NULL) return;
    // 第一步：模板2 快慢指针找中点
    NODE *slow = head->next, *fast = head->next;
    while(fast->next != NULL && fast->next->next != NULL){
        slow = slow->next; fast = fast->next->next;
    }
    // 第二步：模板1 断开并头插逆置后半段
    NODE *second = slow->next, *rev = NULL;
    slow->next = NULL;
    while(second != NULL){
        NODE *temp = second->next;        // 先存后继
        second->next = rev; rev = second; // 头插到 rev 前
        second = temp;
    }
    second = rev;                         // second 指向逆置后的头
    // 第三步：交替插入（新动作）
    NODE *first = head->next;
    while(second != NULL){
        NODE *temp1 = first->next, *temp2 = second->next;   // 先存两个 next
        second->next = temp1; first->next = second;
        first = temp1; second = temp2;
    }
}

// 约瑟夫环（模板11：循环单链表模拟，不带头结点）
int Josephus(int n, int s, int m){
    LNode *head = (LNode*)malloc(sizeof(LNode));
    head->data = 1;  LNode *r = head;
    for(int i = 2; i <= n; i++){
        LNode *p = (LNode*)malloc(sizeof(LNode));
        p->data = i;  r->next = p;  r = p;
    }
    r->next = head;
    LNode *p = head, *pre = r;
    while(p->data != s){ pre = p; p = p->next; }
    while(p->next != p){
        for(int i = 1; i < m; i++){ pre = p; p = p->next; }
        pre->next = p->next;  free(p);
        p = pre->next;
    }
    return p->data;
}

// 稀疏多项式奇偶分解（缺口14补写版：利用原结点空间）
void SplitPoly(PolyNode *L, PolyNode *&odd, PolyNode *&even){
    odd  = (PolyNode*)malloc(sizeof(PolyNode));  odd->next  = odd;
    even = (PolyNode*)malloc(sizeof(PolyNode));  even->next = even;
    PolyNode *p = L->next, *temp;
    while(p != L){
        temp = p->next;                          // 先存后继
        if(p->exp % 2 == 0){ p->next = even->next; even->next = p; }
        else{ p->next = odd->next; odd->next = p; }
        p = temp;
    }
    free(L);
}

## 附录三：勘误位

本节登记 1 处材料修正：408统考2019 重排（Reorder）。

材料原文（`知识笔记/代码总结.md` 链表·经典算法段）两处缺陷：

1. 快慢指针终止条件"fast 不等于 NULL 且 fast 的 next 不等于 NULL"：偶数个结点时 slow 停在后半段的第一个结点，断出的前半段多一个结点，第三步交替接不齐。
2. 第二步以 second 为锚做头插，但没有先把 second 的 next 置空，且 p 从 second 的 next 起跳、漏掉后半段首元；按 n 等于 6 逐行推演出现自环、丢结点、第三步解引用空指针。

修正版（课件 P6、P7 与附录二已采用）：终止条件改为"fast 的 next 与 fast 的 next 的 next 均不为空"，偶数个结点时 slow 停在前半段最后一个；逆置改为以 rev 当头、含后半段首元在内的完整头插循环，与模板1原地逆置同一循环体。待统筹方复核后回写缺口代码与勘误文档。
