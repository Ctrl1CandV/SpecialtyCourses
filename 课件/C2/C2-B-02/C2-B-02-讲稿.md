## P2 引题：改链的结构（约2分钟）

屏幕上这一节四个算法，先建立整体印象。

归并成递减表：给你两条递增的链，拆成一条递减的链，指针全部重接。重排：把 a1 到 an 改成 a1、an、a2、an-1 交替的次序，先断成两半、后半逆置、再交替拼接。约瑟夫环：n 个人围成圈报数，报到 m 出列，单链表首尾接成环来模拟。多项式分解：一个循环链表表示的稀疏多项式，按指数的奇偶拆成两个链，数据结点一个不许新malloc。

共同点一句话：**改链的结构**。上一节的算法是顺着链走、边走边改个别指针；这一节是把链拆开、重接、接环，动的不是一两个指针，是整条链的形状。所以推演页更多，每一页都拿纸跟着画，画不出来就是没懂。

## P3 归并两个递增表为递减表（约4分钟）

第一个算法：归并两个递增表为递减表，模板1头插法的第二个用途。

思想一句话：pa、pb 两个指针各扫一条表，每次摘较小的那个结点；要递减，就头插——头插天然反序，**不需要先归并再逆置**。这是这一类题的通用套路，记住它。

看代码 Union，从头到尾过一遍。第一句判空：la 为空或者 lb 为空就返回 false，这里必须用 ||。然后 pa、pb 指向各自的第一个数据结点，la 的 next 置空，拿 la 的头结点当新表的头。主循环：比较 pa 和 pb 的数据，谁小摘谁，摘完那个指针后移；摘下来的结点两句头插进 la。一个表走空后主循环停，另一个表还剩一段，由下面两个收尾循环继续头插。最后 free(lb)：lb 的头结点已经没用了，它的数据结点早被一个个摘走。

三个细节各说一遍。第一，判空用 || 不用 &&：写成 &&，只有当两个都为空才返回，la 为空、lb 不空时会接着往下走，下一步解引用 la 的 next，空指针，直接崩。第二，收尾循环不能省：pa 还有结点就先把 pa 的摘完，pb 同理，漏一个就丢数据。第三，free 的是 lb 的头结点，不是整条 lb。

复杂度：每个结点摘一次、插一次，时间 O(n)；没有新开数据结点，空间 O(1)。

【停顿】设问一句：要递减的结果，为什么不先归并成递增、再整条逆置？头插每摘一个就反一个，摘完全部自然就是递减；先归并再逆置多写一次逆置、多走一趟，考场上没必要。

## P4 递增版与递减版对比（约3分钟）

屏幕上这张表就两行：递增版尾插、要维护 rear、结果从小到大；递减版头插、不要 rear、结果从大到小。

两版的差别**只改一处**：主循环里插入那两句。尾插要一个 rear 指针永远指着结果表的尾，每摘一个结点接到 rear 后面、rear 后移；头插永远插在头结点之后，不需要 rear，指针更少。其余全部一样：双指针比较、判空用 ||、两个收尾循环、free(lb)。

两个提醒。第一，易错点：题目要递减，你顺手写成尾插，做出来的是递增表，白做。看到"递减"两个字，先想头插。第二，相等怎么办：pa 的数据小于等于 pb 时摘 pa，稳定的写法，谁前谁后不影响正确性。

【停顿】再追一句上一页的判空：为什么用 ||？因为任一为空就不能解引用，&& 拦不住"一个空一个不空"的情况。这个判断两秒内要给出来。

## P5 过程页：归并动画（约4分钟）

这一页拿纸跟着画，PPT逐步放。屏幕上初始两条链：la 存 1、3、5，lb 存 2、4、6，la 的头结点之后已经置空，当作新表。

第1次比较，1 对 2：摘 1，头插，la 指向 1；pa 移到 3。第2次比较，3 对 2：摘 2，头插，la 指向 2 指向 1；pb 移到 4。第3次比较，3 对 4：摘 3，la 前成 3、2、1；pa 移到 5。第4次比较，5 对 4：摘 4，la 前成 4、3、2、1；pb 移到 6。

第5次比较，5 对 6：摘 5，la 前成 5、4、3、2、1；pa 走空，主循环停，pb 还剩 6，进收尾循环。摘 6 头插：la 指向 6 指向 5 指向 4 指向 3 指向 2 指向 1。归并完成，free(lb)。

【停顿】回头看：每摘一个就头插一次，新结点总在所有已插结点的前面，所以结果天然递减。对照三条规矩：摘之前 pa、pb 已经后移到位，先存后继再头插，是先接后断；画到最后，6 到 1 每个结点都有人指着，没有孤立结点。

## P6 重排第一步：快慢指针找中点（约4分钟）

进入第二道题：把 L 等于 a1 到 an 重排成 a1、an、a2、an-1 这样交替的次序，要求空间 O(1)。这是一道统考真题的题型，整个解法三步，每一步都点明用哪个模板，这是本题最重要的学法。

第一步，快慢指针找中点，用上一节的模板2。看代码：slow 和 fast 都从第一个数据结点出发，循环里 fast 走两步、slow 走一步。终止条件是 fast 的 next 为空，或者 fast 的 next 的 next 为空：fast 每走两步就越接近尾，一旦再往前走会越界，就停；这时 slow 正好走到一半。

【停顿】关键结论记牢：**偶数个结点时 slow 停在前半段的最后一个**，奇数个结点时停在中点。为什么终止条件不写 fast 不等于 NULL 就停？先写下你的理由。提示：看六个结点的情况，那种停法 slow 会停进后半段，断出来的前半段多一个结点，第三步交替到后面会剩一个结点接不上，答案直接错。

slow 的 next 就是后半段的头，第二步从它开始。

## P7 重排第二三步：逆置与交替插入（约4分钟）

第二步，断开并逆置后半段，用模板1原地逆置。看代码：second 指向 slow 的 next，也就是后半段的头；rev 置空，当逆置后新链的头。slow 的 next 置空，前后两半断开。循环体就是上一节原地逆置那四行的核心：先存后继 temp，再把当前结点头插到 rev 前面，rev 前移。循环结束，second 指向 rev，就是逆置后的头。六个结点的话，a4、a5、a6 逆置成 a6 指向 a5 指向 a4。

第三步，交替插入，这是新动作，前面没学过。first 指向 a1。每轮循环：先存 first 的 next 和 second 的 next 两个指针，记成 temp1、temp2；然后把 second 当前结点插到 first 当前结点之后；最后 first 走到 temp1，second 走到 temp2，进入下一轮。

【停顿】次序为什么必须先存两个 next？因为 second 的 next 改成 temp1 之后，原来 second 后面是谁就找不回来了；first 的 next 改成 second 之后，first 后面是谁也丢了。**先存两个 next 再改指针**，一句都不能换。这是三条规矩里"先接后断"在交替插入里的样子。

复杂度：三步每步最多扫一遍表，时间 O(n)；只用了几个指针，空间 O(1)，满足题意。

## P8 过程页：重排动画（约5分钟）

这一页拿纸跟着画，三步各画一遍。六个结点 a1 到 a6。

第一步：slow 和 fast 从 a1 出发，fast 的 next 的 next 越界时停，slow 停在 a3。断点就在 a3：a3 的 next 置空，前半段是 a1、a2、a3，后半段从 a4 开始。

第二步：后半段 a4、a5、a6 头插逆置。先存后继再头插：a4 先摘，rev 指向 a4；a5 摘，rev 指向 a5 指向 a4；a6 摘，rev 指向 a6 指向 a5 指向 a4。逆置完，second 指向 a6。

第三步交替插入，三轮。第1轮：temp1 是 a2，temp2 是 a5；a6 的 next 改成 a2，a1 的 next 改成 a6；first 到 a2，second 到 a5。第2轮：temp1 是 a3，temp2 是 a4；a5 的 next 改成 a3，a2 的 next 改成 a5；first 到 a3，second 到 a4。第3轮：temp1 为空，temp2 为空；a4 的 next 改成空，a3 的 next 改成 a4；first 为空，second 为空，循环停。

【停顿】结果：a1 指向 a6 指向 a2 指向 a5 指向 a3 指向 a4。回到第一步那个问题：终止条件必须看 fast 的 next 的 next，偶数个结点时 slow 才停在前半段最后一个；停点错一格，第三步就接不齐。现在把你的理由和这帧结果对上。

## P9 约瑟夫环（约4分钟）

第三个算法，约瑟夫环，模板11循环链表模拟。题型：n 个人围成一圈编号 1 到 n，从第 s 个人开始报数，报到 m 的人出列，下一个人重新从 1 报，直到只剩一个人。这两年刚考过，是循环链表的标准考法。

看代码 Josephus，分三段。第一段建环：head 直接存 1 号，r 指着它；循环里依次 malloc 2 到 n 号，用尾插接到 r 后面；最后 r 的 next 指向 head，成环。第二段定位：p 从 head 出发，没到第 s 个就 p 和 pre 一起后移，pre 的初值是 r，也就是尾结点。第三段报数：只要 p 的 next 不等于 p，就报数循环走 m 减 1 次，pre 跟着 p 走；数到 m 的 p 出列，pre 的 next 跨过 p 接好，free 掉 p，p 从 pre 的 next 重新取。

【停顿】这里有一个刻意的对照，屏幕上代码注释也标了：**不带头结点**。数据结构基础阶段第3节默认带头结点，这一题题目没要求头结点，就直接拿第一个数据结点当起点，head 存的就是 1 号。考场上按题面来：题面说带头结点你才建头结点，没说就不建。四个要点各记一句：成环靠 r 的 next 指向 head；定位第 s 个必须维护 pre，摘结点要知道前驱；报数循环是 m 减 1 次，因为自己算第 1 个；只剩一个的判定是 p 的 next 等于 p，自己指向自己，环里没有 NULL 可用。

复杂度：出列 n 减 1 轮，每轮报数走 m 步，时间 O(nm)；n 个结点同时在环里，空间 O(n)。

## P10 过程页：约瑟夫环报数动画（约4分钟）

这一页拿纸跟着画，n 等于 5、s 等于 1、m 等于 3。屏幕上环：1 指向 2 指向 3 指向 4 指向 5 再指回 1，p 在 1，pre 在 5。

第1轮：报 1、2、3，3 出列。pre 跨过去：2 的 next 接到 4，free 掉 3，p 指 4。环剩 1、2、4、5。第2轮：从 4 接着报 4、5、1，1 出列。5 的 next 接到 2，free 掉 1，p 指 2。环剩 2、4、5。第3轮：报 2、4、5，5 出列。4 的 next 接到 2，free 掉 5，p 指 2。环剩 2、4。第4轮：报 2、4、2，2 出列。4 的 next 接到 4，free 掉 2，p 指 4。现在 4 的 next 等于 4，自己指自己，循环停，返回 4。

【停顿】四轮动作一模一样：报数 m 减 1 次、pre 跨过去、free、从 pre 后面继续。变的只有环越来越短。所以你画图时不用画四轮全图，画两轮，第三轮起口述就够。

## P11 稀疏多项式奇偶分解（约4分钟）

第四个算法：循环链表表示的稀疏多项式，按指数的奇偶拆成两个链，各自只含奇次项或偶次项，并且利用原链表中的结点空间，数据结点不许新malloc。这也是这两年考过的题型。

看代码 SplitPoly。开头 malloc 两个新头结点 odd 和 even，各自指向自己，自成环。然后 p 从 L 的 next 开始扫，终止条件是 p 不等于 L：循环链表回到头结点就停，这里没有 NULL。循环体四行：先存后继 temp，再按指数奇偶把 p 头插进 even 或 odd，最后 p 走到 temp。

【停顿】为什么必须先存后继？头插那两句会改掉 p 的 next，**先存后继** temp，改完之后才找得到下一个待处理的结点。这和逆置、归并里是同一个动作，第三次出现了，应该刻进手里。

四个要点。第一，利用原结点空间：数据结点全部从原链上摘下重接，只新建两个头结点；新malloc数据结点违反题意，要扣分。第二，两个新链都用头插，挂进去的顺序和原链相反；题目要求保持原顺序就换尾插，各维护一个 rear，两种都给分，答题时说明一句。第三，指数判奇偶用对 2 取余等于 0，指数是非负整数，负偶数取余也是 0，判断照样成立。第四，扫完 free 掉原头结点 L，它已经没用了。

复杂度：每个结点只处理一次，时间 O(n)；只新建两个头结点，空间 O(1)。

## P12 指针次序专题：先接外部，再改自身（约3分钟）

这一页不收新算法，收拢次序。屏幕上三张：双链表插入四条赋值、双链表删除三条赋值、上一节交换相邻两个结点六条赋值。

插入四条：先把新结点的 prior 和 next 接好，再改前后两个老结点的 next 和 prior。删除三条：先让前驱的 next 跨过被删结点，再收尾被删结点自己。交换相邻六条：前四条先把外部两端接好，⑤⑥两条互指必须最后，因为⑤一执行 p 的 prior 旧值就没了，⑥一执行 q 的 next 旧值就没了，前四句再也写不出来。

共同原则一句话：**先接外部、再改自身**。先用旧指针把外部接好，最后再改要插入或交换的结点自身的指针。一旦先改了自身，旧值被覆盖，外部那几句就没有原料可写。插入与删除在数据结构基础阶段第4节，交换相邻在上一节，这一页只做收拢，原则只有一句。

写完任何插删代码，按三条规矩自查：先接后断、画图再写、查孤立结点。

跟练题一：归并两个递增表为递减表。

```c
bool Union(LinkList &la, LinkList lb){
    if(la == NULL || lb == NULL) return false;    // 判空用 ||：任一为空就不能解引用
    LNode *pa = la->next, *pb = lb->next;
    la->next = NULL;                              // 以 la 的头结点作新表
    while(pa != NULL && pb != NULL){
        LNode *temp;
        if(pa->data <= pb->data){ temp = pa; pa = pa->next; }
        else{ temp = pb; pb = pb->next; }
        temp->next = la->next; la->next = temp;   // 头插：自然反序
    }
    while(pa != NULL){ LNode *t = pa; pa = pa->next; t->next = la->next; la->next = t; }
    while(pb != NULL){ LNode *t = pb; pb = pb->next; t->next = la->next; la->next = t; }
    free(lb);                                     // lb 的头结点已无用
    return true;
}
// 时间 O(n)：每个结点摘一次插一次；空间 O(1)：没有新开数据结点
```

跟练题二：约瑟夫环。

```c
int Josephus(int n, int s, int m){
    // 不带头结点：head 直接存 1 号，与基础阶段默认带头结点形成对照
    LNode *head = (LNode*)malloc(sizeof(LNode));
    head->data = 1;  LNode *r = head;
    for(int i = 2; i <= n; i++){
        LNode *p = (LNode*)malloc(sizeof(LNode));
        p->data = i;  r->next = p;  r = p;
    }
    r->next = head;                               // 成环
    LNode *p = head, *pre = r;                    // 定位第 s 个，pre 同步维护
    while(p->data != s){ pre = p; p = p->next; }
    while(p->next != p){                          // 自己指自己＝只剩一个
        for(int i = 1; i < m; i++){ pre = p; p = p->next; }
        pre->next = p->next;  free(p);            // 摘结点
        p = pre->next;
    }
    return p->data;
}
// 时间 O(nm)：出列 n-1 轮、每轮报数 m 步；空间 O(n)
```

```c
void Intersect(LinkList &la, LinkList lb){        // 利用 A 的空间存交集
    if(la == NULL || lb == NULL) return;
    LNode *pa = la->next, *pb = lb->next;
    la->next = NULL;                              // 以 la 的头结点作结果表
    while(pa != NULL && pb != NULL){
        if(pa->data < pb->data){ pa = pa->next; }
        else if(pb->data < pa->data){ pb = pb->next; }
        else{ LNode *t = pa; pa = pa->next;       // 相等：摘下 pa 头插进结果表
              t->next = la->next; la->next = t; pb = pb->next; }
    }
}
// 时间 O(n)；空间 O(1)：结果结点全部来自 A
```

// 重排 a1..an 为 a1,an,a2,an-1,...（修正版：找中点 + 头插逆置后半 + 交替插入）
void Reorder(NODE *head){
    if(head == NULL || head->next == NULL || head->next->next == NULL) return;
    // 第一步：模板2 快慢指针找中点
    NODE *slow = head->next, *fast = head->next;
    while(fast->next != NULL && fast->next->next != NULL){
        slow = slow->next; fast = fast->next->next;
    }
    // 第二步：模板1 断开并头插逆置后半段
    NODE *second = slow->next, *rev = NULL;
    slow->next = NULL;
    while(second != NULL){
        NODE *temp = second->next;        // 先存后继
        second->next = rev; rev = second; // 头插到 rev 前
        second = temp;
    }
    second = rev;                         // second 指向逆置后的头
    // 第三步：交替插入（新动作）
    NODE *first = head->next;
    while(second != NULL){
        NODE *temp1 = first->next, *temp2 = second->next;   // 先存两个 next
        second->next = temp1; first->next = second;
        first = temp1; second = temp2;
    }
}

// 约瑟夫环（模板11：循环单链表模拟，不带头结点）
int Josephus(int n, int s, int m){
    LNode *head = (LNode*)malloc(sizeof(LNode));
    head->data = 1;  LNode *r = head;
    for(int i = 2; i <= n; i++){
        LNode *p = (LNode*)malloc(sizeof(LNode));
        p->data = i;  r->next = p;  r = p;
    }
    r->next = head;
    LNode *p = head, *pre = r;
    while(p->data != s){ pre = p; p = p->next; }
    while(p->next != p){
        for(int i = 1; i < m; i++){ pre = p; p = p->next; }
        pre->next = p->next;  free(p);
        p = pre->next;
    }
    return p->data;
}

## 附录三：勘误位

本节登记 1 处材料修正：408统考2019 重排（Reorder）。

材料原文（`知识笔记/代码总结.md` 链表·经典算法段）两处缺陷：

1. 快慢指针终止条件"fast 不等于 NULL 且 fast 的 next 不等于 NULL"：偶数个结点时 slow 停在后半段的第一个结点，断出的前半段多一个结点，第三步交替接不齐。
2. 第二步以 second 为锚做头插，但没有先把 second 的 next 置空，且 p 从 second 的 next 起跳、漏掉后半段首元；按 n 等于 6 逐行推演出现自环、丢结点、第三步解引用空指针。

修正版（课件 P6、P7 与附录二已采用）：终止条件改为"fast 的 next 与 fast 的 next 的 next 均不为空"，偶数个结点时 slow 停在前半段最后一个；逆置改为以 rev 当头、含后半段首元在内的完整头插循环，与模板1原地逆置同一循环体。待统筹方复核后回写缺口代码与勘误文档。
