## P2 引题：数组的两个硬约束（约3分钟）

那么讲完了顺序表，我们先回头看它有什么不好的地方，这样你才知道链表为什么要存在。

顺序表底层实际上还是数组，那么数组有两个硬约束。第一个，元素必须存储在一段连续的内存里，一个挨着一个，中间不能断。第二个，大小在定义的时候就写死了，它永远不会改变，不仅内存利用率低，而且一旦出现溢出的情况，只能整个数组复制粘贴到另一块内存中，非常不便。

这两个约束会带来麻烦。数据本来只有10个，你怕不够开得很大，浪费；数据突然涨到200个，装不下了，你得重新申请一块更大的内存，再把原来100个全搬过去，很费事。还有，你在中间删掉一个元素，后面会留一个空洞，为了保持连续，你得把后面的元素全都往前挪，这就是上一节讲的移动次数。举个数：一个存了100个数的顺序表，在最前面插一个，后面100个全往后挪一格；删最前面那个，后面99个全往前挪。数据量一大，光挪元素的时间花销就很贵。

链表就是来绕开这两个约束的。它的思路是：结点不必挨着放，每个结点单独申请一块内存，散落在内存各处都行，然后每个结点里存一个指针，指向下一个结点在哪。这样一串指针就把散着的结点连成了一条链。用指针把分散的内存串起来，这个动作我们在C语言强化阶段练过，这一节把它变成一个正式的数据结构。

## P3 定义 LNode 与 LinkList（约2分钟）

先看单链表的定义。typedef struct LNode，里面两个成员：一个int data存数据，一个 struct LNode指针next存下一个结点的地址。最后给这个结构体起了两个名字，LNode 和 LinkList。

为什么要起两个名字？因为需要区分它们指向的是两样东西。LNode 指的是一个结点本身，就是那个装着 data 和 next 的结构体；LinkList 前面带了个星号，指的是指向结点的指针，一般也就是整条链表的头。你以后看到 LinkList L，就知道 L 是指向这条链的指针；看到 LNode 星号 p，就知道 p 指向链上的某个结点。

这里还有一个点，next 的类型是 struct LNode 指针，也就是指向它自己这种类型，这叫自引用。为什么能这么写？因为 next 是个指针，指针只占固定大小、存的是地址，不需要知道 LNode 内部到底多大，所以编译器认。这个在C语言强化阶段讲结构体的时候说过，这里直接用。你还要习惯一件事：链表里的结点是一个一个单独 malloc 出来的，散在内存各处，不像数组连成一片；把它们串起来的唯一纽带，就是每个结点里那个 next 指针。所以链表的一切操作，本质上都是在改这些 next 指针的指向。

## P4 头结点（约3分钟）

那么定义有了，接下来要讲操作，在这之前先说一个贯穿整节的约定，就是我们的链表默认带头结点。

什么叫头结点？就是在第一个存数据的结点前面再加一个结点，这个结点不存数据只是作为个标志，代表这个链表的头，且头指针 L 指向它。真正第一个存数据的结点，是 L->next，我们叫它首元结点。看屏幕上的初始化 InitList：先 malloc 一个结点给 L，判空，然后把 L->next 置成 NULL，这就是一个只有头结点的空表。

这里你可能会问，白白多一个不存数据的结点，图什么？头结点本身是为了解决边界问题，在实际使用中可能存在的两个麻烦。第一个，在首元结点前面插入、或者删除首元结点，本来是要单独处理的，因为它们的"前一个"不存在；有了头结点，首元结点的前一个就是头结点，永远存在，所以在第一个位置的插删和在中间位置的插删，代码完全一样，不用写两套。第二个，对于单元素链表的删除和空链表的插入这两种特殊的情况，有了头结点就不需要单独区分了。

我给你举个具体的。假设要删第一个数据结点：带头结点时，它的前驱就是头结点 L，一句 L->next = L->next->next 就把它删了，跟删中间任何结点的写法一模一样；要是不带头结点，删第一个就得单独改头指针 L 本身、让它指向第二个结点，这是另一套代码。头结点就是靠永远有一个前驱在那，把表头这个特殊情况抹平了。

所以记住，本课程链表默认带头结点。不带头结点的版本也存在，但它插入删除表头时要单独改头指针 L，麻烦也容易错，我们后面遇到再说。

## P5 初始化与头插法建表（约4分钟）

初始化刚才在头结点那页写过了，就是建一个只有头结点的空表。接下来看怎么用头插法建一个有数据的表。

头插法的意思是，每读入一个新元素，都把它放在首元结点，即插在头结点的后面，也就是插在最前面。看代码 CreateByHead：先建头结点、L->next 置 NULL 成空表；然后循环 n 次，每次 malloc 一个新结点 s，读一个数进 s->data，接着是关键两句——先 s->next = L->next，再 L->next = s。

这两句的次序绝对不能换，我们想清楚它在干什么。s->next = L->next，是让新结点 s 先指向当前链表的第一个数据结点；L->next = s，是让头结点转而指向 s，s 就成了新的第一个。如果反过来先写 L->next = s，那头结点原本指向的第一个结点就没人指了，地址丢了，整条后半截链就找不回来了。所以记牢：先接后面，再改前面。

这么插的结果是什么？因为每个新结点都插在头部，后读进来的排在前面，所以建出来的表是输入次序的逆序。顺带说一句，这个逆序不是缺点，后面强化阶段讲链表逆置，靠的正是头插法这个性质，到时候你会再见到它。这一点下一页画图你就看得很清楚。

## P7 尾插法建表与 rear 指针（约3分钟）

头插法建出来是逆序，可有时候我就想按输入的顺序建表，这就要用尾插法。尾插法是每个新结点都接在链表的最后面。

问题是，怎么快速找到最后一个元素？如果每次插入都从头结点开始，顺着 next 一个一个走到尾结点，再往后接，那插一个要走一趟，插 n 个就走 n 趟，总共是 O(n²)。你算一下，插第1个不用走、插第2个走1步找尾巴、插第3个走2步，一直到插第 n 个走 n-1 步，加起来是 1 加到 n-1，跟上一节顺序表那个求和是一回事，n² 级别。为了避免每趟都从头走，我们专门用一个指针 r 一直记着当前尾结点在哪，这样新结点直接接在 r 后面，再把 r 往后移一位就行，每次插入都是 O(1)，整体 O(n)。这就是 r 这个指针的价值。

看代码 CreateByTail：建头结点，r 先指向 L；循环里每次新建 s、读数，然后 r->next = s 把 s 接到尾巴上，再 r = s 让 r 指向新的尾巴。循环结束有一步千万不能忘：r->next = NULL。因为最后一个结点的 next 必须置空，表示链到此为止；malloc 出来的内存不清零，你不置 NULL，里面是脏数据。那什么时候用头插、什么时候用尾插？要保持输入顺序就用尾插，不在乎顺序、或者本来就想要逆序，用头插更省事，因为它不用维护 rear 指针。

## P8 GetElem 与 LocateElem（约3分钟）

那么建好表了，接下来是两个查找。链表的查找和顺序表不一样，顺序表能直接按下标访问 data[i]，链表不行，只能从头顺着 next 一个一个走。

第一个是 GetElem，按位序找，给你个 i，返回第 i 个结点的指针。看代码：p 从头结点 L 开始，j 从0开始，while 循环里只要 j 还没到 i 并且 p 不是 NULL，就 p = p->next、j 加一，走 i 步。注意这里 p 是从头结点 L 起的，所以 GetElem(L,0) 返回的是头结点，GetElem(L,i) 返回第 i 个数据结点。

第二个是 LocateElem，按值找，给你个 elem，返回第一个 data 等于它的结点。看代码：p 从 L->next 开始，也就是从第一个数据结点起，只要 p 不为空、并且 p->data 不等于 elem，就 p = p->next 往后走；找到就返回 p，走到头没找到就返回 NULL。

这两个函数你要对比着记，差别就在起点：GetElem 从头结点 L 起，因为要数到第 i 个；LocateElem 从 L->next 起，因为头结点不存数据、不用比。起点搞混是这里最常见的错。我们走一遍 GetElem(L,2)，找第2个数据结点。p 从头结点 L 起、j 从0起：第一轮 j=0 小于2，p 走到第一个数据结点，j 变1；第二轮 j=1 小于2，p 走到第二个数据结点，j 变2；这时 j=2 不再小于2，循环停，返回 p，正好是第2个数据结点。你可能要问，为什么 p 从头结点起、不是从第一个数据结点起？因为要多走一步抵消掉头结点，走 i 步正好落在第 i 个数据结点上，这就是 GetElem(L,i) 返回第 i 个的道理。LocateElem 也一样走一遍：找值为30的结点，p 从第一个数据结点起，逐个比 p->data，比到30就停下返回那个结点；要是走到 NULL 都没匹配上，就返回 NULL 表示没有。

## P9 ListInsert（约3分钟）

接下来是插入 ListInsert，在第 i 个位置插入一个新元素 elem。

链表插入和顺序表最大的不同在这：顺序表能直接访问 data[i-1]，链表不行，你得先走到第 i-1 个结点，也就是要插入位置的前一个结点，我们叫它前驱。为什么要找前驱？因为插入是靠改前驱的 next 完成的。看代码第一句，LNode 星号 p 等于 GetElem(L, i-1)，就是调用刚才的 GetElem 找前驱；如果 p 是 NULL，说明这个位置不合法，返回 false。

找到前驱 p 之后，新建结点 s、把 elem 放进 s->data，然后是关键的两步：第一步 s->next = p->next，让 s 先接住 p 原来的后继；第二步 p->next = s，让 p 转而指向 s。这样 s 就插进了 p 和它原来后继之间。这里要强调，链表插入为什么找的是前驱、不是第 i 个结点本身？因为插入是靠改前驱的 next 完成的，你得先站在前驱上，才能把新结点接在它后面。举个具体的：链表是 头结点→10→20→30，在第2位插15。先 GetElem(L,1) 走到10那个结点当 p；新建 s 装15；s->next = p->next 让15指向20；p->next = s 让10指向15。链变成 头结点→10→15→20→30，15 落在第2位。

这两步的次序，又是不能换的，跟头插法一个道理。下一页我们专门拿一道题来练这个次序，因为它太容易错了。

## P10 检查页：在 p 之后插 s，哪组语句对（约4分钟）

这一页你先自己判断，别急着看答案。这是题集勾画里 2选18 那种题：要在结点 p 之后插入结点 s，屏幕上给了两组语句，A 组是先 s->next = p->next 再 p->next = s，B 组是先 p->next = s 再 s->next = p->next。你先选一选，哪组对？

【停顿】答案是 A 对。我们走一遍为什么。A 组：先 s->next = p->next，这一步让 s 接住了 p 原来的后继，链暂时还是完整的；再 p->next = s，让 p 指向 s。这样 p、s、原来的后继就正确串起来了。

B 组错在哪？它第一步就 p->next = s，这一句一执行，p 原来指向的那个后继就再没有任何指针指着它了，地址当场丢失。第二步 s->next = p->next，可这时候 p->next 已经是 s 自己了，所以 s->next 指向了 s，成了自己指自己，p 后面的整条链全丢了。

所以你看，插入这两步，"先接后、再改前"这个次序是铁定的，换了就断链。这类"读指针代码、判断结果或选正确语句"的题，是程序阅读题的常考形态，你练的就是在脑子里把指针一根一根画清楚。给你一个稳妥的习惯：写链表题先在草稿上画结点图，改哪根指针就在图上先改一遍，比空想靠谱得多。这类题在802程序阅读里很常见，给你一段指针操作的代码，问你执行完链表长什么样，或者让你选出正确的语句序列，考的就是你能不能在脑子里把指针一根一根理清楚。

## P11 ListDelete（约3分钟）

那么插入会了，删除是它的反操作。ListDelete 删除第 i 个结点，还要把删掉的值用 elem 带出来。

跟插入一样，删除也要先找前驱，p 等于 GetElem(L, i-1)。然后要判两次空：第一次判 p 是不是 NULL，p 空说明前驱都不存在，位置非法；第二次判 p->next 是不是 NULL，p->next 空说明 p 已经是最后一个结点、它后面没有第 i 个结点可删。两次判空缺一不可。

判完之后，用 s 记住要删的结点，也就是 s 等于 p->next。接下来的次序很重要：先 elem = s->data 把值取出来，再 p->next = s->next 让前驱跨过 s 接住它的后继，最后 free(s) 释放 s。

【停顿】为什么必须先取值、再 free，不能反过来？因为 free(s) 之后，s 指向的那块内存已经被回收了，你再去读 s->data，读的是别人的或者已经作废的内存，值是乱的，程序也可能崩。所以记牢这个次序：取值、改指针、最后 free。再说说为什么要判两次空。第一次判 p，p 空说明前驱都不存在，位置 i 太大；第二次判 p->next，它空说明 p 已经是最后一个结点、后面没有第 i 个可删。走一遍：链 头结点→10→20→30，删第2个。GetElem(L,1) 到10那个结点当 p；两次判空都过；s 指向20；elem 取出20；p->next = s->next 让10直接指向30、跨过20；free(s) 释放20。链变成 头结点→10→30，elem 是20。

## P12 求表长与销毁链表（约2分钟）

最后两个操作，求表长和销毁。

求表长 ListLength 很简单：p 从 L->next 开始，也就是从第一个数据结点数，注意不数头结点；p 不为空就 n 加一、p 往后走，走到 NULL 为止，返回 n。

销毁 DestroyList 要释放整条链的所有结点。关键在一个细节：循环里必须先用 q 把 p 的后继存下来，q = p->next，然后 free(p)，再 p = q。为什么先存后继？因为 free(p) 之后 p 指向的内存就没了，你要是这时候再读 p->next 就晚了。还有一个常见的坑：只 free 头结点，那后面所有数据结点都没释放，这是内存泄漏。销毁要从头到尾一个一个 free 干净。举个例子，链是 头结点→10→20。p 先指头结点，q 存住10，free 头结点，p 移到10；下一轮 q 存住20，free 10，p 移到20；再一轮 q 存住 NULL，free 20，p 移到 NULL，循环停。三个结点全释放，最后 L 置 NULL。哪一步要是忘了先存 q，free 之后就找不到下一个结点在哪，剩下的全泄漏。

## P13 小结（约2分钟）

这一节收一下。单链表是用指针把散着的结点串起来的链式结构，我们默认它带头结点。你要能默写这些基本操作：定义 LNode 和 LinkList，初始化带头结点的空表，头插法建表（结果是逆序）、尾插法建表（用 rear 记住尾巴，否则变 O(n²)），GetElem 按位序找、LocateElem 按值找，ListInsert 找前驱两步接指针，ListDelete 两次判空、先取值再 free，还有求表长和销毁。

有三条最容易错、也最常考的，你重点记：一是插入的两步次序，先接后再改前，换了就断链；二是删除和销毁，都要先保存好该保存的（删除先取 data、销毁先存后继）再 free；三是找前驱，链表插删都得先走到第 i-1 个结点。

最后对比一下链表和顺序表。链表按下标访问是 O(i)，得从头走，没有随机访问，这是它不如顺序表的地方；但链表插入删除不用挪一大片元素，只要改几根指针，这是它比顺序表强的地方。两种存储各有代价，后面遇到具体问题再选：频繁按下标访问、很少插删，用顺序表；频繁插删、很少随机访问，用链表。还有一个容易被忽略的点：链表插入删除，一旦找到前驱，改指针本身是 O(1)，慢的是找前驱、要从头走 O(i)，所以按位插删整体还是 O(n)；顺序表正好相反，找位置是 O(1)、慢在挪元素 O(n)。两种按位插删都是 O(n)，但慢的地方不同，这个对比802爱考。

```c
typedef struct LNode{ int data; struct LNode *next; }LNode, *LinkList;

void CreateByHead(LinkList &L, int n){          // 头插法，结果逆序
    L = (LNode *)malloc(sizeof(LNode));  L->next = NULL;
    for(int i = 0; i < n; i++){
        LNode *s = (LNode *)malloc(sizeof(LNode));
        scanf("%d", &s->data);
        s->next = L->next;  L->next = s;         // 先接后，再改前
    }
}
bool ListInsert(LinkList &L, int i, int elem){
    LNode *p = GetElem(L, i - 1);                // 找前驱
    if(p == NULL) return false;
    LNode *s = (LNode *)malloc(sizeof(LNode));
    if(s == NULL) return false;
    s->data = elem;  s->next = p->next;  p->next = s;  return true;
}
bool ListDelete(LinkList &L, int i, int &elem){
    LNode *p = GetElem(L, i - 1);
    if(p == NULL) return false;
    if(p->next == NULL) return false;            // 第 i 个不存在
    LNode *s = p->next;  elem = s->data;         // 先取值
    p->next = s->next;  free(s);  return true;   // 再改指针、后 free
}
void DestroyList(LinkList &L){
    LNode *p = L, *q;
    while(p != NULL){ q = p->next; free(p); p = q; }  // 先存后继再 free
    L = NULL;
}
```

模仿题（2算17）：单链表就地逆置。

```c
// 思想：从头结点后依次摘下每个结点，用头插法重新插回，走一遍即逆置
void Reverse(LinkList &L){
    LNode *p = L->next, *r;
    L->next = NULL;
    while(p != NULL){
        r = p->next;          // 先存后继
        p->next = L->next;    // 头插到 L 之后
        L->next = p;
        p = r;
    }
}
// 复杂度：时间 O(n) 每结点摘下重接一次；空间 O(1) 只用 p、r 两个指针
```

要点：逆置就是不断把头结点后的第一个结点摘下、再头插回去；只改指针、不新开结点，所以空间 O(1)。

```c
typedef struct LNode{ int data; struct LNode *next; }LNode, *LinkList;

bool InitList(LinkList &L){
    L = (LNode *)malloc(sizeof(LNode));
    if(L == NULL) return false;
    L->next = NULL;  return true;
}
LNode *GetElem(LinkList L, int i){
    if(i < 0) return NULL;
    LNode *p = L; int j = 0;
    while(j < i && p != NULL){ p = p->next; j++; }
    return p;
}
LNode *LocateElem(LinkList L, int elem){
    LNode *p = L->next;
    while(p != NULL && p->data != elem) p = p->next;
    return p;
}
int ListLength(LinkList L){
    int n = 0; LNode *p = L->next;
    while(p != NULL){ n++; p = p->next; }
    return n;
}
```
