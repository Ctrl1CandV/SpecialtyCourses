## 正课：六条约定与复杂度分析（第6—15页，约28分钟）

## P6 六条约定总览（约3分钟）

导学到这，下面进正课。这一讲的正课分两块：先是六条全局约定，再是复杂度分析。先看六条约定的总览，心里有个数，后面三页逐条展开。

第一条，两套下标基准。线性表和查找这两章，数据从下标0开始存；排序那一章，数据从下标1开始存。这条最要紧，后面每段代码的下标写法都由它决定。第二条，链表默认带头结点，让第一个结点的插入删除和其他位置统一处理。第三条，顺序栈的栈顶指针 top 初值取负一，循环队列判满时牺牲一个存储单元，这两样把栈和队列的判空判满式子定死了。第四条，栈和队列当工具用的时候，里面存的元素类型按需替换，不一定是 int。第五条，伪代码里那种“数组等于大括号零”的写法是把整个数组清零的简写；但要赋非0初值，比如全初始化成无穷大，就必须写循环。第六条，函数参数用C++的引用符号 & 表示传入传出，让函数改得动外面的数据。

这六条不是我随便定的，是从你手里那份代码总结的开篇抄下来的，跟考生的复习资料完全一致，你不用换体系。先记住有这么六条，为什么这么定、各自解决什么问题，我们一条一条说。

## P7 约定1：两套下标基准（约4分钟）

第一条约定展开讲，它是六条里最要紧的。这一页你拿纸跟着画，PPT一条一条放。

先画左边。画五个格子，标上下标 data[0] 到 data[4]，往里依次填 10、20、30、40、50。这是线性表和查找章节的存法：数据从下标0开始，第一个元素就住在 data[0]。你要找第 i 个元素，它在下标 i-1 的位置，也就是 data[i-1]。为什么差一个？因为“第几个”从1数起，“下标”从0数起，第1个元素对应下标0，第 i 个自然对应下标 i-1。

再画右边。同样这五个数，但这次 data[0] 空着，里面标两个字：哨兵。数据从 data[1] 存到 data[5]。这是排序章节的存法：下标0那格不存数据，留着当哨兵或者暂存位。这一套里第 i 个元素就在 data[i]，下标和“第几个”正好对上，不用减一。

【停顿】两张图画完，问一个问题：排序为什么非要从1开始，把 data[0] 空着，不是浪费一格吗？答案在堆排序。堆排序要求下标 i 的结点，它的左孩子正好是 2i、右孩子是 2i+1。这个整齐的关系只有从1开始存才成立；要是从0起，左孩子就变成 2i+1、右孩子 2i+2，式子处处多一个加一，很容易写错。教材为了统一，排序一律从1起，牺牲掉 data[0] 这一格。

最后落到答题上。写代码的时候，开头先交代一句：“本题下标从0起”，或者“从1起”。阅卷老师不会因为你选了哪一套就扣分，他要看的是一份答卷前后一致。真正扣分的是自相矛盾：前面按0起写，后面又按1起算，同一道题两套混着用，那基本就全错了。记一句话，**一套题一套基准，从头到尾不换**。

## P8 约定2—4（约3分钟）

第二、三、四条约定放一页，各说一句它解决什么问题。

第二条，链表默认带头结点。什么叫带头结点？链表的第一个格子不存数据，专门放一个标志性的结点，头指针 L 指向它，真正的第一个数据结点是 L 的 next。为什么要多这么一个头结点？两个好处。一是插入删除的时候，第一个数据结点的位置和其他位置处理起来完全一样，不用为“插在表头”单独写一套代码；二是空表和非空表能用同一个式子判断，空表就是头结点的 next 等于 NULL。头结点具体怎么省事，第3节讲单链表的时候你会看得很清楚，这里先记住“默认带头结点”这个约定。

第三条分两半。顺序栈的栈顶指针 top 初值取负一。为什么是负一？数组下标从0开始，栈空的时候 top 指向最后一个元素再往前一个位置，也就是负一；入栈先加一再放，写成 S.data[++S.top]。循环队列判满时故意牺牲一个存储单元，判满条件是 rear 加一再对 MaxSize 取模等于 front。这两个约定把栈和队列所有的判空判满式子都定死了，第5节会把 top 等于0的版本、加 size 的版本、加 tag 的版本放一起对比。

第四条，栈和队列当工具用的时候，里面存的元素类型按需替换。材料里为了省事 data 都写成 int；但到了树和图的算法里，栈里压的是结点指针，队列里排的是顶点编号。考场上你不用为每种类型重新定义一个栈，直接写 SqStack S，再 Push(S, p) 就行，但答题要补一句“栈中存放的是结点指针”，让阅卷老师知道你清楚里面装的是什么。

## P9 约定5—6（约3分钟）

第五、第六条约定一页讲完，都是写代码的细节。

先看第五条，数组初始化。伪代码里常见这种写法：int a[n] = {0}，意思是把整个数组清零。提醒一件事，这是伪代码允许的简写；严格的C语言里变长数组不允许带初始化列表，真要在机器上跑得先声明再循环赋值。802不挑这个，写简写没问题。

但有个陷阱你必须记住。要是把大括号里的0换成别的值，比如 int dist[n] = {INF}，想把所有元素都初始化成无穷大，这就错了。大括号里只写一个值，C语言只拿它初始化第一个元素，剩下的全是0。也就是说 dist[0] 是 INF，dist[1] 一直到 dist[n-1] 全是0。这在求最短路径那类算法里是致命的：0会被当成“已经到达、距离为零”。所以规矩是，清零可以用等于大括号0简写，赋任何非0初值必须写循环，for i 从0到 n-1 逐个赋 INF。

再看第六条，引用。函数参数前面写一个 & 符号，比如 SqList &L，这个 & 是C++的引用，作用等价于C语言里的二级指针，表示参数既传入又传出：函数里改了 L，调用处那个 L 也跟着变。为什么要它？因为初始化、插入、删除这些操作都要改传进来的结构体本身，不用引用，改的只是一个副本，外面的原对象纹丝不动。这个符号在C语言强化阶段专门讲过，这里记一句话就够：**伪代码里参数写了 &，就是让函数改得动外面的东西**。

## P10 时间复杂度怎么数（约4分钟）

约定讲完，进第二块，复杂度分析。这是答题三件套里的第三件，也是最容易丢分的一件，因为很多同学只会写结论、不会给理由。先说时间复杂度怎么数。

数时间复杂度就数一件事：基本操作执行了多少次。基本操作通常是循环最里面那句。数出来之后，只保留最高阶，把系数和低阶项都去掉，写成大O。这就是**数基本操作的次数**这一条。

看这段代码。外层 for i 从0到 n-1，内层 for j 从 i 到 n-1，最里面 x 自增一次，这个自增就是基本操作。它执行多少次？关键是内层的范围依赖外层的 i。当 i 等于0，内层 j 从0到 n-1，跑 n 次；i 等于1，j 从1到 n-1，跑 n-1 次；i 等于2，跑 n-2 次；一直到最后 i 等于 n-1，内层只跑1次。

【停顿】所以总次数不是简单的 n 乘 n，而是把每一趟加起来：n 加 n-1 加 n-2，一直加到1。这是个等差数列求和，结果是 n 乘 n+1 再除以2。去掉系数二分之一，最高阶是 n 的平方，所以时间复杂度是 O(n²)。

这里最容易犯的错，是看到两层循环就写 O(n²)，看到三层就写 O(n³)。不对，要看内层到底跑多少次。举个反例：三层循环，如果最内层只执行固定几次、不随 n 增长，那总体可能还是 O(n)，甚至是 O(1)。所以别数循环的层数，要数基本操作真正执行的次数；内层范围依赖外层的时候，先老老实实求和，再化简。

## P11 递归式怎么展开（约3分钟）

循环的复杂度会数了，再看递归的。递归函数的时间复杂度往往写成一个递归式，比如 T(n) 等于 2T(n/2) 加 O(n)。这个式子的意思是：处理一个规模 n 的问题，先做 O(n) 的活，再把它拆成两个规模 n/2 的子问题分别解决。这种式子怎么算出大O？用逐层累加，一层一层把代价加起来。

我们把它想成一棵递归树。最上面第0层，就一个问题，规模 n，这一层做的活是 O(n)。往下第1层，问题拆成两个，每个规模 n/2，两个加起来，这一层的活是 2 乘 O(n/2)，还是 O(n)。再往下第2层，四个问题，每个规模 n/4，加起来 4 乘 O(n/4)，仍然是 O(n)。

【停顿】规律出来没有？每往下一层，问题个数翻一倍，但每个问题的规模减半，一乘一除抵消掉，所以每一层的总代价都是 O(n)，层层都一样。那有多少层？规模每次减半，从 n 减到1，要减 logn 次，所以一共 logn 层。每层 O(n)，一共 logn 层，加起来就是 O(n) 乘 logn，也就是 O(nlogn)。

这就是归并排序、快速排序平均情况的复杂度来历。这个逐层累加的办法比死记公式靠谱：你只要记住**算出每层的代价，再算出层数，两个一乘**，绝大多数递归式都能这么拆出来。到了强化阶段讲归并和快排，这个展开还会再用一次，到时候你不用重新想。

## P12 空间复杂度（约2分钟）

说完时间说空间。空间复杂度数的是：为了完成这件事，你额外开了多少辅助空间。注意是“额外”，输入数据本身占的空间不算。额外空间来自两个地方，一是你开的辅助数组，二是递归调用压的栈。

先说辅助数组。新开了一个大小 n 的数组，空间就是 O(n)；只用了固定几个变量，不管 n 多大都是这几个，那就是 O(1)。这里澄清一个误解：原地算法说的空间 O(1)，不是指一点都不占内存，而是指额外空间不随 n 增长，就固定那么几个变量。

再说递归栈，这个最容易漏。很多人以为一个递归函数没开数组，空间就是 O(1)，错了。递归每调用一层，栈上就多压一帧，存这一层的参数和返回地址。所以递归的空间至少要算栈的最大深度。比如二叉树的递归遍历，没开任何数组，但栈深度等于树的高度，空间是 O(树高)；要是这棵树退化成一条链，树高等于结点数 n，空间最坏就是 O(n)。答题的时候时间和空间两个都要给，各配一句理由，别只盯着数组，把递归的栈深度漏掉。

## P13 答题三件套格式（约2分钟）

复杂度会算了，把整个答题格式收一下。802的算法大题，标准答案是三件套：第一件算法思想，用文字说清你打算怎么做；第二件代码或者伪代码；第三件时间和空间复杂度，各带一句理由。三件缺一件就扣一件的分，这是阅卷的评分点。

我用一个例子给你看格式长什么样，例子是把一个带头结点的单链表原地逆置。第一件思想，两句话：把头结点后面的每个结点依次摘下来，再用头插法重新接回头结点后面，走一遍，整条链就反过来了。第二件代码，核心是一个 while 循环，用一个指针 p 顺着链走，一个指针 r 存住 p 的后继，把 p 摘下来插到 L 的后面，再把 p 移到 r。第三件复杂度，时间 O(n)，因为每个结点都被摘下、重接了一次，一共 n 个；空间 O(1)，因为自始至终只用了 p 和 r 两个指针，没开数组。

说明一句：单链表和头插法是第3节才正式讲的内容，今天借它只是给你看**思想、代码、复杂度**这个三段式怎么排版，你先不用纠结代码细节，重点记住这个格式。

## P14 小结（约2分钟）

这一讲收一下，两块内容。

第一块，六条全局约定。两套下标基准，线性表查找从0起、排序从1起；链表默认带头结点；顺序栈 top 等于负一、循环队列牺牲一个单元；栈队元素类型按需替换；数组清零可以用大括号0简写、赋非0初值必须写循环；参数用引用 & 让函数改得动外面。这六条先记牢，后面每一节的代码都会用到，尤其第一条两套下标基准，几乎每段代码的下标写法都由它决定。

第二块，复杂度分析。时间复杂度数基本操作的次数，内层依赖外层先求和再化简，只保留最高阶；递归式用逐层累加，每层代价乘层数；空间复杂度数额外的辅助空间，包括辅助数组和递归栈的深度，递归的空间不是 O(1)。答题按三件套来，复杂度一定要一句结论配一句理由，光写结论不给理由要扣分。

这两块是工具性的地基，本身不是某个数据结构，但后面八节每一节都踩着它们走：约定保证代码写出来统一、不自相矛盾，复杂度保证你答大题第三件不丢分。

## 附录一：课后题参考答案

跟练题：六条约定各一句作用，加约定5的错误示例与正确写法。

- 约定1 两套下标基准：固定线性表与排序各自的下标写法，同一道题里不混用，避免自相矛盾。
- 约定2 带头结点：第一个结点的插入删除与其他位置统一，空表判定也用同一个式子。
- 约定3 top=-1与牺牲一单元：把顺序栈与循环队列的判空判满式子定死。
- 约定4 元素类型按需替换：栈队当工具时可放结点指针或顶点编号，不必重新定义。
- 约定5 ={0}是简写、{INF}必须写循环：避免只初始化第一个元素的错误。
- 约定6 引用 &：让函数改得动调用处的变量。

约定5的错误示例与正确写法：

```c
int dist[n] = {INF};                    // 错：只有 dist[0]=INF，其余全是0
for(int i = 0; i < n; i++)              // 对：赋非0初值必须循环
    dist[i] = INF;
```

模仿题：三段程序的时间复杂度与理由。

```c
// (1) 嵌套循环，内层依赖外层
for(i=0;i<n;i++) for(j=i;j<n;j++) x++;
// (2) 循环变量翻倍
int i=0,x=1; while(x<n){ x*=2; i++; }
// (3) 递归函数
void f(int n){ if(n<=1) return; for(i=1;i<=3;i++) f(n/3); }
```

- (1) O(n²)。内层 j 从 i 到 n-1 共跑 n-i 次，总次数 n+(n-1)+…+1 = n(n+1)/2，最高阶 n²。
- (2) O(logn)。x 从1每次翻倍，到 x≥n 停，循环次数是 logn 级。
- (3) O(n)。递归式 T(n)=3T(n/3)+O(1)，每层问题数乘3、规模除以3，共 logn 层，末层 n 个结点，逐层累加得 O(n)。

答题三件套样例，单链表原地逆置（头插法，第3节正式讲）：

```c
// 思想：把头结点后每个结点依次摘下，用头插法重新接回，走一遍即逆置
void Reverse(LinkList &L){
    LNode *p = L->next, *r;
    L->next = NULL;
    while(p != NULL){
        r = p->next;            // 先存后继
        p->next = L->next;      // 头插到 L 之后
        L->next = p;
        p = r;
    }
}
// 复杂度：时间 O(n)，每结点摘下重接一次；空间 O(1)，只用两个指针
```
