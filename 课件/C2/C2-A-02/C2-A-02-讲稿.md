## P2 引题：为什么数组外面要包结构体（约3分钟）

先思考一个问题。我要存一串数，比如一个班的成绩，用一个数组 int data[100] 不就行了吗？为什么还要专门定义一个叫顺序表的结构体，把数组包进去？

关键在于，数组有一个它自己解决不了的问题：它不知道自己存了几个数。你开了100格，可能只用了5格，剩下95格是空的，或者是上次留下的垃圾值。数组本身没有任何地能表达"我现在有效的是前5个"。可是你要做插入、删除、查找，每一步都得先知道当前到底有几个元素。就拿查找说，你总不能把100格全扫一遍，那样连没用的垃圾值都扫进去了，你得知道只扫前5个。再说插入，你要在第3个位置插一个新数，就得先知道从第3个到最后一个分别是哪些，才能把它们统统往后挪一格，这同样要靠length这个属性告诉你表现在有多长，删除也一样。可以说没length，插入、删除、查找全都无从下手，所以顺序表才要在数组旁边配一个记个数的length。

所以我们需要在数组旁边再配一个数，专门记当前存了几个，这个数就是 length。把数组data和计数length打包进同一个结构体，让它俩始终待在一起，这就是顺序表。我们可以发现，顺序表不是什么新东西，它就是"数组加一个记个数的 length"，为的是解决数组不知道自己有多长这个问题。记住这个动机。后面每学一个结构的定义，你都可以这么问一句，那些多出来的东西是为了记录什么信息。

## P3 静态顺序表定义（约3分钟）

先看静态顺序表的定义。开头 #define MaxSize 1000，给容量起个名字。然后 typedef struct，里面两个成员：一个是 int data[MaxSize]，这是真正存元素的数组，最多能装1000个；另一个是 int length，记当前实际存了几个。最后给这个结构体起个名字叫 SqList。

这里有两个数你要分清，MaxSize 和 length。MaxSize 是容量，是这个表最多能装多少，它在编译的时候就定死了，是1000就是1000，运行中不变。length 是个数，是现在实际装了多少，它随着你插入、删除一直在变。举个例子，你刚建了一个空表，MaxSize 是1000，length 是0；你插进去5个元素，MaxSize 还是1000，length 变成5。一个值表示上限，另外一个值表示现值。后面插入的时候有一个判断"还能不能再装"，比的就是 length 有没有到 MaxSize。换句话说，MaxSize 是容量、编译时定死不变，length 是个数、随插入删除一直变；容量不会因为你多存几个元素就变大，个数也永远超不过容量。typedef struct 这个写法你在C语言强化阶段学过，就是给这个数组加计数的组合起一个新类型名叫 SqList，之后写 SqList 就代表这一整个结构。这个版本叫静态，是因为数组的大小 MaxSize 写死在宏里，一旦编译就固定，运行时改不了。

## P4 动态顺序表定义（约3分钟）

静态版有个不方便的地方，这个容量是固定的。要是你事先不知道要存多少，或者不同情况想开不同大小，就得用动态版。看动态顺序表 SeqList 的定义，它跟静态版有两个区别。

第一个区别，data 不再是数组，而是一个指针，指向一片运行时才申请出来的连续内存，也就是 malloc 出来的那块。第二个区别，MaxSize 从宏变成了结构体里的一个字段，跟 length 并排写着。为什么要把它存进结构体？因为动态版的容量是运行时才定的，由初始化时传进来的参数决定，所以得有个地方记住这个表到底开了多大，这个地方就是结构体里的 MaxSize 字段。

malloc 怎么申请、申请完为什么要判空，这些在C语言强化阶段都讲过了，这里直接用，不再展开。这一节后面的基本操作，我都用静态版 SqList 来写，因为它更直观。动态版的操作思路完全一样，差别只在 data 是个指针、容量存在结构体里，你把静态版看懂了，动态版自己就能改出来。那到底什么时候用静态、什么时候用动态？如果你事先知道数据大概有多少、上限固定，用静态版最省事，一个数组摆在那，不用操心申请和释放内存。如果数据量事先说不准，或者可能很大又怕开小了装不下，就用动态版，运行时按需要申请。802 答题的时候两种都可能碰到，办法很简单：题目给的定义里 data 是数组，你就按静态版写；data 是指针，你就按动态版写，初始化记得 malloc 加判空。跟着题目给的结构走，别自己乱换。

## P5 初始化：静态清零，动态 malloc 判空（约4分钟）

那么我们讲完了动态顺序表和静态顺序表的定义，就要开始讲基本操作了，第一个基本操作是初始化，就是建一个空表。两个版本各写一个 InitList。

先看静态版。它做两件事：一个 for 循环把整个数组 data 从头到尾清零，然后把 length 置0。清零是把数组里的垃圾值抹掉，length 置0表示现在一个元素都没有，是个空表。

再看动态版。它先 malloc 申请一片 InitSize 个 int 那么大的内存，把地址交给 data；紧接着必须判空，如果 data 等于 NULL 就返回 false，因为内存可能申请失败，不判空后面就会出事，这是C语言强化阶段反复强调的习惯；申请成功再把 length 置0、MaxSize 记成 InitSize，返回 true。

这里要再次重申一下&这个符号。两个 InitList 的参数都写成 SqList &L，这个&是C++的引用，第一节我们提过它，现在是它第一次真正派上用场。为什么初始化要写 &L，不写 L？因为InitList 的任务是把外面那个表改成空表，也就是把它的 length 改成0。如果参数只写 SqList L，不带 &，那函数拿到的只是外面那个表的一份副本，你在函数里把副本的 length 改成0，函数一结束副本就没了，外面那个真正的表纹丝不动，等于白初始化。加上 & 就不一样了，& 表示这个参数是外面那个表本身，不是副本，函数里改 L.length，改的就是外面那个表的 length。

所以记住一句话：**凡是函数要修改传进来的结构体，参数就得写 &**。初始化、插入、删除都要改表，所以它们的 L 前面都有 &。查找不改表，理论上可以不带，但材料里也统一带了，你照着写就行。-我再把没有 & 的后果说具体点你就彻底记住了。假设 main 里有一个 SqList L，你调用 InitList(L)，如果 InitList 的参数写成 SqList L 不带 &，函数内部那个 L 只是 main 里 L 的一份拷贝，你把拷贝的 length 改成0，函数一返回拷贝就销毁了，main 里 L 的 length 还是原来那个乱值，这个表等于没初始化，后面全乱。还有人会问&引用是C++的语法，但我们写的主要是C语言，这个会有冲突吗。那么实际上802考的是伪代码，不在乎具体的语法，这里只是代表了一种传参的思想，你用\*表示引用也是没问题的。

## P6 按值查找 LocateElem（约4分钟）

第二个操作是按值查找 LocateElem，给一个值 key，问它在表里排第几。代码是一个 for 循环，i 从0扫到 length-1，逐个比较 L.data[i] 和 key，相等就返回 i+1；扫完都没找到，返回 -1。这里有两个点要讲清楚，都跟下标有关，也是第一次正式说顺序表的下标从几开始。

第一个点，顺序表属于线性表这一章，它的数据从 data[0] 开始存，第1个元素在 data[0]，第2个在 data[1]，以此类推，第 i 个元素就在 data[i-1]。所以下标从0起，"第几个"从1起，两者差一个1。

第二个点，循环里 i 是下标，从0开始；可是命中的时候返回的是 i+1，不是 i。为什么要加这个1？因为题目问的是"这个值是第几个"，答案要用位序，位序是从1数起的。下标 i 从0数，下标 i 上的这个元素，它是第 i+1 个，所以要返回 i+1。

这个 i 和 i+1 的差别，是程序阅读题最爱考的陷阱。给你一段查找代码，问它返回的是什么，你就要弄清楚它返回的是下标，还是位序？差一个1，答案完全不同。所以看这类代码，第一件事是看清 data 从几开始存、返回的又是不是加了1。我们拿一个具体的表走一遍。表里存的是 10、20、30、40、50，我要找30排第几。循环开始，i=0，data[0] 是10，不等于30，i 加1；i=1，data[1] 是20，还不等，i 再加1；i=2，data[2] 是30，相等了，返回 i+1 也就是3，没错，30 确实是第3个。再找一个表里没有的，比如99，循环从 i=0 一直比到 i=4，没一个等于99，i 变成5，不满足 i 小于 length，退出循环，执行最后那句 return -1，告诉你没找到。返回正数就是位序，返回 -1 就是没有，这个约定后面查找类的函数都会沿用。当然，如果题目明确问的是下标不是位序，那你就返回 i，不加这个1。关键还是先看清题目问的是第几个还是下标几，再决定加不加1，别想当然。

## P7 按位插入 ListInsert（约4分钟）

第三个操作是按位插入 ListInsert，在第 i 个位置插入一个新元素 elem。这个操作比查找相对复杂一些，我们一行一行看。

函数首先做两个判断，这两个判断就是插入的合法范围。第一个，如果 i 小于1，或者 i 大于 length+1，返回 false。这是位序的合法范围。你可能会问，插入位置为什么能到 length+1？因为你可以插在最后一个元素的后面，也就是新的末尾。表里现在有 length 个元素，你能插的位置是从第1个到第 length+1 个，第 length+1 位就是接在最后。所以上界是 length+1，不是 length，这一点很容易记错。第二个判断，如果 length 大于等于 MaxSize，返回 false，这是判满，表已经装到容量上限了，再插入就超出容量了。注意这里是大于等于，等于的时候已经满了，不能写成大于。

两个判断都过了，才开始挪数据。看这个 for 循环：j 从 length 开始，一直减到 i，每次把 L.data[j-1] 挪到 L.data[j]。它在干什么？它在把从第 i 个位置开始的元素，全部往后挪一格，给新元素腾地方。

【停顿】这里最关键、也最容易错的一点：为什么必须从后往前挪，不能从前往后？你想，如果从前往后挪，先把 data[i-1] 挪到 data[i]，可是 data[i] 原来的值还没搬走，就被覆盖了，这个值永远丢了。只有从后往前，先把最后面的挪到更后面，每一格挪的时候，它要覆盖的那一格都已经先搬走了，才不会丢数据。所以记住，顺序表插入，挪动一定从后往前。顺便说说开头那两个判断为什么一个都不能少。要是少了位序判断，传进来一个 i=0，你访问 data[i-1] 就是 data[-1]，直接越界写到数组前面去了；传进来 i=length+5，又会写到数组后面很远，都是越界。要是少了容量判断，表已经装满 MaxSize 个还硬插，就会写到数组末尾外面。所以这两句 return false 不是摆设，它们专门挡越界，答题时一定要写全，漏了就是边界不完整，阅卷要扣分。

最后一步，data[i-1] = elem，把新元素放进腾出来的那一格。为什么是 i-1？还是那个下标关系，位序 i 对应下标 i-1。放好之后 length 加1，返回 true。

## P8 动画演示：在第3位插入25（约5分钟）

插入的挪动过程光听容易糊，我们拿一个具体的表，一格一格画出来。这一页你拿纸跟着画，PPT一步一步放。

第一步，画一个存了5个数的表：data[0] 到 data[4]，依次是 10、20、30、40、50，length 等于5。现在要在第3位插入25。

第二步，先过两个判断。位序3在1到6之间，合法；length 是5，没到容量，也合法。两个都过，可以插。

第三步，开始从后往前挪。j 从 length 也就是5开始：data[5] 等于 data[4]，把50挪到 data[5]；j 减到4，data[4] 等于 data[3]，把40挪到 data[4]；j 减到3，data[3] 等于 data[2]，把30挪到 data[3]。j 再减就到2，小于 i=3，循环停。你看这三格，30、40、50 都往后让了一位，data[2] 这个位置就空出来了。每挪一步，你在纸上把数组重画一次，看清楚哪一格搬到了哪一格。

第四步，把25写进空出来的 data[2]，因为第3位对应下标2。然后 length 加1变成6。现在这个表是 10、20、25、30、40、50，25 落在第3位，后面的数一个不少地往后排好了。

画完对一下你的图：挪动是从 j=5 到 j=3，从后往前，一共挪了3格，正好是 n-i+1，也就是 5-3+1 等于3。这个挪动的格数，就是下一页要算的移动次数。画完这张图你自己再验两个极端。要是插在第1位，也就是最前面，j 从5一直挪到1，五格全部往后让一位，data[0] 空出来放新数，这是挪得最多的，正好对应插在表头要挪 n 个。要是插在末尾第6位呢，j 从5减到6，循环一次都不执行，一格不用挪，直接写 data[5]，这是最省的，对应插在末尾挪0个。这两个极端自己想一遍，插入到底挪多少你就有感觉了。

## P9 按位删除 ListDelete（约4分钟）

第四个操作是按位删除 ListDelete，把第 i 个元素删掉，还要把它带出来。它跟插入正好是一对反操作，我们对照着看。

先做范围判断：如果 i 小于1，或者 i 大于 length，返回 false。注意这里上界是 length，不是插入的 length+1。为什么不一样？因为删除删的是已经存在的元素，表里就 length 个，你能删的是第1个到第 length 个，没有第 length+1 个可删。插入能插在第 length+1 位，也就是末尾之后，删除不行，这个差别你要分清楚。

判断过了，第一件事是 elem = L.data[i-1]，把要删的那个元素取出来。注意参数里 elem 前面也有个 &，写的是 int &elem。这就是上一页讲的引用的另一个用途，传出。删除要把删掉的值告诉调用的人，靠的就是这个带 & 的 elem，函数里给它赋值，外面那个变量就跟着变了。你对比一下插入的 elem 和删除的 elem：插入的 elem 前面没有 &，删除的有。为什么？插入是往表里放一个值，elem 是传进来的，函数只读它不改它，不用 &；删除要把删掉的值带出去，elem 是传出的，函数要改它，所以用 &。一句话，传进来只读不用 &，要带出去才用 &。

然后挪数据，这次是从前往后：for j 从 i 到 length-1，每次把 L.data[j] 挪到 L.data[j-1]。它把第 i+1 个到最后一个元素，全部往前挪一格，盖住被删掉的那个。跟插入正好相反，插入是从后往前腾地方，删除是从前往后填坑。为什么删除可以从前往后？因为你把 data[i] 后面那格挪到 data[i]，data[i] 反正是要删的，覆盖掉没关系；接着后面一格再往前挪，每一格覆盖的都是已经搬走或本该删掉的位置，不会丢有用的数据。

最后要注意吧length更新减1，返回 true。我们还是拿一个表走一遍删除。假设现在表里是 10、20、25、30，length 是4，我要删掉第2个。先判范围，位序2在1到4之间，合法。然后 elem 等于 data[1]，data[1] 是20，通过引用把20带回给调用的人。接着从前往后挪：j 从2开始，data[1] 等于 data[2]，把25挪到 data[1]；j 到3，data[2] 等于 data[3]，把30挪到 data[2]；j 变成4，等于 length，循环停。最后 length 减1变成3。表现在是 10、25、30，20 被删掉了，它后面的数各自往前补一格，elem 里装着20交回调用处。你对比一下插入和删除：插入从后往前挪、删除从前往后挪，方向相反；范围上界一个 length+1、一个 length。这两组对比记牢就不会写混。

## P10 移动次数与平均复杂度（约4分钟）

这一页你先自己算一道，别急着听答案。一个 length 等于4 的表，存着 10、20、25、30，我执行删除第2个。你先想三件事：删完这个表变成什么？elem 带出来的是多少？挪了几格？

对一下答案。删的是第2个，也就是20，所以 elem 带出20；它后面的 25、30 各往前挪一格，表变成 10、25、30；一共挪了2格。这三件你都想对了，说明删除的过程你是真懂了，不是背下来的。

把这一道具体的题推广开，就是移动次数。先看插入，在第 i 位插入，要把第 i 个到第 n 个都往后挪一格，一共 n-i+1 个。插在表头 i=1 挪 n 个最费，插在末尾 i=n+1 挪0个最省；插在任意位置概率相等时，平均是 n/2。再看删除，删第 i 位，把第 i+1 个到第 n 个往前挪，一共 n-i 个；删表头挪 n-1 个，删末尾挪0个，平均 (n-1)/2。

n/2 和 (n-1)/2 都是 n 的一半上下，去掉系数就是 O(n)。所以顺序表插入删除的平均时间复杂度是 O(n)，这也是平均移动次数和时间复杂度之间的关系，并且只有插在末尾或删末尾才是 O(1)。这两个平均移动次数是填空和综合应用的常考点，你不仅要记结果，还要能说清怎么算出来的。

补两句。第一，这个平均是在插在任意位置概率都相等的前提下算的，题目要是给了别的分布，比如插表头概率特别大，就得按它给的重新加权，不能直接套 n/2。第二，顺序表插入删除的代价全花在挪元素上，表越长、位置越靠前挪得越多，这是它最大的缺点。下一节的单链表，插入删除就不用这样挪一大片，代价换到了别的地方，两相对照你会理解得更透。

## P11 小结（约2分钟）

这一节收一下。顺序表就是数组加一个记个数的 length，为的是解决数组不知道自己存了几个这个问题。它的五个基本操作，你合上书要能默写：初始化 InitList，静态版清零加 length 归0，动态版 malloc 加判空；查找 LocateElem，从头扫，命中返回位序 i+1，找不到返回 -1；插入 ListInsert，两个范围判断，从后往前挪，写进 data[i-1]；删除 ListDelete，范围到 length，elem 用引用带出，从前往后挪；复杂度，插入删除平均挪一半元素，都是 O(n)。

这一节还第一次正式用上了两条书写约定，你留意它们都是对着代码讲的。一条是引用 &，凡是函数要改外面的表，参数就带 &，初始化、插入、删除都是。另一条是下标从0起、位序从1起，所以第 i 个元素是 data[i-1]，查找命中返回 i+1。这两条后面每个结构都会再用到。

比这五个函数更要紧的是学一个数据结构的路子：先定义，再初始化，然后查找、插入、删除，最后算复杂度。顺序表这么走，后面链表、栈、队列、树、图全都这么走。这个框架搭好了，后面就是往里填不同的结构。最后提醒你两个最容易写错的地方，默写时特别留意：一个是插入和删除的位序上界不一样，插入能到 length+1，删除只到 length，别记反了；另一个是插入从后往前挪、删除从前往后挪，方向相反，写循环时 j 的起点和增减方向都要跟着变。这两处是顺序表最容易丢分的地方，也是程序阅读题爱挖的坑。

## 附录一：课后题参考答案

跟练题：默写 SqList 定义、静态版 InitList、ListInsert、ListDelete。

```c
#define MaxSize 1000
typedef struct{ int data[MaxSize]; int length; }SqList;

bool InitList(SqList &L){                       // 静态版
    for(int i = 0; i < MaxSize; i++) L.data[i] = 0;
    L.length = 0;  return true;
}
bool ListInsert(SqList &L, int i, int elem){
    if(i < 1 || i > L.length + 1) return false; // 位序上界 length+1：能插在末尾之后
    if(L.length >= MaxSize) return false;       // 容量已满
    for(int j = L.length; j >= i; j--) L.data[j] = L.data[j-1];  // 从后往前挪
    L.data[i-1] = elem;  L.length++;  return true;
}
bool ListDelete(SqList &L, int i, int &elem){
    if(i < 1 || i > L.length) return false;     // 位序上界 length：删已有元素
    elem = L.data[i-1];                         // 引用把删掉的值带出
    for(int j = i; j < L.length; j++) L.data[j-1] = L.data[j];   // 从前往后挪
    L.length--;  return true;
}
```

模仿题（2算15）：顺序表就地逆置。

```c
// 思想：首尾对称交换，i 从头走到中间，每次和末尾对称位置交换
void Reverse(SqList &L){
    for(int i = 0; i < L.length / 2; i++){
        int t = L.data[i];
        L.data[i] = L.data[L.length - 1 - i];
        L.data[L.length - 1 - i] = t;
    }
}
// 复杂度：时间 O(n) 交换 n/2 对；空间 O(1) 只用一个临时变量 t
```

要点：就地逆置只能用原表空间，借一个临时变量做对称交换，不能新开数组；走到 length/2 就停，否则会交换回来。

## 附录二：本节代码合集

顺序表的定义与全部基本操作，均与 `知识笔记/代码总结.md` 一致。

```c
#define MaxSize 1000
typedef struct{ int data[MaxSize]; int length; }SqList;          // 静态
typedef struct{ int *data; int MaxSize, length; }SeqList;         // 动态

bool InitList(SqList &L){
    for(int i = 0; i < MaxSize; i++) L.data[i] = 0;
    L.length = 0;  return true;
}
bool InitList(SeqList &L, int InitSize){
    L.data = (int *)malloc(sizeof(int) * InitSize);
    if(L.data == NULL) return false;
    L.length = 0;  L.MaxSize = InitSize;  return true;
}
int LocateElem(SqList &L, int key){
    for(int i = 0; i < L.length; i++)
        if(L.data[i] == key) return i + 1;   // 返回位序
    return -1;
}
bool ListInsert(SqList &L, int i, int elem){
    if(i < 1 || i > L.length + 1) return false;
    if(L.length >= MaxSize) return false;
    for(int j = L.length; j >= i; j--) L.data[j] = L.data[j-1];
    L.data[i-1] = elem;  L.length++;  return true;
}
bool ListDelete(SqList &L, int i, int &elem){
    if(i < 1 || i > L.length) return false;
    elem = L.data[i-1];
    for(int j = i; j < L.length; j++) L.data[j-1] = L.data[j];
    L.length--;  return true;
}
```
