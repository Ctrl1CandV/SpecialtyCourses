## P2 引题：为什么树的算法大部分都是递归（约3分钟）

先看一个事实：上一阶段写过的树算法，先序、中序、后序遍历，全是递归；这一节要讲的七个算法，也全是递归。为什么树的算法大部分都是递归？

答案在定义里。二叉树的定义本身就是递归的：二叉树要么是空树，要么是由一个根结点加上左、右两棵子树构成，而左、右子树本身还是二叉树。也就是说，树的每一个局部和整体长得一模一样。定义是递归的，顺着定义写出来的算法自然就是递归的。

再看动作。对树做的任何统计，在根结点这一层做的事都一样：看看自己，然后把同样的统计交给左子树和右子树。每往下一层，对象小一层，动作一个不换。这样的结构，不用递归反而别扭——你要用循环写，得自己开栈保存沿途结点，而函数调用栈替你把这个事办了。

【停顿】先回答屏幕上这个问题：求树的高度、求结点数，如果不用递归，循环该怎么写？想两三秒。你会发现，你要手写一个栈才能记住走到哪了，那个栈就是递归调用栈的穷人版。所以结论不是树的算法爱用递归，是树的定义决定了**递归最顺手**。

## P4 三个实例对比：求高度、结点数、叶子数（约5分钟）

三个函数在屏幕上并排，对着骨架看。

求高度 TreeDepth：空树返回 0，这是基准值。合并用 max 加 1：左子树多深、右子树多深，取深的那个，再加本结点这一层。求结点数 CountNodes：基准值同样是 0，合并改成相加加 1，左右子树各多少个结点，加起来，再加自己。求叶子数 CountLeaves：基准值还是 0，合并相加不加 1，因为叶子只长在下面；多出来的是中间那个判断——如果当前结点左右孩子都空，它自己就是叶子，直接返回 1，不用再往下递归。

看下面这张对比表，三个函数**只有两处不同**：基准值是什么、两个子结果怎么合并。求高度和求结点数只差一个合并方式，一个取 max 一个相加；求叶子数在骨架里多插了一个叶子判定，插进去的位置是合并之前。

这张表讲透，你就掌握了写一个新的树统计函数的方法，三步：先定终止值，再定合并方式，最后看需不需要额外判断。考场上见到没见过的统计量，比如求度为 2 的结点数，你先填基准值 0，再想合并是相加，最后加一个“左右孩子都非空就返回 1 加下去”的判断，代码就出来了。这个方法下一节判二叉排序树还要再用一次。

【停顿】对照表格问自己：求叶子数能不能写成左右相加再加 1？不能，那样算的是结点数。差别就在加不加那个 1。

## P5 过程页：7 个结点的树求高度（约5分钟）

拿纸跟着画。屏幕上是一棵 7 个结点的树：根 1，左 2 右 3；2 的左 4 右 5；3 的左 6 右 7。我们用 TreeDepth 对它求高度，看递归怎么展开、怎么收回。PPT逐步放，你在纸上画调用框。

展开。从 1 开始，1 调左，对 2 递归；2 再调左，对 4 递归；4 的左是空，返回 0，右也是空，返回 0。这是第一个到底的调用。

【停顿】设问：4 这个结点的 TreeDepth 返回几？它在纸上画出来。4 往下碰到两个空树，各返回 0，合起来是 max(0,0) 再加 1，**max(0,0)+1=1**。4 是叶子，它的高度是 1，不是 0——这个 1 就是叶子结点自己那一层。

收回从这一层开始。4 返回 1，5 同样返回 1；回到 2，左右都是 1，2 返回 max(1,1) 加 1 等于 2。右半边对称：6 返回 1，7 返回 1，3 返回 2。最后回到 1，左右都是 2，1 返回 3。整棵树高度 3。

看整个轨迹：展开是从根一路压到最底层的空树，每个结点的调用框进栈；收回是从最底层往上一层一层弹栈，每弹一层算一次 max 加 1。数据结构基础阶段第7节写过三种遍历的递归过程，那张调用栈图和这里完全同一张，这里把它补完整了。

## P6 判完全二叉树：层序加 tag 的思路（约4分钟）

换一类问题。前三个函数递归直接能写，从这一个开始，树统计要带点辅助信息了。

判完全二叉树，先记材料里的一句话判据：在完全二叉树中，若某个结点缺少子结点，则其后所有结点都必须是叶子结点。完全二叉树按层排满，只有最后一层允许缺，缺的还都得靠右。所以层序往里看，一旦看见一个结点缺孩子，后面再出现任何带孩子的结点，就不是完全二叉树。

做法是把层序遍历的框架拿过来，加一个 tag。层序每个结点出队，分别检查它的左孩子和右孩子：孩子非空，入队；孩子为空，把 tag 置 1，表示“我已经见过缺孩子了”。关键在于顺序——tag 置 1 之后，再有任何非空孩子撞上来，当场返回 0。

为什么要左、右孩子分开查、分开置 tag？因为“缺”分两种情况：左右都缺是一个结点本身到了末尾；有右孩子没左孩子是缺在中间，这棵树更不可能完全。分开查，两种情况都漏不掉。

【停顿】设问：tag 在什么时候置 1？不是看见叶子的时候，是检查到某个孩子为空的时候。这个位置记准，下一页代码你就看得懂。

## P7 判完全二叉树的代码与三个分支（约4分钟）

看代码 JudgeComplete。开头空树直接返回 1，空树约定算完全二叉树。然后建队列、根入队，tag 初始 0。循环体出队一个 p，两个 if 各管一个孩子，每个 if 就三个分支：

分支一，孩子非空且 tag 是 1：返回 0。含义是缺孩子之后还有非空结点，违反判据。分支二，孩子为空：置 tag 等于 1，这是整个函数唯一置 tag 的地方。分支三，孩子非空且 tag 是 0：正常入队，队伍往后走。

看**有右孩子没左孩子**这个坑是怎么被拦的。p 的左孩子空，第一个 if 走 else，tag 置 1；接着查右孩子，右孩子非空，撞上 tag 是 1，第二个 if 直接返回 0。所以不需要专门写“有右无左”的判断，两个 if 分开查、顺序执行，它自动被拦下。

最容易错的写法是只在左右孩子都空时才置 tag。那样写，有右孩子没左孩子这种结点会被放过，而它绝对不是完全二叉树。记死：每个 if 的 else 都置 tag，见到空就置。

复杂度：每个结点入队出队各一次，时间 O(n)；队列最多装一层，空间 O(w)，w 是树宽。

## P8 判平衡二叉树：为什么返回高度而不用 bool（约4分钟）

判平衡二叉树，判断每个结点左右子树高度差不超过 1。先想清楚返回什么，再写代码。

这个函数同时干两件事：往上报高度，往上报是否平衡。这就是它不能返回 bool 的原因。返回 bool，调用者只知道平不平衡，不知道高度；下一步算父结点的差值还要高度，你就得再写一个求高度的函数，整棵树递归第二遍。每个结点都这么干，时间从 O(n) 退成 O(n²)。802考场上写出 O(n²) 的判平衡，分就拿不全了。

正确做法：**一个返回值带两种信息**。平衡的时候返回高度本身，高度总是不小于 0；不平衡的时候返回 -1。用 -1 当信号为什么安全？因为合法高度最小是 0，-1 不可能和任何真高度混淆，上层接到 -1 就知道这棵树废了，不用管具体是几。

【停顿】设问：子树已经不平衡了，还有必要算另一边的高度吗？没必要。这个判断写进代码，就是下一页的两个短路。

## P9 判平衡的代码与 -1 短路（约4分钟）

看代码 JudgeAVL。空树返回 0：空树高度 0，也算平衡，这个返回值一身二任，既是高度又是“平衡”的信号。然后递归左子树拿 HL，紧接着一个 if：HL 等于 -1，直接返回 -1。这个 if 就是**-1 短路**——左子树已经废了，右子树根本不用算。右边对称，拿到 RL 之后同样先拦 -1。

两边都活着，才轮到本结点的判断：HL 减 RL 小于 -1 或者大于 1，本结点不平衡，返回 -1。都通过，返回 max(HL, RL) 加 1，高度照常往上报。

两个易错点对着代码记。第一，忘写短路：子树返回 -1 你还接着当高度算，差值判断全错，而且浪费一遍递归。第二，写成先调 TreeDepth 求高度再判差值：逻辑对，但那是两遍递归，O(n²)，考场上等价于不会。

复杂度收尾：每个结点只被算一次高度，时间 O(n)；递归栈 O(h)。

## P10 求镜像树：三行交换（约3分钟）

求镜像树：把整棵树左右翻转，每个结点的左、右指针互换。代码 mirrorTree，核心就是三行交换加一个临时变量，然后对左、右孩子各递归一次。

先想次序问题：先交换再递归，和先递归再交换，结果一样吗？一样。因为交换换的是两棵子树的整体身份，先进去换里面的，出来再换顶层的，每个结点恰好被换一次；先换顶层再进去，同样每个结点恰好一次。两种都对，选一种写到底，别混着写。

参数这里有个细节，材料特意标了。这题只改结点内部的指针，不改 T 这个指针变量本身指向谁，所以参数写成 BiTree T 值传递也能完成；只有当函数要把 T 指到别处去，才必须写成 BiTree 引用。去年那道错题很多人就是在这里纠结，看清题目改的是谁的指向。

复杂度：每个结点一次交换，O(n)；递归栈 O(h)。

## P13 小结：七个算法一张表（约2分钟）

收一下，屏幕上这张表把七个算法压成三列：关键技巧、最容易错的。

递归三件套一行行过。求高度：终止 0，合并取 max 再加 1，容易错在把合并写成相加。求结点数：终止 0，相加加 1。求叶子数：是叶子直接返回 1，最容易错是多写加 1，一写加 1 就变成结点数了——三个函数的差别全在终止返回和合并这两处，外加叶子数那一个判断。

int TreeDepth(BiTree T){

    return max(TreeDepth(T->lchild), TreeDepth(T->rchild)) + 1;

    if(T == NULL) return 0;

}

跟练题二：判完全二叉树与判平衡二叉树。

```c
int JudgeComplete(BiTree T){
    if(T == NULL) return 1;
    SqQueue Q; InitQueue(Q); EnQueue(Q, T);
    int tag = 0; BiTree p;
    while(!IsEmpty(Q)){
        DeQueue(Q, p);
        if(p->lchild != NULL){ if(tag) return 0; EnQueue(Q, p->lchild); }else{ tag = 1; }
        if(p->rchild != NULL){ if(tag) return 0; EnQueue(Q, p->rchild); }else{ tag = 1; }
    }
    return 1;
}
int JudgeAVL(BiTree T){
    if(T == NULL) return 0;
    int HL = JudgeAVL(T->lchild);
    if(HL == -1) return -1;
    int RL = JudgeAVL(T->rchild);
    if(RL == -1) return -1;
    if(HL - RL < -1 || HL - RL > 1) return -1;
    return max(HL, RL) + 1;
}
```

变式题 6算10：递归求叶数，即求叶子数 CountLeaves，是叶子直接返回 1，不加 1。

变式题 6算11：左右子树交换，即求镜像树 mirrorTree，三行交换加两行递归，见附录二。

变式题 6算17：判完全二叉树，即 JudgeComplete，层序加 tag，三个分支照跟练题二。

变式题 6答17 与 6答33：树递归代码的读算法纠错。定位错处的顺序：先查终止返回值（空树返回什么），再查合并方式（max 还是相加、加不加 1），最后查短路（-1 不能被当高度用，忘短路会把 -1 带进差值判断）。两题答案按此顺序在题集上勾画。

## 附录二：本节代码合集

与 `知识笔记/代码总结.md` 树与二叉树段一致。

```c
// 求树的高度
int TreeDepth(BiTree T){
    if (T == NULL) return 0;
    return max(TreeDepth(T->lchild), TreeDepth(T->rchild)) + 1;
}

// 统计结点总数
int CountNodes(BiTree T){
    if(T == NULL) return 0;
    else return CountNodes(T->lchild) + CountNodes(T->rchild) + 1;
}

// 统计叶结点数（二叉链表）
int CountLeaves(BiTree T){
    if(T == NULL) return 0;
    if(T->lchild == NULL && T->rchild == NULL) return 1;
    else return CountLeaves(T->lchild) + CountLeaves(T->rchild);
}

// 统计叶结点数（孩子兄弟表示法）：叶子判据是 firstchild == NULL，兄弟链必须统计
int CountLeaves(CSTree T){
    if(T == NULL) return 0;
    if(T->firstchild == NULL) return 1 + CountLeaves(T->nextbro);
    return CountLeaves(T->firstchild) + CountLeaves(T->nextbro);
}

// 判断完全二叉树：若某结点缺少子结点，则其后所有结点都必须是叶子结点
int JudgeComplete(BiTree T){
    if(T == NULL) return 1;
    SqQueue Q; InitQueue(Q);
    EnQueue(Q, T);
    int tag = 0; BiTree p;
    while(!IsEmpty(Q)){
        DeQueue(Q, p);
        if(p->lchild != NULL){ if(tag) return 0; EnQueue(Q, p->lchild); }else{ tag = 1; }
        if(p->rchild != NULL){ if(tag) return 0; EnQueue(Q, p->rchild); }else{ tag = 1; }
    }
    return 1;
}

// 判断平衡二叉树：返回高度，-1 表示不平衡（短路）
int JudgeAVL(BiTree T){
    if(T == NULL) return 0;
    int HL = JudgeAVL(T->lchild);
    if(HL == -1) return -1;
    int RL = JudgeAVL(T->rchild);
    if(RL == -1) return -1;
    if(HL - RL < -1 || HL - RL > 1) return -1;
    else return max(HL, RL) + 1;
}

// 求镜像树：每个结点三行交换，再递归左右
void mirrorTree(BiTree &T){
    if(T == NULL) return;
    BiTNode *temp = T->rchild;
    T->rchild = T->lchild;
    T->lchild = temp;
    mirrorTree(T->lchild);
    mirrorTree(T->rchild);
}

// 求树的度：孩子兄弟递归，全局变量记最大度
int degree = 0;
int Post(CSNode *p){
    if(p == NULL) return 0;
    Post(p->firstchild);
    int d = 1 + Post(p->nextbro);
    degree = max(degree, d);
    return d;
}
```
