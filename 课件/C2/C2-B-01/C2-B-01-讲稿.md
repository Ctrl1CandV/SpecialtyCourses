## P5 改指针的三条规矩（约3分钟）

进入正课。这一节四个算法——逆置、倒数第k、条件删除、交换相邻——本质上是同一个动作：改指针。所以先约定三条规矩，后面每讲一个算法，都回来对照一遍。

第一条，**先接后断**。新结点的指针先接好，再改前驱的指针。次序一换，改完之后原来的链就丢了，C语言强化阶段画过内存图，你知道那意味着什么。

第二条，画图再写。任何改指针的操作，先在纸上画出改之前和改之后两张图，再照着图写代码，不要对着屏幕空想。推演页你都要拿纸跟着画，画熟了考场上在草稿纸上照样画。

第三条，改完检查孤立结点。改完问自己一句：有没有哪个结点没有人指向它了？有，就是漏了一句赋值。这条是查错用的，写完代码扫一眼，能拦住大部分断链。

这三条不是背的概念，是后面每个算法的检查单。接下来每讲一个，你就看这三条是怎么落到代码行的。

## P6 原地逆置的思想（约4分钟）

第一个算法：带头结点单链表的原地逆置，这是模板1，整个课段用得最多的一张卡。

思想一句话：把头结点后面的链整个断开，让它变成一个空表加一串待处理的结点；然后逐个把结点用头插法插回空表。头插每次都把新结点放在最前面，插完一串，顺序正好反过来。逆序这个性质，数据结构基础阶段讲头插法建表时你已经见过一次，当时是建表的副产品，这里拿它来当主角。

看代码 InvertedList。开头判空：L 本身是 NULL、或者只有头结点，直接返回。然后 p 指向第一个数据结点，L 的 next 置空，断成空表。循环体四行，次序是重点：temp 等于 p，把当前结点摘下来；p 等于 p 的 next，先存后继，这一句不能省，因为接下来头插那两句会改掉 temp 的 next，不先存就走不到下一个；然后两句头插，temp 接到 L 之后，L 转向 temp。

复杂度收尾：全程没有新开一个结点，只用 p 和 temp 两个指针，空间 O(1)；每个结点摘下重接一次，时间 O(n)。所以叫原地逆置，原地两个字就体现在空间上。

【停顿】设问一句：为什么动手之前第一句是 L 的 next 置空？不断开行不行？不行。不断开，头插进去的结点就接在原链的尾巴后面，整条链还是原顺序，逆置无从谈起。断成空表，头插才有地方插。

## P7 过程页：普通逆置动画（约4分钟）

这一页拿纸跟着画，PPT逐步放。屏幕上初始状态：L 指向 A 指向 B 指向 C。

第0步，断链：L 的 next 置空，现在是空表加 A、B、C 一串待处理结点，p 指着 A。

第1次头插：temp 指 A，p 移到 B；A 的 next 接住 L 的 next，也就是空；L 指向 A。现在链是 L 指向 A。

第2次头插：temp 指 B，p 移到 C；B 接到 L 之后，链成 L 指向 B 指向 A。

第3次头插：temp 指 C，p 移到空；C 接到 L 之后，链成 L 指向 C 指向 B 指向 A。p 为空，循环停。

【停顿】回头看第6页那个问题：循环里为什么先写 p 等于 p 的 next 再头插？因为头插那两句会覆盖 temp 的 next，把后继弄丢，先存下 p 的后继，才找得到下一个待处理结点。再对照三条规矩：先存后继再头插，是先接后断；每一步改完，A、B、C 个个有人指着，没有孤立结点。三条规矩在这四行里全用上了。

## P8 循环单链表逆置（约4分钟）

模板1的第一个变体：循环单链表逆置。代码你屏幕上看到的，和普通版几乎一样，只差两处，变体就靠这个记。

第一处，while 的终止条件：普通版是 p 不等于 NULL，循环版换成 **p 不等于 L**。道理很直接：循环链表里没有 NULL，最后一个结点的 next 指回头结点，顺着 next 走一圈会回到 L 自己。照抄 p 不等于 NULL 当条件，p 永远碰不到 NULL，死循环。数据结构基础阶段讲循环链表遍历时撞过这个坑，这里是同一个坑第二次出现，记住：循环链表的遍历终止条件永远是看指针是否回到 L。

第二处，循环结束后补一句 rear 的 next 指向 L。rear 在断链之前记下原来的第一个数据结点，就是现在的首元；逆置之后它变成最后一个结点，循环单链表的尾结点 next 必须指回头结点，这句就是把环接回去。没有它，逆置出来的只是一条断开的普通链，环的性质丢了。

除了这两处，逐个头插的过程一字不改。所以循环版不用单独背：先默普通版，再换终止条件、补接环，两处差异写顺手，这个变体就拿下了。

## P9 倒数第k：快慢指针（约4分钟）

第二个算法：输出倒数第 k 个元素。先讲方法一，快慢指针，模板2。

思想：q 先走 k 步，然后 p 和 q 一起往后走；q 走到表尾时，p 恰好落后 k 个结点，p 指的就是倒数第 k 个。原来求倒数第 k 个要先数表长再算位置，走两趟；这个办法一趟就完。

代码三段。第一段，q 先走 k 步：while 里两个条件，k 不为 0 管步数，q 不为空管越界。第二段，q 变成 NULL 就说明 k 超过了表长，返回 0，这是边界处理。第三段，p、q 同步走，直到 q 为空，输出 p 的数据。

【停顿】这一页最容易错的一点是 p 和 q 的出发点：两个**都从头结点 L 出发**，不是从第一个数据结点出发。为什么？头结点占一个位置，q 先走 k 步再一起走到尾，p 落后 k 个位置，正好落在倒数第 k 个数据结点上；要是都从 L 的 next 出发，结果会差一个位置。设问里的“头结点抵消”，抵消的就是这一位。起点不一致，是快慢指针法最常见的错。

复杂度：一趟 O(n)，空间 O(1)。

## P10 倒数第k：辅助栈与两法对比（约3分钟）

方法二，辅助栈，模板14。思路更直白：从头到尾把每个结点的指针全部压栈，然后弹 k 次，第 k 次弹出的就是倒数第 k 个。栈先进后出，表头先进压在栈底，表尾最后进在栈顶，弹 k 次正好从倒数第 k 个弹起。看代码，先全部压栈，再边弹边数，弹满 k 个输出；栈弹空了还没数到 k，返回 0。

两法对比，记三点。时间都是 O(n)，一样。空间不同：快慢指针只用两个指针，O(1)；辅助栈要把全部结点压进去，是 O(n)，拿空间换思路的直白。适用不同：题目只要倒数第 k 个，用快慢指针；题目要“倒数第 k 到倒数第 1 全部输出”这类变体，辅助栈一路弹到底全有了，快慢指针反而别扭。

所以这两个方法不是谁取代谁，是各管一类题。考场上先看题目要什么，再选法。

## P11 条件删除（约4分钟）

第三个算法，按条件删除，模板4。题目形态：删除链表中所有满足某条件的结点，比如删除所有大于 x 的结点，条件换成别的判断，算法骨架不动。

这个算法存在的原因就一句话：单链表没有指向前驱的指针，删 p 必须记住它的前驱 pre，否则摘了链，前驱那一端就接不回来。看代码 DeleteIf：pre 指头结点，p 指第一个数据结点。每次检查 p 的数据，大于 x 就摘链：先让 pre 的 next 跨过 p 接到 p 的 next，再 free 掉 p；然后关键一步，p 从 pre 的 next 重新取，pre 原地不动。不大于 x，pre 和 p 一起后移。

摘链的次序还是先接后断：先改 pre 的 next，再 free；反过来先 free，pre 的 next 读的就是已经回收的内存，值是乱的，还可能崩。这个错前面几页讲过，这里再犯就是同一个坑第三次。

【停顿】设问：删掉一个结点之后，pre 该不该跟着动？先记住你的判断，下一页画图验证，对错你都先押一个答案。

## P12 过程页：条件删除动画（约4分钟）

还是拿纸跟着画。链表是 3、9、5、12、7，条件是大于 8 就删，要删的是 9 和 12 两个。

初始：pre 指头结点 L，p 指 3。3 不大于 8，一起走：pre 指 3，p 指 9。

9 大于 8，删：pre 的 next 跨过 9 接到 5，free 掉 9。现在看仔细，这是本页的关键帧：**pre 不动**，还是指着 3；p 从 pre 的 next 重新取，指 5。为什么？因为下一个待检查的结点，现在紧跟在 pre 后面，p 只要从 pre 后面取就一定是它。

5 不大于 8，一起走：pre 指 5，p 指 12。12 大于 8，同样删：pre 的 next 接到 7，free 掉 12，pre 仍不动，p 重新指 7。

7 不大于 8，一起走，p 变成空，循环停。结果是 L 指向 3 指向 5 指向 7，9 和 12 被释放。

【停顿】对照上一页的问题：删掉结点之后，pre 不动，p 从 pre 后面重新取。如果删完还写 pre 等于 p，p 这会儿指着的下一个待检查结点就被跳过去了，该删的删不掉。材料原注释说的就是这句：只有不删除下一个元素的时候才移动 p。把这句和关键帧一起记住，比背整个循环体管用。

## P13 交换相邻两个结点（约4分钟）

第四个算法，交换相邻两个结点。材料给的是双链表版：给定 p 和 q，q 紧跟在 p 之后，把它们俩的先后次序对调。前提是 p 有前驱、q 有后继，带头结点的双链表天然满足，不用额外判。

六条赋值分三组，屏幕上每行一条。①②先把外部两端接好：p 的前驱的 next 指向 q，q 的后继的 prior 指回 p。③④再改 p、q 自身：p 的 next 指向 q 原来的后继，q 的 prior 指向 p 原来的前驱。⑤⑥最后互指：p 的 prior 指向 q，q 的 next 指向 p。

【停顿】设问：六条里哪两条必须最后做？⑤和⑥。**⑤⑥必须最后**，因为⑤一执行，p 的 prior 旧值就没了；⑥一执行，q 的 next 旧值就没了，而①②写的正是这两个旧值，提前做，①②再也写不出来。这和数据结构基础阶段双链表插入那句先接后断是同一条道理，也是三条规矩第一条的又一次体现。

复杂度：六条赋值，O(1)，没循环。这个算法考的不是复杂度，是你对指针次序的掌握，次序一乱整链就断，所以把它放在检查页的位置来记。

跟练题一：原地逆置（普通版）。

```c
void InvertedList(LinkList &L){
    if(L == NULL || L->next == NULL) return;
    LNode *p = L->next, *temp;
    L->next = NULL;                       // 先断成空表
    while(p != NULL){
        temp = p;                         // 摘下当前结点
        p = p->next;                      // 先存后继（否则下一步找不到）
        temp->next = L->next;             // 头插
        L->next = temp;
    }
}
```

跟练题二：快慢指针求倒数第 k。

```c
int findK(LinkList &L, int k){
    LNode *p = L, *q = L;
    while(k != 0 && q != NULL){ q = q->next; k--; }   // q 先走 k 步
    if(q == NULL) return 0;                            // k 超过表长
    while(q != NULL){ q = q->next; p = p->next; }      // 两个一起走
    printf("%d", p->data);
    return 1;
}
```

变式题 2算12：有序单链表删除大于 mink 且小于 maxk 的元素，条件删除同族，把模板4的判断换成区间条件即可。

```c
void DeleteRange(LinkList &L, int mink, int maxk){
    LNode *pre = L, *p = L->next, *temp;
    while(p != NULL){
        if(p->data > mink && p->data < maxk){
            temp = p; pre->next = p->next;  // 先摘链
            free(temp);
            p = pre->next;                  // pre 不动，p 重新取
        }else{ pre = p; p = p->next; }     // 不删才一起走
    }
}
```

要点：表有序，删完区间后可直接 break，不必扫到表尾；时间 O(n)、空间 O(1)。

// 交换相邻两个结点（双链表版）：q 紧跟 p，且 p 有前驱、q 有后继
void exchange(DNode *p, DNode *q){
    p->prior->next = q;
    q->next->prior = p;
    p->next = q->next;
    q->prior = p->prior;
    p->prior = q;
    q->next = p;
}

void InvertedList(LinkList &L){

    LNode *p = L->next, *temp;
    L->next = NULL;
    while(p != NULL){
        temp = p;
        p = p->next;

// 原地逆置（循环单链表）：差两处——终止条件 p != L，结尾 rear->next = L 接环
void InvertedList(LinkList &L){
    if(L == NULL || L->next == NULL) return;
    LNode *p = L->next, *temp; LNode *rear = p;
    L->next = NULL;
    while(p != L){
        temp = p;
        p = p->next;
        temp->next = L->next;
        L->next = temp;
    }
    rear->next = L;
}

// 输出倒数第 k 个：方法一 快慢指针

    while(k != 0 && q != NULL){ q = q->next; k--; }
    if(q == NULL) return 0;
    while(q != NULL){ q = q->next; p = p->next; }

}

// 输出倒数第 k 个：方法二 辅助栈
int findK(LinkList &L, int k){
    SqStack S; InitStack(S);
    LNode *p = L->next;
    while(p != NULL){ Push(S, p); p = p->next; }
    int i = 0;
    while(!IsEmpty(S) && i < k){ Pop(S, p); i++; }
    if(i == k){ printf("%d", p->data); return 1; }
    else return 0;
}

// 条件删除（前驱跟随）：删除所有大于 x 的结点
void DeleteIf(LinkList &L, int x){
    LNode *pre = L, *p = L->next, *temp;
    while(p != NULL){
        if(p->data > x){
            temp = p;
            pre->next = p->next;            // 摘掉 p
            free(temp);
            p = pre->next;                  // p 从 pre 后面重新取，pre 不动
        }else{
            pre = p; p = p->next;           // 不删时两个一起走
        }
    }
}
