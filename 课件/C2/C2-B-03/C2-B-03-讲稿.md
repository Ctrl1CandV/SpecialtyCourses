## P3 括号匹配：一个栈（约4分钟）

第一个应用：括号匹配。题目形态：给一个只含括号的字符串，判断左右括号是否配对完整。思想一句话：扫描字符串，遇左括号压栈，遇右括号弹栈比对——弹出的左括号必须和当前右括号是一对；配不上就是失配。

看代码 BracketMatch。循环里第一个分支拦左括号，压栈。第二个分支是重点：它必须是 **else if**，条件明确列出三种右括号，只拦右括号。为什么不能写成 else？写 else 的意思是"只要不是左括号就当右括号处理"，那么输入一个带操作数的式子，比如 a+(b\*c)，扫到字母 a 就会走 else 分支、去弹栈判失配，结果全错。处理字符序列时，"不是我要的左括号"和"是我要的右括号"是两件事，else 一笔带过就把这两件事混了。这一句是填空题和程序阅读题的设错点，记住这个反例。

右括号分支里面三行：栈空还遇右括号，右括号多了，返回假；弹栈取出栈顶左括号，类型不配，交叉失配，返回假。循环结束后的 return 也看一眼：返回的是 IsEmpty(S)。全配上，弹干净了，栈空；左括号多了，栈里剩东西，栈非空。一个返回值把结果说完了。

【停顿】设问：最后一句为什么写 return IsEmpty(S)，不直接 return true？——因为"扫描结束"只说明右括号都配掉了，左括号有没有多，得看栈空不空。想两秒，这是 P4 的主线。

复杂度：每个字符压或弹一次，O(n)；栈最坏存 n 个左括号，空间 O(n)。

## P4 三种失配情况（约2分钟）

接着上一页的问题，三种失配分开说，屏幕上这张表三行。

第一种，右括号多了：扫描中途栈已经空了，又遇到右括号，弹无可弹，"())" 里第二个右括号就是。第二种，类型交叉：栈不空，但弹出的左括号和当前右括号不是一对，"[(])" 走到中间的右方括号时，栈顶是左圆括号，圆配方，失配。第三种，左括号多了：右括号全配完了，扫到结尾栈里还剩左括号，"(()" 剩一个。

三种情况各自 return false，两个在中途，一个在结尾。结尾那句 return IsEmpty(S) 专管第三种，这是上页设问的答案。

【停顿】这一页是检查页：给你两个串先自己判——"[()]" 和 "[(])"，只差一个字符，结果一样吗？先押答案。……不一样：前者匹配，后者是表上第二种，类型交叉。判串的时候别只看括号个数，要看弹出配对的那一下。

## P5 中缀转后缀：规则四条（约4分钟）

表达式求值两连的第一连。先说要干什么：中缀表达式里运算符有优先级、有括号，机器不好直接算；转成后缀表达式——运算符跟在操作数后面——从头到尾扫一遍、只用一个栈就能求值。所以求值分两步：先把中缀转成后缀，再对后缀求值。这一页只讲转换规则，四条，屏幕上这张表。

遇操作数，直接输出，不进栈。遇左括号，压栈，等右括号来配对。遇右括号，弹栈并输出，一路弹到左括号为止；左括号弹出但不输出——这句是易错点，右括号自己也不输出，它只是来收摊的。遇运算符，把栈里优先级 **大于等于** 它的都弹出来输出，然后自己压栈。全扫完后，栈里剩下的运算符依次弹出输出。

【停顿】第二条设问：栈里的同级运算符要不要先弹出？要。"大于等于"三个字就是左结合：连续的加减从左往右算，所以栈里先进的同级运算符要先出。考试填空就爱抠这个"等于"。

代码层面两个守卫看讲义附录二的 ToPostfix：第三个分支的 while 里，GetTop 返回假就停，那是栈空保护；条件里 top 不等于左括号，是防误弹——转 1+(2\*3) 时，没有这句会把左括号当运算符弹出去输出，后缀串就脏了。第四个分支同样的守卫再管一次运算符的弹栈。

PPT 版面只放规则表，完整代码在课后发的讲义附录二里，对着规则逐行看，五分钟能看完。现在拿 1+(2\*3) 在纸上手转一遍，下一页动画逐步核对。

## P6 后缀求值：先弹的是右操作数（约4分钟）

第二连。后缀表达式求值，规则反而简单：遇数压栈；遇运算符，弹两个数，算完把结果压回去。全扫完，栈里只剩一个数，就是结果。

看代码 EvalPostfix。数直接压；运算符分支里两行 Pop 是重点：先 Pop 给 b，再 Pop 给 a，然后算 a 加 b、a 减 b。为什么要这个次序？栈是后进先出，后压进去的是表达式里靠右的操作数，**先弹的是右操作数**。减法和除法不对称，b 和 a 一搞反，5-3 算成 3-5，全盘皆错。这是本页最重要的一行，默写时把这两行 Pop 的次序写对。

屏幕上这版把 switch 写成了 if-else 链省行数，讲义附录二给的是 switch 原版，两版完全等价，考场上写哪种都对。

【停顿】设问：先弹出来的是左操作数还是右操作数？……右，栈后进先出。减除搞反就全错，刚讲过，别再错。

复杂度：每个字符压一次或弹两次压一次，O(n)；栈最坏 O(n)。

## P7 动画：A+B\*(C-D)-E/F 全过程（约4分钟）

这一页拿纸跟着画，PPT逐步放，两遍各写一遍栈状态。表达式 A+B\*(C-D)-E/F，第一遍转后缀。

从头扫：遇 A，输出 A，栈空。遇加号，压栈，栈里一个加号。遇 B，输出。遇乘号，栈顶加号优先级比乘号低，弹不动，乘号压栈，现在栈是加号、乘号。遇左括号，压。遇 C，输出。遇减号，栈顶是左括号，弹栈停止，减号压进去——屏幕上第一幅图就是这个状态：加、乘、左括号、减，栈顶是减号。遇 D，输出。

遇右括号，收摊：弹减号输出，再弹左括号、不输出，栈剩加号、乘号。遇第二个减号，栈顶乘号优先级高，弹输出；再加号，同级，**大于等于**，也弹输出；栈空，减号压入。遇 E，输出。遇除号，减号优先级低，除号压栈。遇 F，输出。扫描结束，收尾弹除号、弹减号。后缀串：ABCD-\*+EF/-。拿你的纸逐步核对。

第二遍求值，把字母换成数：A=1、B=2、C=5、D=3、E=4、F=2。1、2、5、3 依次入栈。遇减号，弹 3、弹 5，5-3=2 入栈——第二幅图就是这个状态，栈里 1、2、2。遇乘号，弹 2、弹 2，得 4。遇加号，弹 4、弹 1，得 5。4、2 入栈。遇除号，弹 2、弹 4，4÷2=2。遇减号，弹 2、弹 5，5-2=3。结果 3。代入原式验算：1+2×(5-3)-4÷2，等于 3，对上了。

两遍加起来十四个节拍，课后题就考这个，画的越熟越好。

## P8 判回文：一个返回值表达两种结局（约3分钟）

第三个应用，判回文，材料原文代码，讲之前先说思想：回文串正着读倒着读一样，后半段就是前半段的倒序；栈正好能把顺序倒过来。所以前半段压栈，后半段逐个弹出来比对。

看代码 IsPalindrome。前半段压栈：从头结点后面第一个元素起，压 n/2 个结点指针进栈，指针 p 走到后半段开头。奇数长度那句是边界：中间那个元素没人跟它比，跳过一个。然后后半段逐个比对：弹一个指针 q，q 的数据和 p 的数据不等就 break，相等两个指针一起后移。

妙处在最后的 return IsEmpty(s)。两种结局：失配时 break 出循环，栈里还剩没弹完的元素，栈非空，返回假；全匹配时，n/2 次弹栈刚好弹完，栈空，返回真。**return IsEmpty(s)** 一个返回值把两种结局都说了，不用设布尔标志。判回文的代码别的都好背，就这一句要理解着记。

复杂度：压弹各 n/2 次，O(n)；栈 O(n)。

## P9 双栈模拟队列：s2 空了才倒（约4分钟）

第四个应用，用两个栈实现队列。队列先进先出，栈后进先出，正好反的；反两次就正回来了。思想一句话：入队一律压 s1；出队从 s2 弹；s2 空的时候，把 s1 全部倒进 s2 再弹。s1 倒进 s2，顺序反一次；元素先压 s1、再倒 s2、最后弹出，两次反，出来的次序就是先进先出。

看代码。EnQueue2 一行，压 s1。DeQueue2：s2 非空直接弹；s2 空了，while 循环把 s1 全倒进 s2，再弹。倒完 s2 还是空，说明队空，返回假。

【停顿】设问：什么时候才把 s1 倒进 s2？——**只有 s2 空了才倒**。这一条是正确性关键：假如 s2 里还有旧元素就倒，新倒进来的元素排到栈顶，会比旧元素先弹出去，新旧顺序就乱了。均摊 O(1) 也是它挣来的：每个元素最多倒一次、弹一次，n 次入队配 n 次倒出，平摊到每次操作是常数。每次都倒，操作就变成 O(n)，那是错误写法不是慢写法。

## P10 从 BF 到 KMP：i 永不回溯（约5分钟）

最后一站，串匹配。数据结构基础阶段第6节讲过 KMP 的 next 手算，这一节只回答一个问题：为什么需要 KMP。不重复手算。

先看 BF，暴力匹配。主串指针 i、模式串指针 j 从头比，失配了怎么办？i 退回到本轮起点的下一个位置，j 归零，重新比。问题在于：本轮已经比对过的那些字符，下一轮又从头比了一遍。最坏情况，主串一长串 A、模式串前面一长串 A 结尾一个 B，每轮都比到模式串最后一个字符才失败，O(nm)。

KMP 的观察是：失配之前，主串里有一段已经和模式串的前 j-1 个字符对上了，这个事实下一轮换起点时丢掉了，可惜。next 数组把这个事实存下来：next[j] 是模式串前 j-1 个字符里，最长相等前后缀的长度加一。失配时主串指针 **i 永不回溯**，只把模式串的 j 退到 next[j]——因为模式串自己开头的那段前缀，正好等于刚才对齐过的那段后缀，直接从它后面接着比，主串一个字都不回退。最坏 O(n+m)，n 是主串长度、m 是模式串长度，一遍扫完。

屏幕上这张表三行：失配后谁动、依据、最坏时间，BF 和 KMP 对着记。

【停顿】设问：KMP 相比 BF 省在哪？——主串指针不回溯，已对齐的字符不再重复比。这句是答题话术，802 里串匹配常考 next 数组的手算与含义，手算回去看数据结构基础阶段第6节，那里一步一步推过。

## 附录一：课后题参考答案

跟练题一：括号匹配默写。

```c
bool BracketMatch(char str[], int n){
    SqStack S; InitStack(S);
    for(int i = 0; i < n; i++){
        if(str[i] == '(' || str[i] == '[' || str[i] == '{') Push(S, str[i]);
        else if(str[i] == ')' || str[i] == ']' || str[i] == '}'){   // 只处理右括号，其他字符跳过
            if(IsEmpty(S)) return false;                  // ① 右括号多了
            char top; Pop(S, top);
            if((top == '(' && str[i] != ')') ||
               (top == '[' && str[i] != ']') ||
               (top == '{' && str[i] != '}')) return false;  // ② 类型不匹配（交叉）
        }
    }
    return IsEmpty(S);                                    // ③ 栈非空说明左括号多了
}
```

跟练题二第一问：后缀求值默写（switch 版，与 PPT 上 if-else 链等价）。

```c
int EvalPostfix(char postfix[]){
    SqStack S; InitStack(S);
    for(int i = 0; postfix[i] != '\0'; i++){
        char c = postfix[i];
        if(c >= '0' && c <= '9'){ int x = c - '0'; Push(S, x); }
        else{
            int b, a; Pop(S, b); Pop(S, a);      // 注意次序：先弹的是右操作数
            switch(c){
                case '+': Push(S, a + b); break;
                case '-': Push(S, a - b); break;
                case '*': Push(S, a * b); break;
                case '/': Push(S, a / b); break;
            }
        }
    }
    int result; Pop(S, result);
    return result;
}
```

跟练题二第二问：A+B\*(C-D)-E/F 手工转换与求值（取值 A=1、B=2、C=5、D=3、E=4、F=2）。

第一遍，中缀转后缀，每步记栈与输出：

- 扫 A：输出 A。栈：空。
- 扫 +：栈空，压入。栈：+。
- 扫 B：输出 AB。栈：+。
- 扫 \*：栈顶 + 优先级低于 \*，不弹，压入。栈：+ \*。
- 扫 (：压入。栈：+ \* (。
- 扫 C：输出 ABC。栈：+ \* (。
- 扫 -：栈顶是 (，弹栈停止，压入。栈：+ \* ( -。
- 扫 D：输出 ABCD。栈：+ \* ( -。
- 扫 )：弹 - 输出 ABCD-；再弹 (，不输出。栈：+ \*。
- 扫 -：弹 \* 输出 ABCD-\*；弹 + 输出 ABCD-\*+；栈空，压入。栈：-。
- 扫 E：输出 ABCD-\*+E。栈：-。
- 扫 /：栈顶 - 优先级低于 /，压入。栈：- /。
- 扫 F：输出 ABCD-\*+EF。栈：- /。
- 收尾：弹 / 输出 ABCD-\*+EF/，弹 - 输出 ABCD-\*+EF/-。栈空。

后缀形式：ABCD-\*+EF/-。

第二遍，后缀求值，代入 A=1、B=2、C=5、D=3、E=4、F=2，扫描 1 2 5 3 - \* + 4 2 / -：

- 1、2、5、3 依次入栈。栈：1 2 5 3。
- 扫 -：弹 3（右操作数）、弹 5（左操作数），5-3=2 入栈。栈：1 2 2。
- 扫 \*：弹 2、弹 2，2×2=4 入栈。栈：1 4。
- 扫 +：弹 4、弹 1，1+4=5 入栈。栈：5。
- 4、2 依次入栈。栈：5 4 2。
- 扫 /：弹 2、弹 4，4÷2=2 入栈。栈：5 2。
- 扫 -：弹 2、弹 5，5-2=3 入栈。栈：3。

结果：3。验算：1+2×(5-3)-4÷2 = 1+4-2 = 3，一致。

```c
// 括号匹配：三种失配情况
bool BracketMatch(char str[], int n){
    SqStack S; InitStack(S);
    for(int i = 0; i < n; i++){
        if(str[i] == '(' || str[i] == '[' || str[i] == '{') Push(S, str[i]);
        else if(str[i] == ')' || str[i] == ']' || str[i] == '}'){   // 只处理右括号，其他字符跳过
            if(IsEmpty(S)) return false;                  // ① 右括号多了
            char top; Pop(S, top);
            if((top == '(' && str[i] != ')') ||
               (top == '[' && str[i] != ']') ||
               (top == '{' && str[i] != '}')) return false;  // ② 类型不匹配（交叉）
        }
    }
    return IsEmpty(S);                                    // ③ 栈非空说明左括号多了
}

// 中缀转后缀：Prior(c) 返回运算符优先级，( 在栈内优先级最高、在栈外最低
void ToPostfix(char infix[], char postfix[]){
    SqStack S; InitStack(S);
    int k = 0;
    for(int i = 0; infix[i] != '\0'; i++){
        char c = infix[i];
        if(c >= '0' && c <= '9') postfix[k++] = c;                 // 操作数直接输出
        else if(c == '(') Push(S, c);
        else if(c == ')'){
            char top;
            while(GetTop(S, top) && top != '('){ Pop(S, top); postfix[k++] = top; }
            Pop(S, top);                                            // 弹出左括号，不输出
        }else{
            char top;
            while(GetTop(S, top) && top != '(' && Prior(top) >= Prior(c)){
                Pop(S, top); postfix[k++] = top;
            }
            Push(S, c);
        }
    }
    char top;
    while(!IsEmpty(S)){ Pop(S, top); postfix[k++] = top; }
    postfix[k] = '\0';
}

// 后缀求值：先弹出的是右操作数
int EvalPostfix(char postfix[]){
    SqStack S; InitStack(S);
    for(int i = 0; postfix[i] != '\0'; i++){
        char c = postfix[i];
        if(c >= '0' && c <= '9'){ int x = c - '0'; Push(S, x); }
        else{
            int b, a; Pop(S, b); Pop(S, a);
            switch(c){
                case '+': Push(S, a + b); break;
                case '-': Push(S, a - b); break;
                case '*': Push(S, a * b); break;
                case '/': Push(S, a / b); break;
            }
        }
    }
    int result; Pop(S, result);
    return result;
}

// 双栈模拟队列：s1 负责入，s2 负责出，s2 空了才把 s1 全倒过去
SqStack s1, s2;
bool EnQueue2(int x){ return Push(s1, x); }
bool DeQueue2(int &x){
    if(!IsEmpty(s2)) return Pop(s2, x);
    while(!IsEmpty(s1)){ int t; Pop(s1, t); Push(s2, t); }   // 倒一次，顺序反一次
    if(IsEmpty(s2)) return false;
    return Pop(s2, x);
}

// 判回文：材料原文，前半压栈、后半逐个比对（SqStack 修正版）
bool IsPalindrome(LinkList L, int n){
    SqStack s; InitStack(s);
    LNode *q, *p = L->next;
    for(int i = 1; i <= n / 2; i++){ Push(s, p); p = p->next; }   // 前半压栈
    if(n % 2 == 1) p = p->next;                                   // 奇数跳过中点元素
    while(p != NULL){
        Pop(s, q);
        if(p->data != q->data) break;
        else p = p->next;
    }
    return IsEmpty(s);                                            // 栈空则为回文串
}
```
