## P2 2026 判拓扑序列：题面与关键认识（约3分钟）

第一道题，2026 年真题，12 分。屏幕上为题面：给一个由邻接表存储的图，以及一个序列 V1 到 Vn，判断这个序列是不是该图的一个拓扑序列。

先按暂停自己写，给你两分钟。

【停顿】认结构：邻接表，这道题的边表字段叫 nextarc；序列长度 n 默认等于顶点数。

这道题的钥匙是一个认识：**不需要真的做一遍拓扑排序再比较**。真排序当然也行——排完逐个对照，但代码量与时间都大。巧的做法是反过来：按给定序列的顺序去验证。

验证的依据是拓扑序列的充要条件：对每条边 v→u，v 在序列中都排在 u 前面。怎么检查？求出入度表，然后按序列顺序走：轮到顶点 u 时，如果它当前入度不是 0，说明还有前驱没排在它前面，序列非法；入度是 0 就合法，把它的所有后继入度减 1，继续。

12 分里这个"不真排序、按序模拟"的认识占思想分的大头。

## P3 2026 判拓扑：代码逐行（约3分钟）

代码屏幕上逐段走。第一段求全部入度：遍历每个顶点的边表，指向谁谁的入度加一——这是基础阶段第9节的 Indegree，2026 年这道题的第一步就是它。

第二段按序模拟：for 循环走给定序列，每轮取 u = seq[i]，判 indeg[u] != 0 就返回 false；否则遍历 u 的边表，把每个后继的入度减一。走完整个序列没返回 false，就是合法拓扑序列。

选模板13 入度表法，改条件就一处：把"入度 0 入栈、出栈输出"换成"按给定顺序检查入度是否为 0"。

边界：vexnum == 0 返回 false。复杂度：时间 O(|V|+|E|)——求入度扫一遍所有边表，模拟阶段每个顶点出队一次、每条边再被扫一次；空间 O(|V|) 入度数组。各配一句理由写进答案。

评分点：写成先排序再比较也能得大部分分，但阅卷的人一眼看出你没想到巧办法，思想分打折。

## P4 2025 经过 k 的路径：题面与拆解（约4分钟）

第二道题，2025 年真题。屏幕上为题面：给定一个邻接表表示的连通图，输出从顶点 u 到顶点 v 并经过顶点 k 的一条路径；如果不存在，输出 -1。图的存储结构题目给了完整的 ArcNode、VNode、ALGraph 定义。

先按暂停自己写，给你两分钟。

【停顿】认结构，两处。第一，这道题的边表字段叫 **next**，不是 nextarc——2026 那道叫 nextarc。规则还是基础阶段第9节立的那条：以题目给的为准，答题抄题目的字段名。第二，连通图、邻接表，要求输出一条具体路径。

拆解是这道题的钥匙："u 到 v 经过 k"等价于"u 能到 k"且"k 能到 v"——两段独立的可连性问题，各做一次 DFS 就行。为什么可以拆？因为路径可以拼：u 到 k 的一条路，接上 k 到 v 的一条路，中间在 k 处衔接。拼起来的走法可能在 k 之外有重复顶点，严格说题目要的是简单路径时要再处理，但 802 的标准解答就是拆两段，照这个写。

选模板7 DFS 回溯。最大的坑先埋在这：两段之间 visited 怎么处理——等下看代码。

## P5 2025 经过 k：两处复位（约5分钟）

代码两个函数。checkPath 是标准的 DFS 回溯：u == v 成功；标记 visited[u]；递归所有未访问的邻居，有一条成功就层层 return true；全部失败，visited[u] = false 复位再返回 false。这个复位就是"回溯"——这条路走不通，退回去之前把自己的标记擦掉，让别的路还能用这个顶点。

IsExistPathGoBy 是主函数：先判图空；准备 visited；第一段 checkPath(u, k)——u 到不了 k 直接 false；然后**把 visited 全部清零**；第二段 checkPath(k, v)。

【停顿】两段之间为什么必须全部复位？第一段搜 u 到 k 时，沿途标记了一堆 visited。如果不清，第二段从 k 出发，会发现很多顶点"已访问"——但那些标记是第一段留下的，与第二段无关。第二段的 DFS 会绕开它们，明明存在的路径被判成不存在。这是这道题最容易丢的分，2 到 3 分就在这一行清零上。

一个勘误处置说明：材料原文写 bool visited[G.vexnum] = {false}，变长数组带初始化列表，与伪代码约定不符（约定里只有 ={0} 可以简写）。课件改成固定长度数组 MaxVertexNum 加循环赋值。答题时两种写法都出现过的话，跟着题目给的来，自己写就用固定长度，稳。

复杂度：单次 DFS 是 O(|V|+|E|)，答题写这个并说明是单次代价即可；输出具体路径的话，加一个 path 数组随递归记录，成功时打印，思想同一套。

## P6 2024 长度 k 的路径：depth 参数（约4分钟）

第三道题，2024 年。题面一句话：判断在无向图中是否存在长度为 k 的路径，邻接表存储。长度为 k 指 k 条边。

先按暂停，这道题给你一分钟——它比 2025 那道简单。

认结构：无向图、邻接表，字段名题目给的也是 next。选模板7 DFS 回溯。

改条件一处：递归多带一个 depth 参数——当前走了几条边。每往下一层 depth+1，depth == k 时成功返回 true。这个"递归中携带额外信息"与上一节最长路径的 pathLen 同源：路径长度不是由返回值拼出来的，是往下传的参数。

两个边界是评分点。第一，k 的合法范围：k < 1 或 k > vexnum-1 直接返回 false。【停顿】为什么上界是 vexnum-1？简单路径顶点不重复，k 条边需要 k+1 个不同顶点，最多 n 个顶点就是 n-1 条边。第二，这道题没有给定起点，要**枚举所有起点**，每个起点开始前把 visited 全部清零——不清零的话，上一个起点用过的标记会干扰下一个。

一个小细节：材料代码在成功返回前也做了 visited[i] = 0 的复位。找到答案就层层返回时其实可以不复位（整个搜索结束了），但写上不出错，照着写。

复杂度：最坏要回溯全部路径，指数级；答题写"单次 DFS O(|V|+|E|)，最坏情况需回溯多条路径"并说明即可，空间 O(|V|)。

## P7 两道路径题对比（约3分钟）

2025 与 2024 放一起对比，屏幕上这张表。同一个模板7 DFS 回溯，三处不同。

起终点：2025 给定 u、v 与必经点 k，2024 任意起点要枚举所有顶点。携带信息：2025 拆两段，2024 带 depth。停止条件：2025 是到达目标顶点，2024 是 depth 等于 k。visited 复位：2025 是回溯复位加两段之间全部复位，2024 是回溯复位加每个起点前清零。

## P8 2023 像素距离图：题面（约3分钟）

第四道题，2023 年，当年最难的一道。屏幕上为题面：n×m 的矩形位图，每个像素非白即黑，至少有一个白像素；两像素距离是曼哈顿距离，行差加列差的绝对值；设计时间复杂度尽可能低的算法，计算每个像素到最近白像素的距离。输入输出格式题目给了。

先按暂停，这道题给你三分钟——重点想"时间尽可能低"这五个字。

【停顿】认结构：二维 01 数组。"每个黑像素到最近白像素的距离"——网格图上无权最短距离，BFS 的看家本领，模板8。

朴素做法很直接：对每个黑像素各做一次 BFS，找到最近的白像素。复杂度多少？n×m 个像素，每次 BFS 是 O(nm)，总共 O(n²m²)。n 和 m 到 1000 的话，这是 10 的 12 次方，必然超时。

题目说"时间复杂度尽可能低"，就是在排除这个做法。提示到这，接下来的突破口自己先想一分钟：能不能只做一次 BFS？

## P9 2023 像素距离：多源 BFS 的突破口（约4分钟）

突破口是一个"反过来"：不是每个黑像素出发去找白像素，而是**所有白像素同时出发往外扩散**。

具体做法：第一步，所有白像素先全部入队，dist 置 0；其余像素 dist 置 -1，表示未访问。第二步，普通 BFS 逐层扩散：出队一个像素，看它四个方向的邻居，越界的跳过、已访问（dist 不是 -1）的跳过，剩下的 dist 设为当前像素的 dist 加 1，入队。

【停顿】为什么这样算出来的 dist 就是"到最近白像素的距离"？因为 BFS 逐层扩散：所有白像素同时起跑，第 1 层是距某个白像素 1 步的全部像素，第 2 层是 2 步的……每个黑像素第一次被扩散到时，一定是离它最近的那个白像素的波先到达，那一层的层号就是最近距离。多源与单源只差第一步，其余完全一样。

两个技巧。第一，dist 的 -1 兼作 visited，省一个数组——"未访问"与"距离未定"正好是同一件事。第二，队列里存一维编号 i\*m+j：材料的 SqQueue 只存一个 int，取出时用除 m 与模 m 还原坐标，这是"元素类型按需替换"约定的变通。

复杂度：时间 O(nm)，每个像素入队出队各一次；空间 O(nm)，队列最坏存一层。从 O(n²m²) 降到 O(nm)，这就是"尽可能低"的答案。

## P10 过程页：3×4 位图逐层扩散（约4分钟）

这一页拿纸跟着画。屏幕上是一个 3×4 位图的逐层扩散图，四格分别是第 0 层、第 1 层、第 2 层与最终距离矩阵。

第 0 层：所有白像素 dist=0，全部入队——注意是全部先入队，再开始扩散，不是入一个扩一个。

第 1 层：出队白像素，四个方向的黑邻居 dist=1，入队。第 2 层：出队 dist=1 的像素，它们未访问的邻居 dist=2，入队。以此类推，直到队列空。

你跟着把每层的 dist 数组写出来，与最终矩阵对照。代码里仅有的两个判断：越界 continue、已访问 continue——dist[nx][ny] != -1 就是已访问。

【停顿】检查一个理解：如果两个白像素同时向中间的黑像素扩散，谁先到算谁的？答案是同一层的波同时到，dist 一样，谁先入队都行——第一次被访问时写入，之后 != -1 就跳过，不会覆盖。

## P11 2023 像素距离：完整代码与评分点（约4分钟）

完整代码屏幕上走一遍。dir 数组存四个方向，避免写四段重复代码。PixelDist 两个阶段：双层循环初始化——白的 dist=0 入队，黑的 dist=-1；然后 while 队不空，出队、还原坐标 x=cur/m、y=cur%m，四方向循环，一个 continue 拦越界与已访问，剩下的 dist 加一入队。

边界：题目保证至少一个白像素，队列不会一开始就空；n 或 m 为 0 时循环不进，安全。

复杂度写进答案：时间 O(nm) 每像素入队出队各一次；空间 O(nm) 队列最坏存一层加 dist 数组。

【停顿】这道题的评分点分布很特别：想到"反向扩散"，思想分拿满；写成对每个黑像素做 BFS，思想分能拿一部分（毕竟也是 BFS），但复杂度分全丢。"反过来从白像素扩散"这五个字值大半的思想分——考场上遇到"每个点到最近某类点的距离"，条件反射想多源 BFS。

## P13 选讲：2022 最小半径生成树（约2分钟）

2022 年还有一道图的难题，选讲：从根到叶子的最大距离称为树的半径，给定无向连通图，找出半径最小的生成树。

两个方向各一句话。方向一，枚举根加 BFS：以每个顶点为根做一次 BFS 生成树，BFS 的最大层号就是这个根下的半径，取最小的那棵；时间 O(n(n+e))。依据是 BFS 树里每个顶点到根的距离就是最短距离，所以以 v 为根的最短路径树就是 v 出发的最小半径生成树。方向二，图的中心：Floyd 求全源最短路径，每个顶点算离心率（到所有点距离的最大值），离心率最小的顶点是图的中心，以它为根做 BFS 树；时间 O(n³)。

这道题材料没有解答，难度高。考场策略：先用方向一写，它更好写；时间不够可以先跳过——它的核心动作 BFS 生成树与 Floyd 都在强化阶段第7节讲过，剩下的只是组合。

## P14 小结：图题认题的三个信号（约2分钟）

收一下。图题认题三个信号。信号一，"验证序列"——模板13 入度表，按序模拟不真排序。信号二，"经过某点"或"长度为 k"——模板7 DFS 回溯，拆段或带 depth，盯住 visited 的复位时机。信号三，"最短距离"或"尽可能低"——模板8 BFS，多源就全部源点先入队。

## 附录一：课后题参考答案

真题重写：2023 像素距离图完整三件套。

思想段：直接对每个黑像素做 BFS 是 O(n²m²)，超时。反过来从所有白像素同时做多源 BFS：全部白像素先入队且 dist=0，其余 dist=-1 兼作未访问；逐层扩散，每个像素第一次被访问时的层号就是它到最近白像素的距离。队列存一维编号 i\*m+j，取出时还原坐标。

```c
int dir[4][2] = {{-1,0},{1,0},{0,-1},{0,1}};
void PixelDist(int g[][MaxM], int dist[][MaxM], int n, int m){
    SqQueue Q; InitQueue(Q);
    for(int i=0;i<n;i++) for(int j=0;j<m;j++){
        if(g[i][j]==1){ dist[i][j]=0; EnQueue(Q, i*m+j); }
        else dist[i][j]=-1;
    }
    while(!IsEmpty(Q)){
        int cur; DeQueue(Q,cur);  int x=cur/m, y=cur%m;
        for(int d=0;d<4;d++){
            int nx=x+dir[d][0], ny=y+dir[d][1];
            if(nx<0||nx>=n||ny<0||ny>=m||dist[nx][ny]!=-1) continue;
            dist[nx][ny]=dist[x][y]+1;  EnQueue(Q, nx*m+ny);
        }
    }
}
```

复杂度段：时间 O(nm)，每个像素入队出队各一次；空间 O(nm)，队列最坏存一层。

变式题答案要点：

1. 7算18 长度 k 的简单路径：与课上 2024 题同码；要输出路径则加 path 数组随递归记录，成功时打印 path[0..depth]。
2. 7算19 u 到 v 的所有简单路径：DFS 回溯不短路——找到一条先输出，visited 复位后继续试别的路，直到全部枚举完。
3. 7答9 全部拓扑序列：入度表加回溯——每轮把当前所有入度 0 的顶点各试一次（选它输出、后继减 1、递归），返回后恢复入度与输出，枚举全部合法顺序。
4. 7选28 拓扑序列个数：在 7答9 的枚举上计数；序列唯一当且仅当每轮入度 0 的顶点恰好一个。
5. 八连通变式：dir 扩为 8 个方向（加 {±1,±1} 四个斜向），越界与已访问判断不变。

```c
// 2026 判拓扑序列（模板13 验证形态）
bool IsTopoSeq(ALGraph G, int seq[], int n){
    if(G.vexnum == 0) return false;
    int indeg[MaxVertexNum] = {0};
    for(int i=0;i<G.vexnum;i++)
        for(ArcNode *p=G.vertices[i].firstarc;p;p=p->nextarc) indeg[p->adjvex]++;
    for(int i=0;i<n;i++){
        int u=seq[i];
        if(indeg[u]!=0) return false;
        for(ArcNode *p=G.vertices[u].firstarc;p;p=p->nextarc) indeg[p->adjvex]--;
    }
    return true;
}

// 2025 经过 k 的路径（模板7 拆两段，字段名按题目用 next）
bool checkPath(ALGraph G, int u, int v, bool visited[]){
    if(u==v) return true;
    visited[u]=true;
    for(ArcNode *p=G.vertices[u].firstarc;p;p=p->next)
        if(!visited[p->adjvex] && checkPath(G,p->adjvex,v,visited)) return true;
    visited[u]=false; return false;
}
bool IsExistPathGoBy(ALGraph G, int u, int k, int v){
    if(G.vexnum==0||G.arcnum==0) return false;
    bool visited[MaxVertexNum];
    for(int i=0;i<G.vexnum;i++) visited[i]=false;
    if(!checkPath(G,u,k,visited)) return false;
    for(int i=0;i<G.vexnum;i++) visited[i]=false;      // 两段之间全部复位
    return checkPath(G,k,v,visited);
}

// 2024 长度 k 的路径（模板7 带 depth）
bool DFS(ALGraph &G, int i, int depth, int k, int visited[]){
    if(depth==k) return true;
    visited[i]=1;
    for(ArcNode *e=G.vertices[i].firstarc;e;e=e->next){
        int v=e->adjvex;
        if(!visited[v] && DFS(G,v,depth+1,k,visited)){ visited[i]=0; return true; }
    }
    visited[i]=0; return false;
}
bool existsKSimplePath(ALGraph &G, int k){
    if(k<1 || k>G.vexnum-1) return false;
    int visited[MaxVertexNum];
    for(int i=0;i<G.vexnum;i++){
        for(int j=0;j<G.vexnum;j++) visited[j]=0;
        if(DFS(G,i,0,k,visited)) return true;
    }
    return false;
}
```
