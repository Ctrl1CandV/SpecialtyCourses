## P2 本节四题的共同难点（约3分钟）

树题的遍历骨架大家都会写——强化阶段第4、5节把递归三件套、层序、中序都练熟了。真题拉开差距的地方不在骨架，在"除了遍历还要带什么"。

屏幕上这张表就是本节的地图：判 BST 带一个 prev 值，模板15；繁荣度带层号与本层计数，模板6；最长路径带 path 与 maxPath 两个数组，模板5 的变体；建树带四个下标边界，模板12。

【停顿】所以拿到一道树题，第一个问题不是"怎么遍历"，是"答案能不能由左右子树拼出来"。能拼，套递归三件套，终止值与合并方式定一下就写完了；不能拼——比如判 BST，整棵树的答案不是左右子树答案的简单合并——就想想要携带什么全局信息，用引用或者全局变量带下去。

这个"先问携带什么"的思考顺序，就是本节要训练的东西。四道题按携带的信息分类讲，分类本身就是教学目标。

## P3 2024 判 BST：题面与第一认识（约3分钟）

第一道题，2024 年真题。屏幕上为题面：编写代码及思想，判断一棵树是否为二叉排序树，结构体题目已给——普通的二叉链表，data、lchild、rchild。

先按暂停自己写，给你两分钟。提示一个方向：prev 要跨递归层共享，想想它该怎么传。

【停顿】对一下认结构与选模板。结构没有坑，字段与材料一致，返回 1 是、0 不是。

第一认识是解题的钥匙：BST 的中序序列严格递增。所以判 BST 不需要每个结点跟全树比——那是 O(n²) 的笨办法；中序走一遍，比较相邻两个值就够，O(n)。

选模板：模板15 中序加 prev。骨架强化阶段第8节讲过：中序遍历里加两行，当前值与 prev 比较、更新 prev。

## P4 2024 判 BST：代码逐行与两个坑（约6分钟）

代码屏幕上逐行走。先说结构：checkBST 递归函数加 JudgeBST 入口。入口只做一件事——初始化 prev，然后调 checkBST。

递归体五行：空结点返回 1；递归左子树，左子树不是 BST 直接返回 0，这是短路——左边已经不行了，右边不用看；当前值与 prev 比较，小于等于就返回 0；更新 prev 为当前值；递归右子树并返回它的结果。

两个坑，都是真题评分点。

坑一，prev 必须用引用。【停顿】为什么？prev 是跨递归层共享的状态：左子树最右那个结点的值，要传给根结点做比较。值传递的话，每层递归各有一份 prev 的副本，左子树里更新的 prev 出了那层就丢了，根结点比较用的还是旧值。所以参数写 int &prev。这和最长路径里 maxLen 用引用是同一个道理——凡是递归途中要累积或共享的信息，都用引用。

坑二，prev 的初值。材料写的是 -1，这隐含了一个假设：所有结点值都大于 -1。树里有 0 或者负数，第一个结点就会误判。处置两个都行：用 INT_MIN（需要 limits.h），或者在答案里写明一句"设结点值均为正整数，prev 初值取 0"。这个假设必须写在答案里——写出来是严谨，不写是隐患，阅卷的人看得到你想没想过。

还有一个材料的细节：JudgeBST 调用 checkBST 时后者还没声明，标准 C 里要先声明。课件的代码第一行补了声明，答题时照着写。

复杂度：时间 O(n) 每结点访问一次；空间 O(树高) 递归栈，最坏 O(n)。

## P5 2024 繁荣度：从求宽度改三处（约5分钟）

第二道题，也是 2024 年。题面一句话：计算二叉树的繁荣度，定义是每一层的结点数乘以该层的层数，全部求和。

选模板：模板6 层序加 last 分层。求宽度的代码强化阶段第5节写过——层序遍历，front > last 时结算本层。繁荣度就是它的变体。

这一页是"改条件"的标准示范：从求宽度改三处。改动一，maxwidth 换成累加器 total——宽度是取 max，繁荣度是累加。改动二，加一个 height 计数器，从 1 起——根在第 1 层，与题目"层数"的定义对齐。改动三，每层结算时 total += height \* width，然后 height 加一、width 清零。

三处改完，代码就是屏幕上这段。你对照求宽度的版本看，骨架一个字没动：队列、front、rear、last、front > last 结算，全部保留。

【停顿】这就是 802 命题的本质——模板加改条件。考场上认出"这是求宽度的变体"，三处改动自己就列出来了，不需要从零想。

边界：空树返回 0，开头的 if 处理了；height 从 1 起，如果题目定义根在第 0 层就从 0 起——跟着题目走。

复杂度：时间 O(n) 每结点入队出队各一次；空间 O(n) 队列最坏存一层。评分点最容易丢的是 height 的起点与题目层数定义不一致，差一层全题的乘数就错了。

## P6 2025 最长路径：题面与参数设计（约6分钟）

第三道题，2025 年。屏幕上为题面：给定一棵二叉树，输出从根结点到叶子结点的最长路径，打印路径的结点值，并输出该路径的长度。

这道题有个特别的地方：题目把骨架给了一半——BiTNode 定义、longestPath 与 findLongestPath 两个函数签名都给了。【停顿】拿到这种题第一件事是看题目给了什么：签名里参数的传递方式就是出题人给你的提示。

看签名：path 数组、pathLen 是 int 值传递、maxPath 数组、maxLen 是 int &引用。为什么 pathLen 值传递而 maxLen 引用？这是本题的核心设计，讲透了这道题就通了。

pathLen 值传递：每层递归拿到的是自己的副本，path[pathLen++] 只改本层的副本；从左子树递归回来，本层的 pathLen 还是原来的值——自动恢复，不需要写任何回退代码。路径数组 path 本身是共享的，但递归进右子树时 path[pathLen] 会被右子树的结点覆盖，正好是我们想要的：每层只管往自己的位置写。

maxLen 引用：最长长度要被叶子层的比较结果改写，并且改完要带回来。值传递的话，叶子处更新了 maxLen，出了那层就丢了。

所以分工是：**pathLen 要每层独立、自动恢复，用值传递；maxLen 要跨层累积、子层能改，用引用**。这个对比正是C语言强化阶段引用与传参那一节的知识，在真题里的直接应用。

代码主体：空结点返回；当前结点写进 path、pathLen 加一；到叶子（左右都空）才结算——pathLen 大于 maxLen 就更新 maxLen 并把 path 拷贝到 maxPath；不是叶子就递归左右。findLongestPath 入口初始化后调用，最后打印 maxPath 与 maxLen。

评分点：题目两个要求——"输出路径长度"与"打印路径结点值"，只做一个丢一半分。

## P7 过程页：最长路径的递归（约4分钟）

这一页拿纸跟着画。屏幕上这棵 7 结点的树：根 1，左 2 右 3，2 的左 4 右 5，3 的左 6 右 7。四条根到叶的路径 1-2-4、1-2-5、1-3-6、1-3-7，长度都是 3，最长路径输出第一条找到的即可。

走递归。进 1：path=[1]，本层 pathLen=1，不是叶子，递归左。进 2：path=[1,2]，本层 pathLen=2，递归左。进 4：path=[1,2,4]，pathLen=3，是叶子——3 大于 maxLen 的 0，更新 maxLen=3，maxPath 拷贝 [1,2,4]。

关键一步来了：从 4 返回到 2 那一层。【停顿】2 那层的 pathLen 是多少？还是 2。因为 pathLen 是值传递，4 那层的 pathLen=3 是它自己的副本，2 这层的副本没被改过。自动恢复，不用写 pathLen--。

接着 2 递归右子树 5：path[2]=5 覆盖掉 4——path 数组是共享的，但覆盖的正好是"本层之后的位置"，前面 [1,2] 没动。5 是叶子，pathLen=3 不大于 maxLen=3，不更新。返回 1，同样自动恢复，递归右子树 3，6、7 同理。

最终 maxPath=[1,2,4]，maxLen=3。你把每层的 pathLen 写在纸上，看它怎么"各管各的"，值传递的自动恢复就看清了。

复杂度：时间 O(n) 每结点一次；空间 O(树高) 递归栈，加 path 与 maxPath 两个 O(n) 数组。

## P8 2026 建树：题面与认结构（约4分钟）

第四道题，2026 年，10 分。屏幕上为题面：设一棵二叉树中结点的值互不相同，其先序序列和中序序列分别存于两个一维数组 A[1...n] 和 B[1...n] 中，试编写算法建立该二叉树的二叉链表。

先按暂停自己写，10 分的题给你四分钟。

【停顿】认结构，两处关键。第一，**下标从 1 起**——A[1..n]，这是题目给的基准，与我们材料里 0 起的写法不同。四个下标边界全部按 1 起算，调用入口是 Build(T, A, B, 1, n, 1, n)。认结构这一步看漏下标起点，边界全错。

第二，"结点值互不相同"不是废话，是算法成立的前提——中序里定位根靠的是值相等，值有重复就定位不唯一。这个前提要写进思想段：一句"由结点值互不相同，根在中序中的位置唯一"，这是采分点。

选模板：模板12 递归建树区间划分。四步骨架基础阶段第7节讲过：先序第一个是根；中序定位 k；leftLen = k - inL；用 leftLen 把先序也切两段，递归建左右。

## P9 过程页：区间划分（约4分钟）

这一页拿纸跟着画。例子：先序 A = 1 2 4 5 3，中序 B = 4 2 5 1 3，下标都从 1 起。屏幕上两个数组图，上面是先序（高亮根）、下面是中序（高亮根的位置）。

第一步，根是先序第一个，A[1]=1。在中序里找 1 的位置：B[4]=1，k=4。中序里 k 左边 B[1..3]=4 2 5 是左子树，右边 B[5..5]=3 是右子树。

第二步，leftLen = k - inL = 4 - 1 = 3，左子树 3 个结点。

第三步，用 leftLen 切先序：左子树的先序是 A[2..4] = 2 4 5，右子树的先序是 A[5..5] = 3。这一步是最容易错的——左子树在先序里紧跟根，长度正好 leftLen。

第四步，递归。左子树：先序 2 4 5、中序 4 2 5，根是 2，中序定位 k=2，leftLen=1，2 的左是 4、右是 5。右子树：先序 3、中序 3，单结点。

建出来的树：1 的左 2 右 3，2 的左 4 右 5——正是基础阶段第7节用过的那棵树，先序中序也一致，你可以互相验证。

四个边界随递归不断缩小：preL > preR 时区间为空，返回 NULL，这是终止条件。

## P10 2026 建树：代码与复杂度（约3分钟）

代码屏幕上逐段过。终止：preL > preR 返回 NULL。建根：malloc 一个结点，data 赋 A[preL]。定位：k 从 inL 开始扫，while B[k] != A[preL] 就 k++——这里用了"值互不相同"的前提，扫到的第一个相等就是唯一位置。算 leftLen = k - inL。两段递归：左子树先序 preL+1 到 preL+leftLen、中序 inL 到 k-1；右子树先序 preL+leftLen+1 到 preR、中序 k+1 到 inR。返回 T。

【停顿】四个边界最容易错一个。考场的保命动作：草稿上画两个数组，把 preL、preR、inL、inR、k 五个位置标出来，左右两段的四个端点从图上直接读，不要心算。

复杂度：时间 O(n²)——每层递归定位根要在中序里扫一遍，最坏扫 n 次、共 n 个结点。空间 O(n) 递归栈，最坏单支树。

加分思路写一句进思想段：用哈希表存"中序的值到下标"的映射，定位从 O(n) 降到 O(1)，总体 O(n)。写不写代码都行，思路点到就是加分项。

10 分的构成大约思想 2 到 3、代码 5 到 6、复杂度 1 到 2。

## P11 四题的评分点（约2分钟）

四题的评分点汇总在屏幕表里。判 BST 最容易丢：prev 初值 -1 的假设没声明，或者 prev 没用引用——这两个各值 1 到 2 分。繁荣度最容易丢：height 起点与题目层数定义不一致，乘数全错。最长路径最容易丢：两个输出要求只做了一个。建树最容易丢：四个边界错一个，或者忘写"值互不相同"的前提。

四题共同的采分习惯：把"携带的信息"写进思想段。判 BST 写"中序遍历时用 prev 记录前驱值"，繁荣度写"层序遍历中维护层号与本层结点数"，最长路径写"path 记录当前路径、maxPath 记录最长，pathLen 值传递、maxLen 引用传递"，建树写"递归携带四个下标边界"。思想段就是把你携带什么、怎么携带说清楚。

## P12 一题多解：每题知道第二条路（约2分钟）

每题至少知道一条备选路，考场上第一条卡住时能换。

判 BST 另解：中序遍历把序列存进数组，再检查是否严格递增。空间 O(n)，但思路直白，想不起 prev 引用版就写这个，照样满分。繁荣度另解：递归按层统计，多传一个层号参数与一个每层计数数组。最长路径另解：先求树高 h，再找一条长度等于 h 的路径，两趟递归，不用双数组。建树另解：后序加中序——定根改成后序最后一个，区间划分不变；层序加中序难一档，配合队列逐层定根。

答题写一种就行。知道第二条路的价值不是写两份，是心里不慌。

## 附录一：课后题参考答案

真题重写：2026 先序中序建树（10分）完整三件套。

思想段：由结点值互不相同，根在中序中的位置唯一。先序首元素为根；在中序中定位根的位置 k，k 左边为左子树的中序、右边为右子树的中序；leftLen = k - inL 为左子树结点数，用它把先序也切成左右两段；递归构造左右子树。可用哈希表把定位降到 O(1)。

```c
BiTree Build(BiTree &T, int A[], int B[], int preL, int preR, int inL, int inR){
    if(preL > preR) return NULL;
    T = (BiTNode*)malloc(sizeof(BiTNode));
    T->data = A[preL];
    int k = inL;
    while(B[k] != A[preL]) k++;
    int leftLen = k - inL;
    Build(T->lchild,  A, B, preL+1, preL+leftLen,   inL, k-1);
    Build(T->rchild, A, B, preL+leftLen+1, preR, k+1, inR);
    return T;
}
// 调用入口：Build(T, A, B, 1, n, 1, n)——题目下标 1 起
```

复杂度段：时间 O(n²)，每层定位根需扫中序；空间 O(n)，递归栈。哈希表优化后时间 O(n)。

变式题答案要点：

1. 6答28 中序+后序建树：定根改为后序最后一个 B[preR]；中序定位与 leftLen 切分不变；左右子树的后序段用 leftLen 切。
2. 6答29 层序+中序建树：层序第一个是根；用队列逐层处理——每个结点在中序里定位后，其左右子段在层序里的首元素分别是左右孩子，入队继续。
3. 6算21 输出长度等于 k 的所有路径：与最长路径同骨架，把"叶子处比较 maxLen"改成"叶子处判 pathLen==k 则输出 path[0..pathLen-1]"；要输出全部路径，不能短路。
4. 6算20 繁茂度：与繁荣度同族，结算式按题目定义改（例如层号平方乘结点数），骨架一字不动。
5. 9算7 判 BST：模板15；对照点——prev 用引用、初值处理负数假设（INT_MIN 或声明正整数）、严格递增用 <=。

int JudgeBST(BiTree T){
    int prev = INT_MIN;                          // 或声明"结点值均为正整数"后取 0

}
int checkBST(BiTNode *node, int &prev){
    if(node == NULL) return 1;
    if(!checkBST(node->lchild, prev)) return 0;
    if(node->data <= prev) return 0;
    prev = node->data;
    return checkBST(node->rchild, prev);

// 2024 繁荣度（材料原文，模板6 改三处）
int prosperity(BiTree T){
    if(T == NULL) return 0;
    int front = 0, rear = -1, last = 0;
    BiTree Q[MaxSize], p;  Q[++rear] = T;
    int total = 0, width = 0, height = 1;
    while(front <= rear){
        p = Q[front++];  width++;
        if(p->lchild != NULL) Q[++rear] = p->lchild;
        if(p->rchild != NULL) Q[++rear] = p->rchild;
        if(front > last){ total += height * width; last = rear; height++; width = 0; }
    }
    return total;
}

// 2025 最长路径（材料原文，题目给了签名）
void longestPath(BiTree node, int path[], int pathLen, int maxPath[], int &maxLen){
    if(node == NULL) return;
    path[pathLen++] = node->data;
    if(node->lchild == NULL && node->rchild == NULL){
        if(pathLen > maxLen){
            maxLen = pathLen;
            for(int i = 0; i < maxLen; i++) maxPath[i] = path[i];
        }
    }else{
        longestPath(node->lchild,  path, pathLen, maxPath, maxLen);
        longestPath(node->rchild, path, pathLen, maxPath, maxLen);
    }
}
