## P2 课段导学：这个课段的位置（约2分钟）

先看这个课段管哪两块分。算法分析题 3 道 30 分，这个课段用 17 道真题逐道走四步法，2020 到 2026 年考过的每一道都在这里讲评；程序阅读题约 20 分，第7节课专门讲它的三类考法与各自的做法。

为什么敢说 17 道真题就够了？因为通读这七年的题，全部由经典模板加条件改写而来——链表 6 道、图 5 道、树 4 道、查找 1 道、排序 1 道。题目每年在变，模板从来没变过。所以认模板的能力就是这 30 分的能力。

学法与前两个阶段不一样，先说在前头：每道真题我都先给题面、让你按暂停自己写，然后才讲评。【停顿】为什么必须先自己写？因为不先写，看讲解时会产生"我懂了"的错觉——看懂和写得出是两回事，考场上要的是写得出。

## P4 课段导学：怎么听这个课段（约1分钟）

每道真题的讲法固定四步：给题面按暂停、报结构与模板、逐段改条件、补边界给三件套与评分点。听讲评时重点听两处：从模板到这道题改了哪几处、这道题最容易丢的是哪一分。

## P5 答题三件套：书写格式与分值分布（约2分钟）

三件套在基础阶段第1节立过，这里说考场上的书写细节。三段各标小标题：算法思想、算法代码、复杂度分析。分值分布大约是思想 2 到 3 分、代码 5 到 7 分、复杂度 1 到 2 分。

两个考场策略。第一，三件缺一件扣一件，但思想那一件能在代码没写完时救分——考场上代码卡住了，先把思想写满，分能捞回一部分。第二，答案开头写一句结构声明，比如"设链表带头结点，数据从 L->next 起"，阅卷的人一眼看清你的约定，后面代码里出现 L->next 就不会被当成笔误。

草稿纸的用法：先画结构图再写代码，不要直接在草稿上写代码。改指针的题，画改前改后两张图，照着图写，这是C语言强化阶段就练过的习惯。

## P6 答题四步法：认结构、选模板、改条件、补边界（约5分钟）

这个课段的核心方法，四步。

第一步，认结构。拿到题先看题目给的结构定义：带头结点吗、字段名叫什么、下标从几起、什么存储。【停顿】为什么这一步单独立出来？因为真题里坑最多的就是这里——2026 年约瑟夫环不带头结点，2025 年图题的字段叫 next 不叫 nextarc，2026 年建树题数组下标从 1 起。认错了结构，后面全错。

第二步，选模板。对照 15 张模板卡报编号，说出题面特征命中哪张卡。这一步训练到 30 秒内完成，靠的是前两节课把骨架背熟。

第三步，改条件。把题目条件逐条翻译成模板的改动点，边写代码边核对：一个条件对应一处改动，条件数完了改动就齐了。这是四步里最值钱的一步，因为 802 命题的本质就是模板加改条件。

第四步，补边界。空表、越界、visited 复位、k 与 n 的合法性，一个个过；然后给复杂度，一句结论加一句理由。

每一步都有对应的常见失分，屏幕上表里第三列：抄错字段名、认不出模板从零硬想、漏改一处条件、边界分支整段没写。这四类失分占了算法题丢分的大头。

## P7 检查页：四步法完整示范（约6分钟）

这一页你先按暂停，自己写。题目是题集勾画 2算17 同类：设带头结点单链表 L，设计算法将链表就地逆置，空间 O(1)。给你两分钟，按四步走一遍，写出三件套。

【停顿】对一下四步。第一步认结构：带头结点单链表，L 指头结点，数据从 L->next 开始；"就地"两个字意味着不许新建结点。第二步选模板：要把顺序反过来——模板1 头插法，头插天然反序。第三步改条件：原地逆置的改动是先把链断成"空表加一串待处理结点"，也就是 L->next 置 NULL，然后循环里先存后继、再摘结点、头插回去。第四步补边界：空表与只有一个结点直接返回；复杂度时间 O(n)，每个结点摘下重插一次，空间 O(1)，只用 p 和 temp 两个指针。

你注意一件事：四步走完，三件套已经自动成形了——第二步和第三步说出来就是思想段，第三步的代码就是代码段，第四步就是复杂度段。【停顿】所以四步法不是额外的负担，它就是三件套的生产流程。考场上按四步走，答案格式自然就对。

## P8 骨架一：头插逆置（约3分钟）

那么进入五个链表骨架。骨架不是完整函数，是你要背到能默写的那几行核心。

第一个，头插逆置，模板1。核心四行：断链 L->next=NULL；循环里先存后继 temp=p、p 后移；然后 temp 头插到 L 后面。

题面特征：逆置、重组、归并成递减表、局部区间倒置——凡是"要反序"就想到它。

两处最容易错：忘先存后继，头插会改掉 temp->next，下一个结点就找不到了；忘断链，不断链的话头插会成环。

它的变体要记一个：局部区间逆置。2023 年那道 12 分大题，就是把这个骨架的头插目标从 L->next 换成区间前驱的 next，其他一字不改。第4节课讲那道真题时你会看到。

## P9 骨架二：快慢指针（约4分钟）

第二个骨架，快慢指针，模板2。核心：slow 每次走一步、fast 每次走两步，终止条件是 fast 与 fast->next 都不为空。

题面特征：找中点、倒数第 k、判断有环——本质都是两个指针以不同速度走同一条链。

【停顿】终止条件为什么是双条件？它决定 slow 的停点：偶数个结点时 slow 停在前半段的最后一个。这个停点是 408-2019 重排题第三步能交替插入的前提，强化阶段第2节推过。

倒数第 k 的变体：q 先走 k 步，然后 p、q 同步走，q 到表尾时 p 正好是倒数第 k。2025 年真题考的就是它。

对照解法是辅助栈，模板14：全部结点压栈，弹 k 次。两法对比一句话：快慢指针空间 O(1) 更省；辅助栈思路直白，而且题目变成"输出倒数 k 个全部元素"时栈更自然。考场上两种都行，优先写你有把握的。

## P10 骨架三：断链拼接三步走（约4分钟）

第三个骨架，断链拼接三步走，模板3。它是五个骨架里唯一没有固定代码形态的——它的价值是动作顺序：摘、逆、插。

第一步摘：把目标段从链上断下来。断之前先记住接口——断点两侧的结点、这一段的首和尾，接回时全靠它们。第二步逆：对摘下来的段做处理，最常用的就是骨架一头插逆置。第三步插：把处理完的段插回指定位置，先接后断。

题面特征：重排、改造链的结构。2020 年双向循环链表改造、408-2019 重排（找中点、逆置后半、交替插入）都是它。

为什么它没有固定代码？因为每道题的"摘哪里、插哪里"都不一样，固定的是三个动作的顺序与"记住接口"这个习惯。双链表版本一次要改四条指针，漏一条链就断——所以这个骨架配的动作是画图：改前改后两张图画出来，照着图写四条指针。

## P11 骨架四：条件删除前驱跟随（约2分钟）

第四个骨架，条件删除，模板4。核心结构：pre 与 p 一前一后走，命中条件就摘 p——pre->next 跨过 p、free(p)，然后 p 从 pre->next 重新取，pre 不动；没命中才两个一起走。

【停顿】删除后 pre 为什么不能动？因为下一个待检查的结点现在紧跟在 pre 后面，p 重新取就取到它了。如果删完还写 pre=p，就跳过了下一个结点，连续的待删结点会漏删。

题面特征：删除满足某条件的结点。2021 年真题第三问"删除比 x 大的正偶数"就是它，条件换成 value>x 且 value 是偶数。改条件只改 if 里那一句，骨架一字不动。

顺带一个经典错：先 free 再取 p->data，读的是已回收内存。顺序永远是取值、改指针、再 free。

## P12 骨架五：循环链表模拟（约2分钟）

第五个骨架，循环链表模拟，模板11。核心三段：建环 r->next=head；定位与报数都要 pre 跟随，因为摘结点必须知道前驱；只剩一个结点的判定是 p->next==p。

题面特征：报数出列、轮转、约瑟夫环。2026 年 8 分大题就是它。

与单链表的三处差别要背：终止条件从 p!=NULL 换成 p!=L、判空从 L->next==NULL 换成 L->next==L、尾巴接回头结点。用错任何一个都是死循环。

还有一个认结构的坑先埋在这里：2026 那道真题不带头结点，head 直接存 1 号——与课程默认约定不同。四步法第一步认结构，看清题目给的是什么，跟着题目走。

## P13 小结：五个骨架一张表（约1分钟）

收一下。五个链表骨架：头插逆置管反序，模板1；快慢指针管中点与倒数第 k，模板2；断链拼接管重排改造，模板3；条件删除管按条件摘结点，模板4；循环模拟管报数轮转，模板11。每个骨架记住两件事：核心几行代码、题面特征。认题就是拿题面特征去撞这五张卡。

## 附录一：课后题参考答案

默写题：五个骨架的核心几行。

```c
// 骨架一 头插逆置（模板1）
L->next = NULL;
while(p != NULL){ temp = p; p = p->next; temp->next = L->next; L->next = temp; }

// 骨架二 快慢指针（模板2）
while(fast != NULL && fast->next != NULL){ slow = slow->next; fast = fast->next->next; }
// 倒数第k变体：q 先走 k 步，再 p、q 同步走

// 骨架三 断链拼接三步走（模板3）：无固定代码，动作顺序为
// 摘（记住断点两侧与段首尾）→ 逆（常用头插）→ 插（先接后断）

// 骨架四 条件删除（模板4）
LNode *pre = L, *p = L->next;
while(p != NULL){
    if(条件){ pre->next = p->next; free(p); p = pre->next; }
    else{ pre = p; p = p->next; }
}

// 骨架五 循环链表模拟（模板11）
r->next = head;                                    // 建环
while(p->data != s){ pre = p; p = p->next; }        // 定位，pre 跟随
while(p->next != p){                                // 只剩一个时停
    for(int i = 1; i < m; i++){ pre = p; p = p->next; }
    pre->next = p->next; free(p); p = pre->next;    // 摘除
}
```

识别题四道的答案：

1. 2算21 归并成递减：模板1 头插法。改动点：归并时不用尾插用头插，天然反序；判空用 ||，收尾处理剩余段。
2. 2算12 删区间内结点：模板4 条件删除。改动点：条件换成 data>mink 且 data<maxk；表有序，删完区间可提前 break。
3. 2算6 倒数第 k：模板2 快慢指针。改动点：q 先走 k 步再同步走；k 超过表长时 q 先到 NULL，返回失败。
4. 2算30 循环链表删前驱：模板11 循环模拟。改动点：遍历终止用 p!=L；找目标结点的前驱要绕环走。
