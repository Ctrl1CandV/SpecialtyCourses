## P2 本节三题的共同动作（约2分钟）

三道题的共同动作是模板3 断链拼接：断之前记住接口，改完接回。多项式分解是把一条环链拆成两条；循环段倒置是把局部区间逆置再接环；双向改造是把偶数位结点摘下来插到尾部。

三道题的空间复杂度全是 O(1)。这不是巧合——改结构的链表题，"利用原结点空间"几乎是默认约束：题目不让你新建数据结点，你只能摘下来重新接。违反这条，思想分直接扣。

还有一个通用检查动作，写完代码问自己一句：有没有哪个结点没有人指向它了？有，就是漏了一句赋值，链断了。这个"查孤立结点"的习惯，强化阶段第1节的三条规矩里就有。

## P3 2022 多项式分解：题面与认结构（约3分钟）

第一道题，2022 年真题。屏幕上为题面：设计一个算法，将一个用循环链表表示的稀疏多项式分解成两个多项式，使这两个多项式中各自仅含奇次项或偶次项，并要求利用原链表中的结点空间构成这两个链表。结点定义题目给了：系数 coef 是 float，指数 exp 是 int，一个 next 指针。

先按暂停自己写，给你两分钟。

【停顿】对一下认结构，三处。第一，循环链表——遍历终止条件是 p != L（回到头结点），不是 p != NULL。第二，"利用原链表中的结点空间"——数据结点不许新 malloc，你只能新建两个头结点，数据结点全部从原链上摘。第三，判断依据是 exp 的奇偶，不是 coef——审题看错这一个字，整道题白写。

这道题材料里没有解答，课程给的补写版已经按真题原文核对过：exp 是 int、指数非负，用 exp % 2 判奇偶成立。

## P4 2022 多项式分解：改条件与完整代码（约5分钟）

选模板：拆表加头插，模板1 的变体。骨架是遍历原链，每个结点按条件摘下来，头插到目标链上。

改条件两处。第一处，判断依据换成 exp % 2 == 0：偶次项头插到 even 链，奇次项头插到 odd 链。第二处，摘结点前先存后继 temp = p->next——改指针之后 p->next 就变了，不先存就找不到下一个结点。

代码逐段看：先新建两个头结点，各自成环（odd->next = odd，even->next = even）——循环链表的头结点自己指自己；然后 p 从 L->next 出发，while p != L 遍历；循环体里先存后继，按奇偶分别头插；最后 free(L)，原头结点已经没用了。

【停顿】头插会反序，两个链里的项与原链顺序相反。题目没明确要求保持原顺序，两种都给分；如果你想保序，改尾插并维护两个 rear 指针，答题时说明一句就行。

边界：原链为空（L->next == L）时循环不进，两个新链还是空环，正确返回；只有一个数据结点也正常。

复杂度：时间 O(n)，每个结点处理一次；空间 O(1)，只新建两个头结点——这个 O(1) 正是"利用原空间"的体现，必须写进答案。

评分点：这道题最容易丢的分就是新 malloc 了数据结点。题目把"利用原结点空间"写在明面上，你新建了数据结点，思想分与代码分一起扣。

## P5 2023 循环段倒置：题面与认结构（约3分钟）

第二道题，2023 年真题，12 分。屏幕上为题面：已知 L 为链表的头结点地址，表中共有 m 个结点，m 大于 3；从表中第 i 个结点起到第 m 个结点构成一个循环部分链表，1 小于 i 小于 m。设计时间复杂度 O(n) 的算法 PattemInvertL(LinkList L, int i, int m)，将这部分循环链表中所有结点顺序完全倒置。

先按暂停自己写，这道题给你三分钟。

【停顿】认结构，三处。第一，表的形状很特殊：第 1 到 i-1 个结点是普通链，第 i 到第 m 个结点首尾成环——am 的 next 指回 ai。你要倒置的只是环里这一段，前面那段不动。第二，函数签名题目给死了，PattemInvertL(LinkList L, int i, int m)，照抄，参数名都别改。第三，"时间 O(n)"排除了重新建结点的做法，只能改指针。

这道题的分值构成大约思想 3 分、代码 7 分、复杂度 2 分。代码 7 分是重头，我们一步一步来。

## P6 2023 循环段倒置：四步法（约4分钟）

选模板：模板1 头插法——但这次不是在整条链上用，是在局部区间上用；再配模板3 的"记住接口"。

改条件三处，每一处都来自题面。

改动一："从第 i 个结点起"——所以先走 i-1 步，定位到区间的前驱，代码里叫 head。【停顿】注意，头插的目标是 head->next，不是 L->next。这一处就是"局部"两个字的落地：头插到区间前驱后面，前面的普通链完全不动。

改动二："完全倒置"——头插天然反序，循环次数是 m-i+1 次，也就是区间里结点的个数。p 与 rear 都从第 i 个结点出发：p 是游走的指针，rear 记住区间起点。

改动三："循环部分链表"——倒置完还要把环接回去。区间起点 ai 倒置后变成了尾，尾要接回新的头。这就是最后那句 rear->next = head->next。

为什么 rear 要在循环开始前记住？因为循环里 p 一直在走，走完你就找不到"原来的第一个"了。断链之前记住接口——又是这句话。

## P7 过程页：m=6、i=3 的倒置（约5分钟）

这一页拿纸跟着画。m=6、i=3：表是 L→a1→a2→[a3→a4→a5→a6→a3 环]，屏幕上画的就是这个环。

第一步定位：head 从 L 走 i-1=2 步，停在 a2；p = rear = head->next = a3。

第二步头插四次（m-i+1 = 4）：第一次摘 a3 插到 head 后——a3 的 next 指向 head->next（此刻是 a3 自己，成自环，没关系，后面会被覆盖）；第二次摘 a4 插到 head 后，head 后变成 a4→a3；第三次 a5，head 后是 a5→a4→a3；第四次 a6，head 后是 a6→a5→a4→a3。

第三步接环：rear 还是 a3——它没动过，倒置后它成了尾。rear->next = head->next，也就是 a3->next = a6。

【停顿】你检查最终结果：环是 a6→a5→a4→a3→a6。原来的环 a3→a4→a5→a6→a3，方向完全反了，结点一个没丢、一个没新建。前面的 L→a1→a2 那段，head 是 a2，head->next 现在是 a6，所以完整表是 L→a1→a2→a6→a5→a4→a3→a6 环。

整个过程 head 始终是锚点，rear 始终是接口。第一次头插时 a3 短暂自环不影响正确性——因为 p 已经先存了 a4，链没丢。

## P8 2023 循环段倒置：完整代码与评分点（约5分钟）

完整代码屏幕上逐行走。开头边界：L 为 NULL 返回；i <= 1 返回——i=1 时区间从第一个数据结点起，没有"区间前驱"可锚（头结点 L 的 next 就是 a1，倒置会把普通链也卷进去，题目保证 1<i<m 所以直接拦掉）；i >= m 返回——区间不足两个结点没什么可倒置的。

定位段：head 从 L 出发走 i-1 步，j 计数。主循环段：while j < m，循环体四句——temp 存 p、p 后移、temp 头插到 head 后、j 加一。收尾一句：rear->next = head->next。

复杂度：定位走 i-1 步、头插走 m-i+1 步，合计 O(m)，满足题目 O(n) 的要求；空间 O(1)，四个指针变量。

【停顿】这道题最容易丢的是哪一分？接环那句。头插循环写对了、定位写对了，最后忘了 rear->next = head->next——环没接上，a3 的 next 还指着倒置前的旧位置，整个链断了。12 分的题，这一句值 2 分。

第二个易丢点：循环次数。j 从 i-1 开始，循环到 j == m 停，正好 m-i+1 次。写成 j <= m 多插一次，写成从 0 数少插一次。考场上写完拿 m=6、i=3 代进去数一遍：应该插 4 次，你数一下你的循环是不是 4 次。

思想段的采分点两句话："头插法在局部区间上用"与"最后接环恢复循环结构"。

## P9 2020 双向循环改造：题面与认结构（约3分钟）

第三道题，2020 年真题。屏幕上为题面：将带头结点的双向循环链表 L=(a1,a2,a3,...,an) 改造为 L=(a1,a3,...,an,...,a4,a2)。

先按暂停自己写，给你三分钟。

【停顿】认结构，三处。第一，带头结点的**双向**循环链表——每个结点 prior 与 next 两个指针，改一次结构要动四条指针，这是它比单链表题难的全部原因。第二，目标序列要读对：奇数位按原序在前（a1,a3,...,an），偶数位在后而且是**逆序**（...,a4,a2）——不是 a2,a4。为什么是逆序？等下看思路你就明白，这正好是"依次插到同一个位置"的自然结果。第三，双向循环链表里 head->prior 就是尾结点 an——这个性质给了我们一个免费的插入锚点。

## P10 2020 双向循环改造：思路（约4分钟）

思路一句话：p 从 a1 开始，每轮把 p 的下一个结点 q（偶数位）摘下来，插到 rear 之后；p 跳到 q 原来的下一个，继续。

关键认识：rear = head->prior，是原尾结点 an，**全程固定不动**。每轮把 q 插在 an 与"上一个已插入的结点"之间——后插的离 an 近，先插的离 head 近。所以偶数位结点在尾部 naturally 呈逆序：a2 先插在最靠 head 的位置，a4 后插在 a2 前面（靠 an 一侧），目标序列 ...,a4,a2 就这么自然出来了，不需要任何额外处理。

【停顿】拿 n=6 验证一遍。初始 head↔a1↔a2↔a3↔a4↔a5↔a6↔head，rear=a6，p=a1。第一轮：q=a2，摘下来插到 a6 后，环变成 head↔a1↔a3↔a4↔a5↔a6↔a2↔head，p 跳到 a3。第二轮：q=a4，摘下来插到 a6 后——注意是 a6 与 a2 之间，环变成 head↔a1↔a3↔a5↔a6↔a4↔a2↔head，p 跳到 a5。第三轮：p=a5，p->next=a6==rear，终止条件命中，退出。

结果 a1,a3,a5,a6,a4,a2——奇数位原序在前，偶数位 a4,a2 逆序在后，正是目标。

终止条件两个：p != rear 且 p->next != rear。p 走到尾结点，或者 q 已经是尾结点，都说明没有偶数位可移了。开头还有一个 if 拦 n<3 的情况：空表、只有头结点、只有一个数据结点，都不用改造。

## P11 2020 双向循环改造：四条指针（约5分钟）

代码的核心是循环体里的四条指针，分两组。

第一组，摘：q = p->next，temp = q->next 先存好；然后 p->next = temp、temp->prior = p——p 与 temp 互接，q 从原位置脱离。两条。

第二组，插：q->next = rear->next、q->prior = rear——q 认 rear 做前驱，q 的 next 指向 rear 的 next（也就是头结点，或者上一轮插入的结点）；然后 rear->next->prior = q、rear->next = q——rear 的后继改指 q，那个后继（头结点方向）的 prior 也改指 q。两条。

【停顿】四条指针漏任何一条会怎样？漏 temp->prior = p，从后往前走会走到已摘掉的 q；漏 rear->next->prior = q，头结点的 prior 还指着旧尾，反向遍历出错。双向链表改结构，四条指针一条都不能少——这就是为什么要先画图：图上每条线对应一条赋值，画完图数一数线，再数一数代码里的赋值，对上了才算写完。

次序原则与双链表插入同一条：先把外部接好，最后动接口处。基础阶段第4节讲双链表插入时"③必须在④前"的道理，在这里完全复用。

复杂度：时间 O(n)，每个偶数位结点处理一次；空间 O(1)。

一个说明：材料原文的类型名写的是 LinkList，但用了 prior 字段，按双向链表理解——课件写 DLinkList 与 DNode。答题时抄题目给的类型名，题目给什么用什么。

## 附录一：课后题参考答案

真题重写：2023 循环段倒置（12分）完整三件套。

思想段：先走 i-1 步定位到区间前驱 head；p 与 rear 都指向区间起点（第 i 个结点）；对区间内 m-i+1 个结点逐个摘下单插到 head 之后（头插天然反序）；倒置完成后区间起点成为尾，用 rear->next = head->next 接环，恢复循环结构。

```c
void PattemInvertL(LinkList L, int i, int m){
    if(L == NULL || i <= 1 || i >= m) return;
    LNode *head = L;  int j = 0;
    while(j < i - 1){ head = head->next; j++; }
    LNode *p = head->next, *rear = head->next, *temp;
    while(j < m){
        temp = p;  p = p->next;
        temp->next = head->next;  head->next = temp;
        j++;
    }
    rear->next = head->next;                     // 接环，漏了链就断
}
```

复杂度段：时间 O(m)（定位 i-1 步加头插 m-i+1 步），满足题目 O(n) 要求；空间 O(1)，只用指针变量。

变式题 2算42：多项式分解原题，与课上 SplitPoly 同法；对照点——判断依据 exp 奇偶、只建两个头结点、原头结点 free。

变式题 2算41：多项式求导——遍历中改 coef = coef\*exp、exp = exp-1；exp 变 0 的项摘除并 free（常数项导数为 0）。拆表变删除，模板4 前驱跟随。

```c
// 2022 稀疏多项式奇偶分解（缺口14 补写版）
void SplitPoly(PolyNode *L, PolyNode *&odd, PolyNode *&even){
    odd  = (PolyNode*)malloc(sizeof(PolyNode));  odd->next  = odd;
    even = (PolyNode*)malloc(sizeof(PolyNode));  even->next = even;
    PolyNode *p = L->next, *temp;
    while(p != L){
        temp = p->next;
        if(p->exp % 2 == 0){ p->next = even->next; even->next = p; }
        else               { p->next = odd->next;   odd->next  = p; }
        p = temp;
    }
    free(L);
}

// 2020 双向循环链表改造（材料原文，类型按双向链表写）
void transformList(DLinkList &head){
    if(head == NULL || head->next == head || head->next->next == head) return;
    DNode *rear = head->prior, *p = head->next, *q, *temp;
    while(p != rear && p->next != rear){
        q = p->next;  temp = q->next;
        p->next = temp;  temp->prior = p;          // 摘 q
        q->next = rear->next;  q->prior = rear;    // q 接到 rear 后
        rear->next->prior = q;  rear->next = q;    // 头结点与 q 互指
        p = temp;
    }
}
```
