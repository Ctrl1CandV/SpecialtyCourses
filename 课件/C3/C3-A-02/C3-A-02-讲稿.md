## P2 骨架六：递归三件套（约4分钟）

树的骨架第一个，递归三件套，模板5。骨架四行：终止条件返回基准值；递归拿左子树的结果；递归拿右子树的结果；合并两个结果加上本结点的贡献返回。

题面特征一句话：凡是"整棵树的答案能由左右子树的答案拼出来"就用它。求高度是 max 加 1，求结点数是相加加 1，求叶子数是在叶子处直接返 1。

三个实例只差两行：终止返回什么、怎么合并。这个认识强化阶段第4节立过，这里是把它变成认题的反射：看到"求树的什么什么"，先想三件套。

【停顿】那答案拼不出来的怎么办？比如 2025 年最长路径——一条路径不是"左子树的路径加右子树的路径"拼出来的。这时候用它的变体：遍历中维护全局变量。递归照常走，但答案不由返回值给出，而是途中更新一个全局量（最长路径就是 pathLen 到叶子时与 maxLen 比）。求树的度也是这个变体。

拿到树题第一问就是：答案能不能由左右子树拼出来？能，套三件套；不能，想想要带什么全局信息。

## P3 骨架七：层序加 last 分层（约3分钟）

第二个，层序加 last 分层，模板6。层序遍历本身强化阶段第5节讲过，这里加的是"按层结算"的机制。

核心就一句：if(front > last)。last 记的是本层最后一个结点在队列里的位置，队头 front 越过 last，说明本层全部出队了——这时候结算本层（层号与本层结点数），然后把 last 更新为当前队尾 rear，层号加一，本层计数清零。

题面特征：求宽度、繁荣度、按层统计。改条件示范：求宽度，结算时取 max；2024 年繁荣度真题，结算时累加"层号乘本层个数"，再加一个 height 计数器——从求宽度改三处就是新题。这个"从已知算法改三处"就是四步法第三步的标准动作。

last 的初值与更新时机是这个骨架唯一的难点，拿一个三层树的队列走一遍就清楚。

## P4 骨架八：中序加 prev（约3分钟）

第三个，中序加 prev，模板15。骨架：中序遍历里加两行——当前值与 prev 比较，不满足有序就返回假；然后 prev 更新为当前值。

为什么是中序？因为 BST 的中序序列严格递增。判 BST 不需要每个结点跟全树比，只需要中序走一遍、比较相邻两个值。

两个细节是真题里丢分的地方。第一，prev 必须用引用传递：它是跨递归层共享的状态，值传递的话每层各有一份副本，比较就失效了。【停顿】这和 2025 最长路径里 maxLen 用引用是同一个道理——凡是"递归途中要累积或共享的信息"都用引用。第二，prev 的初值：写 -1 隐含"所有结点值大于 -1"，树里有负数就错。用 INT_MIN，或者在答案里写一句"设结点值均为正整数，prev 初值取 0"——这个假设必须写出来，2024 年真题的评分点之一。

题面特征：判 BST、有序性校验。

## P5 骨架九：递归建树区间划分（约4分钟）

第四个，递归建树，模板12。2026 年 10 分真题的骨架。

四步：先序第一个元素是根；在中序里定位根的位置 k，k 左边是左子树、右边是右子树；算 leftLen = k - inL，左子树结点个数；用 leftLen 把先序也切成两段，递归建左右子树。

先说一个判断题的结论：能唯一确定一棵树的组合是先序加中序、后序加中序、层序加中序——唯独先序加后序不行，因为分不清某个结点是左孩子还是右孩子。中序的作用是划分左右，缺它不可。

定根看哪里：先序看第一个，后序看最后一个。

四个下标边界最容易错一个：左子树的先序段是 preL+1 到 preL+leftLen，右子树是 preL+leftLen+1 到 preR；中序段是 inL 到 k-1 与 k+1 到 inR。leftLen 是桥梁，用它把另一个序列也切开。考场上建议先在草稿上画两个数组、标出四个边界的位置，再写代码。

认结构时看清题目数组下标从几起——2026 那道题给的是 A[1..n]，下标 1 起，与课程材料里 0 起不同，跟着题目走。

## P6 骨架十：DFS 回溯与 visited 复位（约4分钟）

图的骨架第一个，DFS 回溯，模板7。骨架：进一个顶点标记 visited，递归它所有未访问的邻居，这条路走不通要退回去试别的路之前，把 visited 复位。

题面特征：找路径、经过某点、所有简单路径、长度 k 的路径。图有环，不标记会绕圈死循环。

【停顿】复位的时机是这个骨架的核心考点：走不通、返回 false 之前复位；找到答案直接 return true 的时候可以不复位——反正整个搜索结束了。

还有一个更隐蔽的坑：多段搜索之间必须全部复位。2025 年真题"输出从 u 到 v 并经过 k 的一条路径"，标准做法是拆成两段——先搜 u 到 k，再搜 k 到 v。两段之间如果不把 visited 全部清零，第一段用过的标记会让第二段误判"此路不通"。这是那道题最容易丢的分，第6节讲真题时完整走。

与"判连通"对比着记：判连通只需要一次性标记、从不复位（问的是"能不能到"，到达即止）；找路径必须回溯复位（问的是"找一条具体的路"，走不通要退回来试别的）。

## P7 骨架十一：BFS 分层与多源（约4分钟）

图的第二个骨架，BFS，模板8。单源 BFS 强化阶段第9节讲过：入队时就标记 visited，逐层扩散。这里补两个变体。

分层变体：要知道每个顶点在第几层，就用与骨架七同一个机制——队列加 last 结算，每结算一次层号加一。题面特征：最短步数、按层输出。

多源变体：2023 年像素距离图用的。与单源只差第一步——所有源点先全部入队且 dist 置 0，然后普通 BFS 逐层扩散，dist[v] = dist[u] + 1。因为 BFS 逐层的性质，每个点第一次被访问时的 dist 就是它到最近源点的距离。

两个技巧：dist 数组兼作 visited，-1 表示未访问，省一个数组；队列里存一维编号 i\*m+j，取出时用除和模还原坐标——因为材料的队列定义只存一个 int，这是约定4"元素类型按需替换"的变通。

题面特征：无权图最短距离、距离图。2023 那道题的突破口一句话：直接对每个黑像素做 BFS 是 O(n²m²) 会超时，反过来从所有白像素同时扩散就是 O(nm)。

## P8 骨架十二：折半框架改判定（约3分钟）

查找的骨架，折半框架改判定，模板9。骨架：left 与 right 夹逼，mid 处按判定条件决定往哪半走，直到 left 与 right 相遇。

改的就是判定条件这一处。折半查找的判定是"与 key 比大小"；2021 年双调序列找峰值，判定换成"看 mid 在上升段还是下降段"——A[mid-1] > A[mid] 说明在下降段，峰值在左边；A[mid+1] > A[mid] 说明在上升段，峰值在右边；两边都不满足，mid 自己就是峰值。

【停顿】这个骨架有一个通用难点：right = mid 与 left = mid + 1 为什么不对称？道理是——mid 可能就是答案时，不能排除它，写 right = mid 把它留在区间里；mid 一定不是答案时，才排除它，写 left = mid + 1。用错的后果是要么漏解要么死循环。第7节讲 2021 真题时把这个不对称完整推一遍。

题面特征：双调峰值、旋转数组、第一个满足条件的位置。"尽可能高效"四个字就是在暗示 O(logn)，别扫一遍 O(n)。

## P9 骨架十三：归并加计数（约3分钟）

排序的骨架，归并加计数，模板10。二路归并强化阶段第10节讲过，这里加的就一行：else 分支里 count += mid - i + 1。

这一行的道理：合并时右半的元素 temp[j] 被选中，说明它小于左半当前的 temp[i]；左半有序，所以从 i 到 mid 的全部元素都大于 temp[j]，而且它们的下标都在 j 之前——每一个都与 temp[j] 构成一个逆序对，一次加 mid-i+1 个。

写成 count++ 是最常见的错：只算了 temp[i] 与 temp[j] 这一对，漏了左半剩下的全部。

题面特征：逆序对、跨越两半的统计——凡是"一对元素分属左右两半"的计数，都可能在归并时顺手算掉。2020 年逆序对真题，题目给 n≤30000，就是在排除 O(n²) 双重循环：三万的平方是九亿，超时；O(nlogn) 是四十多万，可以。

## P10 骨架十四：辅助栈逆序（约1分钟）

辅助栈，模板14，报卡。题面特征：判回文、倒数第 k、非递归后序——凡是"需要倒着处理"而结构只能顺着走，用栈把顺序翻过来。三个标准用法强化阶段第3、4节讲透了，这里一句话：看到"倒着"想栈。它还常作为其他题的第二解法，答题时写"另解：辅助栈"能展示一题多解。

## P11 骨架十五：入度表法（约1分钟）

入度表法，模板13，报卡。三步：求全部顶点的入度；入度为 0 的入栈、出栈输出、后继入度减 1、减到 0 再入栈；最后输出的顶点数少于总数说明有环。题面特征：拓扑排序、验证拓扑序列、判环。验证序列有个巧认识：不需要真排序，按给定顺序模拟检查入度就行——2026 年 12 分真题的思想分大头就是这个认识。

## P12 决策表：三问定模板（约3分钟）

这一页你先自己试：拿任意一道题面，走三问，看能不能报出模板编号。

问一，什么结构？单链表，候选模板 1、2、3、4、14；双链表或循环链表，模板 3、11；二叉树，模板 5、6、12、15；图，模板 7、8、13；数组，模板 9、10。结构定了候选范围，15 张卡一下子缩到两三张。

问二，做什么操作？走一遍并统计，模板 5、6、8；改结构（插入删除重排），模板 1、3、4；找一个位置或值，模板 2、9；验证或排序序列，模板 13；倒着处理，模板 14。

问三，有什么约束？"原地、空间 O(1)"排除需要辅助数组的解法；"时间尽可能低"排除 O(n²)，想折半或归并；"利用原结点空间"意味着不许新 malloc 数据结点；"经过某点"或"长度为 k"就是模板 7 加参数。

## 附录一：课后题参考答案

默写题：九个骨架的核心几行。

```c
// 模板5 递归三件套
if(T==NULL) return 基准值;  左=递归(T->lchild);  右=递归(T->rchild);  return 合并(左,右,本结点);
// 模板6 层序加 last 分层
if(front > last){ 结算本层(层号,计数); last = rear; 层号++; 计数=0; }
// 模板15 中序加 prev（prev 用引用）
if(!check(node->lchild, prev)) return 0;  if(node->data <= prev) return 0;  prev = node->data;
// 模板12 递归建树
根=A[preL];  中序定位 k;  leftLen=k-inL;  Build(左: preL+1..preL+leftLen, inL..k-1);  Build(右: preL+leftLen+1..preR, k+1..inR);
// 模板7 DFS 回溯
visited[u]=true;  递归未访问邻居;  走不通则 visited[u]=false; return false;
// 模板8 BFS 多源
for(每个源点 s){ dist[s]=0; 入队(s); }  然后逐层 dist[v]=dist[u]+1（dist==-1 兼作未访问）
// 模板9 折半改判定
while(left<right){ mid=(left+right)/2;  if(判定含mid) right=mid;  else left=mid+1; }
// 模板10 归并加计数
右半先出时 count += mid - i + 1;
// 模板13 入度表法
求全部入度 → 按给定顺序检查入度==0 → 把该顶点后继入度减 1
// 模板14 辅助栈逆序
要倒着处理先压栈：判回文（前半压栈）、倒数第k（全压弹k次）、非递归后序（双栈）
```

识别题五道的答案：

1. 6算20 繁茂度：模板6。改动点：结算从取 max 改成累加 层号×本层结点数，height 从 1 起。
2. 7算18 长度 k 的简单路径：模板7。改动点：递归多带 depth 参数，每下一层加 1，depth==k 成功；k 合法范围 1 到 vexnum-1；每个起点前 visited 清零。
3. 9算7 判 BST：模板15。改动点：prev 用引用；初值不能用 -1（负数结点会错），用 INT_MIN 或声明结点值为正的假设。
4. 10算26 有序数组合并：二路归并 Merge（模板10 的载体）。改动点：三指针 p、q、k 加两个收尾循环；若问逆序对，在右半先出处加计数行。
5. 2算32 拆表：模板1 头插的变体。改动点：按条件（奇偶、正负等）分别头插到两个新链；"利用原空间"则只新建头结点，数据结点全部从原链摘。
