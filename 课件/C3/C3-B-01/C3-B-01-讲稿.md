## P2 本节三题的共同点（约2分钟）

三道题都是"顺着链走"型：倒数第 k 是走一趟找位置，2021 三问是走一趟做三件事，约瑟夫环是绕环走并摘结点。都不改链的整体结构，这是它们比下一节"改动链的结构"那组简单一档的原因。

难度是递增的：倒数第 k 只有一个动作；三问有三个动作，还要共享"表有序"这一个条件；约瑟夫环有建环、定位、报数、摘结点四个动作，而且它不带头结点，认结构就先给你一个下马威。

链表是七年真题的第一大项，6 道题。这 6 道全部建立在两个基本动作上：走链、摘结点。这一节三道题把这两个动作的各种组合都过一遍。

## P3 2025 倒数第 k：题面与认结构（约2分钟）

第一道题，2025 年真题。屏幕上为题面：给定一个单链表，找到倒数第 k 个元素；如果找到，打印该元素的值并返回 1，否则返回 0。结点定义题目给了，data 和 next 两个字段。

念完题面，先按暂停，自己写。给你两分钟。

【停顿】对一下认结构。第一，字段名 data、next 与我们的材料一致，直接用。第二，题目没说有没有头结点——这是这道题认结构的关键点。按带头结点写，p 和 q 都从 L 出发，仍然是正确的，因为两个指针的差值关系与头结点无关；答题时在开头声明一句"设链表带头结点"，把你的约定亮出来。第三，返回值语义题目定死了：找到打印并返回 1，找不到返回 0。

这三个认识写出来，思想分就拿到手了。

## P4 2025 倒数第 k：选模板与改条件（约4分钟）

选模板：倒数第 k——模板2 快慢指针。骨架是 q 先走 k 步，然后 p、q 同步走，q 到表尾时 p 恰好落后 k 个结点，p 就是倒数第 k。

【停顿】p、q 都从头结点 L 出发，为什么正好对上"倒数第 k 个数据结点"？因为头结点算了一个位置，正好把"q 到 NULL 停"多走的那一步抵消掉。这个推导强化阶段第1节讲过，这里直接用结论。

改条件两处。改动一：题目要求"找到就打印"，所以返回 1 之前加一句 printf。改动二：题目要求"否则返回 0"——什么情况下找不到？k 超过表长。q 先走 k 步的过程中变成 NULL，就说明表没有那么长，返回 0。

代码十行以内，屏幕上逐段看：p、q 初始化都指 L；第一个 while 让 q 先走 k 步，条件是 k 没走完且 q 没到 NULL；走完判 q，NULL 就返回 0；第二个 while 同步走；打印 p 的值，返回 1。

一个条件对应一处改动，条件数完了改动就齐了——这就是"改条件"这一步的标准动作。

## P5 2025 倒数第 k：评分点与一题多解（约3分钟）

补边界：k 超过表长返回 0，这个分支刚才写了；空表时 q 第一步就变 NULL，同样走返回 0 的分支，不用单独写；k 按题意是正整数，不用处理负数。

复杂度：时间 O(n)，只走一趟——q 先走 k 步加同步走 n-k 步，总共 n 步；空间 O(1)，两个指针。各配一句理由写进答案。

【停顿】这道题最容易丢的是哪一分？k 超过表长返回 0 这个分支。很多人只写主流程，题目明明白白写了"否则返回 0"，你不处理这个"否则"，代码分扣 1 到 2 分。边界分支不是可选项，是题目条件的一部分。

一题多解：辅助栈法，模板14——全部结点压栈，弹 k 次，第 k 次弹出的就是。空间 O(n)，比快慢指针费；但题目如果变成"输出倒数 k 个全部元素"，栈反而更自然。答题写一种就行，学有余力注一句"另解：辅助栈"，展示你知道两条路。

## P6 2021 有序链表三问：题面与共同条件（约3分钟）

第二道题，2021 年真题，一道题三问。屏幕上为题面：一个正整数序列组成的有序单链表，三个问题——第一问，确定序列中比正整数 x 大的数有几个，相同的数值只计算一次；第二问，将比 x 小的数按递减次序排列；第三问，将比 x 大的正偶数从链表中删除。要求时间和空间复杂度最小。

先按暂停，三问都自己写一遍。这道题约 12 分，给你五分钟。

【停顿】认结构：带头结点的有序单链表，元素是正整数。关键词是**有序**——三问全部要用它。

第一问用有序在哪：值相同的结点必然相邻，所以"相同值只计一次"不需要任何额外空间，只要记住上一个计入的值，跟它比就行。第二问用有序在哪：比 x 小的元素必然从表头开始连续分布——不会东一个西一个，找到这段的尾，就找到了断点。第三问其实用不用有序都行，但有序可以让你提前终止（删完大于 x 的区间就不用再扫了）。

"复杂度最小"这个要求怎么满足？三问都是一趟遍历、常数额外空间，O(n) 和 O(1)。用有序性省掉辅助数组，这就是"最小"的答案。

## P7 2021 第一问：比 x 大的数有几个（约4分钟）

第一问最简单，先拿分。顺着走一趟，计数。

改条件就一处："相同的数值只计算一次"翻译成 value != before。before 记住上一个**计入过**的值：当前值大于 x 且不等于 before 才计数，然后 before 更新为当前值。

【停顿】为什么不用一个 visited 数组去重？两个理由：值域没给范围，数组开多大不知道；更重要的是有序性已经保证相同值相邻，一个变量就够——这正是"空间复杂度最小"的采分点。

初始 before = -1：元素是正整数，-1 不会与任何元素相等，第一个大于 x 的值一定能计入。这个初值的道理与判 BST 的 prev 初值同一类——初值要选一个"不会误伤任何合法输入"的值，并且心里清楚它依赖"正整数"这个题目条件。

时间 O(n) 一趟，空间 O(1) 三个变量。这一问约 3 分，是送分的，别在"只计一次"上丢。

## P8 2021 第二问：比 x 小的按递减排列（约5分钟）

第二问是三问里最难的，约 6 分，占这道题一半。先想清楚要干什么：比 x 小的一段在表头连续分布，要把这一段逆置。链上局部逆置——模板3 断链拼接三步走：摘、逆、插。

逐步走代码。第一步，边界：空表、只有一个结点、第一个元素就大于等于 x（说明没有比 x 小的段），直接返回。第二步，找断点：p 从 L 出发，while 条件是 p->next 存在且 p->next->data < x——停下来的时候，p 就是"比 x 小那一段"的最后一个结点。第三步，记接口：q = p->next 是剩余段的头，rear = L->next 是原第一个结点。第四步，断链：p->next = NULL，把小段与剩余段切开。第五步，头插逆置：从 rear->next 开始逐个摘下头插到 L 后面——注意第一个结点 rear 不用动，它逆置后自然变成尾。第六步，接回：rear->next = q。

【停顿】rear 是本题的题眼。为什么要在断链前记住 L->next？因为逆置之后，原来的第一个结点变成了这一段的最后一个，接回剩余段要靠它。不记住的话，逆置完你就找不到这一段的尾了，只能再走一趟去找——时间就多了一趟。断链之前记住接口，是模板3 的通用动作。

复杂度：时间 O(n)，找尾一趟、逆置一趟，合计不超过 2n；空间 O(1)，四个指针变量。

## P9 2021 第三问：删除比 x 大的正偶数（约3分钟）

第三问回到熟悉的模板：模板4 条件删除、前驱跟随。

改条件一处：判断换成 value > x 且 value % 2 == 0——"比 x 大的正偶数"两个条件缺一不可，漏了"正"字或者漏了"偶数"都是漏改条件。

这个写法的结构与前驱跟随稍有不同：p 直接当前驱用，检查的是 p->next。命中条件就摘 p->next——temp 记住它、p->next 跨过它、free；不命中才 p = p->next。

材料解答里那句注释值得背下来：**只有不删除下一个元素的时候才移动 p**。删了还移动，就跳过了下一个待检查的结点；连续两个待删结点会漏删第二个。

顺序细节：先 temp 记住、再改指针、最后 free。先 free 再读 temp->next 是读已回收内存，经典错。

时间 O(n)，空间 O(1)。这一问约 3 分。顺带一句：表有序的话，删完大于 x 的区间其实可以提前 break，但题目没要求，写完整遍历不扣分。

## P10 2021 三问的评分点（约2分钟）

三问的评分点汇总在屏幕的表里。第一问最容易丢的是"只计一次"没翻译成 value != before；第二问最容易丢的是断链前没记住 rear，逆置完接不回去；第三问最容易丢的是删除后还移动 p，跳过下一个结点。

分值分布大约是第一问 3 分、第二问 6 分、第三问 3 分。答题策略：三问独立给分，第二问写不完也先把第一、三问写满——12 分里先保 6 分。

思想段有一个公共采分点：三问共享"表有序"这个条件的认识要写出来。第一问靠有序做相邻去重、第二问靠有序保证小段连续，这一句写进思想段，阅卷的人一眼看到你用上了题目条件。

## P11 2026 约瑟夫环：题面与认结构（约3分钟）

第三道题，2026 年真题，8 分。屏幕上为题面：n 个人围成一个圈，编号 1 到 n；从第 s 个人开始报数，数到 m 的人出列；出列后的下一个人继续从 1 开始报数，重复直到圈中剩下最后一个人，返回其编号。

先按暂停自己写，这道题给你三分钟。

【停顿】认结构，两个关键认识。第一，循环单链表模拟，模板11——"围成圈""报数出列"就是它的题面特征。第二，也是这道题的第一个坑：**题目没有头结点**。我们的课程默认链表带头结点，但这道题 head 直接存 1 号，它本身就是第一个数据结点。答题开头声明一句"不设头结点，首结点即 1 号"——认结构这一步写清楚，思想分就稳了。

改条件三处：建环时结点的 data 存编号 1 到 n；报数起点是第 s 个不是第 1 个，所以建完环要先定位到 s，而且定位时 pre 要跟随；数到 m 出列，内层循环走 m-1 步。

## P12 过程页：n=5、s=1、m=3 走一遍（约6分钟）

这一页拿纸跟着画，PPT 一步步放。n=5、s=1、m=3，屏幕上是这个环：1 到 5 首尾相接，不带头结点。

建环：1 号当 head，依次接 2、3、4、5，最后尾结点 r 的 next 指回 head，成环。pre 初始指 r，也就是 5 号——因为摘 1 号的时候需要它的前驱。

定位：s=1，p 已经在 1 号，不用走。如果 s=3，p 走两步到 3 号，pre 跟到 2 号。

第一轮报数：从 p 当前的 1 号报 1，走一步到 2 号报 2，再走一步到 3 号报 3——数到 m=3，3 号出列。摘除三句：pre 的 next 跨过 p、free(p)、p 从 pre->next 重新取。现在环是 1、2、4、5。

第二轮：从 4 号报 1，5 号报 2，1 号报 3——1 号出列。环剩 2、4、5。第三轮：从 2 号报 1，4 号报 2，5 号报 3——5 号出列。环剩 2、4。第四轮：从 2 号报 1，4 号报 2，2 号报 3——2 号出列。只剩 4 号，p->next == p，自己指向自己，循环停，返回 4。

【停顿】你刚才画的过程中注意两件事：pre 全程跟随，因为摘结点必须知道前驱；"只剩一个"的判定是 p->next == p，不是 p == NULL——环里没有 NULL。这两处是循环链表与单链表的差别，写错任何一处都是死循环或者崩。

## P13 2026 约瑟夫环：完整代码与评分点（约3分钟）

完整代码屏幕上逐段过：建环段，head 存 1 号，循环建 2 到 n 号，尾结点接回 head；定位段，while p->data != s，pre 跟随；主循环段，while p->next != p，内层报 m-1 步，然后三句摘除；返回 p->data。

边界：m=1 时内层循环一步不走，每轮直接摘当前结点，代码不用改；s 按题意在 1 到 n 范围内，如果担心超范围，可以走 (s-1)%n 步定位——这是加分处理，不写不扣分。

复杂度：时间 O(nm)——n 个人各出列一次，每次出列报数走 m 步；空间 O(n)——建了 n 个结点。理由各一句写进答案。

【停顿】这道题最容易丢的是哪一分？"从第 s 个人开始"这个条件。很多人背熟了约瑟夫环从 1 号开始报数的版本，考场上顺手就从 head 报起，定位段整段没写——8 分里代码分直接扣 2 到 3 分。第二个易丢点是复杂度：写 O(nm) 要给理由"每次出列走 m 步"，光写结论拿不全。

8 分的构成大约是思想 2 分、代码 4 到 5 分、复杂度 1 到 2 分。出列后 free 掉结点是代码分的细节采分点，别漏。

## 附录一：课后题参考答案

真题重写：2026 约瑟夫环（8分）完整三件套。

思想段：用循环单链表模拟报数过程，不设头结点、首结点存 1 号；建环后先定位到第 s 个结点（pre 跟随）；每轮报 m-1 步找到出列者，摘除并 free，直到只剩一个结点（p->next == p），返回其编号。

```c
int Josephus(int n, int s, int m){
    LNode *head = (LNode*)malloc(sizeof(LNode));
    head->data = 1;  LNode *r = head;
    for(int i = 2; i <= n; i++){
        LNode *p = (LNode*)malloc(sizeof(LNode));
        p->data = i;  r->next = p;  r = p;
    }
    r->next = head;                                  // 成环
    LNode *p = head, *pre = r;
    while(p->data != s){ pre = p; p = p->next; }      // 定位第 s 个
    while(p->next != p){                              // 只剩一个时停
        for(int i = 1; i < m; i++){ pre = p; p = p->next; }
        pre->next = p->next;  free(p);  p = pre->next;
    }
    return p->data;
}
```

复杂度段：时间 O(nm)，n 个人各出列一次、每次报数走 m 步；空间 O(n)，建了 n 个结点。

变式题 2算6：倒数第 k，与课上 findK 同法；对照点是 q 先走 k 步时判 NULL、返回值语义按题目。

变式题 2算30：无头指针的循环链表删某结点的前驱——模板11 变体；无头指针时先绕环一周找到尾结点作为"前驱起点"，遍历终止从 p != NULL 换成绕回起点。

变式题 2算37：双向循环链表奇偶位置重排——模板3 在双链表上的应用；每轮把偶数位结点摘下来插到尾部，一次改四条指针（p->next=temp、temp->prior=p、q 接到尾、rear 更新），与下一节 2020 真题同族。

// 2025 倒数第 k（模板2 快慢指针）
int findK(LinkList L, int k){
    LNode *p = L, *q = L;
    while(k != 0 && q != NULL){ q = q->next; k--; }
    if(q == NULL) return 0;
    while(q != NULL){ q = q->next; p = p->next; }
    printf("%d", p->data);
    return 1;
}

// 2021 第一问：比 x 大的数有几个（相同值只计一次）
int biggerCount(LinkList L, int x){
    int before = -1, count = 0;
    LNode *p = L->next;
    while(p != NULL){
        int value = p->data;
        if(value > x && value != before){ count++; before = value; }
        p = p->next;
    }
    return count;
}

// 2021 第二问：比 x 小的按递减排列（断链、头插、接回）
void reverseSmaller(LinkList &L, int x){
    if(L == NULL || L->next == NULL || L->next->data >= x) return;
    LNode *p = L;
    while(p->next != NULL && p->next->data < x) p = p->next;
    LNode *q = p->next, *rear = L->next, *temp;
    p->next = NULL;  p = rear->next;
    while(p != NULL){
        temp = p; p = p->next;
        temp->next = L->next; L->next = temp;
    }
    rear->next = q;
}

// 2021 第三问：删除比 x 大的正偶数（条件删除）
void removeBiggerEven(LinkList &L, int x){
    LNode *p = L, *temp;
    while(p->next != NULL){
        int value = p->next->data;
        if(value > x && value % 2 == 0){
            temp = p->next; p->next = temp->next; free(temp);
        }else p = p->next;              // 只有不删除下一个元素时才移动 p
    }
}
