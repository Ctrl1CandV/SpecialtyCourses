## 正课：初识C程序（第7—15页，约30分钟）

## P7 引题页（约2分钟）

先看两行代码：

printf("你好，重邮802！\n");
printf("我是牙膏学长\n");

从内容上可以猜到，这是让屏幕打印两行字。但看得懂内容，和说得清原理是两回事：这两行字是如何出现在屏幕上的？为什么要这样写？括号、引号、分号分别起什么作用？

本讲结束后，不仅看得懂，还能自己写出来。

## P8 思想先行页（约3分钟）

先建立一个总体认识：程序是什么？

一句话概括：程序就是输入、处理、输出。数据进入程序，按指令逐步处理，最后把结果呈现出来。本讲只涉及输出这一环节，printf的作用就是把结果打印到屏幕。

为什么不直接对计算机下指令，而要写C语言？因为计算机只识别0和1，C语言充当翻译：把想法写成C代码，由它翻译给计算机执行。

另需提前说明：802考察的是伪代码，不需要写#include和main，一段函数即可。但当前是零基础阶段，先学会编写完整程序、把整个流程跑通，后续再逐步简化。

## P9 程序骨架页（约4分钟）

第一个完整程序共五个部分，逐一来看。

第一部分，头文件。#include <stdio.h>，作用是引入现成的工具，printf这个输出工具就定义在stdio.h中。不引入它，计算机无法识别printf。

第二部分，宏定义。#define MaxSize 1000，给数值1000起一个名字叫MaxSize，后续代码中写MaxSize即表示1000。

第三部分，主函数。int main()，是程序的入口，无论代码有多少，都从main开始执行。

第四部分，函数体。花括号内的指令，从上到下依次执行。

第五部分，return 0。向操作系统报告：程序正常结束。

先记住这五个部分的名称，后续各讲会逐一展开。

## P10 代码精讲页（约6分钟）

将第一段代码逐行讲解：

#include <stdio.h>：头文件，printf定义于此；
#define MaxSize 1000：宏定义，此后MaxSize即代表1000；
int main()：主函数，程序入口；
printf("你好！\n");：输出工具，双引号内的内容原样打印，\n表示换行；
return 0;：正常结束。

其中有四个要点需要牢记。

第一，main是程序的入口，永远从main开始执行。阅读陌生程序时，先找到main，从它往下读。

第二，printf是输出工具，双引号内的内容原样打印。

第三，\n是换行符，没有它，所有文字会挤在同一行。

第四，分号是语句的结束标志，每条语句末尾都要写分号，遗漏一个就会报错。

【板书】在代码旁圈出这四个要点：main、printf、\n、分号。

## P11 define与注释页（约3分钟）

本讲还有两个工具需要掌握。

第一个是#define。#define MaxSize 1000，给1000起一个名字；#define PI 3.14，此后PI即代表3.14。它的好处是：需要修改数值时，只改这一行，全程序同步生效。

这里提前说明一个考点：802真题中经常出现#define MaxSize 1000这类定义，顺序表的数组大小即来源于此。

第二个是注释。//之后到行尾为单行注释；/* */之间为多行注释。注释是写给人看的，计算机直接忽略。

为什么要写注释？一是给自己看，时隔数月回看代码，依靠注释回忆思路；二是给阅卷者看，考试要求写算法思想，本质上就是把注释扩展成一段文字。从第一讲开始，养成写注释的习惯。

## P12 板书推演页（约5分钟）

现在从零开始，手写第一个程序。我写一步，大家跟一步。

【板书】
第一步，写头文件：#include <stdio.h>
第二步，写主函数开头：int main(){
第三步，写输出语句：printf("第一行\n");
第四步，再写一行输出：printf("第二行\n");
第五步，写结束：return 0;
第六步，补上右花括号：}

写完之后，检查三件事：每条语句末尾是否有分号；双引号是否成对；花括号是否一开一闭。

【停顿】留出半分钟，自行检查一遍。

## P13 板书结论页（约2分钟）

刚才写出的程序如下：

#include <stdio.h>
int main(){
    printf("第一行\n");
    printf("第二行\n");
    return 0;
}

运行之后，屏幕显示两行：

第一行
第二行

注意，\n本身不会显示出来，它的作用只是让后续内容换到下一行。

## P14 总结页（约2分钟）

本讲内容用一句话概括：程序等于main入口、printf输出、分号结尾。

本节不涉及算法，因此不分析复杂度，该环节从下一讲开始。

四个常见错误，初学阶段普遍会遇到：忘写分号、大小写混用、中文引号、花括号不配对。写完后检查一遍即可。建议将检查固化为习惯：逐条检查分号、引号成对、花括号配对。

## P15 课后任务页（约1分钟）

课后任务共两道：一道跟练、一道模仿。

跟练题：编写一个程序，分三行输出姓名、本科院校、考研目标。

模仿题：修改课上的示例程序，用一条printf打印三行诗。提示：\n可以放在字符串中间。

要求只有一条：合上笔记，能够默写出main的框架。

```c
printf("文字\n");           // 打印文字并换行

printf("第一行\n第二行\n");  // \n出现在中间，照样换行
```
