## P6 引题：基础阶段留下的第一个为什么（约2分钟）

下面进入正课。基础阶段讲scanf的时候，你照抄过一个写法：scanf，百分号d，然后变量前面一个&。为什么必须写这个符号，当时留了个尾巴，说好这个阶段讲。

你先想想这个问题，scanf的工作，是把你在键盘上敲的数字，放进某个变量里。注意"放进"这两个字，变量要存入内存里，内存那么大，scanf怎么知道你那个变量住哪？它要是找错了地方，把数字塞进了别的变量里，程序不就乱套了？所以scanf在动手之前，必须那个变量的位置，而这个东西就叫地址。今天这节课，我们把地址搞清楚，scanf那个&的谜就解开了。你可以停下来想一下，如果让你来设计scanf，你怎么告诉它数据放哪？说"放进score里"是不行的，score是你代码里的名字，机器运行起来只认带编号的格子，因此你得给它一个编号。

## P7 地址：内存格子的编号（约4分钟）

先说地址是什么。基础阶段曾讲过，内存是一长排小格子，一格接一格。当时留了个细节没说：每一格都有自己的编号，就像街道两边的门牌号，你的变量放进某一格，那一格的编号就是这个变量的地址。打个比方，你要让快递员上门修东西，光说"来我家修电脑"没用，你得给地址，内存里的数据也一样，要想使用它，先得知道它住哪。

地址用&来取，&放在变量前面，意思是取这个变量的地址。看这段代码，int x = 10，然后printf用%p打印&x，%d是打整数的，%p就是专门打地址的。你跑一下会看到一串类似0x7ffd开头的数，那就是x住的门牌号。你的机器和我的机器打出来不一样，甚至同一台机器跑两次也不一样，这没关系，编号是程序运行时分配的，我们关心的是它有编号这件事，不是编号具体是几。顺带一个小知识点：打印出来的数以0x开头，那是十六进制的前缀，地址习惯上用十六进制表示，你不用会换算，认识就行，我们这门课关心的是它们的相对位置，不是数本身怎么写。

再问一个问题：基础阶段说变量是带名字的盒子，既然有名字，C语言为什么还要地址？因为名字是给人看的，机器内部干活靠的是编号，函数之间传数据、scanf往回写数据，靠的全是编号，名字只是你在代码里的便利贴。另外你在同一个程序里多次打印&x，值是一样的，因为x一旦住进去，这间格子就不换了，变量搬家这种事不存在，搬的只是值。

从这节课起养成一个习惯：看带地址和指针的代码，别盯着符号看，先在脑子里把它翻译成格子，这一句造了哪个格子，那一句改了哪个格子，格子摆清楚了后面怎么变都不乱。很多人觉得指针难，其实难不在符号，难在如何记住这些格子的变换。这一页就一句话：变量是格子，地址是门牌号，&负责把门牌号取出来。

## P8 scanf的&：把门牌号交出去（约3分钟）

到这里，那个为什么就可以解了。scanf("%d", &score)为什么必须写&？因为scanf要把你敲的数字放进score住的那个格子，它必须知道格子的门牌号，你不给地址，它拿着数字不知道该往哪放。&score的意思就是：score的地址给你，放进去。换句话说，&就是交门牌号这个动作，需要进屋改东西的函数，才要交这个门牌号。

反过来问一个问题：printf打印score的时候，为什么不写&？因为printf只是把格子里的内容输出出来，C语言自动会把变量内容给出来，不需要到地址额外看一眼；而scanf是要进屋放东西的，必须拿到门牌号。谁要走进你的格子谁就需要门牌号，只是读取值的不用。这个对比记住，以后看到&先问一句：这个函数是要进去改，还是只是读，读程序阅读题时这个判断能帮你快速分清函数的意图。

再补一个常见疑问：把&写错地方会怎样？比如scanf("%d", score)漏了&，编译器不一定提醒你，程序跑起来，scanf会把score当前的值当成地址，往不知道是谁的内存里写数字，运气好程序崩溃，运气不好某个变量的值被悄悄改掉。这类错误查起来特别痛苦，非常难查出来，所以规矩就一条：scanf读基本类型变量，&一个都不能少。

顺带说一句，scanf其实有返回值，返回的是成功塞进数据的变量个数，拿这个返回值就能判断读取成不成功。读多个数据时它更有用，比如scanf("%d %d", &a, &b)，读成功两个就返回2，少读一个就返回1。现阶段不深用它，但你要知道它存在，写正经程序时这是常用的检查手段。

## P9 指针：专门存地址的变量（约4分钟）

地址能取出来，总得有地方存，存地址的变量就是指针。看这两行代码：int x = 10，然后int *p = &x。第二行读起来别扭，拆开说：int *p是声明，声明一个指针变量p，它专门用来存地址，而且存的是int变量的地址；p = &x是赋值，把x的门牌号放进p。以后p里装的不是10，是x住哪。

初学者最容易在这里犯糊涂：p里到底存的什么？不是10，是x的地址。你打印p看到的是编号，想看10得用下一页的工具。你也可以把p自己打印出来看看，里面装的就是那串编号。习惯上我们说p指向x，你听到"指向"，就理解成里面存着对方的门牌号。p自己也是个变量，也住在某个格子里，也有自己的门牌号，内存图里它就是一个普通格子，只是里面装的不是数据，是另一个格子的编号。

写法上说清楚：int \*p，星号跟谁的问题不用纠结，写int *p或者int\* p编译器都认，看的时候把int *当成一个整体，意思是int指针类型。另外int *也好char *也好，指针自己占的空间都一样大，常见的64位机器上一个指针占8个字节。道理也简单，不管指向哪间屋子，存的都是那间屋子的编号，编号的大小是固定的，指针存的是门牌号不是房子，房子多大由类型决定，门牌号大小固定。

从这节课开始可以养成一个习惯：凡是涉及指针，先画内存图。画法很简单，格子三样东西：变量名、编号、值，指针画箭头，箭头从p指向x。在遇到复杂问题的时候，图一画指针怎么动你都能跟住，不画图硬想，越想越乱。

## P10 *p：顺着地址取值（约4分钟）

&是把门牌号取出来，反过来，拿着门牌号找到格子、拿里面的东西，这个操作用星号。还是刚才那个p，printf("%d", *p)打印出来是10。\*p读作取p指向的值：先看p里存的门牌号，找到那个格子，把里面的东西拿出来。&和*正好互逆，&x拿到地址，再对地址取值，又回到原来的值。

我写一句\*p = 20，会发生什么？顺着p的门牌号找到格子，把里面的10改成20。那个格子是x的，所以你再去打印x，x也变成了20。那么x和*p是两个变量吗？不是的。从头到尾只有一格内存，*p和x是它的两个名字，改谁都是改它。这就是指针的价值：不用碰变量本身，顺着地址就能读它、改它。

顺着想一步，如果再来一个指针q也指向x，那q、p、x就是同一格内存的三个名字，这时候写*q = 5，p和x看到的值都会变。多个名字指向同一块内存，这个现象叫**别名**。今天先把这个词立住，它是指针强大之处，也是代码最容易出bug的地方：你以为改的是一个东西，其实好几个名字都跟着变了。以后读别人的代码经常会碰到这种情况：一个变量明明没在正文里出现过，值却变了，顺藤摸瓜一查，是某个指针替你去改的。不懂别名这种bug能查半天，懂了就是图上两个箭头的事。

给你一个检验，下面这三行：int x = 10; int *p = &x; *p = *p + 1;。x最后是多少？答案是11。第三行的意思是顺着p取出值，加1，再顺着p放回去，全程没出现x这个名字，但x实实在在变了。这就是今天这节课最想让你看见的一幕。

## P11 动画推演：四步画内存图（约6分钟）

这一页不写代码，就做一件事：把刚才四步在内存图里走一遍。PPT会一步一步放，每放一条停两三秒，留给你跟着画的时间，你拿纸跟着画。动笔之前先把纸笔准备好，别光用眼睛看，图不求画得漂亮，求把关系画对。这四步就是后面所有内存图的基本画法，格子、编号、值、箭头，之后每一节的图都从这里长出来。

第一步，画一个格子，写上名字x，值填10，门牌号随手写一个，比如1000。第二步，声明int *p，再画一个格子存p，p里面放x的门牌号1000，然后从p画一个箭头指向x，这就是p指向x。画p这个格子的时候注意：把p画得和x一样大就行，指针自己占的空间是固定大小，不管指向谁格子都一样大，变的只是里面写的编号。箭头从p的格子出发，顶在x的格子上，单向，别画双向，双向箭头是另一种关系，和今天的场景不是一回事。

第三步，写\*p等于多少。顺着箭头看过去，x那格里是10，所以\*p是10。第四步，写*p = 20，顺着箭头找到格子，把里面的10擦掉写上20。这时候x是多少？也是20。

检查一下自己的图：两个格子，一个箭头，x格子里现在写着20。画对了说明你真的懂了，画不出来倒回去把P7到P10再看一遍。这张图后面会经常用到，现在画得利索，后面省力。在图的旁边再记一句话：*p改的是x那一格，p自己的格子没动。这句话是初学者最容易搞反的地方。这四步图就是今天内容的一半，课后自己再画一遍，能画顺，指针的入门就过了。画图建议用大一点的空白纸，格子画大点，周围留白，后面加箭头和注释方便，这张图整个强化阶段都会用到。

## P12 指针有类型，p自己也有地址（约4分钟）

把指针的几条规矩补齐。第一，指针是有类型的：int *存int的地址，char *存char的地址。类型的作用是告诉编译器，这个指针指向的盒子是多大规格的，你手里拿着一个门牌号，只知道位置还不够，还得知道那间屋子住的是int还是char，取值的时候才知道要读几个格子：int *取4格，char *取1格。所以指针声明都要写清类型，没有类型的void *不能直接取值，原因就在这。现阶段记住一句话：声明指针，写清楚它指向什么类型。

第二，p自己也有地址。p是个变量，也住在内存里，也有自己的门牌号和格子，内存图里别忘了给p画格子，里面填的是x的编号。这样就有两个容易混的操作，分清楚：改\*p，改的是x那格；改p，比如p = &y，改的是p自己格子里存的编号，x一点没动。一个是进屋改东西，一个是换门牌号，完全不同的两件事。举个具体例子：int x = 10, y = 20，p = &x，写p = &y，p就改指到y，这时\*p打印出来是20；而在p指向x的情况下写*p = 99，变的是x，x成了99，y不受影响。两行代码就是两种操作的差别，画个图一目了然。

第三，野指针。声明了一个指针没初始化，里面存的是一个没人知道的地址，这时候对它\*p赋值，就是往一片不知道是谁的内存里写东西，比数组越界还危险，因为你连踩进了哪都不知道。因此在指针没初始化的时候，就不要用*，要么让它指向一个真实的变量，要么先赋成NULL。赋NULL本身也算初始化，先把指针置成NULL、需要时再改指，是稳妥的写法。NULL表示它现在不指向任何有效的东西，一个存着NULL的指针就像一把明确的空白钥匙，你知道它现在打不开任何门，也就不会贸然去开。以后读代码看到p = NULL，基本就是作者在说：这个指针暂时歇着，别用。

三条规矩串起来记：声明写清类型，画图分清*p和p，暂时不用的指针先置NULL。这三条能管住后面所有的指针代码。

## P13 读指针代码的笨办法（约3分钟）

最后给一个读指针代码的笨办法，但是好用。三句话：见到&就念"取地址"，见到*就念"取值"，见到指针移动就想象箭头挪一格。三个动作翻译下来，再绕的代码也能拆成一步步的格子操作。大家可以现场练一个，看这三行：int a = 5; int *p = &a; *p = *p + 1;。a最终变成几？答案是6。全程，只需要一格一格地翻。程序阅读题里的指针挖空，就用这个法子走，比盯着符号硬猜稳得多。

然后再补充一个习惯：遇到读不顺的指针代码，别盯着看，先画内存图再读，把变量一个个摆进格子，把箭头画上，代码说什么你就在图上动什么。这个习惯看着慢，实际上是最快的，因为你不用来回猜。笨办法还能反着用：自己写代码的时候，每写一行带&或*的句子，在脑子里念一遍，念不通就是写错了。

## P14 本节小结（约2分钟）

今天的内容收一下，就三件事。第一，地址是内存格子的编号，&取地址，*顺着地址取值，两个操作互逆。第二，scanf要写&，因为它得拿着门牌号才能把数据放对地方，printf只读不写所以不用。第三，指针是存地址的变量，int *p = &x读作p指向x，*p和x是同一格内存的两个名字，改谁都是改它。

两条安全规矩也要记住：指针不初始化不许用*；改\*p和改p是两件事，画图分清楚。再交代一句，今天画的是最简单的情况：一个指针指一个变量。往后会见到指针指向数组里的格子、一个格子被好几个指针指着，但图再怎么变，还是格子、箭头、值这三样，基础图画扎实了，复杂的图只是格子多一点。今天这节课是后面一切代码的基础，结构体的结点要靠指针连起来，链表的插入删除就是指针挪来挪去，这三件事扎实了后面会越走越顺；还有模糊的地方别急着往下赶，把内存图再画一遍，画通了再走。

## 附录一：课后题参考答案

跟练题：

```c
#include <stdio.h>
int main(){
    int x = 10;
    int *p = &x;
    *p = 25;
    printf("%d\n", x);      // 25
    return 0;
}
```

内存图：格子x（值10→25），格子p存x的地址，箭头p→x。*p=25作用在x所在的格子上。推演口诀：先找p里存的门牌号，再顺着门牌号找到格子，最后在格子里改值。

模仿题：

```c
#include <stdio.h>
int main(){
    int x = 10;
    int y = 20;
    int *p = &x;
    p = &y;
    printf("%d\n", *p);     // 20
    return 0;
}
```

要点：p = &y只改p自己格子里的编号，x和y的值全程没动。常见错法：把p = &y写成*p = &y，这是把地址往x那格里塞，类型都对不上。对照检查一下你写的版本。

## 附录二：本节代码合集

本节出现的代码都在下面，顺序和讲课顺序一致。默写的时候按"取地址、存指针、取值、隔空改物"这条线来，能串下来就说明结构清楚了。

```c
int x = 10;
printf("%p", &x);               // 打印地址，%p专门打地址

scanf("%d", &score);            // 必须写&：scanf要进屋放数据
printf("%d", score);            // 不用&：printf只读不写

int *p = &x;                    // p指向x
printf("%d", *p);               // 顺着地址取值：10
*p = 20;                        // x也变成20，改的是同一格

int *q = &x;                    // q也指向x：别名
*q = 5;                         // p、x看到的值都变

int a = 5;
int *r = &a;
*r = *r + 1;                    // a变成6，全程没出现a的名字
```
