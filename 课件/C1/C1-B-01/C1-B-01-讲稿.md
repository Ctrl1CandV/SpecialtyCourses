## P6 引题：基础阶段留下的第一个为什么（约2分钟）

进入正课。

基础阶段讲scanf的时候，你照抄过一个写法：scanf，百分号d，然后变量前面一个&。抄得对不对？对。但为什么必须写这个符号，当时留了个尾巴，说好这个阶段讲。今天兑现。

你先想想这个问题。scanf的工作，是把你在键盘上敲的数字，放进某个变量里。注意"放进"这两个字。变量住在内存里，内存那么大，scanf怎么知道你那个变量住哪？它要是找错了地方，把数字塞进了别的变量家里，程序不就乱套了？

所以scanf在动手之前，必须拿到一样东西：那个变量的位置。这个东西就叫地址。今天这节课，我们把地址搞清楚，scanf那个&的谜就解开了。顺便说一句，这节课教的工具，是后面整个强化阶段的地基，你值得把它学扎实。

你可以停下来想十秒：如果让你来设计scanf，你怎么告诉它数据放哪？说"放进score里"是不行的，score是你代码里的名字，机器运行起来只认带编号的格子。你得给它一个编号。

## P7 地址：内存格子的编号（约4分钟）

先说地址是什么。

基础阶段讲过，内存是一长排小格子，一格接一格。当时留了个细节没说：每一格都有自己的编号，就像街道两边的门牌号。你的变量住进某一格，那一格的编号，就是这个变量的地址。

打个比方。你要让快递员上门修东西，光说"我家有台电脑坏了"没用，你得给地址。内存里的数据也一样，谁想动它，先得知道它住哪。

顺带把基础阶段的一个知识点接上。int的盒子占4格，char占1格，double占8格。现在你能理解得更深一层：盒子大，占的格子就多，门牌号用的是它第一格的编号。

地址怎么拿到？用&。&放在变量前面，意思是取这个变量的地址。看这段代码：int x = 10，然后printf用%p打印&x。%d是打整数的，%p就是专门打地址的。你跑一下，会看到一串类似0x7ffd开头的数，那就是x住的门牌号。你的机器和我的机器打出来不一样，甚至同一台机器跑两次也不一样，没关系，编号是程序运行时分配的，我们关心的是它有编号这件事，不是编号具体是几。

再问你一个问题：基础阶段说变量是带名字的盒子，既然有名字，C语言为什么还要地址？因为名字是给人看的，机器内部干活靠的是编号。函数之间传数据、scanf往回写数据，靠的全是编号。名字只是你在代码里的便利贴。

还有一个细节。你在同一个程序里多次打印&x，值是一样的，因为x一旦住进去，这间格子就不换了。变量搬家这种事不存在，搬的只是值。

再给你一个习惯。从这节课起，看带地址和指针的代码，别盯着符号看，先在脑子里把它翻译成格子：这一句造了哪个格子，那一句改了哪个格子。格子摆清楚了，后面怎么变都不乱。很多人觉得指针难，其实难不在符号，在脑子里没建起这张格子图。

收一下：变量是格子，地址是门牌号，&负责把门牌号取出来。

## P8 scanf的&：把门牌号交出去（约3分钟）

到这里，那个为什么就可以解了。

scanf("%d", &score)，为什么必须写&？scanf要把你敲的数字放进score住的那个格子，它必须知道格子的门牌号。你不给地址，它拿着数字不知道该往哪放。&score的意思就是：score的地址给你，放进去。

我考你一个反向的问题：printf打印score的时候，为什么不写&？

【停顿】

因为printf的活不一样。printf只是把格子里的东西读出来看一眼，它顺着名字就能找到格子，看完就走，不进屋。scanf是要进屋放东西的，所以必须拿钥匙。一句话：谁要走进你的格子，谁就需要门牌号；只是远观的，不用。

这个对比你记住，以后看到&，先问一句：这个函数是要进去改，还是只是读。读802的程序阅读题，这个判断能帮你快速分清函数的意图。

再补一个常见疑问。有同学问，那我把&写错地方会怎样？比如scanf("%d", score)，漏了&。编译器不一定提醒你，程序跑起来，scanf会把score当前的值当成地址，往那片不知道是谁的内存里写数字。运气好程序崩溃，运气不好，某个变量的值被悄悄改掉。这类错误查起来特别痛苦，所以规矩立住：scanf读基本类型变量，&一个都不能少。

顺带补一句完整的知识。scanf其实有返回值，返回的是成功塞进数据的变量个数。你拿这个返回值就能判断读取成不成功。我们现阶段不深用它，但你要知道它存在，写正经程序时，这是常用的检查手段。

## P9 指针：专门存地址的变量（约4分钟）

地址能取出来，总得有地方存。存地址的变量，就是指针。

看这两行。int x = 10，然后int *p = &x。第二行读起来别扭，我拆开说。int *p是声明，意思是声明一个指针变量p，它专门用来存地址，而且存的是int变量的地址。p = &x是赋值，把x的门牌号放进p。以后p里装的不是10，是x住哪。

初学者最容易在这里犯糊涂：p里到底存的什么？不是10，是x的门牌号。你打印p，看到的是编号；你想看10，得用下一页的工具。

习惯上我们说：p指向x。这个说法后面会一直用，你听到"指向"，就理解成"里面存着对方的门牌号"。

再补一句。p自己也是个变量，也住在某个格子里，也有自己的门牌号。内存图里它就是一个普通格子，只是里面装的不是数据，是另一个格子的编号。这一点先有个印象，画图的时候你就不会懵。

顺便把写法说清楚。int *p，星号跟谁的问题，不用纠结，写int *p或者int* p编译器都认。你看的时候把int *当成一个整体，意思是"int指针类型"。

再说一个你可以自己验证的事实：int *也好，char *也好，指针自己占的空间都一样大。常见的64位机器上，一个指针占8个字节。道理也简单，不管指向哪间屋子，存的都是那间屋子的编号，编号的大小是固定的。指针存的是门牌号，不是房子，房子多大由类型决定，门牌号大小固定。

从这节课开始，给你立一个贯穿整个强化阶段的规矩：凡是涉及指针，先画内存图。画法很简单，格子三样东西：名字、编号、值，指针画箭头，箭头从p指向x。图一画，指针怎么动你都能跟住；不画图硬想，越想越乱。

## P10 *p：顺着地址取值（约4分钟）

&是把门牌号取出来，那反过来呢？拿着门牌号找到格子、拿里面的东西，这个操作用星号。

还是刚才那个p。printf("%d", *p)，打印出来是10。*p读作取p指向的值：先看p里存的门牌号，找到那个格子，把里面的东西拿出来。&和*正好互逆：&x拿到地址，再对地址取值，又回到原来的值。你绕一圈，拿回来的还是10。

关键来了。我写一句*p = 20，会发生什么？顺着p的门牌号找到格子，把里面的10改成20。那个格子是谁的？是x的。所以你再去打印x，x也变成了20。

我问你：x和*p是两个变量吗？

【停顿】

不是。从头到尾只有一格内存，*p和x是它的两个名字，改谁都是改它。这就是指针的价值：不用碰变量本身，顺着地址就能读它、改它。

顺着这个想一步。如果再来一个指针q，也让它指向x，那q、p、x就是同一格内存的三个名字。这时候你写*q = 5，p和x看到的值都会变。多个名字指向同一块内存，这个现象叫**别名**。今天先把这个词立住，它是指针强大之处，也是代码最容易出bug的地方：你以为改的是一个东西，其实好几个名字都跟着变了。

为什么要专门强调别名？因为以后读别人的代码，经常会碰到这种情况：一个变量明明没在正文里出现过，值却变了。顺藤摸瓜一查，是某个指针替你去改的。不懂别名，这种bug能查半天；懂了，图上两个箭头的事。

给你一个检验。下面这三行：int x = 10; int *p = &x; *p = *p + 1;。x最后是多少？

【停顿】

11。第三行的意思是，顺着p取出值，加1，再顺着p放回去。全程没出现x这个名字，但x实实在在变了。这就是今天这节课最想让你看见的一幕。

## P11 板书推演（约6分钟）

【板书】

动手。这次板书不写程序，骨架那些东西早就会了，我们只做一件事：画图，把刚才四步在内存里走一遍。你拿纸跟着画。

第一步，画一个格子，写上名字x，值填10，门牌号随手写一个，比如1000。

第二步，声明int *p。再画一个格子存p，p里面放什么？放x的门牌号1000，然后从p画一个箭头，指向x。这就是p指向x。

画p这个格子的时候，有个细节提醒你：把p画得和x一样大就行。前面说过，指针自己占的空间是固定大小，不管指向谁，格子都一样大，变的只是里面写的编号。箭头怎么画也立个规矩：从p的格子出发，箭头顶在x的格子上，单向，别画双向。双向箭头是"两个人互相指着"，那是另一种关系，和今天的场景不是一回事。

第三步，写*p等于多少。顺着箭头看过去，x那格里是10，所以*p是10。

第四步，写*p = 20。顺着箭头找到格子，把里面的10擦掉，写上20。这时候我问你，x是多少？

【停顿】

同一格，x也是20。

你检查一下自己的图：两个格子，一个箭头，x格子里现在写着20。画对了，说明你真的懂了；画不出来，倒回去把P7到P10再看一遍，不亏。

再给你加一个动作。在图的旁边写一行字：*p改的是x那一格，p自己的格子没动。这句话是初学者最容易搞反的地方，写下来，贴在显眼的地方。这四步图就是今天全部内容的一半，课后自己再画一遍，能画顺，指针的入门你就过了。

## P12 指针有类型，p自己也有地址（约4分钟）

把指针的几条规矩补齐。

第一条，指针是有类型的。int *存int的地址，char *存char的地址。类型有什么用？它告诉编译器，这个指针指向的盒子是多大规格的。你手里拿着一个门牌号，只知道位置还不够，还得知道那间屋子住的是int还是char，取值的时候才知道要读几个格子：int *取4格，char *取1格。同一个门牌号，取出来的房子不一样大。所以指针声明都要写清类型；没有类型的void *不能直接取值，原因就在这。现阶段你记住一句话：声明指针，写清楚它指向什么类型。

第二条，p自己也有地址。p是个变量，它也住在内存里，也有自己的门牌号和格子。内存图里别忘了给p画格子，里面填的是x的编号。这么一来就有两个容易混的操作，我帮你分清楚：改*p，改的是x那格；改p，比如p = &y，改的是p自己格子里存的编号，x一根汗毛都没动。一个是进屋改东西，一个是换门牌号，完全不同的两件事。

第三条，野指针。声明了一个指针，没初始化，里面存的是一个没人知道的地址。这时候对它*p赋值，就是往一片不知道是谁的内存里写东西，比数组越界还危险，因为你连踩进了哪都不知道。规矩只有一条：指针没初始化，就不许用*。要么让它指向一个真实的变量，要么先赋成NULL，表示它现在不指向任何有效的东西，这是标准写法。

赋NULL的意义，是把"没人知道"变成"明确的空"。一个存着NULL的指针，就像一把明确的空白钥匙，你知道它现在打不开任何门，也就不会贸然去开。以后读代码看到p = NULL，基本就是作者在说：这个指针暂时歇着，别用。这么看，NULL与其说是一个值，不如说是一个记号。

## P13 读指针代码的笨办法（约3分钟）

最后给你一个方法，读指针代码的笨办法，但是好用。

三句话：见到&就念"取地址"，见到*就念"取值"，见到指针移动就想象箭头挪一格。三个动作翻译下来，再绕的代码也能拆成一步步的格子操作。

现场练一个。看这三行：int a = 5; int *p = &a; *p = *p + 1;。用我们的办法逐句翻。第一句，普通变量，a住进一格，值5。第二句，取a的地址，放进p，p指向a。第三句，顺着p取出值，加1，放回去。a变成几？

【停顿】

6。你看，全程不需要灵感，只需要一格一格地翻。程序阅读题里的指针挖空，就用这个法子走，比盯着符号硬猜稳得多。

再来一个稍复杂的，两个指针。int x = 3; int y = 7; int *p = &x; int *q = &y; 最后一句：*p = *q;。逐句翻：x是3，y是7，p指向x，q指向y，最后一句是把q指向的值——也就是7——放进p指向的位置——也就是x。结果x变成7，y不变。注意，复制的是屋里的值，不是屋子本身。这句也是以后画图最常写的一句话。

再补一个习惯。遇到读不顺的指针代码，别盯着看，先画内存图再读。把变量一个个摆进格子，把箭头画上，代码说什么你就在图上动什么。这个习惯看着慢，实际上是最快的，因为你不用来回猜。

## P14 本节小结（约2分钟）

今天的内容收一下，就三件事。

第一，地址是内存格子的编号。&取地址，*顺着地址取值，两个操作互逆。

第二，scanf要写&，因为它得拿着门牌号才能把数据放对地方；printf只读不写，所以不用。谁进屋谁要钥匙。

第三，指针是存地址的变量。int *p = &x读作p指向x；*p和x是同一格内存的两个名字，改谁都是改它。

两条安全规矩也立在这：指针不初始化不许用*；改*p和改p是两件事，画图分清楚。

再交代一句。今天画的是最简单的情况：一个指针指一个变量。往后会见到指针指向数组里的格子、一个格子被好几个指针指着，但图再怎么变，还是格子、箭头、值这三样。基础图画扎实了，复杂的图只是格子多一点。

今天这节课，是后面一切代码的地基。结构体的结点要靠指针连起来，链表的插入删除就是指针挪来挪去。今天这三件事扎实了，后面会越走越顺；还有模糊的地方，别急着往下赶，把内存图再画一遍，画通了再走。

## P15 课后任务（约2分钟）

跟练题：声明int x = 10和一个指向x的指针p，用*p把x改成25并打印出来，然后把每一步的内存图画出来。这道题把今天的板书四步重走一遍。画图的时候检查三件事：p的格子里写的是x的门牌号不是10；箭头从p指向x；*p=25之后，被改的是x那一格，p的格子纹丝不动。三件都对，你才是真懂了。

## 附录一：课后题参考答案

跟练题：

```c
#include <stdio.h>
int main(){
    int x = 10;
    int *p = &x;
    *p = 25;
    printf("%d\n", x);      // 25
    return 0;
}
```

内存图：格子x（值10→25），格子p存x的地址，箭头p→x。*p=25作用在x所在的格子上。推演口诀：先找p里存的门牌号，再顺着门牌号找到格子，最后在格子里改值。

模仿题：

```c
#include <stdio.h>
int main(){
    int x = 10;
    int y = 20;
    int *p = &x;
    p = &y;
    printf("%d\n", *p);     // 20
    return 0;
}
```

要点：p = &y只改p自己格子里的编号，x和y的值全程没动。常见错法：把p = &y写成*p = &y，这是把地址往x那格里塞，类型都对不上。对照检查一下你写的版本。

## 附录二：本节代码合集

本节出现的代码都在下面，顺序和讲课顺序一致。默写的时候按"取地址、存指针、取值、隔空改物"这条线来，能串下来就说明结构清楚了。

```c
int x = 10;
printf("%p", &x);               // 打印地址，%p专门打地址

scanf("%d", &score);            // 必须写&：scanf要进屋放数据

int *p = &x;                    // p指向x
printf("%d", *p);               // 顺着地址取值：10
*p = 20;                        // x也变成20，改的是同一格

int *q = &x;                    // q也指向x：别名
*q = 5;                         // p、x看到的值都变

int a = 5;
int *r = &a;
*r = *r + 1;                    // a变成6，全程没出现a的名字
```
