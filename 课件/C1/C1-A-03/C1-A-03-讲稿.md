## P1 封面页（约0.5分钟）

大家好，我是牙膏学长，这节课第三讲，运算符与表达式。前两节咱们学会了存数据、输入输出数据，这一节，要让程序真正会运算。

## P2 引题：程序光会存不会算（约1.5分钟）

先看看上一节咱们写到哪了。可以看到数据进来了，然后原样打出去了。我们可以发现，这个程序其实什么也没干——它就当了个传声筒，你给它什么，它还你什么。但是真正的代码不是传声筒，你随便翻一道真题的伪代码，里面全是计算：判断这个结点的编号是奇数还是偶数、取一个数的个位、比较两个元素谁大谁小、数一数链表有几个结点。这些事，全得靠运算符。

我给你举个具体的。比如说要把链表里"比x大的正偶数"删掉。你拿到这题，第一步就得判断：这个数是不是偶数？是不是正数？是不是比x大？三个判断，那么就对应三个条件，全是我们今天要讲的运算符。没有运算符，你连题目让你干嘛都无法翻译为代码。所以这一节，咱们把C语言里咱们用得到的运算符一次认全。放心，不多只有五类，认完之后到考研结束都够用了。

## P3 算术运算符：加减乘除，除法有两个坑（约3.5分钟）

先看算法运算符，包含最简单的加减乘除和取余。a + b，加法；a - b，减法；a * b，乘法；a / b，除法。注意乘号是星号*，不是数学里的×，然后加减乘没什么可说的，坑全在除法上。

先看除法：a / b。听首先第一个坑是：**两个整数相除，结果是整数**。比如9除以2，数学里是4.5，但在C语言里，9 / 2 等于4，因为小数点后面的部分被直接舍弃了，不是四舍五入。这个坑你其实已经见过了，但与上一节的 int x = 3.9 打印出的结果是3不同，并非是赋值的时候做的截断，而是c语言就定义当两个操作数都是整数类型时，除运算符执行的是整数除法。今天的 9 / 2 得4，是除法的时候截断。

那我要真想要4.5怎么办？那么就要写为写 9.0 / 2，结果就是4.5。记住一句话：**两边只要有一个小数，结果就是小数**。9.0是double常量，2是int，混合运算的时候C语言会自动把结果往宽的类型靠，9.0 / 2 就能出4.5。

这里多说一句，整数除法这个"丢小数"的设定，在802里反而是个大用处。你以后会学到折半查找，它的核心一行是 mid = (low + high) / 2，求中间位置。low加high可能是个奇数，除以2，C语言自动把小数扔掉，给你一个干脆利落的整数下标——下标本来就得是整数，这里截断不是坑，是正好要的行为。所以同一个特性，在看似没用的地方是坑，在802的代码里是工具，就看你怎么用。

再看取余：a % b。这个%不是百分号，是取余数。9除以2，商4余1，所以 9 % 2 等于1。取余就是问"除完剩多少"。取余有个限制：**只能对整数用**。你写10.5 % 3，编译器直接报错，小数没有余数这个概念。还有个负数的情况，说一句就过：-9 % 2 得 -1，余数跟着被除数走。为什么这么规定？因为C语言希望 / 和 % 配套：-9 / 2 得 -4，-4乘2是-8，-9减-8剩-1，所以余数是-1，符号跟被除数一致，两个运算才能对得上账。802手算基本不碰负数取余，你有个印象就行。

## P4 取余的两个用途：% 在802里就这两个用法（约2.5分钟）

取余看着不起眼，但是它在802里有俩用法，而且这俩用法反复考，你现在就记牢，后面省事。

第一个用法，**判断奇偶**。x % 2，任何整数除以2，余数要么0要么1。余1是奇数，余0是偶数。你可以去翻真题，2021年那道"删除大于x的正偶数"，第一步就是判断偶数，用的就是这个式子。

第二个用法，**取个位**。x % 10，任何整数除以10，余数就是个位。125除以10，商12余5，5就是个位。那么要取十位的话，就先x / 10，再% 10，拿到2。x / 10 % 10，十位就出来了，那么百位千位，就同理往下推。

这俩用法非常重要，在无论802真题还是其他代码里，涉及到判断奇偶数以及取一个数字的某一位的部分，到吗使用的全是这个。

## P5 取余还能拆时间（约1.5分钟）

取余再给你一个真实场景，顺便巩固一下。3670秒，是多少分多少秒？你心算一下：60秒是1分钟，3670除以60，商61余10，也就是61分10秒。这个换算，C语言里怎么写？

int seconds = 3670;
printf("%d分%d秒", seconds / 60, seconds % 60);

除以60取整，得61是分钟数；对60取余，得10是秒数。看明白没有，又是/和%这对搭档：一个取商一个取余。以后再遇到拆天数、拆小时、拆分钟，凡是"逢多少进一"的单位换算，那么全是这一个套路，在802手算题里换单位的活，思路跟这一模一样。

## P6 赋值运算符：老朋友，加几个简写（约1.5分钟）

然后就是赋值运算符，我们上一节认识过就是=，今天加几个简写。首先score = 125，从右往左读，先算右边然后塞进左边盒子。

看这几个新的：score += 5，就是 score = score + 5 的简写；score -= 5，就是 score = score - 5；score *= 2，score /= 2，同理。读法跟=一模一样：从右往左。先把 score + 5 算出来，再放回 score 盒子。

这个功能一般什么时候用？你看数据结构代码里，统计结点个数要加一、循环里下标要往后挪，这些"在原来的基础上变一下"的操作，全用这种简写。你现在先认个脸熟，会读就行。那为什么C语言要发明这些简写？因为"在自己身上加一个数"这个操作太常用了，常用到值得给它一个专门的写法。你写 score += 5，比写 score = score + 5 短，而且读起来意图更清楚——一眼就知道是"score自己加5"，而不是什么别的赋值。C语言里凡是高频的动作，基本都有简写，++和--也是这个逻辑。

## P7 关系运算符：比较大小，结果是个bool（约3分钟）

第三类是关系运算符，用于比较大小用。大于、小于、大于等于和小于等于。这四个跟数学一样，不用记。注意一个写法上的小坑：大于等于是>=，先写大于号再写等号，写成=<就错了，C语言不认。这种符号顺序的小细节，手写代码的时候容易出错，你写的时候留个心眼。

重点看最后两个：a == b，两个等号，等于和a != b，不等于。注意了，这是全节最重要的内容，即**一个等号和两个等号是两回事**。上节课讲过一个=是赋值，是把东西塞进盒子的动作。==，两个等号，才是比较，是问"这两个东西一不一样"。你写 a = 3，是在把3塞进a这个盒子；你写 a == 3，才是在问"a是不是3"。这俩长得就差一个等号，意思天差地别。初学者栽得最多的就是这个，而且这错有个特点：编译不报错，程序照跑，结果就是不对。为什么？因为 a = 3 本身是个合法语句，编译器觉得你没写错。

此外还有一件事，关系运算的结果是什么？就是上一节讲的bool。a > b 成立的时候，结果是true；不成立，结果是false。你看，上一节单独讲bool，这一节就用上了——比较的结果就是bool，bool就是给比较用的。再往前接一步。802伪代码里那些边界判断，比如顺序表插入前的 if(i < 1 || i > L.length + 1) return false; 翻译过来就是"如果位置不合法，就不插了"。这里面的每一个 <、>，都是今天讲的关系运算符。你把这些运算符吃透，后面读伪代码的边界判断，就是顺理成章的事。

## P8 一个必踩的坑：0 < x < 10（约2.5分钟）

关系运算这里有一个坑，很多初学者都踩会犯这个错，这也是本节的重点之一，你看仔细。你想判断"x在0到10之间"，数学写 0 < x < 10，特别自然。然后你照抄进C语言，写了 0 < x < 10。你以为程序在判断"x在不在0和10之间"，但是它根本不在干这件事。为什么？因为C语言**不能连着写比较**，它是从左往右一步一步算的。先算 0 < x，这个式子要么true要么false，true在C语言里就是1，false就是0。算完得到1或者0，再拿这个1或0去跟10比。1 < 10，永远成立。所以不管你x是多少，x是5也好，是100也好，是-8也好，整个式子的结果永远是真的。你以为在判断范围，其实在判断一句废话。

有条件的你把 0 < x < 10 打印出来看看，x随便取，结果永远是1。亲眼看见"永远为真"，这个坑你这辈子不会再踩。

这类错误有个共同特点，就是大家会把**数学写得顺手的，照抄到代码里面，但C语言不一定认**。数学是给人看的，怎么自然怎么写；C语言是给机器执行的，它有自己死板的一套规矩。你以后遇到"看起来应该对"的写法，多留个心眼，先想想机器会怎么一步一步执行它。那正确写法是什么？范围判断要拆成两个比较：x > 0，这是一个；x < 10，这是另一个；两个条件都要满足，用&&接起来：x > 0 && x < 10。&&是什么？下一页就讲。

## P9 逻辑运算符：与、或、非（约2.5分钟）

第四类，逻辑运算符，它是把关系运算的结果串起来用的，这个好像在高中的技术课有提到过。

三个符号：

a && b，这个&&读作"与"，意思就是"并且"，当且仅当两边都是true的时候结果才是true，如有一边是false，结果就是false。

a || b，这个||读作"或"，意思就是"或者"，当且仅当两边都是false的时候结果才是false，如有一边是true，结果就是true。

!a，这个感叹号读作"非"，就是把结果反过来。true变false，false变true。

举个例子你就通了。考研报名要满足"学历符合"和"专业符合"，两个条件都得满足，这就是&&。调剂的时候，"A校有名额"或者"B校有名额"，有一个就行，这就是||。你看上一页那个坑，救它的就是&&：x > 0 && x < 10，两个比较的结果用&&接起来，两边都是true，整个才是true。现在你明白为什么上一页那么写了。

逻辑运算的结果还是bool。802的伪代码里写边界条件，全是这个语句。你以后会天天见到 i >= 0 && i < length 这种写法，它的意思就是"下标i没越界"——既不小于0，又没超过表长。你现在会读，后面讲循环判断的时候直接就能用。

&&还有一个特点叫短路，这个在802里也是一个考点，就是&&是从左往右算的，只要左边算出来是false，整个式子就已经是false了，**右边它根本不看，直接跳过**。这个特性在链表代码里是很显著的，你以后会见到这样一行：p != NULL && p->data != elem，它的意思是"p不是空，并且p里存的值不是我要找的"。注意顺序——先判 p != NULL，再去看 p->data。为什么这个顺序不能反？因为如果p已经是NULL了，左边判出false，右边 p->data 就**不会被执行**，程序安全。你要是把顺序写反了，先去访问 p->data，p是NULL，程序当场崩溃。一个&&的顺序，决定程序是安全还是崩溃，这就是短路。这个点你现在有个印象，等学链表的时候，你会再见到它一次。

## P10 自增自减：++ 和 --，给自己加1减1（约1.5分钟）

第五类，也是最简单的两个，即自增与自减。i++，就是 i = i + 1；i--，就是 i = i - 1。没别的意思，就是"自己加1""自己减1"。

为什么专门讲它俩？因为你去看数据结构代码，到处都是：循环里 i++、j++，链表里 length++，数结点个数 count++，这个代码出现的频率非常高，你必须会读。有一个细节我先不展开：i++ 和 ++i 写在表达式里的时候，结果有一点点区别。但是——用不着现在纠结。咱们现在只需要知道"加1"这个直觉就够了，什么时候真遇到那个区别了，我再专门给你讲。现在记住一句话：看到++就是加1，看到--就是减1。

提前给你透个底：下一节讲循环，循环里有个专门负责"更新"的部分，十有八九就是 i++。今天把它认熟了，下一节你读循环代码就顺了。

## P11 优先级：只记这一句（约1.5分钟）

最后说优先级。数学里有"先乘除后加减"，C语言也一样，但它有一整张十几行的优先级表，非常复杂。咱们只需要一句口诀：自增减 > ! > 算数 > 关系 > 逻辑。

为什么C语言要规定优先级？因为一个式子里有好几个运算符，计算机必须知道先算谁。它不能问你，只能按一张固定的表来。这张表很长，但咱们用到的部分，就口诀这一句，后续会进行补充和修改。就这么回事。完整的关系、逻辑这些放哪一层，不需要背下来，你写代码的时候拿不准就**加括号**。多写一对括号不丢人，算错了才丢人。你看802的参考代码，人家也是加括号加得明明白白的。

## P12 板书推演：从零写，读入整数拆个位十位（约4分钟）

现在动手。今天的程序有意思了——读入一个整数，把它的个位和十位拆出来。用到的就是这节的两大杀器：%和/。

我写一行，你跟一行。

【板书】
第一步，头文件：#include <stdio.h>
第二步，大门：int main(){

## P13 板书结论（约1分钟）

对答案：

#include <stdio.h>
int main(){
    int n;
    scanf("%d", &n);
    printf("个位：%d\n", n % 10);
    printf("十位：%d\n", n / 10 % 10);
    return 0;
}

跑一下，输入125，屏幕输出：个位5、十位2。

看明白没有，%和/一配合，一个三位数你想拆哪一位就拆哪一位。这个"拆数字"的手艺，802手算题里考散列、考进制的时候，用的都是这个思路。你回头看看这个程序，它把咱们这三节课学的东西全用上了：头文件和main是第一节学的，声明变量、scanf、printf是第二节学的，%和/是今天学的。三节课攒下来的东西，凑在一起就是一个能干实事的程序。这就是编程的感觉——零件一个个攒，攒够了就能拼出东西。

## P14 总结（约1分钟）

这一节五类运算符，帮你收一下。

算术：加减乘除取余。两个坑：整数除法丢小数，想留小数就让一边是小数；取余只能对整数。

取余两个用途：x % 2判奇偶，x % 10取个位。拆时间、拆数字，都是它。

赋值和比较：一个等号是动作，两个等号是问题。混了不报错，但结果全错。范围判断不能连着写，0 < x < 10是句废话，拆成两个条件用&&接。

优先级就一句：括号大于乘除取余，大于加减。拿不准就加括号。

## 附录二：本节代码合集

**五类运算符一览**

```c
// 算术
a + b;  a - b;  a * b;
a / b;          // 整数除法：9/2 得 4
9.0 / 2;        // 一边是小数，结果就是小数：4.5
a % b;          // 取余：9%2 得 1

// 赋值与简写
score = 125;
score += 5;     // 即 score = score + 5

// 关系（结果是bool）
a > b;  a < b;  a >= b;  a <= b;
a == b;         // 比较相等，两个等号
a != b;

// 逻辑（结果是bool）
a && b;         // 并且
a || b;         // 或者
!a;             // 取反

// 自增自减
i++;            // i = i + 1
i--;            // i = i - 1
```

**取余的三个用法**

```c
x % 2           // 判断奇偶：1是奇数，0是偶数
x % 10          // 取个位
x / 10 % 10     // 取十位
seconds % 60    // 拆时间：总秒数对60取余，得秒数
```

**范围判断的正确写法**

```c
0 < x < 10          // 错：永远为真，是句废话
x > 0 && x < 10     // 对：拆成两个条件，用&&接
```

**板书完整程序**

```c
#include <stdio.h>
int main(){
    int n;
    scanf("%d", &n);
    printf("个位：%d\n", n % 10);
    printf("十位：%d\n", n / 10 % 10);
    return 0;
}
```
