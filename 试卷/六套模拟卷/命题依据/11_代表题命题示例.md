## S5-I04　平衡检查中的失败传播（5分）

下列函数在二叉树平衡时返回高度，不平衡时返回−1。空树高度为0。`max`及`abs`按通常整数含义使用。

```c
int bh(Node *t) {
    if (t == NULL) return 0;
    int lh = bh(t->left);
    int rh = bh(t->right);
    /* 待补：处理子树已经不平衡的情况 */
    if (abs(lh - rh) > 1) return -1;
    return 1 + max(lh, rh);
}
```

1. 未补语句时，若左右递归调用均返回−1，本层错误地返回多少？（2分）
2. 补上所缺的判断。（2分）
3. 修正后最坏时间复杂度是多少？说明依据。（1分）

**参考答案：** 错误返回0；应在高度差判断之前加入 `if (lh == -1 || rh == -1) return -1;`。最坏每个结点访问一次，时间O(n)。这里−1代表失败，不能作为正常高度参与合并。只检查当前高度差而不传播子树失败，不能判断整树平衡。

## S6-II04　朴素匹配末端起点的边界（3分）

文本T以0基下标存放n个字符，不另存终止符。非空模式P有m个字符，n、m均为非负整数长度且m>0。朴素匹配在起点i比较 `T[i..i+m-1]` 与P。原程序只尝试 `0 <= i < n-m`，对 `T="abc"`、`P="bc"` 漏报成功。以下修改正确的是：

A. m>n时直接失败，否则尝试 `0 <= i <= n-m`。

B. 对任意m，尝试 `0 <= i < n`。

C. 保持 `0 <= i < n-m`，只把比较顺序从左到右改为从右到左。

D. m<=n时尝试 `0 <= i <= n-m+1`。

**参考答案：A。** 最后合法起点为n−m；本例为1。B、D可能访问文本末尾之后的位置；C仍未检查起点1。选择正确得3分，不另要求学生写解释。

## S5-III07　LSD桶内顺序错误的诊断（10分）

对记录 `(21a,12,21b,11,22,10)` 做两位十进制LSD基数排序。字母a、b只区分同为21的两条记录，初始21a先于21b。桶按数字0到9收集。

1. 桶内先进先出时，写个位趟、十位趟后的记录序列。（4分）
2. 若仅个位趟改成桶内后进先出，十位趟仍保持稳定，写错误个位趟及最终序列。（3分）
3. 对第2问的最终结果，分别判断数值是否有序、记录是否稳定，并给证据。（3分）

**参考答案：**

| 情况 | 个位趟后 | 十位趟后 |
|---|---|---|
| 两趟均稳定 | 10,21a,21b,11,12,22 | 10,11,12,21a,21b,22 |
| 仅个位桶逆序 | 10,11,21b,21a,22,12 | 10,11,12,21b,21a,22 |

错误版本在本例中仍按键值有序，但21a、21b的次序颠倒，已经不稳定。不能据此推断桶内逆序对其他数据也能保证排序正确。给分对应两趟正确状态、错误状态和两个不同判据；前问算错但后续按自己的状态正确推演时，不重复扣同一失误。

## S5-IV01　有序数组中和为K的下标对计数（8分）

整数数组A按非递减顺序排列，长度n可为0。统计所有满足 `0 <= i < j < n` 且 `A[i]+A[j]=K` 的下标对数。重复值对应不同下标，均应计数。不得修改A，要求O(n)时间、O(1)辅助空间。说明思想，写关键代码并分析边界和复杂度。

例如，A为 `(-2,0,0,2,2)`、K=2时答案为4；A为 `(1,1,1,1)`、K=2时答案为6。使用足够宽的整数计算和与计数。

**参考实现：**

```c
long long countPairs(const int A[], int n, long long K) {
    int i = 0, j = n - 1;
    long long ans = 0;
    while (i < j) {
        long long s = (long long)A[i] + A[j];
        if (s < K) ++i;
        else if (s > K) --j;
        else if (A[i] == A[j]) {
            long long r = j - i + 1;
            ans += r * (r - 1) / 2;
            break;
        } else {
            int x = A[i], y = A[j];
            long long leftCount = 0, rightCount = 0;
            while (i <= j && A[i] == x) { ++leftCount; ++i; }
            while (j >= i && A[j] == y) { ++rightCount; --j; }
            ans += leftCount * rightCount;
        }
    }
    return ans;
}
```

和太小时，当前左端值与所有剩余值都无法得到K，可安全跳过；和太大时对称处理。命中时若两端值不同，左右相同值组中任取一个下标都构成一对，共cL×cR对；若两端值相同，中间也全部相同，共r(r−1)/2对。组被处理后整体跳过，不重复计数。

思想与排除规则2分；不同值组与同值组的正确实现4分；n<2边界和O(n)/O(1)分析2分。只找到一对即返回，不能获得计数实现部分的全部分数。

## S6-IV02　不建树直接输出后序（10分）

给同一棵二叉树的先序数组pre与中序数组in，长度均为n。结点标识互异，为0到n−1；输入保证合法。另已给位置表 `pos[x]`，表示x在in中的0基下标。不得申请树结点，直接将后序写入长度n的输出数组post，要求O(n)时间。说明思想、关键代码，并分别说明已给数组、输出数组和递归栈的空间。

例如 `pre=(0,1,3,4,2,5)`，`in=(3,1,4,0,5,2)`。

**参考实现：**

```c
void emitPost(const int pre[], const int pos[],
              int start, int left, int len, int post[], int *out) {
    if (len == 0) return;
    int root = pre[start];
    int leftLen = pos[root] - left;
    emitPost(pre, pos, start + 1, left, leftLen, post, out);
    emitPost(pre, pos, start + 1 + leftLen, pos[root] + 1,
             len - 1 - leftLen, post, out);
    post[(*out)++] = root;
}
/* int out=0; emitPost(pre,pos,0,0,n,post,&out); */
```

示例结果为 `(3,4,1,5,2,0)`。根在中序中的位置确定左右子树大小；先输出两侧后序，再输出根。每结点只做常数工作，时间O(n)，额外递归栈O(h)。已给pos与输出post各占O(n)，另列而不隐去；n=0时不访问数组。

划分及边界3分；递归次序与输出游标4分；空区间1分；时空分析2分。只把构树算法换函数名、仍申请结点的答案未满足题目约束。

## S6-IV03　新增依赖后的三种结果（12分）

给DAG的邻接表和一个已验证合法的完整拓扑序sigma，顶点编号为0到V−1。计划加入一条弧u→v，u、v均合法且允许相同。返回以下三种结果之一：原序仍可用；需要重排但仍无环；加入后有环。不修改原图，不要求输出新序，要求最坏O(V+E)。说明算法、关键代码、正确性和复杂度。

示例原图为 `0→2,1→2,2→3`，sigma为 `(0,1,2,3)`。以下每次加入都独立从原图开始：

| 新弧 | 结果 |
|---|---|
| 0→1 | 原序仍可用 |
| 1→0 | 需要重排，但无环 |
| 3→0 | 有环 |

正式学生题可只给原图，以上三种结果留在教师答案中。

**参考伪码：**

```text
for i = 0 .. V-1:
    pos[sigma[i]] = i
if u == v: return 有环
if pos[u] < pos[v]: return 原序仍可用

seen[0..V-1] = false
Q = empty queue
seen[v] = true; enqueue(Q, v)
while Q not empty:
    x = dequeue(Q)
    if x == u: return 有环
    for y in Adj[x]:
        if not seen[y]:
            seen[y] = true
            enqueue(Q, y)
return 需要重排
```

原图无环，新增后任何新环必包含u→v。因此只有原图已经有v到u的路径，才会形成新环。若新弧仍按sigma从前指向后，所有弧仍向前，原序可直接使用；若新弧逆序但没有形成环，图仍有拓扑序，只是原序需要改变。搜索不能误写成u到v。

位置数组、正向新弧与自环处理3分；从v搜索u的实现4分；三种返回及其理由3分；O(V+E)时间、O(V)空间2分。无需为本题实现动态拓扑排序。
