题面、答案、蓝图及配图的既有审查绑定继续有效，目录迁移未改动它们的JSON源数据或PDF。历史出处中的旧路径用`tools/project_paths.py`和`tools/目录迁移.csv`解析。

| 查阅目的 | 位置 |
|---|---|
| 为什么选题、来源与验算依据 | 本目录`逐题溯源.json`、各答案JSON的references/checks，以及上级命题依据 |
| 既有逐题独立审查 | `独立审查_第1至2套.json`、`独立审查_第3至4套.json`、`独立审查_第5至6套.json` |

| 图与题面、答案是否相符 | 配图源JSON、PNG/SVG、`配图与学生页检查.json` |
| 成品是否发生变化 | 当前`交付核对.json`；迁移前清单为`历史交付核对-20261025.json` |
| 题型与用户分层要求 | [命题依据](../命题依据/)中的题型规范说明、用户意见、近三年任务证据和覆盖矩阵 |

## 从项目根目录核对

```powershell
python tools/exam_blueprint.py
python tools/verify_exam_delivery.py
```

需要修改内容时，先改对应源稿并核答，再生成成品、复查受影响页和更新独立审查绑定。以下命令会写文件，不用来简单检查封存成品：

```powershell
python tools/build_exam_papers.py --build --render
python tools/build_answer_figures.py
python tools/build_exam_answers.py --render
```

最后使用`python tools/package_exam_delivery.py`登记当前交付清单；该工具已停止生成ZIP。历史快照压缩包已按本次整理要求移除，已提交的版本仍可从Git历史追溯；不再把已删压缩包列为现行依赖。

验算源文件中的历史路径和工作机编译器路径按原记录保留。它们用于追溯对应版本，执行前须核对路径和输出位置；当前结构与来源完整性用现行核验脚本检查。实际难度和作答用时仍待教研限时试做。
