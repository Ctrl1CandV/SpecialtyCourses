## 一、程序阅读题

### 1（6分）

①a[write-2]；②++write；③write。

write 表示已保留元素个数。当前值与已保留区倒数第二个值相同，说明该值已保留两次；否则可以写入。有效区依次变为1，1,1，1,1,2，1,1,2,2，1,1,2,2,3，1,1,2,2,3,3，最后加入5；输出1 1 2 2 3 3 5。时间O(n)，额外空间O(1)。

### 2（6分）

①next；②pre=p；③next。

循环开始时pre是p在A中的前驱。摘下p后pre保持不动；保留p时pre前进到p。B使用尾插保持原相对次序，保存next保证改写p->next后仍可继续扫描。例如A为8,2,6,3,9,5，lo=3、hi=6，最终A为8,2,9，B为6,3,5。时间O(n)，额外空间O(1)。

### 3（4分）

输出：1 2 3 4 5 6。Push调用6次，Pop调用6次；Top调用8次。

栈底到栈顶依次为：[4]、[4,1]、[4,3]（输出1）、[4,3,2]、[6]（依次输出2,3,4）、[6,5]；最后依次弹出5,6。每个输入只入栈一次，最终也只出栈一次。六轮Top调用次数依次为0、1、2、1、3、1；栈空时短路，不调用Top。

### 4（4分）

返回值为3×2+3×7+3×9=54。时间O(n)，辅助空间O(h)。

只有叶结点返回“层数×值”，非叶只把左右子树结果相加，根6和内部结点3、8不计入加权和。每个结点访问一次，递归栈最长为根叶路径长度。

### 9（3分）

## 四、算法设计与分析题

### 1（8分）

思想：先从当前组前驱向后试走k步。只有找到完整组才逆置；保存组后第一个结点after，逆置时以after为初始前驱，自动接好组尾，再让原组前驱接向新组首。原组首成为下一组的前驱。
```cpp
void reverseGroups(Node *head, int k) {
    if (head == NULL || k <= 1) return;
    Node *before = head;
    for (;;) {
        Node *last = before;
        for (int i = 0; i < k && last != NULL; ++i)
            last = last->next;
        if (last == NULL) return;
        Node *after = last->next;
        Node *oldFirst = before->next;
        Node *prev = after, *p = oldFirst;
        while (p != after) {
            Node *next = p->next;
            p->next = prev;
            prev = p;
            p = next;
        }
        before->next = last;
        before = oldFirst;
    }
}
```
每个结点最多被完整组探测和逆置各访问一次，尾部不足一组再探测一次，总时间O(n)，辅助空间O(1)。空表、k=1、k>n均保持原表。评分建议：完整组检测2分，保存断点和逆置3分，两端接回及推进1分，复杂度与边界2分。

### 2（10分）

思想：后序处理，先修剪左右子树并把返回的新根接回。修剪后当前结点mark=0且两个孩子均为空，说明整棵原子树无标记，应释放当前结点并返回NULL；否则返回当前结点。不能在访问孩子前释放根。
```cpp
TNode *prune(TNode *root) {
    if (root == NULL) return NULL;
    root->left = prune(root->left);
    root->right = prune(root->right);
    if (root->mark == 0 && root->left == NULL &&
        root->right == NULL) {
        free(root);
        return NULL;
    }
    return root;
}
```
每个结点只进入一次，时间O(n)，辅助空间O(h)，h为原树高度。全部mark=0时返回NULL；根mark=0但后代有1时根必须保留。示例：根0、左叶0、右子树根0且其左叶1，修剪后只删除左叶0，根—右—左这条路径保留。评分建议：后序与返回新根思想2分，孩子接回3分，删除条件及释放3分，复杂度2分。

### 3（12分）

思想：从终点t进行反向BFS。当前已知u能到达t，只要存在v→u，v也能到达t；因此扫描矩阵的第u列扩展。队列只保证访问，不直接用出队顺序输出；搜索结束后按编号扫描标记输出。
```cpp
int reachTarget(const int A[100][100], int n, int t) {
    int q[100], front = 0, rear = 0;
    bool seen[100] = {false};
    seen[t] = true;
    q[rear++] = t;
    while (front < rear) {
        int u = q[front++];
        for (int v = 0; v < n; ++v) {
            if (A[v][u] != 0 && !seen[v]) {
                seen[v] = true;
                q[rear++] = v;
            }
        }
    }
    int count = 0;
    for (int v = 0; v < n; ++v) {
        if (seen[v]) {
            printf("%d ", v);
            ++count;
        }
    }
    return count;
}
```
每个顶点至多入队一次；每次扫描n个可能前驱，时间O(n²)，队列与标记O(n)。例如0→1、1→3、2→1、4→2、3→5，以t=3时输出0,1,2,3,4，不输出5。t没有入弧时仍输出t。评分建议：逆向搜索依据3分，列扫描与标记入队4分，递增输出及计数3分，复杂度2分。
