## 一、程序阅读题

### 1（4分）

①k % n；②k-1。调用中有效右移位数为3，三次逆置后分别是7,6,5,4,3,2,1；5,6,7,4,3,2,1；5,6,7,1,2,3,4。时间O(n)，辅助空间O(1)。先处理n≤1避免n=0时取模。

### 2（4分）

①p->next；②ta=p。

先保存原后继，然后把当前结点变成独立结点尾插。对11,22,33,44,55,66,77，结果A为11,33,55,77，B为22,44,66；尾指针若不更新，后续结点会覆盖已有链接。时间O(n)，辅助空间O(1)。

### 3（4分）

插入结束堆数组：1,3,2,8,5,6。依次删除1、2；第二次删除后堆数组：3,5,6,8。六次插入比较次数依次为0,1,1,2,1,2，总计7次。

插入数组依次为[8]、[3,8]、[3,8,6]、[1,3,6,8]、[1,3,6,8,5]、[1,3,2,8,5,6]。第一次删除后为[2,3,6,8,5]；第二次以5补根后与较小孩子3交换，再在位置2保持5≤8。

### 4（4分）

n=8时12次：规模8层4次，两个规模4共4次，四个规模2共4次。时间O(n log n)，辅助空间O(log n)。

递归每个非叶层总循环工作量为n/2，共log₂n层。两次子调用先后执行，共享同一进程栈，不同时占用全部调用结点数。

### 5（4分）

①dist[v]==-1；②dist[u]+1。

dist=-1表示尚未发现；第一次入队时立即确定距离并作访问标记，防止同一顶点被多个邻点重复入队。样例各点0～5的最短距离为0,1,1,2,2,3；函数只让0,1,2,3,4入队，返回5。dist达到limit的点计入答案但不继续扩展，因而limit=0时返回1。邻接矩阵实现最坏时间O(n²)，辅助空间O(n)；每个顶点至多入队一次，容量100足够。

### 1（3分）

### 2（3分）

C,A,B,E,D,F,G；6。

从C先访问A，再沿A→B→E→D；D的邻点A、C、E均已访问，回溯到E，再访问F、G。生成树边为C-A、A-B、B-E、E-D、E-F、F-G。最长根叶路径C→A→B→E→F→G有6个结点；D是E的另一孩子，不能把访问序列全部当作一条路径。

### 3（3分）

### 4（3分）

6；8；9。

叶结点数24/4=6。设第2层内部结点有r个，即根有r个孩子。每个第2层结点有2～4个孩子，故2r≤6≤4r，又根至少有2个孩子，得到r=2或3。第2层的索引关键字总数等于叶结点总数6，根的索引关键字数为r，故全体内部索引数为6+r，最少8、最多9。r=2时可各有3个孩子，r=3时可各有2个孩子，两种界均能达到。

### 9（3分）

## 四、算法设计与分析题

### 1（8分）

思想：快指针每次两步、慢指针每次一步，判断是否相遇。相遇后一个指针回到head，两指针每次各一步，再次相遇即入口。然后从入口沿环走到next等于入口的结点，断开该边。此处断边不能任意选，否则会丢失入口到断点之间的可达次序。
```cpp
Node *breakCycle(Node *head) {
    Node *slow = head, *fast = head;
    bool found = false;
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) { found = true; break; }
    }
    if (!found) return NULL;
    slow = head;
    while (slow != fast) {
        slow = slow->next;
        fast = fast->next;
    }
    Node *entry = slow, *tail = entry;
    while (tail->next != entry) tail = tail->next;
    tail->next = NULL;
    return entry;
}
```
设前缀长度a、环长r，相遇时慢指针步数是r的倍数；从相遇点再走a步与从head走a步会在入口相遇。检测、找入口、找环前驱合计O(n)，辅助空间O(1)，n为不同结点数。自环时tail=entry，直接断开；环入口在head时也适用。评分建议：相遇与入口定位3分，定位唯一环前驱并断边3分，边界和复杂度2分。

### 2（10分）

思想：有条件中序遍历。只有根值大于lo，左子树才可能有答案；根值在闭区间内则输出；只有根值小于hi，右子树才可能有答案。严格不等号利用关键字互异，避免访问只可能比边界更小或更大的子树。
```cpp
int printRange(TNode *root, int lo, int hi) {
    if (root == NULL) return 0;
    int count = 0;
    if (root->data > lo)
        count += printRange(root->left, lo, hi);
    if (lo <= root->data && root->data <= hi) {
        printf("%d ", root->data);
        ++count;
    }
    if (root->data < hi)
        count += printRange(root->right, lo, hi);
    return count;
}
```
最坏时间O(n)；更细上界O(h+k)：区间内的结点均需输出，区间外可能访问的结点限制在边界搜索路径上。辅助空间O(h)。空树/区间无键返回0；lo=hi最多输出一个结点。BST退化时h可达n，不能无条件写O(log n+k)。评分建议：中序输出2分，剪枝条件3分，计数与边界2分，两种时间口径及空间3分。

### 3（12分）

思想：先把label全部置-1。按顶点递增扫描，遇到非w且尚未编号的顶点，就以它为新分量起点做BFS。遍历时跳过w并在入队时赋分量号；一次BFS后分量计数加1。不能只从任一剩余顶点做一次遍历，也不能用原图的连通性代替删点后的连通性。
```cpp
int componentsWithout(const Graph &G, int w, int label[]) {
    for (int i = 0; i < G.n; ++i) label[i] = -1;
    int q[MAXV], count = 0;
    for (int s = 0; s < G.n; ++s) {
        if (s == w || label[s] != -1) continue;
        int front = 0, rear = 0;
        label[s] = count;
        q[rear++] = s;
        while (front < rear) {
            int u = q[front++];
            for (Arc *e = G.head[u]; e != NULL; e = e->next) {
                int v = e->to;
                if (v != w && label[v] == -1) {
                    label[v] = count;
                    q[rear++] = v;
                }
            }
        }
        ++count;
    }
    return count;
}
```
所有非w顶点最多入队一次，邻接链总长不超过2E，时间O(V+E)，队列O(V)；若把输出数组也计入辅助空间，仍为O(V)。例如边0—1、1—2、1—3、3—4，删除1后label=[0,-1,1,2,2]，返回3。n=1时剩余图为空，返回0。评分建议：外层分量启动及编号规则3分，BFS跳过w且入队标记5分，空图/输出2分，复杂度2分。
