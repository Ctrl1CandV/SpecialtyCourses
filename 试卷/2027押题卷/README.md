## 分值与命题要求

| 部分 | 题数与分值 | 实施方式 |
|---|---|---|
| 程序阅读 | 卷一4题，6/6/4/4；卷二、三各5题，每题4分；均20分 | 线性表/链表为主，保留一道状态序列及次数、一道自由题；卷二加数组抵消记录，卷三加限距BFS。每卷树或图至多一题 |
| 填空 | 10题，每题3分，共30分 | 保留高频核心，每卷替换3～4个重复题位为树或图的结构/操作计算；各卷至多一道地址式迁移 |
| 综合应用 | 7题，每题10分，共70分 | 树、Huffman、散列与ASL、查找、图、AOE和排序；卷二、三排序题各为内部逐趟4分与基础外排6分 |
| 算法设计 | 3题，8/10/12，共30分 | 传统线性表、树、图；综合条件与读题要求提升，统一要求思想、代码、时间及辅助空间复杂度 |

每套150分、180分钟。难度目标中等偏上，填空与应用的计算量高于已交六套巩固卷；实际难度需限时试做确认，不以题干长度或数字大小代替难度。教师源稿标记少量迁移题位，并另注明本轮新增B/B+树与基础外排的依据，教师源稿记录理由，学生卷不印预测标签。

明确标记的迁移题位为第一套有序三下标压缩与成组链表逆置、第二套四维地址与普通二叉树最近公共祖先、第三套找环入口并断环。本轮按主讲要求补入B/B+树、外排等纲内基础，不将其表述为已经证实的高频或必考。九道算法设计题保持前一版原始JSON对象字节一致，仍统一要求思想、实现及复杂度。

## 对考情的判断

2024—2026可核材料显示，算法题仍围绕链表、树和图的基本操作组合：2024有BST判定、定长路径和分层统计；2025有倒数k、最长根叶和经指定点路径；2026有约瑟夫、先中序重建和拓扑序验证。适合练完整实现与条件处理，无需按竞赛题设置技巧门槛。

应用题适合增加多步计算，但现有材料不足以证明计算量逐年增加：2024已经有5阶Floyd矩阵更新和查找树综合，2025有较大的AOE事件、活动计算，2026回忆稿若干图和数据缺失。主讲对难度趋势的经验作为命题考虑，不能写成已量化验证的事实。

本机没有2023重邮802原卷及可比的旧版考纲，无法验证“比2023更简单”或逐条认定2027考纲新增内容。现存2027考纲用于确认范围；本轮B/B+树与外排的加入来自主讲明确要求，不能反推其802历年考频。具体任务依据见六套模拟卷命题依据中的近三年任务证据及各题basis字段。

本轮填空分布：卷一新增有序三下标压缩、图的度与删除后邻接表计数、固定根容量的B树、由先中序还原后序及高度；卷二新增带前缀约束的拓扑序计数、三叉树度数反推、连通分量数上下界；卷三新增DFS生成树深度、B+叶记录与内部索引副本、由先后序统计不唯一结构。其余循环队列、next、栈、树森林计数、堆/AVL、查找等经典内容分散保留。

外排应用的层次参考[2023年408第42题网页转载](https://www.csgraduates.com/study_methods/408quiz/2023/)：原题第一问给19个关键字与容量m=4，求置换选择初始段；第二问求首段长度上下界。卷三改为12项、容量3，考分段及二路归并趟数；卷二另考固定内存分段、输入/输出缓冲分配及块I/O。未照搬原题输入，也未将未成功读取的PDF记作已读来源。本地[408导出](../../题库/导出/408真题.md)中的408-2024-10是二路归并比较次数选择题，不能用来冒称外排应用原题。
