## 一、程序阅读题

### 1．执行次数（5分）

仅 i=1,2,...,n/2 时执行内层循环。给定 i 时，j 从2i到n，共执行 n-2i+1 次。

**总次数：**T(n)=Σ(i=1至n/2)(n-2i+1)=(n/2)(n+1)-2×(n/2)(n/2+1)/2=**n^2/4**。时间复杂度 O(n^2)。

### 2．单链表操作（5分）

（1）S1：从新的首结点起扫描，使 p 指向原链表的尾结点。

（2）S2：把原首结点 q 接到尾结点之后，再令 q->next=NULL，使 q 成为新的尾结点。

（3）n≥2 时返回的线性表为 **(a2,a3,...,an,a1)**，即循环左移一个位置。空表、单结点表保持原状。时间 O(n)，辅助空间 O(1)。

### 3．非递归折半查找（5分）

从上到下各空依次为：

```c
high = n - 1;
low <= high
mid = low + (high - low) / 2;
low = mid + 1;
high = mid - 1;
```

数组须按关键字递增有序。成功返回下标，区间变空时返回-1。时间 O(log n)，辅助空间 O(1)。

### 4．递归折半查找（5分）

从上到下各空依次为：

```c
(low <= high)
A[mid].key == K
Binsch(A, mid + 1, high, K)
return -1
```

末空后题面已有分号。原函数名 Binsh/Binsch 拼写及参数中的 high.KeyType 有笔误，统一写为同一个函数名和逗号。时间 O(log n)，递归栈辅助空间 O(log n)。

### 1．next与nextval（3分）

**答案如下。**next[j]等于P[1..j-1]最长相等真前后缀长度加1，首项固定0；nextval对相同字符的重复比较继续跳转。

|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 字符 | c | d | d | c | d | e | c | e | c | d | e | a |
| next | 0 | 1 | 1 | 1 | 2 | 3 | 1 | 2 | 1 | 2 | 3 | 1 |
| nextval | 0 | 1 | 1 | 0 | 1 | 3 | 0 | 2 | 0 | 1 | 3 | 1 |

### 2．多重链表空指针（3分）

**(m-1)n+1**，其中 n 为树的结点总数。共有 mn 个孩子指针域，其中 n-1 个对应树边，故空指针数 mn-(n-1)。原题漏给总结点数，须用 n 表示，不能仅凭度 m 得出固定数值。

### 3．根的左右孩子（3分）

**左孩子B，右孩子F。**后序末项A为根；中序切成CBED与GJIFH，对应后序CEDB与JIGHF，两部分末项分别为B、F。

**7次，2次。**127=2^7-1；查K>a127沿最右路径比较a64,a96,a112,a120,a124,a126,a127；查a32依次比较a64,a32。按一次与中点关键字的三路比较计一次。

### 5．KMP两项（3分）

**next(4)=2；nextval(7)=0。**P[1..3]=cbc的最长真前后缀为c。next(7)=3，P[7]=P[3]=c，继续跳到nextval(3)=0。

### 6．循环队列插入位置（3分）

**(rear+1) mod n**。rear指实际队尾，插入到其下一槽；入队前须保证队列未满。

### 7．数组地址（3分）

**A[2][3]**。每行11个元素；50/2=25=2×11+3。

### 8．三叉树叶结点（3分）

**21**。n0=1+n2+2n3=1+6+2×7=21，度为1的结点不改变该关系。

### 9．拓扑排序复杂度（3分）

**O(n+e)**，采用邻接表和入度表实现。若采用邻接矩阵扫描，时间为O(n^2)；原题未指定存储结构，通常填前者并写明条件。

### 10．5阶B树最少关键字（3分）

**5**。高度2时根至少1个关键字、2个孩子；非根结点至少ceil(5/2)-1=2个关键字，合计1+2×2=5。

### 6．不能得到的出栈序列（10分）

**唯一不可能的序列：CAB。**C首先出栈时，A、B、C必已全部入栈；弹出C后，栈顶为B，必须先弹B再弹A，故不能接着弹A。

### 7．顺序表插入的平均移动次数（10分）

长为n的顺序表有n+1个插入位置：第一个元素之前，以及每个元素之后。各位置等概率1/(n+1)。

在第i个元素之前插入（i=1,...,n+1）时，需后移n-i+1个元素；i=n+1即表尾插入，移动0个。

**平均移动次数：**E=Σ(i=1至n+1)[(n-i+1)/(n+1)]=(n+(n-1)+...+1+0)/(n+1)=**n/2**。

时间复杂度平均O(n)，辅助空间O(1)；这里统计元素后移次数，不把写入新元素本身算作移动。

**（2）路径输出算法**

**基本思想：**若path[i][j]=k≠0，则i到j的路径分为i到k和k到j两段。递归输出前一段的内部中转顶点，再输出k，最后输出后一段的内部中转顶点。最外层输出起点i和终点j，避免重复输出分段端点。不可达时单独报告无路径；i=j时只输出该顶点一次，长度为0。

**完整C实现：**调用前将a初始化为带权邻接矩阵，对角线为0，无弧为INF。先调用Floyd(n,a,path)，再调用PrintAllPaths(n,a,path)。若题目已经给出Floyd计算结果，可直接调用PrintAllPaths。

```c
#include <stdio.h>
#include <limits.h>

#define MAXV 100
#define INF (LLONG_MAX / 4)

/* 顶点下标为1..n；path=0表示没有内部中转顶点。 */
void Floyd(int n, long long a[MAXV + 1][MAXV + 1],
           int path[MAXV + 1][MAXV + 1])
{
    int i, j, k;
    for (i = 1; i <= n; ++i)
        for (j = 1; j <= n; ++j)
            path[i][j] = 0;

    for (k = 1; k <= n; ++k) {
        for (i = 1; i <= n; ++i) {
            for (j = 1; j <= n; ++j) {
                if (a[i][k] == INF || a[k][j] == INF)
                    continue;
                long long cand = a[i][k] + a[k][j];
                if (cand < a[i][j]) {
                    a[i][j] = cand;
                    path[i][j] = k;
                }
            }
        }
    }
}

/* 只输出i到j之间的内部中转顶点。 */
void PrintInner(int i, int j,
                int path[MAXV + 1][MAXV + 1])
{
    int k = path[i][j];
    if (k == 0)
        return;
    PrintInner(i, k, path);
    printf(" -> %d", k);
    PrintInner(k, j, path);
}

void PrintAllPaths(int n,
                   long long a[MAXV + 1][MAXV + 1],
                   int path[MAXV + 1][MAXV + 1])
{
    int i, j;
    for (i = 1; i <= n; ++i) {
        for (j = 1; j <= n; ++j) {
            printf("<%d,%d>: ", i, j);
            if (a[i][j] == INF) {
                printf("unreachable\n");
                continue;
            }
            printf("length=%lld, path=%d", a[i][j], i);
            if (i != j) {
                PrintInner(i, j, path);
                printf(" -> %d", j);
            }
            printf("\n");
        }
    }
}
```

**复杂度：**Floyd三重循环的时间复杂度为O(n^3)，距离矩阵与中转矩阵占O(n^2)空间。对已求出的矩阵输出全部路径，时间为O(n^2+所有输出路径的顶点总数)，最坏为O(n^3)；递归输出一条简单路径的辅助栈空间最坏为O(n)。

### 2．循环链表中的括号配对（10分）

**基本思想：**从L->link起扫描，回到表头L时结束。遇左括号入栈，遇右括号时要求栈非空且栈顶与其匹配，然后出栈。其他字符略过。扫描后栈空才匹配。以下同时支持圆、方、花括号。

**C语言实现：**

```c
#include <stdlib.h>
typedef struct Node {
    char ch;
    struct Node *link;
} Node;
static int pair(char a, char b) {
    return (a == '(' && b == ')') ||
           (a == '[' && b == ']') ||
           (a == '{' && b == '}');
}
int bracketsMatch(const Node *L) {
    int n = 0, top = 0;
    const Node *p;
    for (p = L->link; p != L; p = p->link) ++n;
    char *st = malloc((size_t)n + 1);
    if (st == NULL) abort();
    for (p = L->link; p != L; p = p->link) {
        char c = p->ch;
        if (c == '(' || c == '[' || c == '{') st[top++] = c;
        else if (c == ')' || c == ']' || c == '}') {
            if (top == 0 || !pair(st[top - 1], c)) {
                free(st);
                return 0;
            }
            --top;
        }
    }
    int ok = (top == 0);
    free(st);
    return ok;
}
```

**复杂度：**设表达式含n个字符，两次扫描均为O(n)，栈最多存n个字符，辅助空间O(n)。空表达式返回1。只要求圆括号时也可用计数器，遇右括号先判计数是否为0，最终判0，辅助空间O(1)。

### 3．带子树规模的BST中第k小结点（原卷本题另标16分）

**基本思想：**设左子树结点数为s，则当前根的排名是s+1。k=s+1返回根；k≤s向左递归；否则向右递归查第k-s-1小。每次仅进入一个子树，直接读取num即可取得左子树规模。

**C语言实现：**

```c
#include <stddef.h>
typedef struct BSTNode {
    int element, num;
    struct BSTNode *lchild, *rchild;
} BSTNode;
BSTNode *selectK(BSTNode *T, int k) {
    if (T == NULL || k < 1 || k > T->num) return NULL;
    int s = T->lchild ? T->lchild->num : 0;
    if (k == s + 1) return T;
    if (k <= s) return selectK(T->lchild, k);
    return selectK(T->rchild, k - s - 1);
}
```

**复杂度与理由：**每层常数次操作，时间O(h)，递归栈辅助空间O(h)。按互异关键字随机排列、依次插入建立BST的通常随机模型，平均查找路径长度为O(log n)，故平均时间、平均栈空间均为O(log n)。最坏退化为链时二者均为O(n)。原题rechild按rchild解释，num已正确预存，无须在查询中重新统计。
