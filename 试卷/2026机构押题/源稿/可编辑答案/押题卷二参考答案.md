## 一、程序阅读题

### 1．Prime函数（5分）

（1）**对n≥2判断n是否为素数**：检查2至floor(sqrt(n))是否有n的因子；有则返回0，无则返回1。若n为合数，必有一个不大于sqrt(n)的非平凡因子。

（2）最坏时间复杂度 **O(sqrt(n))**，辅助空间O(1)。小因子很早出现时可以提前结束。原代码对n=0或1也会返回1，实际使用须在开头补 `if (n < 2) return 0;`；负数不应进入sqrt计算。

### 2．折半查找填空（5分）

从上到下各空依次为：

```c
= low + (high - low) / 2
high = mid - 1
low = mid + 1
```

题面空后已有分号。原文 `K<[mid].key` 缺数组名A，应为 `K < A[mid].key`；该if条件后的多余分号须删去，使后面的语句确为if分支。递增有序表上查找时间O(log n)，辅助空间O(1)。

### 3．栈的输出（5分）

**按教材通常从左到右演算两次Pop，逐行输出：**

```text
15
22
8
5
2
10
```

先弹出4、再弹出3，x=4+2×3=10。随后数组按2、5、8、22、15依次入栈，所以最后按相反次序弹出，再输出10。

**原码歧义：**C++没有规定加号左右操作数的求值顺序，`Pop(S)+2*Pop(S)`中若先算右操作数，x=3+2×4=11，末行会变为11。为使题意唯一，应拆为 `int p=Pop(S); int q=Pop(S); int x=p+2*q;`。前五行不受影响。

### 4．alk函数功能（5分）

**计算Ackermann函数A(m,n)**，其递推定义为：A(0,n)=n+1；m>0时A(m,0)=A(m-1,1)；m,n>0时A(m,n)=A(m-1,A(m,n-1))。

例如A(1,n)=n+2，A(2,n)=2n+3，A(3,n)=2^(n+3)-3。函数增长极快；上述功能以数学整数且不发生机器整数溢出为前提。

### 1．所有拓扑有序序列（10分）

**答案：**所有可能的拓扑有序序列共有 **4种**。

| 序号 | 拓扑有序序列 |
|---:|---|
| 1 | 1，2，3，5，4，6 |
| 2 | 1，2，5，3，4，6 |
| 3 | 1，2，5，4，3，6 |
| 4 | 1，3，2，5，4，6 |

**计算过程：**由原图可读出弧集为{1→2，1→3，1→4，2→4，2→5，5→4，5→6，4→6，3→6}。初始入度如下。

| 顶点 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---:|---:|---:|---:|---:|---:|

|---|---|---|---|---|---|---|
| 1，2，3，5，4，6 | {1} | {2,3} | {3,5} | {5} | {4} | {6} |

### 6．线性探查散列表（10分）

**（1）答案：**取H(key)=key mod7，线性探查地址为H_i(key)=[H(key)+i] mod7，i=0,1,…。最终散列表如下。

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---:|---:|---:|---:|---|---:|---:|
| 关键字 | 55 | 22 | 63 | 31 | 空 | 26 | 13 |

**插入过程：**

| 关键字 | 初始地址 | 依次探查的地址 | 最终地址 | 探查次数 |
|---:|---:|---|---:|---:|
| 13 | 6 | 6 | 6 | 1 |
| 22 | 1 | 1 | 1 | 1 |
| 31 | 3 | 3 | 3 | 1 |
| 55 | 6 | 6→0 | 0 | 2 |
| 26 | 5 | 5 | 5 | 1 |
| 63 | 0 | 0→1→2 | 2 | 3 |

例如，55的初始地址为6，该位置已有13，故回绕探查地址0并存入；63的初始地址为0，依次遇到55和22，最终存入地址2。

**（2）模数的选择：**除留余数法一般选取不大于表长、且接近表长的素数作为模数，以减少某些关键字分布规律造成的冲突。本题表长为7，7本身是素数，故取模7。

**（3）删除方法：**采用“删除标记”法。每个位置设置三种状态：从未使用的空位置EMPTY、已有元素的位置OCCUPIED、已删除的位置DELETED。删除时将该位置改为DELETED，查找遇到DELETED仍继续探查；只有遇到EMPTY或探查完整个表，才能判定查找失败。插入时可以复用DELETED位置。

不能把删除位置直接改为空。例如，13位于地址6，55因冲突存于地址0。若删除13后把地址6直接置为EMPTY，再查找55时会在初始地址6提前结束，错误地报告不存在。保留DELETED标记即可维持原探查链。

## 四、算法设计与分析题

### 1．双亲数组求层次和树高（10分）

**基本思想：**设parent[i]存结点i的双亲下标，根的双亲记为-1；输出数组c初始化为0，表示层次尚未计算。递归求某结点层次时，先求双亲层次再加1；已计算的结果直接复用。无须假定双亲总排在孩子前面。所有层次的最大值就是树高。

**C语言实现：**

```c
static int getLevel(int i, const int parent[], int c[]) {
    if (c[i] != 0) return c[i];
    if (parent[i] == -1) c[i] = 1;
    else c[i] = getLevel(parent[i], parent, c) + 1;
    return c[i];
}
int levelsAndHeight(const int parent[], int n, int c[]) {
    for (int i = 0; i < n; ++i) c[i] = 0;
    int height = 0;
    for (int i = 0; i < n; ++i) {
        int h = getLevel(i, parent, c);
        if (h > height) height = h;
    }
    return height;
}
```

**复杂度：**每个结点的c值只求一次，时间O(n)；递归栈最大O(h)，最坏O(n)。c为题目指定的输出数组，占O(n)；若计入输出空间，总空间O(n)。假定输入为合法的树；n=0时返回高度0。逐个结点独立上溯而不复用层次，最坏会耗时O(n^2)。

### 2．递归求Huffman树的WPL（10分）

**基本思想：**从根的深度0开始递归，仅在叶结点计算“权值×深度”；内部结点的element不计入WPL。子树深度每深入一条边加1，累加左右结果。

**C语言实现：**

```c
#include <stddef.h>
typedef struct HNode {
    int element;
    struct HNode *lchild, *rchild;
} HNode;
static long long weightSum(const HNode *p, int depth) {
    if (p == NULL) return 0;
    if (p->lchild == NULL && p->rchild == NULL)
        return (long long)p->element * depth;
    return weightSum(p->lchild, depth + 1) +
           weightSum(p->rchild, depth + 1);
}
long long WPL(const HNode *T) {
    return weightSum(T, 0);
}
```

**复杂度：**每个结点访问一次，时间O(n)；递归栈O(h)，最坏O(n)。空树返回0；仅一个叶结点的树，其根深度为0，按带权路径长度的数学定义返回0。此处不额外约定单字符编码至少占1位。

### 3．有序单链表插入（10分）

**基本思想：**假设原表按element非递减有序，L为头结点。从头结点起找第一个element≥x的结点，将新结点插在其前面；若不存在则在表尾插入。新结点的后继先指向原后继，再修改前驱的link。

**C语言实现：**

```c
#include <stdlib.h>
typedef struct Node {
    int element;
    struct Node *link;
} Node;
void insertSorted(Node *L, int x) {
    Node *pre = L;
    while (pre->link != NULL && pre->link->element < x)
        pre = pre->link;
    Node *s = malloc(sizeof *s);
    if (s == NULL) abort();
    s->element = x;
    s->link = pre->link;
    pre->link = s;
}
```

**复杂度：**最坏扫描全部n个数据结点，时间O(n)；除新插入的结果结点外，辅助空间O(1)。空表、表头前插、表尾后插和等值元素均能处理；若原表为非递增，循环中的 `< x` 改为 `> x`。
