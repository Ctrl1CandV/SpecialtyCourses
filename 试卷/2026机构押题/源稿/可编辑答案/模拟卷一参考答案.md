## 一、程序阅读题（20分）

### 1．运行时间估计（5分）

三重循环各执行N次，核心语句共执行N^3次，时间复杂度O(N^3)。按题设的同比例运行时间模型：

**T(10000)=0.1×(10000/100)^3=100000秒**，约27小时46分40秒。

这是按操作次数比例作出的考试估计。若实际运行原C程序，sum在大规模下会发生int溢出，输出耗时也随环境变化；不能把该估计作为原程序的实测保证。

### 2．栈操作输出（5分）

**按题意修正输出语句后，连续输出为：stack。**

第一次Pop后x='k'，栈自底向上为c、a；之后压入t、k，弹出k，再压入s，循环开始前栈为c、a、t、s。循环依次输出s、t、a、c，最后输出x='k'。

原题printf(y)、printf(x)把char当作格式串地址，不能得到有定义的C输出。应分别改为printf("%c", y)、printf("%c", x)；上面的结果按此通常题意给出。

### 3．单链表数据交换（5分）

**从head指向的结点起，每三结点一组，交换该组前两个结点的数据，第三个结点数据不变；不足两结点的末组不交换。**

以参与结点依次编号1、2、3……，交换的是(1,2)、(4,5)、(7,8)……。例：(1,2,3,4,5,6,7,8)变为(2,1,3,5,4,6,8,7)。

原因是交换分支只让current前进一步；下一次else内、循环末尾各前进一步，共再跨过两个结点，才开始下一次交换。它不是通常的“两两相邻结点全部交换”。prev只被赋值，没有参与接链。时间O(n)，辅助空间O(1)。head若指向额外头结点，该头结点也会被代码当作参与结点，题面未另作排除。

### 4．双向循环链表判回文（5分）

**按明显笔误修正后，判断带头结点的双向循环链表是否为回文：是返回1，否则返回0。**

p从首数据结点向后走，q从末数据结点向前走；两端数据有一对不等即返回0，二者相遇或交叉则返回1。空表和单结点表也返回1。时间O(n)，辅助空间O(1)。

原代码的结点指针类型应统一为struct DNode *；p-p->next、q²q->prior、Else等须分别按p=p->next、q=q->prior、else理解。照原排印文本不能直接编译。

## 四、算法设计与分析题（30分）

### 1．表达式树转中缀表达式（15分）

**基本思想：**叶结点直接输出操作数；二元运算结点按“左子树、运算符、右子树”输出，非根运算子树外加括号。单目运算符先输出符号，再输出唯一子树。原图中的单目负号子树位于右指针，本实现也兼容唯一子树在左侧的情况。

```c
#include <stdio.h>
typedef struct node {
    char data[10];
    struct node *left, *right;
} BTree;

static void printExpr(const BTree *t, int isRoot) {
    if (t == NULL) return;
    if (t->left == NULL && t->right == NULL) {
        printf("%s", t->data);
        return;
    }
    if (!isRoot) printf("(");
    if (t->left == NULL || t->right == NULL) {
        printf("%s", t->data);       /* 单目运算符 */
        printExpr(t->left ? t->left : t->right, 0);
    } else {
        printExpr(t->left, 0);
        printf("%s", t->data);
        printExpr(t->right, 0);
    }
    if (!isRoot) printf(")");
}

void Infix(const BTree *root) {
    printExpr(root, 1);
}
```

两例分别输出**(a+b)*(c*(-d))**和**(a*b)+(-(c-d))**，与题面等价。不要求删去所有可省括号。

**复杂度：**每个结点访问一次，结点字符串长度有常数上界，时间O(n)；递归辅助栈O(h)，最坏O(n)。评分建议：思路4分，正确处理二元、单目及括号的代码9分，复杂度2分。

### 2．判断无向连通图是否存在EL路径（15分）

**基本思想：**题设已经保证连通且有边。无向图存在经过每条边恰好一次的欧拉路径，当且仅当奇度顶点数为0或2。扫描邻接矩阵计算每个顶点的度即可。

按通常无权简单图的0/1邻接矩阵，主对角线为0；题给MGraph定义不再重复。

```c
int isExistEL(MGraph G) {
    int odd = 0;
    for (int i = 0; i < G.numVertices; ++i) {
        int degree = 0;
        for (int j = 0; j < G.numVertices; ++j)
            degree += G.Edge[i][j];
        if (degree % 2 != 0) {
            ++odd;
            if (odd > 2) return 0;
        }
    }
    return odd == 0 || odd == 2;
}
```

**复杂度：**邻接矩阵至多扫描V^2个单元，时间O(V^2)，辅助空间O(1)。若允许自环，计算度时主对角线的自环应贡献2；不能直接沿用上述简单图的对角线约定。评分建议：判定条件4分，矩阵扫描及返回值9分，复杂度2分。
