## 一、程序阅读题

### 1．BST非递归查找（5分）

按题意，各空依次为 **BST->data；lchild；rchild；false**。

原题比较行写为 `if(item=____)`，此处应是相等比较：完整条件须改为 `if (item == BST->data)`；若严格只在原单个等号后的空处填写，应填 `= BST->data`，从而组成双等号。while行的印刷错误也须统一为 `while (BST != NULL)`。

关键字相等即成功，小于当前根则查左子树，大于则查右子树。时间O(h)，辅助空间O(1)，h为树高。

### 2．单链表操作（5分）

（1）S1沿next向后扫描，使p指向原链表尾结点。

（2）S2把原首结点q接到尾部，再把其next置空，使其成为新尾结点。

（3）n≥2时返回 **(a2,a3,...,an,a1)**，相当于循环左移一位；空表或单结点表保持原状。时间O(n)，辅助空间O(1)。

### 3．BST查找填空（5分）

两空依次为：

```c
return t
t = t->rchild
```

题面空后已有分号。循环可能因t变空而结束，原函数漏写查找失败返回值，应在while之后、函数结束之前补 `return NULL;`。否则非空树中的查找失败会落到非void函数末尾。字段和运算符中的多余空格按正常C语法恢复。

### 4．冒泡排序填空（5分）

两空依次为 **n-i；r[j+1]=r[j]**。

原题还须改正：`n-l`为`n-1`；if后的左圆括号应为左花括号；提前结束条件 `exchange=-0` 应为 `exchange==0`。修正后的主要循环如下，数组下标为0至n-1。

```c
for (int i = 1; i <= n - 1; ++i) {
    int exchange = 0;
    for (int j = 0; j < n - i; ++j) {
        if (r[j] > r[j + 1]) {
            int temp = r[j + 1];
            r[j + 1] = r[j];
            r[j] = temp;
            exchange = 1;
        }
    }
    if (exchange == 0) return;
}
```

最终按非递减次序排序；最坏和平均时间O(n^2)，已有序时O(n)，辅助空间O(1)。

### 1．Kruskal最小代价生成树（10分）

**（1）答案：**一种最小生成树的边集为 **{1-2，0-4，2-4，4-6，2-5，0-3}**，总代价为 **23**。

**计算过程：**将边按权值非递减排列，依次选择连接不同连通分量的边；权值相同时按端点编号顺序考察。

| 考察的边 | 权值 | 处理 | 累计代价 |
|---|---:|---|---:|
| 1-2 | 2 | 选择 | 2 |
| 0-4 | 3 | 选择 | 5 |
| 2-4 | 3 | 选择 | 8 |
| 0-1 | 4 | 形成环，舍去 | 8 |
| 4-6 | 4 | 选择 | 12 |
| 2-5 | 5 | 选择 | 17 |
| 4-5 | 5 | 形成环，舍去 | 17 |
| 0-3 | 6 | 选择；已得到6条边，结束 | 23 |

总费用为2+3+3+4+5+6=23。由于2-5和4-5的权值均为5，将边2-5替换为4-5，也可得到另一棵代价为23的最小生成树。

{{FIG:三-mst}}

**（2）时间复杂度：**将m条边排序需O(m log m)时间；使用并查集判环、合并的总时间为O(mα(n))，因此通常记Kruskal算法的时间复杂度为 **O(m log m)**。对简单无向图，因m≤n(n-1)/2，也常写为O(m log n)。

## 四、算法设计与分析题

### 1．连接两个带头结点单链表（10分）

**基本思想：**找到X的尾结点，将其link接到Y的首个数据结点。Y的头结点不应接入X的数据链；本实现保留Y的头结点，并把Y置为空表，避免两表头同时拥有同一条数据链。假定X、Y为互不共享结点的两张合法链表。

**C语言实现：**

```c
#include <stddef.h>
typedef struct Node {
    int data;
    struct Node *link;
} Node;
void concatenate(Node *X, Node *Y) {
    Node *p = X;
    while (p->link != NULL) p = p->link;
    p->link = Y->link;
    Y->link = NULL;
}
```

**复杂度：**设X原有m个数据结点，时间O(m)，仅使用一个游标，辅助空间O(1)。X或Y为空表均适用。若约定连接后不再保留Y的头结点，也可在接链后释放Y头，但不能把该头结点作为数据结点接入结果。

### 2．单链表的简单选择排序（10分）

**基本思想：**将表分成已排序前段和未排序后段。p依次指向后段首结点，每趟从p开始扫描，找最小值结点min，与p交换数据，再将p向后移动一位。原头结点和所有link指针保持不变。

**C语言实现：**

```c
#include <stddef.h>
typedef struct Node {
    int data;
    struct Node *link;
} Node;
void selectionSort(Node *L) {
    for (Node *p = L->link; p != NULL; p = p->link) {
        Node *min = p;
        for (Node *q = p->link; q != NULL; q = q->link)
            if (q->data < min->data) min = q;
        if (min != p) {
            int temp = p->data;
            p->data = min->data;
            min->data = temp;
        }
    }
}
```

**复杂度：**比较次数为(n-1)+(n-2)+...+1=n(n-1)/2，时间O(n^2)，辅助空间O(1)。空表、单结点表均正确。此交换数据的简单选择排序一般不稳定；本题未要求稳定性，也未禁止交换数据。

### 3．以非增次序打印BST，常数辅助空间（10分）

**基本思想：**BST的逆中序“右-根-左”给出非增序列。为满足只使用若干指针变量的限制，采用逆中序Morris遍历，利用右子树最左结点原本为空的lchild暂存返回线索；第二次沿线索回到当前结点时立即清除，再访问当前结点。无需递归或显式栈。

**C语言实现：**

```c
#include <stdio.h>
#include <stddef.h>
typedef struct TNode {
    int data;
    struct TNode *lchild, *rchild;
} TNode;
void printNonIncreasing(TNode *T) {
    TNode *cur = T, *p;
    while (cur != NULL) {
        if (cur->rchild == NULL) {
            printf("%d ", cur->data);
            cur = cur->lchild;
        } else {
            p = cur->rchild;
            while (p->lchild != NULL && p->lchild != cur)
                p = p->lchild;
            if (p->lchild == NULL) {
                p->lchild = cur;
                cur = cur->rchild;
            } else {
                p->lchild = NULL;
                printf("%d ", cur->data);
                cur = cur->lchild;
            }
        }
    }
}
```

**复杂度：**每条相关边仅被常数次扫描，总时间O(n)，只用固定个数指针，辅助空间O(1)。所有临时线索在正常遍历结束时恢复为NULL，原树结构保持原样。普通递归逆中序会使用O(h)调用栈，不能严格满足本题的空间限制。
