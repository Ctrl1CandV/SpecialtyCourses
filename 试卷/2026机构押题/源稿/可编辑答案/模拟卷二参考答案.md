### 2．辗转相除法（5分）

**（1）求两个正整数n1、m1的最大公约数。**每轮用(n,m)更新为(m,n mod m)，最大公约数保持不变，余数为0时返回非零数。

**（2）返回3。**15 mod6=3，6 mod3=0。

If、Return按小写C关键字修正；题设输入应为正整数，否则m=0时原代码首先计算n%m会除零。

### 3．两段代码的时间复杂度（5分）

**（1）O(n^2)。**按明显笔误iK=n应为i<=n，内层执行1+2+…+n=n(n+1)/2次。

**（2）常用答案O(2^n)。**递推式T(n)=T(n-1)+T(n-2)+O(1)。更精确的指数增长率为O(phi^n)，phi=(1+sqrt(5))/2。这里没有记忆化，不能写为O(n)。

### 4．倍增循环的count（5分）

设n=2^k，k≥2。执行t轮后x=2^(t+1)；终止时x=n/2=2^(k-1)，所以**count=k-2=log_2(n)-2**。

**时间复杂度O(log n)，辅助空间O(1)。**例如n=4时循环一次也不执行，count=0；原题变量声明和return分号按常规补齐。

## 四、算法设计与分析题（30分）

### 1．删除有序顺序表中的闭区间元素（15分）

**基本思想：**假定A按非递减排列。两次二分分别找到第一个≥x的位置first和第一个>y的位置after，删除区间[first,after)。把after起的后缀整体向前移动after-first个位置，每个保留元素至多移动一次。

以下用A[0..*n-1]表示顺序表；函数更新长度并返回删除个数。

```c
int DeleteRange(int A[], int *n, int x, int y) {
    if (*n == 0 || x > y) return 0;
    int lo = 0, hi = *n;
    while (lo < hi) {               /* 第一个 >= x */
        int mid = lo + (hi - lo) / 2;
        if (A[mid] < x) lo = mid + 1;
        else hi = mid;
    }
    int first = lo;
    hi = *n;
    while (lo < hi) {               /* 第一个 > y */
        int mid = lo + (hi - lo) / 2;
        if (A[mid] <= y) lo = mid + 1;
        else hi = mid;
    }
    int after = lo, removed = after - first;
    if (removed == 0) return 0;
    for (int k = after; k < *n; ++k)
        A[k - removed] = A[k];
    *n -= removed;
    return removed;
}
```

**复杂度：**边界查找O(log n)，后缀搬移O(n-after)，合计O(log n+n-after)，最坏O(n)；辅助空间O(1)。没有命中元素时不搬移。评分建议：有序边界及一次搬移思路4分，代码8分，复杂度与边界3分。

### 2．输出两顶点之间的所有简单路径（15分）

**基本思想：**DFS枚举当前路径，用onPath只标记本条递归路径中的顶点。到达终点就输出；离开当前递归层时撤销标记，使该顶点能出现在其他路径中。不能把visited永久保留，否则会漏掉路径。

下例顶点按0～G->n-1编号，MAXV为已定义的顶点上界；输入s、t均为合法编号。

```c
#include <stdio.h>
typedef struct ArcNode {
    int adjvex;
    struct ArcNode *nextarc;
} ArcNode;
typedef struct {
    int n;
    ArcNode *first[MAXV];
} ALGraph;

static void enumerate(const ALGraph *G, int u, int t,
                      int onPath[], int path[], int depth) {
    onPath[u] = 1;
    path[depth] = u;
    if (u == t) {
        for (int i = 0; i <= depth; ++i)
            printf("%d%s", path[i], i == depth ? "\n" : " ");
    } else {
        for (const ArcNode *p = G->first[u]; p; p = p->nextarc) {
            int v = p->adjvex;
            if (!onPath[v])
                enumerate(G, v, t, onPath, path, depth + 1);
        }
    }
    onPath[u] = 0;                   /* 回溯恢复 */
}

void AllSimplePaths(const ALGraph *G, int s, int t) {
    int onPath[MAXV] = {0}, path[MAXV];
    enumerate(G, s, t, onPath, path, 0);
}
```

**复杂度：**这是枚举算法，不能写为普通一次DFS的O(V+E)。若P为实际递归访问的路径前缀总数，L为输出的顶点总数，简单图中时间可界为O(VP+L)，稠密图的路径数量可达阶乘级；路径数组、标记和递归栈共O(V)辅助空间。不把打印结果另存成所有路径的副本。评分建议：逐路径标记与回溯思路4分，完整枚举及输出代码8分，复杂度和边界3分。
