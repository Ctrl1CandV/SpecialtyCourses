## P2 冲刺阶段先补缺，再讲完整题目（约2分钟）

冲刺补缺部分集中补两类尚未完整讲过的算法思想。进入讲题部分后，会把题目条件、选法、过程、代码和复杂度连起来看。这里的分值只说明代码题在现行卷面中的位置，不表示算法必须写成固定长度。

这节课默认大家会走链表、判断空指针和保存后继。把纸上的结点按位序编号，记录指针指向的结点。指针名相同不代表方法相同：一个先走 k 步再同步走，与一快一慢交替推进，所保持的关系完全不同。

## P3 先区分三种双指针的关系（约2分钟）

请先看每一行保持什么关系。固定间距法中，两指针开始可以相差 k 个结点，随后同速，间距不会变。找分点靠速度比例，快指针结束时慢指针才到某个位序。有环链表中也用速度差，但终止事件变成两指针相遇，随后还要再找入口。

这三行是选法条件，不能只看到“两指针”便套同一个循环。尤其是倒数第 k 的 k 表示固定间距，分点中的 k 表示步长比例。

## P4 有环链表的入口是什么（约2分钟）

本节带头结点，传入的 L 指向头结点；算法从 first，也就是 L 的 next 开始。头结点不在环中。如果没有环，沿 next 最终到 NULL；有环时，尾部的 next 指向某个已经经过的数据结点，这个结点就是入口。

例子中从 1 出发先到 2，再到 3，后续一直绕 3、4、5、6、7。入口是 3，不是最后一结点 7，也不是两指针将来第一次相遇的地方。我们比较结点地址，数据相等不表示同一结点。

## P5 数据相同的三个结点仍然可以无环（约2分钟）

这三个结点都存7，但next最终指向NULL，因此一定无环。若把比较条件改成slow->data==fast->data，第一轮slow在v、fast在w，程序会错误报告相遇。地址比较能够区分这两个结点。

再看另一个独立错误：两指针都从u初始化，如果移动前就判断slow==fast，即使u的后继为空也会返回有环。让学生指出两个反例分别约束比较对象和比较时机，随后再读检测函数。

## P6 检测环时，两指针先移动再比较（约2分钟）

两指针都从 first 出发，开始相等毫无意义。因此要进入循环、移动之后再比较。fast 每轮走两步，必须同时保证 fast 和 fast 的 next 都存在。短路求值会先检查左边，前面为假便不会访问后面的字段。

循环结束有两种原因：快指针遇到 NULL，说明这条链没有环；或者走过之后 slow 等于 fast，说明到达同一个结点。下面把检测部分单独作为函数，后面找入口时会调用它。

## P7 逐轮跟踪第一次相遇（约3分钟）

让学生先在纸上标出前两轮，再显示后面三轮。箭头到 7 后回到 3，不回到 1。第三轮 fast 到 7，第四轮从 7 经过 3 到 4，第五轮再到 6，slow 同时到 6。

【停顿】第一次相遇在 6，而题目要求入口 3。此时可以确认有环，但还不能返回 6。记住这两个结果是不同任务，接下来要利用相遇形成的路程关系。

## P8 第五轮两指针在6相遇（约1分钟）

让学生沿图分别数5条边和10条边。快指针多走的5条边正好是一圈，这为下一页的路程关系提供了一个可以检查的实例。图中的结点号只是名称，不参与运算；不能把“6减1”等数字运算当作路程。

【停顿】要求学生指出两指针共同经过的入口3，以及实际相遇点6。此处只确认有环，完整题目还要求给出入口。

## P9 为什么有环就一定能相遇（约2分钟）

当慢指针还没有进入环时，不用计算相对位置。等它进入环，两个指针都在长度固定的环上。每轮快指针比慢指针多走一步，相对间隔按环长循环变化，所以至多再走一个环长的轮数就会相遇。

假设入口前有 a 条边，环长为 c，检测阶段所走轮数是 O(a+c)。只存两个指针，所以额外空间 O(1)。这里依赖快走两步、慢走一步，不能随意改成任意速度然后沿用同样的找入口步骤。

## P10 相遇后，入口由路程关系确定（约3分钟）

把从 first 到入口的距离记为 a，入口顺 next 到相遇点的距离记为 b，环长记为 c。慢指针到相遇时可能绕过完整的环，所以它的总路程要写成 a 加 b 加若干圈，不能默认没有绕圈。

快指针路程是慢指针的两倍，两者路程之差就是慢指针走过的路程，同时必须是环长的整数倍。由此得到 a 加 b 是 c 的整数倍。这表示从相遇点再走 a 步，会到达入口；从 first 走 a 步也刚好到入口。因此放一个指针回 first，两者同速前进，第一次相遇就是入口。

## P11 复位后不会在入口之前相遇（约2分钟）

公式说明走a步后会在入口重合，还需要解释为什么返回的第一次重合就是入口。p尚未到入口时一直在非环部分，q始终在环中，两部分没有相同结点，所以不可能提前重合。

本例a=2、b=3、c=5，p和q两步后同时到3。若入口就是首元，则a=0，复位时已经相等，第二段循环应允许执行零次。让学生把这一情况对应到while(p!=meet)，不要为了“至少走一步”改成do-while。

## P12 在同一条链上验证复位过程（约2分钟）

回到刚才七个结点的例子。相遇点为 6，把 p 放回 first，也就是 1，q 仍在 6。两者同走一步到 2 和 7，再走一步都到 3。

这里 a 等于 2，b 等于 3，a 加 b 正好等于环长 5。在入口前，p 指向的结点尚不在环里，而 q 一直在环上，所以不可能提前相等。这个事实说明找到的是入口，而不只是某个环内结点。

## P13 找环入口的完整调用（约2分钟）

Meet 返回 NULL 时直接报告无环。返回相遇点后，让 p 从首个数据结点出发，让 meet 原地保留；两者同步前进，返回相等的指针。

这个函数不改任何结点的 next，不需要先断开环。若入口本身就是 first，检测阶段相遇位置也在 first，第二个 while 一次都不用执行，直接返回正确结点。

## P14 环入口题的完整思想段（约2分钟）

可写成这样的思想段：“从第一个数据结点同时出发，快指针每次移动两步，慢指针移动一步。若快指针或其后继为空，返回NULL；若二者相遇，将其中一个复位到首元，另一个保留在相遇点，再同步每次移动一步，首次相等处就是环入口。相遇时快慢路程之差为整圈，故首元到入口的距离与入口到相遇点的距离之和是环长的整数倍，因此上述同步移动成立。”

这段话交代检测、无环、复位和依据。代码承担具体边界判断，不需要在思想段重复所有变量赋值。题目只问程序填空时，按空号填写即可，不必额外抄这一整段。

## P15 两个阶段的时间按实际路程相加（约1分钟）

检测阶段在进入环前花费与a同阶的轮数，两者都在环上后，相对距离每次减少一格，至多再走c轮。第二阶段至多a轮。两阶段顺序执行，所以时间相加，不相乘。

若用n表示链表中不同的数据结点数，有环时n=a+c，因此可以写时间O(n)、辅助空间O(1)。环会反复经过某些结点，但两指针在有限轮数内相遇，不能因此说“有环就无限循环”。

## P16 环检测的四类边界（约2分钟）

让学生先说每个输入会在哪一行结束。空表进入 Meet 后 fast 为空，直接返回。一个结点、next 为 NULL 时，fast 的 next 为空，不进入循环。一个结点自己指向自己时，第一轮移动后两指针仍指它，确定有环，入口就是它。

有多个结点且 data 都一样，也必须继续比较地址。若误用 data 相等，普通无环链表就可能被误判成环。

## P17 找分点前，先定义位序与取整（约2分钟）

“三分之一点”本身还不够精确。长度不是 3 的倍数时，必须说明取第几个数据结点。本节选向上取整：第 ceil(n 除以 k) 个，位序从 1 开始。ceil 只是向上取整的记号，不要求学生背新概念。

例如 8 个结点找三分之一点，返回第 3 个；6 个结点返回第 2 个。中点取向上取整时，偶数长度返回前中点。题目如果指定后中点或向下取整，要先改目标位序，不能直接复制本函数。

## P18 按每组k个结点推进快指针（约2分钟）

slow 和 fast 都从第一个数据结点开始。fast 每次消耗最多 k 个结点；如果消耗后还有下一组，slow 才前进一步。这样 slow 的位序就是当前组的编号，最后一组不足 k 个也算一组。

这种写法不需要预先求长度。关键是 slow 的前进时机：先让 fast 处理完一组，再看 fast 是否还有结点。若最后一组结束后仍让 slow 前进，会多走一个结点。

## P19 八结点链表寻找三分之一点（约3分钟）

链表是 1 到 8，再到 NULL。快指针第一组经过 1、2、3 后指向 4，此时确实有下一组，slow 从 1 到 2。第二组结束 fast 指向 7，slow 到 3。第三组只剩 7、8，fast 到 NULL，slow 保持在 3。

【停顿】如果把慢指针移动放到每组开头，最后会在哪里？它会走到第 4 个，多了一步。这一页重点不是记数值，而是看“还有下一组”与 slow 前进的对应关系。

## P20 处理完第二组时，slow恰好位于第3个（约1分钟）

图固定在第二组处理完成的瞬间：fast指7，slow指第3个结点。这两个位置之所以不同，是因为fast负责数每组k个，slow只负责记录组数。不能把slow也放到第三组的起点7。

【停顿】让学生预测接下来两次fast=fast->next的结果。经过7和8后fast为空，第三组完成，但没有第四组，因此slow不再前进，最终返回第3个。

## P21 分点代码先确定入口与合法参数（约1分钟）

这一页只做函数入口。无环是调用条件，不在函数里额外做一遍环检测；若未知是否有环，调用者先用前面的检测函数处理。k 小于 1 没有合法的分组意义，直接返回 NULL。

slow 和 fast 都从 L 的 next 开始，不把头结点计入长度。后面的循环接在这一段之后。

## P22 分点代码按组推进并返回（约2分钟）

内层 for 最多执行 k 次，但 fast 到 NULL 就停止。每个数据结点只被 fast 消耗一次，所以内外循环不是 n 乘 k。外层最多处理向上取整的 n 除以 k 组，slow 只在还有下一组时移动。

最后返回 slow。计时应看所有内层循环合起来的步数：fast 一共走 n 次 next，slow 最多走 n 减 1 次，总时间 O(n)，额外空间 O(1)。

## P23 最后一组结束后再移动slow会多走一步（约2分钟）

先不给表中最后一列，让学生在一个结点上跑错误版本：fast一组后到NULL，若无条件执行slow=slow->next，直接丢掉唯一正确结点。这比拿长链试运行更容易看出错误。

对非空链，设共有g组，slow初始位序为1，只应再移动g−1次。原代码的if(fast!=NULL)恰好判断下一组是否存在。这个条件既负责向上取整，也负责避免多走一步，不是随手补的空指针判断。

## P24 分点题的思想与复杂度可以这样写（约2分钟）

完整思想段可以写：“从首元设置fast和slow。fast每轮最多向后走k步，最后不足k步时遇空停止；若一轮后fast非空，说明还有下一组，slow向后移动一步。slow初始位于第一个数据结点，因此最后位序等于总组数，即向上取整的n/k，返回slow。”

复杂度单独数真实推进次数。内层看起来有k次，外层也在循环，但所有内层合计只有n次next访问，即使k大于n也会提前遇空退出。取整约定和无环条件要与题面一致。

## P25 用短链验证取整规则（约2分钟）

先让学生填最后一列，再核对表格。k 等于 1 时每个结点自成一组，最后 slow 到尾结点。k 大于 n 时所有结点只有一组，返回第一个结点。n 等于 0 没有第 0 个数据结点，所以返回 NULL。

如果题目要求 floor(n 除以 k)，最直接可靠的做法是先数长度，再按要求的目标位序走第二遍，仍是 O(n) 时间与 O(1) 空间。目标为 0 时怎样处理必须由题目说明。单趟不是所有题目的必要要求。

## 附录二 本节代码合集

以下使用带头结点链表；头结点不属于数据环。FindEntry不修改链表。FractionPoint与ThirdFloor要求无环。

```cpp
#include <cstddef>
typedef struct LNode { int data; LNode *next; } LNode;
typedef LNode *LinkList;

LNode *Meet(LNode *first){
    LNode *slow=first, *fast=first;
    while(fast!=NULL && fast->next!=NULL){
        slow=slow->next;
        fast=fast->next->next;
        if(slow==fast) return slow;
    }
    return NULL;
}

LNode *FindEntry(LinkList L){
    LNode *first=(L==NULL ? NULL : L->next);
    LNode *meet=Meet(first), *p=first;
    if(meet==NULL) return NULL;
    while(p!=meet){
        p=p->next;
        meet=meet->next;
    }
    return p;
}

// 普通无环链表；返回第 ceil(n/k) 个数据结点。
LNode *FractionPoint(LinkList L, int k){
    if(L==NULL || L->next==NULL || k<1) return NULL;
    LNode *slow=L->next, *fast=L->next;
    while(fast!=NULL){
        for(int step=0; step<k && fast!=NULL; ++step)
            fast=fast->next;
        if(fast!=NULL) slow=slow->next;
    }
    return slow;
}

LNode *ThirdFloor(LinkList L){
    if(L==NULL) return NULL;
    int n=0;
    for(LNode *p=L->next; p!=NULL; p=p->next) ++n;
    int target=n/3;
    if(target==0) return NULL;
    LNode *p=L->next;
    for(int i=1; i<target; ++i) p=p->next;
    return p;
}
```

环入口：有a个前缀结点、c个环结点时，O(a+c)时间、O(1)额外空间；无环时O(n)。分点与两趟定位均为O(n)时间、O(1)额外空间。
