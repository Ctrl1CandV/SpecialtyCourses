这节补三种常用做法：用标记表记录出现情况，用读写指针完成稳定保留，以及在有序数组上用两端指针排除候选。它们都从已学的数组遍历出发，重点是题目条件怎样决定额外存什么、指针怎样移动。

## P2 同是扫描数组，保留的信息不同（约2分钟）

这节的三个目标各有一个具体问题：找缺失值需要知道某个数出现过没有；删除一批元素需要知道下一个保留元素写在哪里；找两数之和需要知道哪些候选已不可能成功。

这些方法用于补足基础选法，不据此宣称它们是某年必考点。先读条件，再决定状态。一个题目可能同时用到两种方法，例如有界值去重既要标记出现情况，也要维护写入位置。

## P3 标记数组先由取值范围确定大小（约2分钟）

设数组中只允许出现 0 到 M，seen 的下标就可以直接表示数值。读到 x，先确认 x 在范围内，再访问 seen[x]。这一步是方法成立的前提；不能拿一个没有限制的整数直接当下标。

有 n 个元素不表示值域只有 n。比如仅两个元素，值可能是 100 和 100000。时间要把初始化标记表的 M 加进去，不能只数扫描输入的 n。

## P4 求最小缺失正整数，先缩小答案范围（约3分钟）

给 n 个整数，可能有负数、零、大数和重复值。问最小没有出现的正整数。直接把最大值作为数组大小会浪费空间。我们先证明答案范围：如果 1 到 n 都出现，答案就是 n 加 1；否则答案在 1 到 n 里。

因此只需记住 1 到 n 是否出现，其余数不会改变这次判断。这里把很大的原始值域缩成与输入长度相同的范围，是标记表能用的原因。不是所有缺失值题都能这样做，要看所求答案。

## P5 把输入逐个映射到标记表（约3分钟）

先在纸上写 1 到 6 六个位置，因为本例 n 为 6。读到 3，把第 3 格标真；负数跳过；1 标真；第二个 3 不会产生新信息；7 超过 n，跳过；最后 2 标真。

标记结束后从 1 开始找第一个假，得到 4。注意不是在原数组中找一个最大的空隙，也不用对原数组排序。重复值对布尔标记没有影响。

## P6 标记表保存出现情况，不保存原数组位置（约1分钟）

这里seen[3]的3是待判断的数值，不是原数组下标。输入两个3不会形成两个格子，因为题目只问出现与否。标记表完成以后，答案由候选值从小到大的顺序决定，与输入顺序无关。

【停顿】让学生回答：如果把7换成一百万，标记表长度是否增加？不增加。我们已经证明答案不超过n+1，因此超过n的值对寻找第一个缺失正整数没有帮助。

## P7 最小缺失值代码：建立并填写标记（约2分钟）

seen 动态申请 n 加 1 个布尔单元，0 号不用，1 到 n 号对应候选值。申请失败返回 −1，表示没有得到结果；这不是一个合法的最小缺失正整数。正常考试伪代码可以说明存储足够，但这里保留完整返回。

注意条件先检查下界，再检查上界，只有两个条件都满足才访问 seen。整段只记录是否出现，不改原数组。

## P8 最小缺失值代码：找到答案并释放（约2分钟）

循环先令 answer 为 1，遇到已经出现的数继续向后找。answer 可以变成 n 加 1，此时左侧条件为假，不会再访问 seen[n+1]。找到结果后先释放标记数组，再返回答案。

初始化、扫描和查找分别是线性工作量，总时间 O(n)，额外空间 O(n)。空数组时 n 为 0，寻找循环不执行，返回 1。全是负数时也返回 1。

## P9 最小缺失正整数的完整思想段（约2分钟）

可写成：“最小缺失正整数必在1到n+1之间。设置长度n+1的布尔数组，初始均为假，0号不用。遍历输入，仅对1到n范围内的数标记。再按升序检查1到n，第一个未标记位置就是答案；若均出现，则答案为n+1。”

说明范围可以从两种情况写，也可以用n个位置最多容纳n个不同候选来写。最后补充空间O(n)，说明输入不修改。若只写‘用哈希记录’，没有说清记录哪些值和如何得到最小值，关键步骤还不完整。

## P10 批量删除不必每删一次就搬移（约2分钟）

第二个问题要求删掉所有落在闭区间 lo 到 hi 中的元素，同时保留其他元素的相对次序。如果遇到一个删除值就调用一次按位删除，每次都搬动后续元素，最坏会做平方级工作。

我们只让 read 从左到右看一遍，write 表示已经留下多少个元素。遇到应该保留的值，就放到 a[write]，再增加 write。数组尾部旧数据不用清空，因为返回的新长度已经说明有效范围。

## P11 读写指针不会覆盖尚未读取的值（约3分钟）

例子删掉 2 到 4。第一项 2 删除，write 仍为 0；读到 7，将它写入 0 号位；后面的 3 和 2 删除；再把 5 写到 1 号，1 写到 2 号。最后有效前缀是 7、5、1。

每次循环开始时 write 不大于 read，所以写入只会发生在当前格或更靠左的位置，右边尚未读取的数据不会被破坏。保留动作严格按读取顺序进行，因此稳定。

## P12 read=4时，写入位置仍在已读区域（约2分钟）

这幅图展示物理数组，里面出现两个7是正常的。0号是已经保留的7，1号仍是原来读过的7，后者已不属于有效前缀。read指4号的5，write指1号，因此本轮覆盖1号不会破坏未来要读的5和1。

把循环开始时的状态说清楚：0到write−1正好是已读部分中应保留的元素，且顺序正确；read到n−1还未处理。每次删除只推进read，每次保留才写入并推进write，这个关系会一直成立。

## P13 稳定删除区间值的代码（约2分钟）

循环里判断的是保留条件：小于 lo，或者大于 hi。因为删除区间包含两个端点，等于端点时也应删掉。write 在写入之后增加，正好表示有效元素个数。

没有元素保留时返回 0；全保留时每次赋值是自己写自己，结果正确。这种自赋值不必另外加复杂判断，代码更容易核对。只扫描一次，所以 O(n) 时间、O(1) 额外空间。

## P14 稳定压缩的思想与工作量（约2分钟）

完整思想可以写：“从左到右检查每个元素，以write记录保留前缀长度。当前元素不属于删除闭区间时，将它复制到有效前缀末尾并增加write；属于删除区间时只继续扫描。由于写入顺序与原遍历顺序一致，保留元素的相对次序不变。扫描结束返回write作为新长度。”

再比较逐个删除并搬移的做法：若n个元素全部删除，反复删首项需要搬移(n−1)+(n−2)+…+1次。读写法只遍历n次，不需要每次立即补齐数组。最坏时间的差别来自搬移次数，并非循环书写得短。

## P15 有序去重也可以维护一个有效前缀（约2分钟）

如果数组已经非递减排列，相同值连续出现。第一个元素先保留，从第二个元素开始，只要它不同于当前结果的末项，就保留。write 指向下一个写入位置，所以结果末项下标是 write 减 1。

这道题要求有序。对无序数组直接这样比较，会漏掉不相邻的重复值。这里不再完整重讲读写指针，而是看保留条件怎样由“是否在删除区间外”变成“是否不同于结果末项”。

## P16 无序有界去重需要两类状态（约2分钟）

现在把有序条件拿掉，但保证值在 0 到 M 内，并要求保留每个值第一次出现的位置次序。例如 3、1、3、2、1，要留下 3、1、2。

只比较结果末项不够，要知道这个数在所有已读元素中出现过没有。因此 seen 管重复判断，write 管有效结果。先读取当前值到 x，若未出现就写到前缀并标记。读取仍从左到右，保持首次出现次序。完整代码放在附录，课后练习要求自己把这两种状态接起来。

## P17 先排序再去重会改变首次出现的顺序（约2分钟）

这三个结果说明选法必须同时满足去重和顺序要求。排序能把相等值放到一起，但把第一次出现的3移到了后面；比较相邻值只能识别连续重复，本例的重复不相邻。

题面给出有限值域，允许seen记录所有已见值，所以第三个3会被拒绝，第一次的2会被保留。若值域没有限制，不能直接开到最大值；需要按题目限制另选方法，或接受逐项扫描已保留前缀带来的平方级代价。

## P18 两端指针依靠有序条件排除候选（约2分钟）

第三个问题给非递减数组，找两个不同位置，使它们的值之和等于 target。要求返回一组下标即可。最朴素的方法枚举所有位置对，需要平方级比较。

现在让 left 从最左开始、right 从最右开始。如果两端和太小，是否可以放心丢掉 left？因为右端已经是目前能选的最大值，固定 left 再换更小的右端只会更小。和太大时对称地丢掉 right。每次移动都要有这个排除理由。

## P19 从两端开始，逐次排除不可能的位置（约3分钟）

例子数组是 1、2、4、7、9、11，目标 13。第一步 1 加 11 等于 12，太小，因此排除最左的 1。下一步 2 加 11 就是 13，返回这两个位置。

再换一个目标 10，不改变数组。1 加 11 太大，排除 11；1 加 9 等于 10。让学生说出每一步排除的是哪个固定端点，而不只报“左加一”或“右减一”。这两条短轨迹已经分别展示了两个分支。

## P20 移动一端的理由要能说完整（约2分钟）

我们再把刚才的排除理由写成不等式。和小于目标时，区间内任意候选 j 的 a[j] 都不大于 a[right]，因此 a[left] 加 a[j] 也小于目标，固定 left 的所有候选全部失效。和大于目标时，任意 i 的 a[i] 都不小于 a[left]，固定 right 的所有候选全部太大。

如果数组没有排序，这些大小关系不成立；如果题目要返回原下标，先排序还会改变位置关系，必须额外保存原下标。不能把“先排序”当作无代价的前处理。

## P21 无序数组会使两端排除漏掉正确答案（约2分钟）

这是一组只含三个元素的反例。首轮和太大时，有序算法依赖“当前left已经是区间最小值”。本例3右边还有更小的2，所以不能说固定4的所有组合都太大。删掉4就把真正的解删掉了。

【停顿】要求学生指出具体失效的不等式：a[1]并不大于等于a[left]。这样才能判断是前提不满足，而非碰巧没试到某一对。若先排序，另需计算排序代价，并在要求原下标时保留位置映射。

## P22 两端指针的代码（约2分钟）

sum 用 long long，并在加法之前把一个操作数转为 long long，避免两个 int 先相加溢出后再转换。找到时把下标写入 i 和 j，返回 true；失败时返回 false，调用者不能再把 i、j 当有效答案。

left 小于 right 保证两个位置不同，相同值可以来自不同位置，例如两个 5 可以凑成 10。每轮至少收缩一个端点，最多 n 减 1 轮，所以时间 O(n)，额外空间 O(1)。

## P23 两端求和题的完整思想与复杂度（约2分钟）

可写成：“设置左右游标指向有序数组两端。当左下标小于右下标时计算两数之和。若相等则输出两位置；若和小于目标，由于右端已是当前最大值，固定左端不可能得到目标，故左游标右移；若和大于目标，同理右游标左移。区间缩到不足两个位置仍未找到，则不存在符合条件的一对。”

复杂度说明每轮至少缩短一个位置间隔，最多n−1轮，因此时间O(n)。只保存游标与和，所以辅助空间O(1)。n=0或1时循环不进入，两个相同数值可来自不同位置，代码用left<right保证位置不同。

## P24 读题时怎样决定用哪一种方法（约2分钟）

现在不给代码，分别看条件。数值范围小并且要记曾经出现，可以考虑标记；要求原地保留一批元素且相对次序不变，先考虑读写；已有序并能证明移动端点会排除一批候选，再考虑相向移动。

这些不是互斥选项。无序有界去重已经用到标记和读写组合。选好方法后，仍要检查输出要求是值、下标、新长度还是结点指针，并保证函数真正返回题目所需的信息。

## 附录二 本节代码合集

以下代码采用数组0起；所有长度非负，内存规模及 n+1、M+1 可表示，动态申请失败返回−1。两端求和将int先转为long long再加，防止int加法溢出。

```cpp
#include <cstdlib>
#include <cstddef>

// n>=0；实际存储和 n+1 的计算在合法范围内。失败返回-1。
int MissingPositive(const int a[], int n){
    bool *seen=(bool*)malloc((n+1)*sizeof(bool));
    if(seen==NULL) return -1;
    for(int x=0; x<=n; ++x) seen[x]=false;
    for(int i=0; i<n; ++i)
        if(a[i]>=1 && a[i]<=n) seen[a[i]]=true;
    int answer=1;
    while(answer<=n && seen[answer]) ++answer;
    free(seen);
    return answer;
}

// n>=0，lo<=hi；返回有效前缀长度。
int RemoveRange(int a[], int n, int lo, int hi){
    int write=0;
    for(int read=0; read<n; ++read)
        if(a[read]<lo || a[read]>hi)
            a[write++]=a[read];
    return write;
}

// 输入为非递减数组，n>=0。
int UniqueSorted(int a[], int n){
    if(n==0) return 0;
    int write=1;
    for(int read=1; read<n; ++read)
        if(a[read]!=a[write-1])
            a[write++]=a[read];
    return write;
}

// 输入为非递减数组；成功时写入两个不同下标，失败时下标无意义。
bool TwoSumSorted(const int a[], int n, long long target,
                  int &i, int &j){
    int left=0, right=n-1;
    while(left<right){
        long long sum=(long long)a[left]+a[right];
        if(sum==target){ i=left; j=right; return true; }
        if(sum<target) ++left; else --right;
    }
    return false;
}

// n>=0，M>=0，0<=a[i]<=M；实际存储和 M+1 的计算在合法范围内。
int UniqueBounded(int a[], int n, int M){
    bool *seen=(bool*)malloc((M+1)*sizeof(bool));
    if(seen==NULL) return -1;
    for(int x=0; x<=M; ++x) seen[x]=false;
    int write=0;
    for(int read=0; read<n; ++read){
        int x=a[read];
        if(!seen[x]){ a[write++]=x; seen[x]=true; }
    }
    free(seen);
    return write;
}
```
