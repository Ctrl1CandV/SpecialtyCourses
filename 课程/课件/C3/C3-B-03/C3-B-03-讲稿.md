## P3 模拟卷一：求 A 与 B 的差集（约2分钟）

这是已做模拟卷的原题重讲，训练重点是读出“B不变”与“释放A”。若套用2026交集阅读题的代码，会把B释放掉，虽然都叫双指针归并，任务已经不同。

## P4 三种比较分别意味着什么（约3分钟）

两个序列严格递增让排除成立。比如A当前值3、B当前值5，B后面只会更大，不必再拿3和所有B元素比较。等值时A与B均可推进，但prev停在原地，因为它仍是新pa的前驱。

## P5 第一次相等时，prev仍指向保留的1（约1分钟）

A中的1已经确定不在B中，因此prev停在1。当前pa和pb都指值为2的结点，但属于不同链，题面明确没有共享结点。删除的是A中的2，B中的2和它的next保持原样。

【停顿】让学生先用手指出删除完成后1的next应该指谁。应当直接到3，不能把A中2的地址释放以后再去读取它的next。

## P6 用连续删除检查前驱（约3分钟）

A初始1、2、3、5、7，B为2、3、4、5。连续删除2、3时，prev必须一直指1。最后B用尽，A剩余的7不需要继续扫描，因为已经没有任何可能匹配值。让学生检查最终1的next直接指7。

## P7 删掉2后，prev继续为下一个删除提供前驱（约2分钟）

连续删除正是检验前驱是否更新正确的情形。删除2后pa到了3，但prev必须留在1，因为保留链的末端仍然是1。下一次删除3时，1的next再改到5。

若错误地令prev=pa，prev和pa就同时指3。下一次重连只改了3自己的next，随后又释放3，1还指向已经释放的3，保留链便损坏。错误可能在一次删除后暂时不显现，因此必须测试连续命中。

## P8 差集的完整实现（1/2）（约2分钟）

前驱从A头结点开始，首数据结点也能用同一删除方式。pb声明为指向常量结点的指针，表达不改B的要求。第一分支移动A，第二分支移动B，每一轮至少一个游标前进。

## P9 差集的完整实现（2/2）（约2分钟）

先保存待释放指针old，再推进pa和接回prev->next，最后释放old。不能free(pa)后再通过pa->next找后继。相等分支没有prev=pa；这正是连续删除测试的用途。

## P10 释放结点之前必须取得仍要使用的地址（约2分钟）

这里的顺序可以从“释放后不再访问”推出，而不是背四行代码。必须在free之前取出后继，也必须保留待删结点的地址，才能既不丢余链又正确释放。重连和释放的相对次序在保存好地址后可以有等价写法，但任何版本都不能读已释放结点。

本题严格递增，所以等值时pb也可以前进一次；如果题目允许重复值，就要重新规定差集语义并处理整组重复，不能直接沿用这条推导。

## P11 把答案中的理由写具体（约2分钟）

答案的思想段不需要复述所有变量名，但要交代三种比较和有序性。全不相交时A保持原链，全相等时A只剩头结点；B为空时A不变，这三个边界足以快速发现任务理解错误。

## P12 差集算法的完整思想段（约2分钟）

可写成：“利用两表严格递增的条件，用pa、pb分别扫描A、B，以prev保存A当前结点的保留前驱。若A当前值较小，B后面不可能再匹配它，故保留并推进A；若B当前值较小，只推进B；若相等，从A删除并释放当前结点，前驱保持不动，同时推进两游标。扫描在任一游标为空时结束，B结束后A余段自然保留。”

复杂度再补一句：每次比较至少推进一个游标，两者合计最多访问m+n个数据结点，因此O(m+n)时间、O(1)辅助空间。头结点始终保留，使首数据结点删除与中间删除用同一套语句。

## P13 机构题解改编：循环表中的括号（约2分钟）

这是根据现存机构答案重述的教学题，课堂条件已补齐，不把它当作缺失原卷的逐字题面。链表负责存字符，栈负责记尚未匹配的左括号；题目把两种已学结构放在同一过程里。

## P14 循环表的扫描终点是回到头结点（约1分钟）

结构是循环单链表，最后一个数据结点的next明确指向L，沿任何合法next都不会遇到NULL。扫描条件因此是尚未回到L。头结点只是终止标志，它的字符域不属于表达式。

空表有L->next=L，所以循环执行零次，后面的栈空检查返回true。这个边界与普通单链表的NULL终止条件不同，读到“循环”两字就必须核对结束方式。

## P15 计数相等仍可能不匹配（约3分钟）

两类反例说明为什么不能只数总数。先看最近的未匹配左括号，它必须和当前右括号配成一对；后进先出正好对应栈。只含圆括号时可以用计数，但本题有三类括号，计数不足以记录类型。

## P16 读到右圆括号时，栈顶方括号必须先匹配（约2分钟）

计数只知道左右各几个，无法记录等待关闭的先后次序。当前右括号是圆括号，但最近未关闭的左括号是方括号，因此发生交叉。即使栈底存在圆括号，也不能跳过栈顶去找它。

后进先出的规则正好对应嵌套要求，所以选择栈。读取普通字符x时不改变这组未匹配左括号；遇左括号入栈；遇右括号先判空再检查类型，通过后才弹栈。

## P17 逐字符跟踪尚未匹配的左括号（约3分钟）

本页把纯字母段略去，重点仍是每个括号的栈变化。遇到右括号要先检查栈非空，再读栈顶，否则可能访问下标−1。扫描到头结点时还需检查栈空，因为输入“((”从未遇到右括号，也应失败。

## P18 成功条件包括过程合法与最终栈空（约2分钟）

三个失败位置分别约束三段代码：栈空判断在读取st[top]之前，类型检查在--top之前，最终栈空判断在整个循环结束之后。省略其中任意一个，都能用表中的短例子发现。

【停顿】让学生先判断((a)为何没有在扫描中返回false。它唯一的右括号确实匹配成功，但最先进入的左括号还在，因此必须由结束时的top==-1拒绝。

## P19 括号匹配的实现（1/2）（约2分钟）

循环表结束条件是p!=L，而非p!=NULL。题面保证结点数不超过BCAP，所以最多入栈BCAP次；不需要为了分配空间预先再遍历一次。top按课程约定从−1开始。

## P20 括号匹配的实现（2/2）（约2分钟）

短路或运算先检查top==-1，栈空时不访问st[top]。类型不匹配立即返回false，不应继续尝试靠后面的字符弥补。完整扫描后只需看是否还有未匹配左括号。

## P21 综合题的复杂度与边界（约2分钟）

空间写法要和具体实现一致。按输入长度讨论通用算法，需要线性容量栈；这份定长实现实际分配BCAP格，严格写O(BCAP)。考试里若把MaxSize当随问题规模的容量上界，常简写线性空间。不要把“只有一个数组”误写成常数空间。

## P22 括号匹配题的完整思想段（约2分钟）

可写成：“建立空栈，沿循环表从首数据结点扫描到头结点。遇左括号将其入栈；遇右括号，若栈空或与栈顶不匹配则返回false，否则弹出栈顶；其他字符忽略。扫描结束时，栈空说明全部括号配对完毕，返回true，否则返回false。”

每个字符只读一次，每次最多一次入栈或出栈，故时间O(n)。若输入全为左括号，逻辑使用n格栈空间；本实现始终分配BCAP格，写实际分配量O(BCAP)，并说明题设保证n≤BCAP。链表输入未修改，栈与扫描指针分别处理匹配和遍历终止。

## 附录二 完整代码

### 差集的完整实现
```cpp
#include <cstdlib>
struct DiffNode { int data; DiffNode *next; };
void listDifference(DiffNode *A, const DiffNode *B) {
    DiffNode *prev = A, *pa = A->next;
    const DiffNode *pb = B->next;
    while (pa != NULL && pb != NULL) {
        if (pa->data < pb->data) {
            prev = pa; pa = pa->next;
        } else if (pa->data > pb->data) {
            pb = pb->next;
        } else {
            DiffNode *old = pa;
            pa = pa->next;
            prev->next = pa;
            free(old);
            pb = pb->next;
        }
    }
}
```

### 括号匹配的实现
```cpp
#include <cstddef>
const int BCAP = 1000;
struct CharNode { char ch; CharNode *next; };
bool matchPair(char a, char b) {
    return (a=='(' && b==')') || (a=='[' && b==']') ||
           (a=='{' && b=='}');
}
bool bracketsMatch(const CharNode *L) {
    char st[BCAP]; int top = -1;
    for (const CharNode *p=L->next; p!=L; p=p->next) {
        char c = p->ch;
        if (c=='(' || c=='[' || c=='{') st[++top]=c;
        else if (c==')' || c==']' || c=='}') {
            if (top==-1 || !matchPair(st[top],c)) return false;
            --top;
        }
    }
    return top==-1;
}
```
