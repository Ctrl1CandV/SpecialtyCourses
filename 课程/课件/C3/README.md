## 核验与维护

内容、代码、逐页对应及静态版面已检查。PPT放映、逐条动画与实际讲解节奏仍需录制前验收，静态检查不代替放映验收。

九节229页已逐页查看，修正后的代码框、图标签和密集文字页另行复查。全套经LibreOffice导出检查页数，另抽查代码、图示与表格显示；未进行PowerPoint交互放映。源稿、讲稿、PPT及原底图的SHA-256绑定保存在[成品核对.json](维护/成品核对.json)，用于后续修改追溯。

九节均已补充选法依据、状态推演、错误反例、完整思想段和实际工作量推导，共229页、438分钟、39幅可编辑算法状态图。机构底图保留，正文、代码、表格、节点和连线均可编辑；逐页讲稿同时写入PPT备注。源稿、页标题、时长和代码附录保持对应。

- [verify_a_lessons.py](维护/verify_a_lessons.py)：读取A01、A02现行讲稿代码，编译并检查环入口、k分点、数组算法的随机与边界情况。
- [verify_b_lessons.py](维护/verify_b_lessons.py)：读取B01—B06现行附录代码，编译并与独立结果对照，覆盖12个算法和关键状态。
- [review_b07_independent.py](维护/review_b07_independent.py)：独立编译B07现行代码，区间删除138,098例、表达式解析与语义25,007例通过；题面已明确负值用单目负号结点表达。
- [render_c3.mjs](维护/render_c3.mjs)：C3专用生成器，使用@oai/artifact-tool；读取deck与讲稿，生成原生表格和算法图，逐页导出预览并执行Presentations最终化校验。

单课构建：`node 课程/课件/C3/维护/render_c3.mjs C3-A-01 --publish`。不加`--publish`仅在`_tmp/c3_revision/`生成可检查候选；新C3不要运行会重建PPT的旧`tools/check.js`。引擎依赖Codex随附运行库和Presentations技能，可用`RUNTIME_NODE_MODULES`、`PRESENTATIONS_SKILL`、`C3_PYTHON`指定其路径。图示直接维护deck的diagram节点、边和标签；旧PNG配图已由原生图替换。临时预览、验证回执和编译缓存完成审查后清理。

本轮A系列与B系列由不同子进程交叉审查，B07另做独立穷举及表达式解析核验；A系列作者测试通过123,707例，独审另核随机与极值。9节课均已检查题源、题面条件、实际代码复杂度、逐页讲稿和静态渲染，内容以当前三件套为准。
