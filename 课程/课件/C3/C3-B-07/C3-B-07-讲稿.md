## P3 题一：删除所有落在闭区间内的元素（约2分钟）

先圈出非递减和闭区间。非递减允许重复，因此二分找到任意一个等于x的元素并不够；闭区间要求等于两个端点的元素也删除。函数既更新长度又返回删除数，是两个输出。数组尾部旧值不必清零，长度n才决定有效范围。

## P4 先在一个例子里圈出删除区段（约2分钟）

【停顿】先请学生只标要删的下标，不写代码。这里三个2和两个6都在删除范围内。剩余元素原来已经有序，任务只需要把9向前补到下标2。若逐个删除并每次移动后缀，会重复移动同一批元素；整段删除可以把这些重复工作合并。

## P5 把闭区间转换成两个位置（约1分钟）

注意第二个边界用大于y。这样after落在第一个必须保留的后缀元素上，用半开区间表示能直接相减得长度。n是合法的边界位置，但不是合法的数组访问下标；后面的二分代码必须保证不读取A[n]。

## P6 找到某个相等元素不足以确定删除边界（约2分钟）

原数组长度9，第一次mid=4，刚好找到一个2。若立即返回4，删除区间便从第三个2开始，前面两个本应删除的元素会留下。题目允许重复，决定了我们需要边界查找而不是查找任意相等位置。也可能根本没有等于x的元素，例如x=3时仍应从4所在位置开始删除；所以正确目标是第一个大于等于x的位置。

## P7 第一次二分找第一个大于等于2的位置（约2分钟）

初始右界是9，不是8，因为这里使用半开区间。遇到2仍要向左找，不能立即返回mid。A[mid]小于目标时，mid以及更左位置都不能成为答案，所以下界变成mid+1；否则mid还有可能是第一个满足条件的位置，右界只能收缩到mid。让学生分别解释这两次排除范围。

## P8 第二次二分找第一个大于6的位置（约2分钟）

因为x≤y，第一个大于y的位置一定不会在first左边，所以第二次搜索可以沿用lo=first。这里遇到6时仍须右移，因为所有6都应删除。两个循环形状相同，比较符号不同；用重复端点值走一遍，最容易发现把小于等于写错的问题。

## P9 两个二分循环分别维护哪条边界（约2分钟）

第一段遇到小于x的元素，可以把mid及其左侧排除，lo更新到mid+1；遇到大于等于x，mid仍可能是首个满足条件的位置，所以保留为新hi。第二段只是把满足条件改成严格大于y，于是等于y时仍应向右推进。第二次从first开始合法，因为x≤y，first左边都小于x，也必定不大于y。最后lo和hi相遇在边界上，允许等于n，但任何实际读取A[mid]的时刻mid都小于n。

## P10 删除函数：定位左边界（约2分钟）

这段代码的返回目标是一个边界位置，可能等于n；不要求目标x本身存在。mid使用lo加差值一半，避免直接相加的溢出风险。n通过指针传入，用来更新调用者的长度。先处理空表和非法值域，可以让后面的区间语义保持一致。

## P11 删除函数：定位右边界（约2分钟）

恢复hi到原长度，lo保持第一次找到的位置。没有命中元素时first和after相同，直接返回可以避免把整个后缀原地自赋值。这会影响特殊情况下的实际运行量，也使复杂度分析更准确。不要在搬移之前先减n，否则循环将过早终止。

## P12 删除函数：一次搬移并更新长度（约1分钟）

读取位置始终大于写入位置，因此从左向右搬移不会覆盖尚未读取的数据。原尾部还留着2、4或6都没有关系，函数更新后只承诺A[0…n−1]是有效顺序表。

## P13 后缀向左搬移时应从左向右读取（约2分钟）

这里增加一个保留后缀长于一项的例子，才能真正检验搬移方向。写入下标总比读取下标小removed，因此正向循环不会覆盖后面还没读的源元素。若从末尾向前，先做A[3]=A[5]，原来A[3]的4立刻丢失，后面再读它就得到6。这个推导说明了for为什么递增，而不是只说“向前移动”。全部搬移结束后再减n，保证循环仍按原数组的有效末端读取。

## P14 题一的思想段与复杂度（约2分钟）

思想段要写出两个边界的比较关系和整段搬移，单说使用二分没有覆盖删除动作。对于n≥1，两次查找与搬移合计可写O(log n+n−after)；若removed为0，则实际省略搬移，只需查找。空表在入口常数时间返回。题目没有要求必须二分时，线性稳定压缩也是最坏O(n)的正确方案，本讲二分的增量是充分利用有序性定位区间。

## P15 边界检查：先判断位置再判断值（约2分钟）

【停顿】请学生给出四个小输入，并检查两个边界是否符合表中的描述。若x恰好等于某个重复值，第一次二分向左收缩，第二次二分在等于时向右推进，两者合起来才能删除整组。这里没有要求清除数组物理尾部，不额外增加清零循环。

## P16 题二：输出保持运算次序的中缀表达式（约2分钟）

这次任务是输出表达式字符，而不只是列出中序结点序列。叶子的data可以是一个多字符标识符或非负整数，需要按字符串输出；负值由单目负号结点表示，叶子不直接存带符号的字符串。这样不会把二元减法和负操作数连写成a--2。单目负号的位置已经在题面说明，不能把只有一个孩子的结点错误地当作不完整的二元运算。允许多一层正确括号，会显著简化可靠实现。

## P17 先辨认单目负号与二元减法（约2分钟）

树根加号的左子树是a乘b，右子树先计算c减d，再取负。图中两个减号的孩子数量不同，决定了它们的输出次序。让学生分别指认两个减号所表示的子表达式，再口头说出整棵树的运算顺序。不要先套一段遍历代码再猜它输出什么。

## P18 直接中序输出会在哪里失去语义（约2分钟）

第一类问题要求保留括号，第二类问题要求按运算符元数决定访问顺序。不能因为某一张图单目孩子恰好在右侧，就认为普通中序可以覆盖所有题面。最后一行说明同一优先级也可能需要括号，因此本题直接给所有非根运算子树加外括号，比临时推最少括号规则稳妥。

## P19 右子树的括号会改变减法结果（约2分钟）

学生可能认为只在乘法下面出现加法时需要括号，这个反例可以纠正那种过窄判断。根的右孩子是一棵减法子树，必须先算b−c，再从a中减去结果。去掉括号后，通常的左结合规则会先算a−b。题目允许可省括号，因此直接对所有非根运算子树加一对括号，能够统一覆盖优先级、结合方向和单目嵌套，避免临时设计最少括号规则。

## P20 递归函数处理三类结点（约2分钟）

先写函数的任务：完整输出以t为根的这一棵子表达式。叶子是递归终止情形；对运算结点，函数返回时应已经把该子表达式的所有字符和所需外括号输出完。单目分支可以选择非空孩子，因此与左右指针约定兼容。这里不会输出中间字符串对象，减少额外复制和存储。

## P21 结构定义与根标志（约2分钟）

结构中的data存放以空字符结束的字符串，left、right保存两个孩子。isRoot表示当前调用是否处理整棵表达式树，不能拿来表示当前结点是否只有一个孩子。第一次调用后，所有递归调用传0；因此右边的单目表达式和它内部的减法表达式各有自己的括号。这种括号策略保证语义，题目没有要求省到最少。

## P22 跟踪右侧单目子树的输出（约1分钟）

这一页只跟踪右子树，暂时不把左边a乘b混进来。每次左括号都对应一个尚未结束的非根运算调用，返回时由同一层补右括号。让学生用手指指出最后两次右括号分别由哪一层输出。

## P23 每层递归配对自己输出的括号（约2分钟）

进入非根负号结点先输出左括号，再输出负号。进入减法孩子时，它也先输出自己的左括号，依次输出c、减号和d，返回前补上它的右括号。最后负号这一层再补外层右括号。叶结点在加括号逻辑之前返回，所以不产生多余叶括号。若只在二元分支末尾补右括号，单目分支就会留下未配对括号；把右括号放在两种运算分支之后，才能与同一层入口对应。

## P24 表达式输出：空树与叶结点（约1分钟）

叶子分支在加括号之前结束，保证输出的是操作数字符串本身。不是只输出data[0]，因为data可以为ab或123。空树不输出，也无需为它制造一对括号。

## P25 表达式输出：按孩子数量选择顺序（约2分钟）

前一页已经排除了两孩子均空的叶子，因此这里的或条件准确表示只剩一个孩子。单目分支先输出负号，再处理唯一子树；三目表达式只负责取那个非空指针。二元分支才使用左—根—右的次序。让学生把唯一孩子换到左指针，确认结果仍正确。

## P26 表达式输出：配对括号与调用入口（约1分钟）

右括号由当前调用自己补齐；不能把它只放到二元分支末尾，否则单目子表达式的左括号没有匹配。包装函数统一指定根调用，学生最终答案应包含入口，避免调用时忘记传isRoot。

## P27 题二的完整答案与复杂度（约1分钟）

本题data数组固定为10个字符，所以每次输出字符串的代价可视为常数；加上括号仍是O(n)输出量。若题面改为任意长字符串，时间更准确写O(n+L)。调用栈看同一时刻的递归深度，不把所有递归调用次数当成同时分配的空间。

## P28 表达式题的思想段交代输出规则（约1分钟）

这段思想说明覆盖了题面给出的每类结点，后面的代码可直接按照三种情况组织。不要只写“中序遍历”，因为单目孩子在左时那样会输出x−。最后补时间与空间：字符串长度有常数上界时每个结点只处理一次，时间O(n)，调用栈O(h)；若题目允许任意长操作数字符串，再加实际输出字符数L，写O(n+L)。输出本身是题目要求，不需要把整条表达式先拼成中间大字符串。

## 附录二 完整可执行代码

### 有序顺序表区间删除

```cpp
#include <cstdio>
#include <cassert>
int DeleteRange(int A[], int *n, int x, int y) {
    if (*n == 0 || x > y) return 0;
    int lo = 0, hi = *n;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (A[mid] < x) lo = mid + 1;
        else hi = mid;
    }
    int first = lo;
    hi = *n;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (A[mid] <= y) lo = mid + 1;
        else hi = mid;
    }
    int after = lo;
    int removed = after - first;
    if (removed == 0) return 0;
    for (int k = after; k < *n; ++k)
        A[k - removed] = A[k];
    *n -= removed;
    return removed;
}
int main() {
    int A[] = {-3,-1,2,2,2,4,6,6,9}, n = 9;
    int removed = DeleteRange(A, &n, 2, 6);
    assert(removed == 6 && n == 3);
    assert(A[0] == -3 && A[1] == -1 && A[2] == 9);
    for (int i = 0; i < n; ++i) std::printf("%d ", A[i]);
    return 0;
}
```

### 表达式树输出

```cpp
#include <cstdio>
#include <cstddef>
typedef struct node {
    char data[10];
    struct node *left, *right;
} BTree;
void printExpr(const BTree *t, int isRoot) {
    if (t == NULL) return;
    if (t->left == NULL && t->right == NULL) {
        printf("%s", t->data);
        return;
    }
    if (!isRoot) printf("(");
    if (t->left == NULL || t->right == NULL) {
        printf("%s", t->data);
        printExpr(t->left ? t->left : t->right, 0);
    } else {
        printExpr(t->left, 0);
        printf("%s", t->data);
        printExpr(t->right, 0);
    }
    if (!isRoot) printf(")");
}
void Infix(const BTree *root) {
    printExpr(root, 1);
}
int main() {
    BTree a={"a",NULL,NULL}, b={"b",NULL,NULL};
    BTree c={"c",NULL,NULL}, d={"d",NULL,NULL};
    BTree mul={"*",&a,&b}, sub={"-",&c,&d};
    BTree neg={"-",NULL,&sub}, root={"+",&mul,&neg};
    Infix(&root); // 输出 (a*b)+(-(c-d))
    return 0;
}
```
