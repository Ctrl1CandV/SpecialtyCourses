## P2 简单选择：哨兵位存的是下标（约4分钟）

上节课讲完了插入排序和交换排序，这节先讲选择排序。选择排序中简单选择是最基础的，其思路是每趟从未排序区间 [i..n] 寻找到最小值，与 data[i] 交换；i 从 1 走到 n-1。

材料的写法有个巧妙处：用哨兵位 data[0] 存**当前最小值的下标**，不是值。所以比较那一行是 L.data[j] < L.data[L.data[0]]——双重下标，里层 data[0] 取出的是下标，外层再拿这个下标去取值，这是最容易看错的一行。

外层循环到 length-1，内层到 length，为什么两个边界不一样？因为最后一轮只剩一个元素，就不用比较了，外层少走一趟；但找最小值的时候，最后那个元素也得算进去，所以内层要走满。复杂度：时间 O(n²)，而且与初始序列无关，不管序列本身是如何，我们每趟都要扫完整个i到n，并寻找到找到最小的元素。

稳定性要专门说：简单选择是**不稳定**的。很多人认为用 <，而不用 <= 就稳定了，这是错误的，因为破坏稳定的是交换本身。反例 {3a, 3b, 1}：第一趟最小是 1，与 3a 交换，变成 {1, 3b, 3a}——3a 跑到了 3b 后面，相对次序变了。所以不管比较用 < 还是 <=，只要发生跨距离交换，就可能不稳定。

## P3 大根堆：父结点与孩子的下标关系（约4分钟）

那么讲完了简单选择，接下来看本节的重点堆排序。我们先来看定义，堆是完全二叉树的顺序存储，下标从 1 开始。屏幕上这张图：数组存在上面一排，对应的完全二叉树画在下面，每个结点标了值和下标。

下标关系三条：结点 i 的左孩子是 2i，右孩子是 2i+1，父结点是 i/2。还记得基础阶段第1节埋的约定吗，排序章节 data[0] 留作哨兵、数据从 1 起存。为什么排序偏偏要从 1 起？就是为了这三条下标关系干净：2i 和 2i+1 正好是左右孩子，不用加减修正。如果从 0 起存，孩子就变成 2i+1 和 2i+2，父结点是 (i-1)/2，式子全别扭。下标口径（1） 在这里兑现了。

大根堆的要求：每个结点不小于它的两个孩子，arr[i] >= arr[2i] 且 arr[i] >= arr[2i+1]。推论是堆顶 arr[1] 是最大值。小根堆反过来，堆顶最小。

堆排序的思路两步：第一步建堆，把无序数组调成大根堆；第二步排序，反复"把堆顶与当前末尾交换（最大值就位）、范围缩小一位、对新堆顶重新调整"，每趟送一个最大值到末尾。

## P4 HeapAdjust 逐行：哨兵存待下沉结点（约6分钟）

堆排序的核心操作是 HeapAdjust：把 arr[k] 往下"沉"到合适位置，沉的过程保持堆性质。逐行走。

第一句 arr[0] = arr[k]，哨兵存待下沉的结点——哨兵的又一个用途。然后 for 循环，i 从 2k 开始，也就是 k 的左孩子，每轮 i\*=2 往下一层。

循环体三句。第一句 if(i < len && arr[i+1] > arr[i]) i++，选较大的孩子。【停顿】i < len 这个条件防的是什么？防的是 k 只有左孩子没有右孩子的情况——i 已经是最后一个元素时，arr[i+1] 越界。第二句 if(arr[0] >= arr[i]) break，待下沉的值已经不小于较大的孩子，到位了，停。第三句 arr[k] = arr[i] 把大孩子上移，k = i 继续往下比。

循环结束后 arr[k] = arr[0]，哨兵里的值落到最终位置。

注意整个过程是"先挖坑、大孩子逐层上移、最后坑里填哨兵值"，与直接插入的哨兵用法同族。时间 O(logn)，最多沉到树底，树高是 logn。

这一页是手算题的常考点，题集勾画的 10选22、10选30 就是给你数组和 k，让你写出下沉后的结果。下沉过程中要能根据父结点下标写出左右孩子的位置。

## P6 建堆与排序主循环（约4分钟）

有了 HeapAdjust，建堆就一行：for(int i = len/2; i > 0; i--) HeapAdjust(arr, i, len)。

【停顿】为什么从 len/2 开始，不从 len 开始？下标大于 len/2 的结点全是叶子——叶子没有孩子，天然满足堆性质，不需要调整。len/2 是最后一个分支结点（它可能有孩子），从它开始往前逐个下沉，就把整棵树调成堆了。从 len 开始会多调用若干次 HeapAdjust，但叶结点不需要调整。

建堆的总代价是 O(n)，不是 O(nlogn)。这个结论要记住，原因是大多数结点靠近树底，下沉距离较短：叶子沉 0 层，倒数第二层沉 1 层，越往上结点越少、沉得越深，求和收敛到 O(n)。

排序主循环：while(len > 1)，每轮把堆顶 arr[1] 与末尾 arr[len] 交换（当前最大值就位），然后 HeapAdjust(arr, 1, --len)——范围缩小一位，对新堆顶重新下沉。注意 --len 不能忘，忘了就把已就位的末尾又卷进调整。

交换的写法两份材料不一样（勘误 B5）：本节用局部变量 tmp，另一版用 arr[0] 当暂存（哨兵位这会儿空闲，正好复用）。两种写法都对，页脚已注明，做题跟着题目给的写法走。

复杂度：建堆 O(n)，n 趟调整每趟 O(logn)，总时间 O(nlogn) 且最坏也是 O(nlogn)；空间 O(1)；不稳定（交换是跨距离的，反例同简单选择）。

## P7 二路归并 Merge：三指针、两收尾、取等号（约4分钟）

那么讲完了选择类，接下来看归并。二路归并的思想：把两个已有序的段合并成一个有序段。

Merge 的参数是 low、mid、high，左半段 [low,mid]、右半段 [mid+1,high]。三个指针：p 扫左半、q 扫右半、k 写辅助表 T。主循环里谁小取谁：L.data[p] <= L.data[q] 就取 p 的，否则取 q 的。

【停顿】为什么是 <= 不是 <？相等的时候先取左半段的那个。相同值先取前面的，相对次序就不变——这就是归并稳定的原因。写成 <，相等时先取右半的，稳定性就破了。

主循环退出后，p 与 q 谁没走完就把谁整体接到 T 后面——两个收尾循环，一个都不能少。最后把 T 的 [low,high] 拷回 L。

Merge 一次合并的代价是 O(段长)，每个元素恰好被处理一次。

## P8 MergeSort 递归式与复杂度（约3分钟）

MergeSort 的递归式三行：mid 取中，递归排左半、递归排右半，然后 Merge 合并。终止条件 low < high 不成立，也就是段里只剩一个元素，天然有序。

复杂度用基础阶段第1节教的逐层累加推：递归式 T(n) = 2T(n/2) + O(n)。每层合并的总代价是 O(n)（所有段加起来每个元素处理一次），共 logn 层，所以 T(n) = O(nlogn)。

两个性质：时间与初始序列无关——不管乱不乱，都要递归到底、合并 logn 层；空间 O(n)，是辅助表 T 的开销。稳定，Merge 里 <= 保证的。

对比快排：递归式同形，平均都是 O(nlogn)，但归并的最坏也是 O(nlogn)，快排最坏会退化到 O(n²)（已有序时枢轴每次都是最值）。要最坏情况有保证，用归并或堆。

## P9 逆序对：补全 merge 函数并统计跨段计数（约4分钟）

逆序对是 2020 年考过的：统计有多少对下标 (i,j) 满足 i<j 且 A[i]>A[j]。直接枚举是 O(n²)；题目给出的 n≤30000，需要用 O(nlogn) 的方法，归并排序可以做到。

这页把 merge 函数完整写出来。调用它之前，A[left..mid] 和 A[mid+1..right] 已经分别有序。先复制当前区间到 temp，i、j 指向两段开头，k 指向写回 A 的位置，count 记录这次合并产生的跨段逆序对。

比较两个当前元素时，若 temp[i] 小于或等于 temp[j]，就先写回左段元素。否则，右段的 temp[j] 更小。由于左段有序，从 i 到 mid 的元素都大于 temp[j]，所以一次增加 mid-i+1，而不是只加 1。随后把较小的右段元素写回。

一段取完后，把另一段剩下的元素依次写回；最后返回 count。这里返回的是本次合并新增的跨段逆序对。MergeSort 还会把左右递归返回的数量加进来，于是整个区间的逆序对都被统计到。

## P10 过程页：归并时统计跨段逆序对（约3分钟）

【PPT动画·3击】
左右有序段分别是 [2,4,6] 和 [1,3,5]。第1击取右段的1：它小于左段当前的2，左段剩下三个数都与1构成逆序对，count 加3。
第2击先输出2，再比较4与3；取右段的3时，左段剩4、6，再加2，累计5。随后输出4。
第3击取5时左段只剩6，再加1；最后取6。合并结果为1、2、3、4、5、6，跨段逆序对共6对。
`count += mid-i+1` 计算当前右段元素与左段所有剩余元素的配对数；左右子段内部的数量由递归另外累加。

## P11 基数排序与外部排序（约2分钟）

基数排序和外部排序由于是新加入考纲的内容，时至今日仍未考过，因此各一段简单带过，如果考察到，也是手算与概念相关的题目，都无关代码。

基数排序不比较大小，而是进行按位分配与收集，其流程是从低位到高位做d趟按位分配，每趟按当前位把元素分配进 10 个队列，再按队列序收集。为什么能不比较就排对？是因为低位排完后，高位相同的元素保持低位的次序，收集是稳定的，d 趟之后整体有序。时间 O(d(n+r))，稳定，适合位数少、范围小的场景。

外部排序主要认识四个概念：对r个初始归并段，多路平衡归并一次合并 k 个段，可把归并趟数从约 log₂r 降到约 logₖr；败者树帮助 k 路归并快速选出下一条记录；置换选择用于生成较长的初始归并段；最佳归并树安排合并顺序，减少总读写量。

## P12 排序比较表（上）：O(n²) 组（约2分钟）

这一页和下一页是本阶段的收官必背表，分两张：这一页 O(n²) 组五个，下一页 O(nlogn) 组四个。每个记三列：平均时间、空间、稳定性。

O(n²) 组：直接插入与折半插入都是 O(n²)、O(1)、稳定；希尔约 O(n^1.3)、O(1)、不稳定；冒泡 O(n²)、O(1)、稳定（加 swapped 优化最好 O(n)）；简单选择 O(n²)、O(1)、不稳定。

易错点就一个：简单选择不稳定，很多人以为稳定。P2 讲过反例——交换破坏相同元素的相对次序，用 < 还是 <= 都救不了。

O(nlogn) 组四个：快排平均 O(nlogn)、最坏 O(n²)（已有序退化）、空间 O(logn) 递归栈、不稳定；堆排平均与最坏都 O(nlogn)、空间 O(1)、不稳定；二路归并平均与最坏都 O(nlogn)、空间 O(n) 辅助表、稳定；基数 O(d(n+r))、空间 O(r)、稳定。

选择依据五句背下来：要稳定且 n 小用插入；n 大要平均最快用快排；要最坏情况也有保证用堆排；要稳定且 n 大用归并；位数少范围小用基数。

再补一句：链表存储下快排与堆排不适用，它们需要随机访问（按下标取元素），链表做不到；归并与插入仍可用，只需要顺序访问与改指针。题集勾画的 10算14 就是链表归并。

        L.data[0] = i;
        for(int j = i+1; j <= L.length; j++)
            if(L.data[j] < L.data[L.data[0]]) L.data[0] = j;
        if(L.data[0] != i){ int tmp = L.data[i];
            L.data[i] = L.data[L.data[0]];  L.data[L.data[0]] = tmp; }
    }
}

// HeapAdjust：把 arr[k] 下沉到位（哨兵存待下沉结点）
void HeapAdjust(int arr[], int k, int len){
    arr[0] = arr[k];
    for(int i = 2*k; i <= len; i *= 2){
        if(i < len && arr[i+1] > arr[i]) i++;
        if(arr[0] >= arr[i]) break;
        arr[k] = arr[i];  k = i;
    }
    arr[k] = arr[0];
}

// 堆排序（建堆 + 主循环；交换用 tmp，勘误 B5）
void HeapSort(int arr[], int len){
    if(arr == NULL || len <= 1) return;
    for(int i = len/2; i > 0; i--) HeapAdjust(arr, i, len);
    while(len > 1){
        int tmp = arr[1]; arr[1] = arr[len]; arr[len] = tmp;
        HeapAdjust(arr, 1, --len);
    }
}

// 二路归并 Merge（<= 保稳定，两个收尾循环）
void Merge(SqList &L, SqList &T, int low, int mid, int high){
    int p = low, q = mid+1, k = low;
    while(p <= mid && q <= high){
        if(L.data[p] <= L.data[q]) T.data[k++] = L.data[p++];
        else T.data[k++] = L.data[q++];
    }
    while(p <= mid) T.data[k++] = L.data[p++];
    while(q <= high) T.data[k++] = L.data[q++];
    for(int i = low; i <= high; i++) L.data[i] = T.data[i];
}
void MergeSort(SqList &L, SqList &T, int low, int high){
    if(low < high){
        int mid = (low + high) / 2;
        MergeSort(L, T, low, mid);
        MergeSort(L, T, mid+1, high);
        Merge(L, T, low, mid, high);
    }
}

// 逆序对：归并加计数（真题 2020 第 2 题原文）
int merge(int A[], int temp[], int left, int mid, int right){
    for(int k=left;k<=right;k++) temp[k]=A[k];
    int i=left, j=mid+1, k=left, count=0;
    while(i<=mid && j<=right){
        if(temp[i]<=temp[j]) A[k++]=temp[i++];
        else{ count += mid-i+1;  A[k++]=temp[j++]; }
    }
    while(i<=mid) A[k++]=temp[i++];
    while(j<=right) A[k++]=temp[j++];
    return count;
}
