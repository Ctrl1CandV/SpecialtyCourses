## P3 判两点连通（约4分钟）

第一个算法，判两点连通：给定图里两个顶点 i 和 j，问 i 能不能到 j。代码 Pathitoj 是材料原文，九行。

走一遍。开头是终止：i 等于 j，说明走到了，返回 1。然后把自己的 visited 置 1，逐个邻居试：邻居 k 没访问过，就递归问 k 能不能到 j；任何一个邻居递归返回 1，这一路就返回 1。所有邻居都试完还没返回，说明从 i 出发到不了 j，返回 0。

【停顿】设问：这题的 visited 打了标记就再没清过，为什么可以不复位？想一下场景：从 i 出发把整片可达的区域都探了一遍，没探到 j；后来换一条路又走到这个区域里的某个顶点 x——x 已经被探过了，从 x 出发的所有路当时都没通到 j，现在再走一遍结果一样。所以标记留着不是错误，是剪枝：探过的区域不再重复探。

但这个写法有一个隐患必须说清：visited 是全局数组，这个函数一旦返回，标记全留着。同一个程序里调第二次 Pathitoj，visited 还是上一次的残留，直接出错。所以要么每次调用前手动清零，要么把它当一次性函数用——判一次就完事。后面会用路径题说明重复调用前为什么要复位。

拿个小例子把函数走一遍：图 4 个顶点，边 0-1、0-2、1-3、2-3，问 0 能不能到 3。调用 Pathitoj(G, 0, 3)：0 不等于 3，标记 0；邻居 1 没访问，递归进 1；1 标记自己，邻居 0 已访问跳过，邻居 3 没访问，递归进 3；3 等于 j，返回 1；一层层传回去，答案是 1。要是问 0 到 4，图里根本没有 4，所有递归走到头返回 0，答案是 0。整个过程没有撤销任何标记。

复杂度：每个顶点和每条边最多访问一次，时间 O(|V|+|E|)，递归栈空间 O(|V|)。

## P4 经过 k 的路径：两段可达与简单路径的区别（约4分钟）
第二个算法把“经过 k”拆成两段可达性判断：u 能到 k，k 能到 v。每段内部用 DFS 回溯，失败时清除当前顶点的 visited 标记；两段之间再把整张图的标记清零。
注意定义边界：这段材料代码允许两段搜索独立选路，因此表达的是经 k 的 walk/两段可达。如果题目明确要求整条简单路径不能重复顶点，清零后拼接并不够，需在一次 DFS 中同时维护 visited 和“是否到过 k”。考试先按题目对路径的定义选写法。

## P5 长度 k 的路径（约5分钟）

第三个算法，路径类第二种形态：判断无向图里是否存在一条长度恰好为 k 的路径。长度指边的条数。

思想是在 DFS 里多带一个参数 depth。数据结构基础阶段第7节写树递归、上一节写最长路径时都用过递归中还可以通过参数携带当前搜索的状态。这里 depth 记"从起点已经走了几条边"，每往下一层加 1，进函数先判 depth 等于 k——走到了，返回 true。标记、递归、失败复位，和上一题同一个骨架。

【停顿】设问：k 的合法范围是什么？看外壳第一行：k 小于 1 或 k 大于 G.vexnum 减 1，直接 false。下界好懂，长度至少是 1 条边。上界推一下：这题要求简单路径，顶点不重复，k 条边要经过 k+1 个不同顶点，图里一共只有 vexnum 个，所以 k 最大是 vexnum 减 1。写题时把这个不等式写在代码里，阅卷时它就是边界分的依据。

外壳还有一处要看：每个起点各试一遍，换起点之前内层循环把 visited 全部清 0。为什么？这次搜索可能从任意顶点出发，上一个起点留下的标记不能让下一个起点带着走。

最后说成功分支。这个版本的成功分支里也写了 visited[i] 等于 0 再返回 true，和上一题"成功不清"不一样。两种写法都对——成功了就不再继续搜索，清不清都不影响结果——但你自己的代码里要统一，不能一题一种。

复杂度：每个起点一次 DFS，最坏 O(|V|) 个起点，每次 O(|V|+|E|)，总时间 O(|V|乘(|V|+|E|))；空间 O(|V|)。

## P6 两种 visited 处理对比（约4分钟）

先按题意选择标记方式。只问 u 能否到 v 时，visited 在这一次搜索里保留；已经完整搜过的顶点无需重复。要输出或枚举路径时，沿递归路径标记，回溯离开结点前清除，其他分支才可以再经过它。
如果题目把“经过 k”定义成两段独立可达，第一段和第二段之间要清空 visited；若要求一条不重复顶点的 u-v 简单路径经过 k，就不能拆成两次独立搜索，应在同一次 DFS 里记录是否到过 k。
所以看到路径题先确认：题目问可达性、输出路径、还是两段独立可达；不要只凭“经过某点”四个字决定复不复位。

## P7 过程页：visited 复位的两段搜索（约3分钟）

【PPT动画·3击】
图上任务是从0到5，并经过3。第1击先搜0到3，经过0、1、3后成功；这些顶点留下 visited 标记。
第2击不清零就从3找5：邻点1被旧标记挡住，另一支经2又遇到0，搜索失败。
第3击把 visited 清零，从3重新找，得到3→1→4→5，两段可达，所以本例返回 true。这里演示的是题目允许把两段可达性分开判断的写法；若题目明确要求整条简单路径不重复顶点，不能这样清零拼接，应在一次 DFS 中记录是否经过3。

## P8 拓扑排序（约5分钟）

后半节转拓扑类。先讲拓扑排序本身：有向无环图里，把顶点排成一个序列，使每条弧都从排在前面的顶点指向排在后面的顶点。

代码 TopoLogicalSort 四步，对应屏幕上的四段。开头先判 G.kind 不等于 1 直接返回 false：kind 记的是图的类型，等于 1 表示有向图；不是有向图就没有拓扑序这个概念，直接拒绝。第一步求入度表：遍历每个顶点的边表，它指向谁，谁的入度加一——这一段就是数据结构基础阶段第9节的 Indegree，原样照抄。第二步，入度为 0 的全部入栈，栈是第3节的基本操作。第三步，循环出栈：弹出一个 u，写进 print 数组，count 加一。第四步，u 的每个后继入度减一，减到 0 的立刻入栈。

【停顿】设问：最后为什么 return count 等于 G.vexnum？反过来想：什么情况下 count 会不够？图里有环。环上的每个顶点都指着环内另一个顶点，它的入度永远减不到 0，永远进不了栈，永远输出不了。所以输出个数不足顶点数，等价于有环。这一句同时是拓扑排序的判环手段，记住。

还有一个判断题先押答案：栈换成队列，输出还是合法拓扑序吗？是。因为入栈和入队的都是"当前入度为 0、可以输出"的顶点，先输出哪一个都合法；所以栈版和队列版得到的序列可能不同，但都合法。这一句话是下一题"判唯一"的引子，先记住结论。

复杂度：求入度表过一遍所有边，主循环每个顶点出入栈一次、每条边被减一次，时间 O(|V|+|E|)，空间 O(|V|)。

## P9 过程页：拓扑排序五步推演（约3分钟）

【PPT动画·5击】
初始入度为[0,1,1,2,1]，栈中只有0。第1击弹出0并输出；1、2入度变0后依次入栈，栈顶是2。
第2击弹出2，结点3的入度从2降到1；第3击弹出1，3的入度降到0并入栈；第4击弹出3，4入栈；第5击弹出4，得到一种拓扑序0、2、1、3、4。
换用队列可能得到另一种合法序列。拓扑排序的核心是只在入度归零时入栈。

## P10 判给定序列是否拓扑序列（约5分钟）

本页的代码不负责排序，而是接收一条已有序列，逐项检验它能不能满足图上的先后关系。先回看 P9 的 DAG：0 指向1、2；1、2都指向3；3指向4。函数先拦住长度不等于顶点数和空图，再从边表重新计算入度。这样只读图，不会改调用方手里的数据。seen 用来辨认重复顶点。
拿合法序列 0、2、1、3、4 跑一遍。取0时入度是0，标记 seen 后把1、2的入度减到0；接着取2，它的入度已经归零，处理后3还剩一个前驱。然后取1，3的入度才归零；处理3使4归零，最后取4。每一步的判据都是“现在能否选这个点”，代码没有真的把栈或队列排序一遍。全部通过才返回 true。
再看两个失败位置。0、3、1、2、4 会在3处失败，因为前驱还没处理完；0、2、2、1、3 会在第二个2处被 seen 拦下。下标有效性也要先检查：若先读 indegree[u] 再判断 u 的范围，越界输入会访问数组之外。由于序列长度已核对、顶点都在范围内且不重复，循环走完就刚好覆盖全部顶点。建入度表和验证出边各扫描一次，时间 O(V+E)，额外空间 O(V)。

## P11 判拓扑序列是否唯一（约5分钟）
唯一拓扑序要求每一轮可选的入度0顶点都恰好一个。若同一轮有两个，它们之间不可能有先后路径约束，先取谁都合法，所以至少存在两种顺序。
代码先沿邻接表统计入度，把所有入度为0的顶点入队并计数。起始可选数不等于1时，已经可以判为 false：没有可选点表示图里有环或为空图；有多个则说明顺序不唯一。
回到 P9 的图，初始只有0入队，先处理0。此后1和2的入度都变成0，可选数是2，程序立即返回 false。对应的两种合法序列正是0、1、2、3、4和0、2、1、3、4。
再看一条链0→1→2：开始只有0；处理0后只有1归零；处理1后只有2归零；处理2后完成。每轮都只有一个选择，处理数也是3，函数返回 true。
循环里的 available 只数本轮新归零的点；队列在唯一性的前提下每轮至多保留一个待处理点。最后检查 processed==vexnum 是为了排除有环的图：队列可能提前空，但仍有顶点未处理。整张图的每条边最多减一次入度，因此时间 O(V+E)，辅助空间 O(V)。题目给的字段名和本课字段名不同，做题时以题目定义为准。

## P12 模板卡（约2分钟）

本节涉及两种常用写法：DFS 回溯和入度表处理拓扑问题。

第一张，模板 7，DFS 回溯。适用场景是路径类一切题目：经过 k、长度 k、输出一条路径、输出全部路径。骨架三行：标记当前点，递归没访问过的邻居，失败返回前复位。变体靠加参数：加 depth 是长度 k，加 path 数组是输出路径，拆成两次调用是经过 k。复杂度 O(|V|+|E|)，递归栈 O(|V|)。卡上标了出处：2025 年和 2024 年的路径大题。

第二张，模板 13，入度表法。适用场景是拓扑类一切题目：拓扑排序、判序列、判唯一、判环。骨架四步：求入度表，入度 0 入栈，出栈输出，后继入度减一。出处：2026 年判拓扑序列，2024 年拓扑排序填空。

写题时先判断属于哪类问题，再按对应算法补上 visited、深度或入度等状态。年份用于定位练习题；完整题目会在 C3 阶段训练。

跟练题一：拓扑排序。

```c
bool TopoLogicalSort(ALGraph G, int print[]){
    if(G.kind != 1) return false;               // 只有有向图才有拓扑序
    int indegree[MaxVertexNum] = {0};
    for(int i = 0; i < G.vexnum; i++)
        for(ArcNode *p = G.vertices[i].firstarc; p != NULL; p = p->nextarc) indegree[p->adjvex]++;
    SqStack S; InitStack(S);
    for(int i = 0; i < G.vexnum; i++) if(indegree[i] == 0) Push(S, i);
    int count = 0;
    while(!IsEmpty(S)){ int u; Pop(S, u); print[count++] = u;
        for(ArcNode *p = G.vertices[u].firstarc; p != NULL; p = p->nextarc)
            if(--indegree[p->adjvex] == 0) Push(S, p->adjvex); }
    return count == G.vexnum;                   // 输出不足说明有环
}
```

跟练题二：判给定序列是否拓扑序列。

```c
bool IsTopoSeq(ALGraph G, int seq[], int n){
    if(n != G.vexnum || G.vexnum == 0) return false;
    int indegree[MaxVertexNum] = {0};
    bool seen[MaxVertexNum] = {false};
    for(int i=0;i<G.vexnum;i++)
        for(ArcNode *p=G.vertices[i].firstarc;p!=NULL;p=p->nextarc) indegree[p->adjvex]++;
    for(int i=0;i<n;i++){
        int u=seq[i];
        if(u<0 || u>=G.vexnum || seen[u] || indegree[u]!=0) return false;
        seen[u]=true;
        for(ArcNode *p=G.vertices[u].firstarc;p!=NULL;p=p->nextarc) indegree[p->adjvex]--;
    }
    return true;
}
```

7算19：输出 u 到 v 的全部简单路径，回溯找到 v 也不停机，path 记录当前路径。

```c
void AllPath(ALGraph G, int u, int v, bool visited[], int path[], int d){
    visited[u] = true; path[d++] = u;            // u 记入当前路径
    if(u == v){ for(int i = 0; i < d; i++) printf("%d ", path[i]); printf("\n"); }
    for(ArcNode *p = G.vertices[u].firstarc; p != NULL; p = p->nextarc)
        if(!visited[p->adjvex]) AllPath(G, p->adjvex, v, visited, path, d);
    visited[u] = false;                          // 回溯：让别的路还能经过 u
}
```

```c
// 判两点连通：visited 全局、从不复位（一次性函数）
int visited[MaxVertexNum] = {0};
int Pathitoj(ALGraph G, int i, int j){
    if(i == j) return 1;
    visited[i] = 1;
    for(ArcNode *p = G.vertices[i].firstarc; p != NULL; p = p->nextarc){
        int k = p->adjvex;
        if(!visited[k] && Pathitoj(G, k, j)) return 1;
    }
    return 0;                       // 注意：这里不复位 visited
}

// 经过 k 的路径：DFS 回溯 + 两段调用（2025 年题，visited 声明按勘误 A6 修正）
bool checkPath(ALGraph G, int u, int v, bool visited[]){
    if(u == v) return true;
    visited[u] = true;
    for(ArcNode *p = G.vertices[u].firstarc; p != NULL; p = p->nextarc)
        if(!visited[p->adjvex] && checkPath(G, p->adjvex, v, visited)) return true;
    visited[u] = false;             // 回溯：失败返回前复位
    return false;
}
bool IsExistPathGoBy(ALGraph G, int u, int k, int v){
    if(G.vexnum == 0 || G.arcnum == 0) return false;
    bool visited[MaxVertexNum] = {false};
    if(!checkPath(G, u, k, visited)) return false;          // 第一段：u 到 k
    for(int i = 0; i < G.vexnum; i++) visited[i] = false;   // 两段之间复位
    return checkPath(G, k, v, visited);                     // 第二段：k 到 v
}

// 长度 k 的路径：DFS 带 depth 参数（2024 年题）
bool DFS(ALGraph& G, int i, int depth, int k, int visited[]){
    if(depth == k) return true;
    visited[i] = 1;
    for(ArcNode* e = G.vertices[i].firstarc; e != NULL; e = e->nextarc){ int v = e->adjvex;
        if(!visited[v] && DFS(G, v, depth + 1, k, visited)){ visited[i] = 0; return true; } }
    visited[i] = 0;                 // 回溯
    return false;
}
bool existsKSimplePath(ALGraph& G, int k){
    if(k < 1 || k > G.vexnum - 1) return false;
    int visited[MaxVertexNum];
    for(int i = 0; i < G.vexnum; i++){ for(int j = 0; j < G.vexnum; j++) visited[j] = 0;
        if(DFS(G, i, 0, k, visited)) return true; }
    return false;
}

// 拓扑排序：入度表加栈
bool TopoLogicalSort(ALGraph G, int print[]){
    if(G.kind != 1) return false;
    int indegree[MaxVertexNum] = {0};
    for(int i = 0; i < G.vexnum; i++)
        for(ArcNode *p = G.vertices[i].firstarc; p != NULL; p = p->nextarc) indegree[p->adjvex]++;
    SqStack S; InitStack(S);
    for(int i = 0; i < G.vexnum; i++) if(indegree[i] == 0) Push(S, i);
    int count = 0;
    while(!IsEmpty(S)){ int u; Pop(S, u); print[count++] = u;
        for(ArcNode *p = G.vertices[u].firstarc; p != NULL; p = p->nextarc)
            if(--indegree[p->adjvex] == 0) Push(S, p->adjvex); }
    return count == G.vexnum;
}

// 判给定序列是否拓扑序列（2026 年题）
bool IsTopoSeq(ALGraph G, int seq[], int n){
    if(n != G.vexnum || G.vexnum == 0) return false;
    int indegree[MaxVertexNum] = {0};
    bool seen[MaxVertexNum] = {false};
    for(int i=0;i<G.vexnum;i++)
        for(ArcNode *p=G.vertices[i].firstarc;p!=NULL;p=p->nextarc) indegree[p->adjvex]++;
    for(int i=0;i<n;i++){
        int u=seq[i];
        if(u<0 || u>=G.vexnum || seen[u] || indegree[u]!=0) return false;
        seen[u]=true;
        for(ArcNode *p=G.vertices[u].firstarc;p!=NULL;p=p->nextarc) indegree[p->adjvex]--;
    }
    return true;
}

// 判拓扑序列是否唯一：按勘误 B2 改写为邻接表版，逻辑与材料邻接矩阵版对应
bool uniquely(ALGraph G){
    int indegree[MaxVertexNum] = {0};
    for(int i=0;i<G.vexnum;i++)
        for(ArcNode *p=G.vertices[i].firstarc;p!=NULL;p=p->nextarc) indegree[p->adjvex]++;
    SqQueue Q; InitQueue(Q); int available=0, processed=0;
    for(int i=0;i<G.vexnum;i++) if(indegree[i]==0){ EnQueue(Q,i); available++; }
    if(available!=1) return false;
    while(!IsEmpty(Q)){
        int u; DeQueue(Q,u); processed++; available=0;
        for(ArcNode *p=G.vertices[u].firstarc;p!=NULL;p=p->nextarc)
            if(--indegree[p->adjvex]==0){ EnQueue(Q,p->adjvex); available++; }
        if(available>1) return false;
    }
    return processed==G.vexnum; // 有环时不能构成拓扑序
}
```
