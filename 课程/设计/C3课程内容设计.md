# C3 冲刺实战：课程内容设计

> 更新日期：2026-10-04。现行方案 **9 节，预计讲解 365 分钟（约 6.1 小时）**；学生暂停作答和课后训练另计。
>
> 本轮只更新课程设计和实施依据。C3 的 PPT、`deck.yaml`、逐页讲稿及训练答案包，等主讲完成当前课程录制后再制作。现有 C3 成品对应旧方案，不能当作本方案已完成。
>
> 配套阅读：`C3实施规格.md`、`课程设计总体框架.md` 第五节、`题库/README.md`。制作前对照实际录制的 C2-B-pro，并核题库原页和答案。

## 一、课程定位

C2-A 建立数据结构和基本操作，C2-B 教经典算法骨架、过程和常见应用，C3 训练学生面对完整考试要求时选法、补条件、写完答案并核对复杂度。C3 不再把 C2-B 已讲过或已布置的原题重新包装成“变式”。

C3 的新增内容包括：

- 把题干中的结构、合法输入、输出、边界与复杂度要求落实到代码；
- 在必要时补足 C2-B 只讲了算法骨架、没有完成原题输出或正确性核对的部分；
- 用尚未在 C2-B 课堂或作业出现的 408/802 代码题训练树形输出、邻接矩阵统计、值域处理和有序数据上的选法；
- 练习程序阅读、代码补全、状态追踪、答案检查和限时作答。

学生须已学完 C2-B 或具有等价基础：能写链表遍历和删除、树递归与层序、DFS/BFS、拓扑处理、二分及基本排序。A1 诊断哪些知识需回看，不从头讲一遍全部模板。

完成本阶段后，学生应能读全题目要求，写出完整代码和结果，说明关键步骤为何成立，处理边界，并按实际代码分析时间与空间复杂度。覆盖目标是 C2+C3 的整体能力，不是让 C3 重讲 17 道历年题。

## 二、题目分工与重复判定

每道 C3 主问题都要写明“这题新增教什么”和“C2-B 在课堂或作业做到哪一步”。仅换年份、数字、变量名、数据或叙述顺序，不构成新题或变式。

| 情况 | 课程标记与处理 |
| :--- | :--- |
| 课堂或作业已经出现同一题、同一要求、同一条件 | 归为重写/回忆练习；不叫变式，不重复逐行教学 |
| 题目算法相同，但任务、实质条件、结构、状态或输出发生变化，且要调整解法 | 才可叫变式；讲稿须写出改变点以及为什么要改算法或关键步骤 |
| 只为检查已学模板，换了输入数据 | 检索练习；需要时留作自查，不算新增教学 |
| 查不到合格的新题 | 不布置变式，不凑题；可留一道重写题或不留课后题 |
| C3 重新使用 C2-B 提及过的原题 | 只为补齐先前未覆盖的题意、输出或正确性要求；讲清增量，不得称为变式 |

每次选题要对照 C2-B-pro 的实际 PPT、讲稿和课后题三处；三者不一致时，以实际录制版本和学生实际拿到的课件为准，并把源文件同步后再生成新课件。作业不设“每节必须一跟练一变式”的数量指标。

## 四、逐节内容设计

### C3-A-01 冲刺诊断与答题书写（25 分钟）

**目标**：定位需要回看之处；把已会的题写成条件、思想、代码、结果和复杂度齐全的答案。

| 内容 | 预算 |
| :--- | :--- |
| C3 学习入口和考试代码任务 | 4 分钟 |
| 链表、树、图短诊断 | 8 分钟 |
| 一份不完整答案的修订 | 9 分钟 |
| 回看路线与个人补缺记录 | 4 分钟 |

短诊断可检查链表前驱更新、树递归参数、图访问状态。倒数第 k、判 BST、约瑟夫环等已在 C2-B 讲过的内容只用于诊断，不再讲解，也不列为变式。修订示例使用自编短题，不提前讲完后续主问题。学生先作答，再按错误类型定位 C2-B 的具体节次和标题。

**课后**：记录一个需回看的主题并重写诊断答案。原题重写标为回忆练习。

### C3-B-01 链表：循环表局部操作与恢复（45 分钟）

**主问题**：802 2023 循环链表部分区间逆置。

C2-B 已讲过循环单链表整体逆置。C3 不重讲整体逆置，而是用这道尚未在 C2-B 作为课堂题或作业题出现的原题，处理“只改一段”带来的定位和恢复要求。先核原题图、头结点、区间下标、m 与 n 的合法范围；材料中疑似 OCR 的符号未核实前不写成定论。

| 内容 | 预算 |
| :--- | :--- |
| 题目结构、区间和终态 | 5 分钟 |
| 找到区间前驱并保存后继 | 10 分钟 |
| 区间内部逆置 | 14 分钟 |
| 接回前后段并恢复循环 | 10 分钟 |
| 小例子、边界与复杂度 | 6 分钟 |

演示中标出不动前缀、待处理区间、后缀、头结点和尾结点。每次改链接前先存后继；处理完后同时验证“前驱接到新区间首”“新区间尾接回后缀”“尾结点仍回到头结点”。奇偶区间长度分别检查。不能拿 `p != NULL` 当循环链表终止条件。

**课后**：可以只留课堂答案的回忆重写，也可以不布置。只换一组 m、n 或结点值仍是检索练习；不得把同一题当变式。

### C3-B-02 树：表达式树转中缀表达式（40 分钟）

**主问题**：408-2017-41，将表达式树输出为能体现运算次序的中缀表达式。

C2-B 的树课讲递归遍历、建树、路径和 BST；本题新增的是按树的结构组织完整输出，并在正确位置添加括号。先说明中序输出为什么给出左右子表达式的相对次序，再讨论哪些子树必须加括号。根和操作数通常不需外层括号；中间运算结点要结合题目对运算符元数和表达式格式的定义处理。

原参考代码函数名写成 `preorder`，实际访问顺序是左—根—右；制作时改为表达其功能的名字。实施前核原题示例中的一元负号与结点左右孩子定义；不能把所有非根结点都当作二元运算符。若只要求等价表达式而未要求最少括号，可说明“多一层括号仍等价”，不要暗示这是最简输出。

讲解代码采用边遍历边输出，避免递归返回长字符串造成额外复制。按实际实现分析时间 O(n+L)（n 为结点数，L 为输出字符数），递归栈 O(h)；如选择字符串拼接，需另行分析复制成本。

| 内容 | 预算 |
| :--- | :--- |
| 题意、表达式树与中序次序 | 6 分钟 |
| 根、叶和内部运算结点 | 10 分钟 |
| 括号插入和一元运算符 | 12 分钟 |
| 完整输出代码与复杂度 | 8 分钟 |
| 反例自查 | 4 分钟 |

**课后**：同一表达式树换字符只算回忆练习。若另有作业，须改变运算符元数或输出约定并导致括号/遍历处理实质变化；否则不布置变式。

### C3-B-03 图：经过指定顶点的路径（45 分钟）

**主问题**：802 2025 “u 到 v 且经过 k”路径题，重点补齐题意解释、路径拼接和输出核查。

C2-B 已讲过两段 DFS、visited 回溯和它适用的条件。C3 不再从头讲 DFS，而是对照完整原题和 C2-B 的写法，确认答案究竟允许 walk、要求简单路径，还是只要求给出一条路径；再据此确定 visited 能否在两段之间清零，以及输出如何拼接。若题意要求简单路径，两段各自简单并不能保证拼接后仍简单；若输出两段，交界点 k 只能输出一次。无论哪种解释，都检查路径起点、终点、经过 k、每对相邻顶点有边、失败时输出 -1。

现有材料的路径定义和参考答案来源须与原题 PDF 对照。若题意不能确认，不把一种假设说成唯一标准答案；可把不同条件分开说明，或用条件明确的改编题教学。不能复制 C2-B 的两段 DFS 代码后只改顶点名。

| 内容 | 预算 |
| :--- | :--- |
| 原题条件和路径术语 | 7 分钟 |
| 两段搜索何时成立 | 10 分钟 |
| 简单路径与状态恢复 | 14 分钟 |
| 拼接输出、失败处理 | 9 分钟 |
| 反例与代码核查 | 5 分钟 |

**课后**：原题重写归入回忆练习，不叫变式。除非新题改变路径定义、输出目标或约束并迫使搜索状态发生改变，否则不布置变式。

### C3-B-04 图：邻接矩阵统计与筛选（40 分钟）

**主问题**：408-2023-41，输出有向图中出度大于入度的顶点并返回个数。

C2-B 已教邻接表遍历、拓扑、最短路和多源 BFS；本题换到邻接矩阵上的行列统计，不复讲这些算法。学生要把每一行的和对应到出度、每一列的和对应到入度，筛选顶点、输出顶点标识并返回计数。

题库参考代码存在字段引用不完整的问题（如应从 G 读取顶点数和矩阵）。实现前按题目结构定义修正，确认顶点表是字符还是字符串，输出格式与函数签名一致。遍历每个顶点的行和列，时间 O(V²)，额外空间 O(1)。如果边权或矩阵取值不止 0/1，题意须先说明矩阵表示的是边存在性还是权值，不能直接求和。

| 内容 | 预算 |
| :--- | :--- |
| 邻接矩阵和有向边方向 | 6 分钟 |
| 行和、列和与度数 | 12 分钟 |
| 筛选、输出和计数代码 | 12 分钟 |
| 边界及复杂度 | 6 分钟 |
| 小题自查 | 4 分钟 |

**课后**：在新的矩阵上重算仍是检索练习。改变图的存储方式、度数定义或输出条件且必须改变实现时，才可称变式；没有合格题就不布置。

### C3-B-05 程序阅读与代码补全（40 分钟）

以 2024—2026 802 阅读材料为主，具体题目和分值制作前再对原题页。C2-B 的算法课不等于程序阅读训练；这节新增完整上下文、状态跟踪、代码依赖、功能说明和复杂度核验。

| 内容 | 预算 |
| :--- | :--- |
| 函数签名、结构、初值和结果要求 | 4 分钟 |
| 挖空：变量状态与循环目标 | 12 分钟 |
| 片段排序：赋值依赖和后继保存 | 9 分钟 |
| 功能、输出与实际复杂度 | 11 分钟 |
| 自查方法 | 4 分钟 |

题源候选：2026 DFS 生成树和队列；2025 复杂度题；2024 在 p 前插入结点、递归功能说明。按原题选取，不把三年每类题都塞进 40 分钟。先呈现完整上下文，跟踪一个小输入，再作答。区分连续与嵌套循环、倍增与线性递增、递归调用总量与栈深度。功能说明要讲清处理对象、操作与结果，不只说“使用了递归”。

**课后**：可留一段未在课上出现的代码作技能检查；只替换变量名、数值或数据仍是同类练习，标注清楚，不凑变式。

### C3-B-06 408 专题一：值域与辅助信息（45 分钟）

**主问题**：408-2018-41 最小缺失正整数；408-2015-41 按绝对值去重的链表处理。

这两题都要求把题目值域落实到存储和边界判断，适合作为代码专题。C2-B 没有讲这两道原题，不与 C2-B-10 的 802 2020 逆序对计数混为一题。逆序对原题及归并计数已在 C2-B-10 讲过，C3 不把它作为新题或变式重复。

| 内容 | 预算 |
| :--- | :--- |
| 值域、数组大小和索引范围 | 5 分钟 |
| 最小缺失正整数：答案范围与标记 | 18 分钟 |
| 绝对值去重：保留、删除和前驱 | 16 分钟 |
| 初始化成本、边界与复杂度 | 6 分钟 |

最小缺失正整数先证明答案在 1..n+1，再决定如何标记 1..n。非正数、大于 n 的值和重复值不能索引标记数组。参考代码漏掉 num≤n 的上界检查，必须先修正。原地交换等 O(1) 空间方案可放选学，不在主课扩展。

绝对值去重统一字段名和键值类型，处理 INT_MIN 取绝对值溢出风险；按题意确认值域，明确辅助数组覆盖范围。删除连续重复结点时前驱不前进，释放被删结点；时间分析计入数组初始化。若原题只按考试常用范围限制，说明该假设；不擅自扩大后再声称原题复杂度。

**课后**：若题目仍是同一“找最小缺失正整数”或同一“绝对值去重”要求，换一组数据只算检索练习。只在新条件迫使调整索引、存储范围或删除策略时才列变式。

### C3-B-07 408/802 专题二：利用有序条件（45 分钟）

**主问题**：408-2020-41 三个升序数组的最小三元组距离；802 2021 双调序列最大值。

第一题新增多指针推进依据，不能暴力枚举三元组；第二题用 C2-B 的二分骨架，但要检查双调条件和边界。C2-B 已教普通二分和快排划分，不再重讲模板。C2-B-09 的实施记录将 2021 双调题留给 C3，选题前仍须核实际录课和作业，若后来已完整讲过则仅做检索练习或换题。

三数组题应按题面正负整数描述处理；题库转写的“均为正数”与给出的负数示例冲突，实施前核 PDF 并标明采用真题原文还是改编题。距离计算用宽类型避免相减或 abs 前溢出。修正参考答案中数组下标混用、函数返回类型不一致等问题。用最大值减最小值解释移动当前最小值指针，给出 O(n1+n2+n3) 时间、O(1) 额外空间。

双调题明确严格单峰等条件，检查峰值在端点、中点右邻访问越界等情况。允许平台或改变单调条件时，先给出旧判定失败的反例，再决定是否仍可二分；没有必要时不扩展到竞赛算法。

| 内容 | 预算 |
| :--- | :--- |
| 条件与暴力成本 | 4 分钟 |
| 三数组距离化简与指针移动 | 21 分钟 |
| 双调序列判定和边界 | 15 分钟 |
| 复杂度与小结 | 5 分钟 |

**课后**：新输入不构成变式。若改变序列条件并导致峰值判定或指针移动规则必须改变，才列迁移练习；否则只留回忆题或不布置。

### C3-C-01 限时训练与讲评（40 分钟）

学生先独立完成训练，之后看讲评。40 分钟只计教师讲解，不把学生暂停作答算入视频时长。

| 内容 | 预算 |
| :--- | :--- |
| 用时与完成情况 | 4 分钟 |
| 算法题关键决策与答案修订 | 20 分钟 |
| 程序阅读共性错误 | 10 分钟 |
| 新条件复测与个人补缺 | 6 分钟 |

配套练习建议算法 45—55 分钟、程序阅读 20—25 分钟，合计 65—80 分钟；这是课程训练安排，不是官方分题用时。教学配分和自查表要标注用途，不能冒充官方阅卷细则。

训练至少包括一道课堂和 C2-B 作业中未出现的实质新任务；只换输入数据不算。其余题可检验 C2-B 的基本模板，但标为检索题。题目选不出来时不强求“变式”，可用未见过的程序片段做阅读复测。训练需提供完整题目、答案、边界和复杂度；讲评集中在漏条件、状态错、输出不全和分析不匹配，不重讲全部模板。

2022 最小半径生成树仅作选学备料：定义、根的选择和图条件核实后再决定是否给答案，不占核心课时。

## 七、题源和实施前核对

802 原题核对 2020—2026 对应 PDF、`资料/笔记/代码总结.md`、`题库/导出` 和实际 C2-B 成品。408 候选核原题页、图、完整输出及答案。回忆版与正式原题须标明来源差异。

| 内容 | 已发现风险 | 制作要求 |
| :--- | :--- | :--- |
| 2025 经过 k 的路径 | 答案把搜索拆两段；路径定义、重复顶点、数组拼接与输出须核原题 | 先确认 walk/simple path 与输出，再写代码并用路径逐项验算 |

| 408-2023 邻接矩阵 | 参考代码字段引用不完整 | 修正 G 字段、顶点标识和输出格式，按矩阵定义算复杂度 |
| 408-2018 最小缺失正整数 | 参考代码漏掉 `num <= n`，可能越界 | 先判断值域，再访问标记数组；核数组大小 |

| 408-2020 三数组距离 | 转写正数限制与负数样例冲突；答案下标、类型有误 | 查原页并统一下标、类型、宽类型距离和返回值 |
