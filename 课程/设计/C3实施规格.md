# C3 冲刺课程实施规格

2026-10-27依据主讲“先补缺，再精讲代码题”的新要求完成本轮制作。课程为A系列2节、B系列7节，共229页、预计438分钟，内容见[C3课程内容设计](C3课程内容设计.md)，各课三件套见[C3入口](../课件/C3/README.md)。总时长没有硬上限，逐页估时与deck元数据必须一致；当前静态检查已完成，放映动画待录制前验收。

## 内容与题源

1. 先读本节设计、项目`课件制作SKILL.md`与`tools/CONTENT-SPEC.md`；核当前实际C1/C2 PPT和讲稿。
2. A系列新增模型需有实际缺口；B系列可重讲高价值原题，完整呈现读题到最终答案的推导。旧方案“不重复完整教学”的约束已由主讲本轮要求更新。
3. 题源优先本校802资料与今年六套卷。主讲已确认历史机构材料对应`试卷/2026机构押题/`，本机只有题解而缺原卷；B03、B07写成条件清楚的整理改编题并注明依据，不能补造原题文字、年份、图或评分。
4. Dijkstra、Floyd、Prim、KMP匹配及next/nextval构造代码不列入训练。对应手算考点保留。
5. 同题换数据仍是检索练习。新条件导致解法或关键步骤变化，才可标变式；不要求每课必须有变式。

## 必须讲透的细节

| 主题 | 核对内容 |
|---|---|
| 环入口 | 无环退出；相遇时走过的距离；复位到首数据结点；入口为首结点、单结点自环 |
| k分点 | 第几个结点、向上或向下取整；n小于k；起点与尾部不足整组的处理 |
| 数组辅助信息 | 标记范围、越界过滤、初始化成本；稳定压缩的读写下标；两端移动的排除依据 |
| 程序阅读 | 结构与初值、每个空的语法类型、先存后继、状态不变量、输出和次数 |
| 树递归 | 参数和返回值分别携带什么信息；空树及叶结点；路径复制成本及递归栈 |
| 图路径 | 可达搜索可全程标记；枚举简单路径需回溯；两段路径各自简单不保证拼接简单 |
| 图复杂度 | 常规DFS/BFS与枚举搜索区分；不得把枚举所有简单路径写成O(V+E) |
| 拓扑验证 | 序列合法编号、无重复、所有弧方向；新增自环与反向可达分别处理 |
| 区间删除 | 非递减允许重复；两个二分边界；整体移动后缀；长度与删除数同时更新 |
| 表达式树输出 | 操作数、单目、二元结点的区别；孩子位置；括号位置与运算顺序 |

## 单课交付

路径为`课程/课件/C3/<节次>/`，保留`deck.yaml`、`<节次>.pptx`、`<节次>-讲稿.md`。必要的配图源跟随课程；临时PDF、截图和编译程序放`_tmp/c3_revision/`。

学生页先问题、后方法与答案。每页代码原则上不超过10行；完整程序在讲稿代码附录保留。逐页讲稿解释关键原因、例子和学生动作；页码、标题、时间与deck逐一对应。使用项目固定机构开场介绍，底图和机构物料保持原样。

C3使用`课程/课件/C3/维护/render_c3.mjs`，通过Presentations技能的@oai/artifact-tool生成PPT并运行包结构、字体、原生表格与版面校验。命令为`node 课程/课件/C3/维护/render_c3.mjs C3-A-01 --publish`；不加`--publish`只生成临时候选。不要用旧`tools/check.js`覆盖新C3课件，也不得重建已录制C1/C2。静态渲染逐页检查后清理截图；PPT放映与逐条动画另作录制前检查，不混写完成状态。

## 代码与独立复核

代码与课件使用同一份实现或可核对片段。C或类C记法按C++17编译；不依赖STL替代学生需要掌握的核心算法。针对本题风险检查边界，必要时用穷举或随机对照验证，不用仅复述实现的测试冒充独立核验。

作者先自核，独立子进程再检查题意、关键状态、答案及复杂度。发现重大旧讲法问题，在新课明确纠正并在备课勘误处留痕；不悄悄重做已录制课件。独立复核记录与结果写入现有课程入口或维护记录，不为每次讨论另建报告。

押题卷与本课共用知识范围；题面、独立答案、逐题讲解分别保存。[三套2027押题卷](../../试卷/2027押题卷/README.md)已制作，共74题，每套150分；成卷与交叉核验结果保留在套卷目录，课程讲稿、试题与答案使用一致的定义。
