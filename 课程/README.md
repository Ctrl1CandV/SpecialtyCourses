## 当前依据

主讲已确认以现在手工修改后的课件为准，保留手工内容，不用旧deck、manifest或构建记录覆盖现有成品。本轮范围勘误只对与主讲新要求冲突的文字作局部更新。C2-B-pro所需的pages、HTML、PNG及manifest已从临时区恢复到各课目录，专用工具在`tools/c2b/`；重建前必须先对照当前成品同步源文件。

[C3设计](设计/C3课程内容设计.md)及[实施规格](设计/C3实施规格.md)保留九节、预计365分钟的旧基线。主讲提出先补重要算法模型、再训练如何做题的新方向，第一阶段须加入快慢指针找环入口、找k分点（中点、三分之一点等）；节次和时长待正式实施前调整。`历史参考/C3旧方案`中的八节旧课件未被删除，也不计入新方案完成状态。

冲刺合集采用当前课程与笔记选材；已补清固定间距/倍速指针、回溯搜索复杂度、二分/快排区别等表述。主讲已确认Dijkstra、Floyd、Prim及KMP匹配、next/nextval构造代码不考，不列为默写、补代码或算法设计训练；相应算法过程与手算题照常复习。旧备课资料中的相关实现仅供参考。

合集维护工具为`tools/build_sprint_collection.py`与`tools/verify_sprint_collection.py`；代码校验每次读取现行源稿，按C++17严格编译并进行随机与边界验算，PDF另做排版检查。

已录制课件、机构底图和机构页面不因目录整理重渲染或改写。一般检查器`tools/check.js`会重建目标PPT，不用于随意检查封存文件。
